Synthesis MapChapter 39

The Forms Ladder

Degree Matches Input Geometry

$$k\text{-form} \quad \leftrightarrow \quad k\text{ directed tangent inputs}.$$

Three Measurements

  • 1-form: reads a directed displacement.
  • 2-form: reads an oriented area element.
  • 3-form: reads an oriented volume element.

Two Operators

\(d\) raises degree by one. Integration asks for a chain whose dimension matches the form degree.

Global Spine

$$\int_{\partial C}\omega=\int_C d\omega,\qquad d^2=0.$$

1/2/3-formsdegree, derivative, and domain must match
Use this slide to rebuild the hierarchy. A 1-form tests a directed segment, a 2-form tests an oriented surface element, and a 3-form tests an oriented volume element. The exterior derivative moves up the ladder, while integration asks which geometric input is appropriate for the degree of the form.

1-Forms Test Directional Input

Local Test

$$\omega_p(v)=a\,dx_p(v)+b\,dy_p(v).$$

Exercise Family

Convert a geometric sentence into a covector, evaluate it on a vector, and check sign under orientation reversal.

Delta-Like Approximation

Concentrating the slices near a point makes the measurement local without turning the covector into a vector.

Diagnostic

If a coordinate change alters both coefficients and vector components but leaves \(\omega(v)\) fixed, the pairing has been understood.

basis-form and covector practicescalar reading survives representation changes
Return to the most concrete exercise family. A covector is not a small arrow; it is a linear test on an arrow. The delta-like picture is useful because it makes concentration visible: the same input vector receives its scalar reading from how it crosses the measurement slices.

Exterior DerivativeChapter 39

Exterior Derivative Converts Local Readings

Exterior Derivative As Upgrade

$$d:\Omega^k(M)\to\Omega^{k+1}(M).$$

Vector Calculus Translation

  • \(df\) is directional change.
  • \(d\omega\) is circulation density.
  • \(d\eta\) is source or flux density.
Structural Check

$$d^2=0.$$

Common Mistake

The derivative is not just a coordinate recipe; it records how lower-dimensional boundary measurements become higher-dimensional density measurements.

exterior derivative and vector-calculus identitieslocal readings become density tests
Make the exterior derivative feel like a boundary detector. It turns a function into a 1-form, a 1-form into a circulation 2-form, and a flux 2-form into a density 3-form. The compact identities d squared equals zero, curl grad equals zero, and div curl equals zero are the same structural statement.

Closed, Exact, CohomologyChapter 39

Closed Is Local; Exact May Be Global

Two Tests

closed: \(d\omega=0\),\qquad exact: \(\omega=d\eta\).

Local Test

Closedness is checked by differentiating the form. It sees local curl, source, or defect.

Global Test

Exactness asks for a potential. Holes in the domain can block that potential even when \(d\omega=0\).

Gauss-Bonnet Echo

The notebook records \(2\pi\chi\) totals for genus \(0,1,2,3\), tying curvature integrals to topology.

closed/exact forms and cohomologylocal equation, global obstruction
Separate the two tests. Closed means the exterior derivative has vanished locally. Exact means the form came from a lower-degree potential globally. The cohomology figure reminds students that topology can block the global potential even when every small patch looks harmless.
Cartan And CurvatureChapter 39

Moving Frames Turn Forms Into Curvature Probes

Cartan Structure Equations

$$d\theta^i+\omega^i{}_j\wedge\theta^j=0,$$

$$\Omega^i{}_j=d\omega^i{}_j+\omega^i{}_k\wedge\omega^k{}_j.$$

Exercise Family

Read off a coframe, compute connection forms, then identify the curvature 2-forms that measure non-flat frame return.

Schwarzschild-Style Tasks

The same pipeline applies when the frame is adapted to a metric with nontrivial radial and angular scale factors.

Diagnostic

If the frame changes but the curvature statement survives, the calculation is geometric rather than coordinate cosmetic.

moving frames and curvature formsconnection first, curvature defect second
Close the technical arc with Cartan's equations. A moving coframe records local measurement axes, connection forms record how the frame turns, and curvature forms record the defect that remains after differentiating the connection. The helix picture makes a frame field visible along a path.
