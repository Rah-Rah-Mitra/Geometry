Why Open Edges Need A Comparator

Closed holonomy is honest

A vector returns to the same tangent plane, so the rotation angle is directly meaningful.

The Field $F$ Supplies The Index

Two jobs for one field

$F$ gives the direction used in $\Phi(K)$ along the boundary and contributes a signed index if it has a singularity inside the polygon.

Index of a singularity inside P

$$I_F(P)=\frac{1}{2\pi}\Delta_{\partial P}\arg F$$

Why the index must be subtracted

Some turning belongs to the field itself. The proof subtracts $2\pi I_F(P)$ so that the remaining boundary ledger measures curvature, not reference-frame winding.

Local target

curvature inside $P$ $\quad$ minus $\quad$ field winding $\quad$ equals $\quad$ edge ledger

field with isolated singularitiesIndex Term
The nonsingular field F gives a reference direction on each edge, but it may have isolated singularities inside polygons. The index records how much F itself turns around a small loop. Subtracting two pi times that index prevents the edge ledger from charging curvature for the field's own winding.

The Polygon Identity: A Local Ledger

For one oriented polygon P

$$\operatorname{curv}(P)-2\pi I_F(P)=\sum_j \Phi(K_j)$$

Left side

The integral of Gaussian curvature over the polygon, corrected by the signed index contribution from $F$.

Right side

A sum of endpoint angle changes along boundary edges, each measured against the same reference field $F$.

What must be true next

To globalize, these edge terms must behave like a signed boundary operator: reverse the edge, reverse the sign.

local identityCurvature - Index = Edge Sum
The local identity is the engine of the proof. For each polygon, total curvature inside the polygon minus the index contribution equals the sum of Phi terms along its oriented boundary edges. This is a local accounting statement: curvature and index live in the region, while Phi lives on the boundary.

Interior Edges Cancel Before Topology Appears

Orientation reversal

$$\Phi(-K)=-\Phi(K)$$

Same geometric edge

Neighboring polygons inherit opposite orientations on their shared boundary edge.

Summing polygons

Every interior contribution appears in a pair. The proof loses all shared edges before it reads off Euler characteristic.

Closed Surface Mesh Ledger

Topology from the partition

$$\chi = V-E+F$$

Why closed matters

No exterior boundary remains after all interior edges cancel. A surface with boundary would keep an extra boundary term.

Notebook mesh checks

  • Sphere: $V=42$, $E=120$, $F=80$, so $\chi=2$.
  • Torus: $V=180$, $E=540$, $F=360$, so $\chi=0$.
  • Every displayed closed-mesh edge has incidence two.

Interpretation

The mesh is not approximating curvature here. It exposes the combinatorial condition that makes global cancellation legal.

closed partitionEuler Characteristic
The triangulated sphere and torus make the closed-surface hypothesis concrete. In a closed mesh every edge has exactly two incident faces, so there is no exterior boundary left over. The Euler characteristic is read from the partition by V minus E plus F, not by sampling curvature.

After Cancellation: Curvature Equals Total Index

Summed local identity on a closed surface

$$\int_M K\,dA = 2\pi\sum I_F$$

What the balance plot checks

The residual $\int K\,dA - 2\pi\sum I_F$ is zero across valid ledgers for genera $0,1,2,3$.

$g=0$$\chi=2$, index sum $2$
$g=1$$\chi=0$, index sum $0$
$g=2$$\chi=-2$, index sum $-2$

Common trap

The theorem counts signed index, not the number of singularities. A source-sink pair on a torus can sum to zero.

total curvature = 2 pi total indexBalance Check
Once all shared edge terms vanish, the equality reduces to total curvature equals two pi times the total index. The notebook check displays several genera: sphere, torus, genus two, and genus three. In each valid row the residual is zero, which is the computational shadow of the proof ledger.

Proof Dependencies And Failure Modes

Failure mode 1: Sign reversal

If $\Phi(-K)$ is not the negative of $\Phi(K)$, shared edges do not cancel.

Failure mode 2: Unsigned index

A source, sink, and saddle cannot be counted as identical. The index sum is signed.

Failure mode 3: Boundary forgotten

The closed-surface proof has no remaining exterior boundary. If the surface has boundary, a boundary term survives.

Intrinsic data

Parallel transport, angle comparison in tangent planes, and Gaussian curvature.

Temporary choices disappear

The fiducial field $U$ only helps define open-edge bookkeeping; it does not survive the global sum.

Why this is the fourth route

Earlier proofs spotlight turning, angular excess, or vector fields. This route makes holonomy do the accounting.

Instructor prompt

Ask students to identify exactly where the closed-surface assumption enters. The answer is not Poincare-Hopf first; it is the disappearance of every boundary edge in the summed local identity.
