Sets

Why sets?
  • The language of sets is an important part of modern mathematical discourse.
  • Sets are interesting mathematical objects.
  • For this course, they provide a topic on which we practise writing and understanding proofs.
Definition 4.1.1
  1. A set is an unordered collection of objects.
  2. These objects are called the members or elements of the set.
  3. Write x ∈ A for x is an element of A;
    x ∉ A for x is not an element of A.
  4. We may read x ∈ A also as "x is in A" or "A contains x (as an element)".
Warning 4.1.2. Some use "contains" for the subset relation, but we do not.

Specifying a Set by Listing Out All Its Elements

Definition 4.1.3 (roster notation)
  1. The set whose only elements are x₁, x₂, …, xₙ is denoted {x₁, x₂, …, xₙ}.
  2. The set whose only elements are x₁, x₂, x₃, … is denoted {x₁, x₂, x₃, …}.
Note 4.1.4
For all objects x₁, x₂, …, xₙ, z,
z ∈ {x₁, x₂, …, xₙ} ⟺ z appears in the list x₁, x₂, …, xₙ.
Example 4.1.5
  1. The only elements of A = {1, 5, 6, 3, 3, 3} are 1, 5, 6 and 3.
    So 6 ∈ A but 7 ∉ A.
  2. The only elements of B = {0, 2, 4, 6, 8, …} are the non-negative even integers.
    So 4 ∈ B but 5 ∉ B.
Question
What are the elements of {2, 3, …}?
All integers x ⩾ 2?

Specifying a Set by Describing Its Elements

Definition 4.1.6 (set-builder notation)
Let U be a set and P(x) be a predicate over U. Then the set of all elements x ∈ U such that P(x) is true is denoted
{x ∈ U : P(x)} This is read as "the set of all x in U such that P(x)".
Note 4.1.7
For all objects z,  z ∈ {x ∈ U : P(x)} ⟺ z ∈ U and P(z) is true.
Example 4.1.8
  1. The elements of C = {x ∈ ℤ⩾0 : x is even} are the non-negative even integers. So 6 ∈ C but 7 ∉ C.
  2. The elements of D = {x ∈ ℤ : x is a prime number} are the prime integers. So 7 ∈ D but 9 ∉ D.

Equality of Sets: Examples

Example 4.1.13
{1, 5, 6, 3, 3, 3} = {1, 5, 6, 3} = {1, 3, 5, 6}.
Slogan 4.1.14.  Order and repetition do not matter.
Example 4.1.15
{y² : y is an odd integer} = {x ∈ ℤ : x = y² for some odd integer y} = {1², 3², 5², …}.
Example 4.1.16
{x ∈ ℤ : x² = 1} = {1, −1}.
Proof
Take any z ∈ {x ∈ ℤ : x² = 1}. Then z ∈ ℤ and z² = 1. So
z² − 1 = (z − 1)(z + 1) = 0.
z − 1 = 0 or z + 1 = 0.
z = 1 or z = −1.
This means z ∈ {1, −1}.
Take any z ∈ {1, −1}. Then z = 1 or z = −1. In either case, z ∈ ℤ and z² = 1. So z ∈ {x ∈ ℤ : x² = 1}.∎

The Empty Set

Theorem 4.1.18
There exists a unique set with no element, i.e.,
  • there is a set with no element; and (existence)
  • for all sets A, B, if both A and B have no element, then A = B. (uniqueness)
Proof
▶ (existence)  The set {} has no element.
▶ (uniqueness)  Let A, B be sets with no element. Then vacuously,
∀z (z ∈ A ⇒ z ∈ B)  and  ∀z (z ∈ B ⇒ z ∈ A)
because the hypotheses in the implications are never true. So A = B.∎
Definition 4.1.19
The set with no element is called the empty set. It is denoted by ∅.

Inclusion of Sets

Definition 4.2.1
Let A, B be sets. Call A a subset of B, and write A ⊆ B, if
∀z (z ∈ A ⇒ z ∈ B).
Alternatively, we may say that B includes A, and write B ⊇ A.
Example 4.2.3 and Example 4.2.6
  1. {1, 5, 2} ⊊ {5, 2, 1, 44}  but  {1, 55, 2} ⊄ {2, 1, 4}.
  2. ℕ ⊆ ℤ ⊆ ℚ ⊆ ℝ ⊆ ℂ.  All these inclusions are proper.
Remark 4.2.4
  1. A ⊄ B ⟺ ∃z (z ∈ A and z ∉ B).
  2. A = B ⟺ A ⊆ B and B ⊆ A.
  3. A ⊆ A.
Definition 4.2.5
Call A a proper subset of B, write A ⊊ B, if A ⊆ B and A ≠ B.
Note 4.2.2. We avoid using the symbol ⊂ because it may have different meanings to different people.

Boolean Operations

Definition 4.3.1
(1)  The union of A and B:   A ∪ B = {x : x ∈ A or x ∈ B}
(2)  The intersection of A and B:   A ∩ B = {x : x ∈ A and x ∈ B}
(3)  The complement of B in A:   A \ B = {x : x ∈ A and x ∉ B}
Convention 4.3.2
When working in a context where U is a fixed universal set including all sets one considers.
Definition 4.3.3
The complement of B:  B̄ = Bᶜ = U \ B.

Proving Set Identities Using Truth Tables

One of De Morgan's Laws. Work in the universal set U. For all sets A, B,
A ∪ B̄ = Ā ∩ B̄
Proof #1
The rows in the following table list all the possibilities for an element x ∈ U:
x ∈ A x ∈ B x ∈ A ∪ B x ∈ A ∪ B̄ x ∈ Ā x ∈ B̄ x ∈ Ā ∩ B̄
TTTFFFF
TFTFFTF
FTTFTFF
FFFTTTT
Since the columns under "x ∈ A ∪ B̄" and "x ∈ Ā ∩ B̄" are the same, for any x ∈ U, x ∈ A ∪ B̄ ⟺ x ∈ Ā ∩ B̄. So A ∪ B̄ = Ā ∩ B̄.∎

Proving Set Identities Directly

One of De Morgan's Laws. Work in the universal set U. For all sets A, B,  A ∪ B̄ = Ā ∩ B̄.
Proof #2
Let z ∈ U. Then
z ∈ A ∪ B̄
⟺ z ∉ A ∪ B
by the definition of ̄· ;
⟺ ¬(z ∈ A) ∨ (z ∈ B)
by the definition of ∪;
⟺ (z ∉ A) ∧ (z ∉ B)
by De Morgan's Laws for propositions;
⟺ (z ∈ Ā) ∧ (z ∈ B̄)
by the definition of ̄· ;
⟺ z ∈ Ā ∩ B̄
by the definition of ∩.∎

Consternation extra material

"There is just one point where I have encountered a difficulty." — Russell (1902)
{x : x ∉ x} ?
Theorem 4.4.3 (Russell 1901)
There is no set R such that
∀x (x ∈ R ⟺ x ∉ x).   (∗)
Proof (by contradiction)
Suppose R is a set satisfying (∗). Applying (∗) to x = R gives
R ∈ R ⟺ R ∉ R.   (†)
▶ Case 1: assume R ∈ R. Then R ∉ R by the ⇒ part of (†). Contradiction.
▶ Case 2: assume R ∉ R. Then R ∈ R by the ⇐ part of (†). Contradiction.
In either case, we get a contradiction.∎
Morals
  • Some predicates do not correspond to any set.
  • The set of all sets, if it exists, needs extreme care.
Question 4.4.4. Can you write a proof that does not mention contradiction?

Summary

Let A, B be sets.
Definition 4.1.1(3).  Write x ∈ A for "x is an element of A".
Roster notation.  {x₁, x₂, …}
Set-builder notation.  {x ∈ U : P(x)} where P(x) is a predicate over a set U
Replacement notation.  {t(x) : x ∈ A} where t(x) is an object for each x ∈ A
Definition 4.1.12.  A = B ⟺ ∀z (z ∈ A ⟺ z ∈ B).
Slogan 4.1.14.  Order and repetition do not matter.
Definition 4.1.19.  The empty set ∅ is the unique set with no element.
Definition 4.2.12.  The power set 𝒫(A) of a set A is the set of all subsets of A.
Definition 4.2.1.  A ⊆ B ⟺ ∀z (z ∈ A ⇒ z ∈ B).
Definition 4.2.5.  A ⊊ B ⟺ A ⊆ B and A ≠ B.
Definitions 4.3.1 and 4.3.3
A ∪ B = {x : (x ∈ A) ∨ (x ∈ B)}
A ∩ B = {x : (x ∈ A) ∧ (x ∈ B)}
A \ B = {x : (x ∈ A) ∧ (x ∉ B)}
B̄ = {x ∈ U : x ∉ B}
