Word metrics

A Finite Generating Set Turns A Group Into A Metric Space

Definition Pattern

If \(S\) is a finite generating set of \(G\), the word length \(|g|_S\) is the shortest number of letters from \(S \cup S^{-1}\) needed to express \(g\).

$$d_S(g,h)=|g^{-1}h|_S$$

Metric Reading

The Cayley graph records one unit edge for every generator move. Distances count shortest edge paths.

Changing a finite alphabet changes local edges, not the coarse group. \(\mathbb{Z}^2\) running example
Stress that a word metric is a measuring device built from a finite alphabet of moves. The same group can receive different local graph structures from different generating sets. The teaching point is that finite changes can shorten many routes without changing the large-scale type.
Finite generating sets

The Identity Map Is Already A Quasi-Isometry

Proof Template

  • Each \(s \in S\) is a bounded word in \(T\).
  • Each \(t \in T\) is a bounded word in \(S\).
  • Word lengths compare by uniform constants.
$$A^{-1}d_S(g,h)-B \le d_T(g,h) \le A d_S(g,h)+B$$

Coarse maps

Before Quasi-Isometry: Bounded Scale Must Stay Bounded

Coarse Control

A map \(f:X\to Y\) is coarse Lipschitz if there are \(A,B\) such that

$$d_Y(fx,fx')\le A\,d_X(x,x')+B.$$

What It Forgets

Subdivision, finite decorations, and bounded jitter can be invisible at large scale.

What It Keeps

Unbounded growth of distances must still be seen as unbounded growth of distances.

Coarse maps are the vocabulary for ignoring bounded noise responsibly. constants matter
Pause on the difference between exact and coarse control. A coarse map does not promise to preserve each short distance exactly; it promises that bounded clusters do not explode into unbounded clusters. This is the right language once local subdivision or generator choices are declared irrelevant.
Distance envelopes

A Quasi-Isometric Embedding Has Upper And Lower Linear Control

Embedding Inequality

$$A^{-1}d_X(x,x')-B \le d_Y(fx,fx') \le A d_X(x,x')+B$$

Interpretation

  • Upper bound: no explosive stretching.
  • Lower bound: no large-scale collapse.
  • Additive \(B\): small distances may misbehave.
A quasi-isometric embedding need not cover the whole target. embedding first, equivalence next
Make the constants visible. The lower line prevents far apart points from collapsing, while the upper line prevents distances from expanding too quickly. The additive constant allows small-scale exceptions, so students should focus on the linear envelope rather than on exact equality.
Coarse surjectivity

A Quasi-Isometry Also Sees The Whole Target

Extra Requirement

For every \(y \in Y\), some \(x \in X\) satisfies \(d_Y(y,f(x)) \le C\).

Equivalent Picture

There is a coarse inverse \(g:Y\to X\) so that \(g\circ f\) and \(f\circ g\) move points only a bounded distance.

Trap

A line embedded in a plane has good intrinsic distance control, but it misses most of the target at unbounded distance.

Quasi-isometry is the equivalence relation, not just the embedding inequality. coarsely onto
An embedding becomes a quasi-isometry only after the target is covered up to bounded error. The visual language is a net: every point of the target lies near the image. This is why an axis in the plane can embed well but still fail to represent the whole plane coarsely.

Efficient paths after distortion

Quasi-Geodesics Are Paths That Waste Only Controlled Distance

Path Inequality

A parametrized path \(\gamma\) is quasi-geodesic when distances along the parameter and distances in the space are linearly comparable up to additive error.

$$A^{-1}|s-t|-B \le d(\gamma(s),\gamma(t)) \le A|s-t|+B$$

Why It Matters

In geometric group theory, routes often come from words, normal forms, or actions rather than from exact shortest paths.

The route may wiggle, but it cannot waste distance faster than linearly. coarse geodesic behavior
Introduce quasi-geodesics as efficient routes with tolerance. The blue route is exactly geodesic in the grid metric, while the teal route wastes bounded effort but still advances at a linear rate. This idea prepares students for later stability results without assuming such stability in every space.
Svarc-Milnor intuition

A Good Group Action Converts Geometry Into A Word Metric

Theorem Shape

If \(G\) acts properly, cocompactly, and by isometries on a proper geodesic space \(X\), then an orbit map \(g \mapsto g\cdot x_0\) is a quasi-isometry.

Intuition

A compact fundamental region is a ruler. Moving between nearby regions costs a bounded number of generators.

A geometric action lets the group inherit the large-scale geometry of the space. Svarc-Milnor
Give the theorem as a geometric compression principle. If a finitely generated group acts on a nice large-scale space with finite local complexity and compact quotient, then the orbit map records the space up to quasi-isometry. The tiling picture explains why generators become bounded moves.
Proof anatomy

Each Hypothesis Pays For One Coarse Feature

1Isometric action: generator moves have uniformly bounded displacement.
2Properness: only finitely many group elements can keep a compact set close to itself.
3Cocompactness: every point of \(X\) lies boundedly close to the orbit.
4Geodesic space: chains of bounded hops can follow long metric segments.
Svarc-Milnor is a dictionary between actions and word metrics. proof roadmap
Do not prove every technical clause on the slide; instead, show how each hypothesis pays for one part of the quasi-isometry. Compact quotient supplies coarse surjectivity, properness prevents infinitely many group elements from living in a bounded region, and the generating set gives Lipschitz control.
Subgroup distortion

Inclusions Can Preserve Algebra While Distorting Geometry

Two Metrics On \(H\)

  • Intrinsic word metric from a finite generating set of \(H\).
  • Restricted ambient metric inherited from \(G\).
$$H \hookrightarrow G \text{ is undistorted when it is a quasi-isometric embedding.}$$

Diagnostic

Look for elements that are long inside \(H\) but have unexpectedly short representatives in \(G\).

Distortion asks whether subgroup geometry agrees with ambient geometry. quasi-isometric embedding test
Distortion is where students learn that subgroup inclusion is not automatically a quasi-isometric embedding. The intrinsic metric counts the subgroup's own generators, while the ambient metric may offer shortcuts. Undistorted means these two measuring systems stay linearly comparable.
A standard distortion picture

Commutator Loops Can Create Short Ambient Representatives

Heisenberg Intuition

In the integer Heisenberg group, central powers can be built by commutator boxes.

$$[x^m,y^m]=z^{m^2}$$

Distortion Signal

The cyclic subgroup generated by the central element has intrinsic length like \(m^2\), while ambient representatives have length on the order of \(m\).

A shortcut family violates the lower bound required for quasi-isometric embedding. distortion example
Use the commutator square as an intuition pump, not as a new algebra course. In the integer Heisenberg group, central motion can be produced by loops whose side lengths are about the square root of the central exponent. That makes the ambient length much smaller than intrinsic cyclic length.
Quasi-isometry invariants

Invariants Turn Coarse Equivalence Into A Classification Tool

Growth Type

How fast balls grow, after allowing coarse rescaling of radius.

Ends

How many unbounded directions remain after removing a large finite region.

Hyperbolicity

Whether triangles are uniformly thin at large scale.

Amenability

Whether large finite regions can have small boundary compared with volume.

Some tests appear later in the course; this chapter supplies the equivalence relation they must respect. roadmap
Frame invariants as reusable tests. Once a property is known to survive quasi-isometry, it can distinguish groups that no finite change of generators could make equivalent. Some entries are developed in later chapters, so present this slide as a roadmap for the rest of the course.
What quasi-isometry deliberately forgets

Do Not Classify By Local Decoration

Not Reliable By Itself

  • Exact vertex degree in a chosen Cayley graph.
  • Finite spikes, leaves, or bounded decorations.
  • A preferred finite presentation.
  • Exact drawing angles or local embedding choices.

Reliable Question

Can every large-scale journey in one space be translated into the other with one set of constants?

Quasi-isometry remembers coarse navigation and forgets bounded ornament. common mistake
This slide prevents a common overreach. Quasi-isometry is powerful because it forgets local details on purpose. Degree, exact angles in a drawing, a preferred presentation, and finite decorations can all change while the large-scale geometry remains the same.

Prove The New Metric Is Still Coarsely Equivalent

Task

Let \(T=\{(\pm1,0),(0,\pm1),\pm(2,1)\}\). Find constants \(A,B\) comparing \(d_S\) and \(d_T\) on \(\mathbb{Z}^2\).

Hint

Every old generator is already in \(T\). Express the new generator \((2,1)\) as a bounded word in the old generators.

Expected Conclusion

The identity map is a quasi-isometry, but the best constants may improve in directions close to the new generator.

The exercise asks for inequalities first and a plot second. finite generator extension
Let this be a five minute closing task or a homework prompt. The generator vector two comma one gives a new shortcut direction, but because the generating set is still finite, students should expect coarse equivalence with different constants. Ask for inequalities, not just a picture.
