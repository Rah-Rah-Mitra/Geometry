Fundamental Groups Remember Loop Failure

Definition View

The fundamental group records based loop classes with multiplication by concatenation:

\( \pi_1(X,x_0) = \{\hbox{based loops}\}/\hbox{homotopy rel endpoints}. \)

Inspection Target
  • Where is the basepoint used?
  • Which loop changes by deformation only?
  • Which feature survives as a group element?
Use the basepoint as the anchor that turns loops into algebra. The diagram separates the moving curve from its endpoint-fixed class, then shows why concatenation becomes multiplication. Stress that the reference material supplies a reusable diagnostic, not a catalog of all possible spaces.

Lifted paths and deck translations

Covering Spaces Turn Loops Into Actions

Action View

A loop class acts on the fiber by lifting from a chosen sheet and reading the endpoint sheet.

\( [\gamma]\cdot \widetilde{x}_0 = \widetilde{\gamma}(1). \)

Why GGT Cares

  • Deck transformations are symmetries over the identity map.
  • Actions convert topology into orbit and stabilizer language.
  • The line-to-circle cover previews Cayley-graph unwrapping.

Inspection habit: find the fiber, lift the loop, then read the sheet change.

Explain the cover as a machine for unwrapping loops. A closed path downstairs can lift to a path whose endpoint has moved upstairs, and that shift is exactly the kind of group action geometric group theory likes to inspect. The integer labels are bookkeeping for deck translations.
Reference Tool 2
Group cohomology as bookkeeping

Group Cohomology Is A Quotient Ledger

Compact Formula

Cohomology keeps compatible cochains after ignoring pure rewrites:

\( H^n(G;M)=\ker(\delta:C^n\to C^{n+1})/\operatorname{im}(\delta:C^{n-1}\to C^n). \)

Common Misread

The quotient is not a loss of information. It removes coordinate choices so the surviving class records a stable obstruction.

Present cohomology as algebraic accounting. Cochains record candidate data, cocycles satisfy a compatibility equation, and coboundaries are changes of coordinates or harmless rewrites. The quotient keeps what cannot be removed, which is why cohomology is useful for extensions and obstruction language.

Use Case

\( s(g)s(h)=f(g,h)s(gh). \)

Reading The Picture

This slide gives a concrete reason cohomology belongs in a geometric group theory appendix. A chosen section of an extension may not preserve multiplication, and the visible triangular defect records that failure. Changing the section changes representatives, while the cohomology class preserves the obstruction.

Hyperbolic plane conventions

Hyperbolic Plane Models Require Conventions

Metric Warning

Euclidean closeness to the boundary does not mean hyperbolic closeness. The boundary is an infinite horizon.

\( d_{\mathbb{D}}(p,q)=\operatorname{arcosh}\!\left(1+\frac{2\lVert p-q\rVert^2}{(1-\lVert p\rVert^2)(1-\lVert q\rVert^2)}\right). \)

geodesic convention boundary at infinity distance sanity check
Slow down on model choice. The disk and half-plane are both valid windows into the same hyperbolic plane, but their Euclidean appearances can mislead students. Boundary points are infinitely far away in the metric, and geodesics are determined by model-specific rules.

Reference Tool 4
Programming tasks as computational laboratories

Programming Tasks Need A Proof-Aware Scaffold

question = "what should survive?"
model = build_finite_window(parameters)
prediction = state_invariant(model)
artifact = render(model)
check = verify(prediction, model)
save(artifact, check)
Boundary Of Evidence

A finite computation can suggest a stable pattern, expose a failure mode, or verify a local identity. It should not pretend to exhaust an infinite group.

Frame programming tasks as experiments with responsibilities. Before code, name the object and predicted invariant. During computation, keep the model small enough to inspect. Afterward, save an artifact and a check so the result remains teachable outside the live notebook.

Appendix Exit Checklist

Every reference tool should leave the room with a visible invariant, an explicit model convention, and a reproducible check.

Loop Tool Name the basepoint, the loop class, and the action or cover where it becomes visible.
Cohomology Tool Separate cocycle compatibility from coboundary rewrites before interpreting the class.
Hyperbolic Tool State the model and metric formula before reading geodesics from the drawing.
Programming Tool Pair every artifact with a prediction, a saved check, and a note about finite-window limits.
Close with an instructor checklist rather than another theorem. For any borrowed reference tool, students should identify the invariant, the model convention, the saved artifact, and the sanity check. That habit keeps the appendix active throughout the course instead of becoming background reading.
