Begin by positioning continuity as a way to control tests on the target space, not as a picture of a smooth graph. The important reversal is contravariant: an open set in the codomain becomes a diagnostic subset of the domain. This framing prepares every later example in the chapter, including restrictions, seam failures, space-filling limits, and metric extensions.
2.1 Open And Closed Sets

Neighborhoods And Open Sets Are Equivalent Languages

Goal: replace pointwise neighborhood axioms with setwise open-set axioms.
Definition 2.1
Topology By Open Sets
A topology on \(X\) is a nonempty collection of subsets closed under arbitrary unions and finite intersections, containing both \(X\) and \(\emptyset\).
  • A neighborhood of \(x\) only needs to contain an open set around \(x\).
  • In Euclidean space, open balls are the visible witnesses.
  • Infinite intersections can lose room: shrinking balls can collapse to one point.
Use this slide to rebuild the chapter's first equivalence. A neighborhood can be larger than the actual room around a point, but it must contain some open witness. Once open sets are adopted as primitive, the topology is easier to manipulate because unions and finite intersections are global rules rather than point-by-point bookkeeping.
Subspace Tests

Subspaces Change What Counts As Room

Artifact: ../figures/open-closed-frontier.png
Subspace Topology
For \(Y\subseteq X\), a set \(U\subseteq Y\) is open in \(Y\) when \(U=O\cap Y\) for some open \(O\subseteq X\).
Discrete Extremum
If every subset is open, every point can be isolated by a legal open test. Integer lattice points inherit this behavior as a subspace of Euclidean space.
Notebook check: the right component of \(X=\{x\le -1\}\cup\{x\ge 1\}\) is both open and closed in the subspace.

The ambient gap is not part of the subspace, so a whole component can be open and closed at once.

Emphasize that subspace topology changes which points are allowed to test nearby behavior. The same drawn component may look like it has a boundary in the plane, yet inside the subspace the missing middle gap is unavailable. That is why the notebook check records the right component as both open and closed in the induced topology.
Limit-Point Criterion

Closed Means All Forced Nearby Points Are Included

Theorem 2.2 and closure scaffold
Theorem 2.2
Closed-Set Test
A subset is closed exactly when it contains every limit point that the topology forces.
Proof Scaffold
  1. If the complement is open, outside points have neighborhoods missing \(A\).
  2. If every outside point has such a neighborhood, the complement is open.

This is the first bridge from local neighborhoods to global closure operations.

Treat closedness as a promise about forced points. The set of points 1 over n illustrates the distinction between belonging to a set and being forced by nearby samples. The theorem says that a closed set has already accepted all such forced points, while a nonclosed set can be detected by a limit point left outside.

Bases

A Smaller Test Kit Can Generate The Whole Topology

Theorem 2.5
Base
A collection \(\mathcal{B}\) of open sets is a base when every open set is a union of members of \(\mathcal{B}\).
Theorem 2.5
If finite intersections stay in \(\mathcal{B}\) and \(\bigcup\mathcal{B}=X\), then all unions of basic opens form a topology.
  • Open intervals form a base for the usual real line.
  • Rational-endpoint intervals already suffice.
  • Continuity can be checked on a target base.
Present a base as a smaller test kit. Instead of checking every possible open set directly, one verifies that basic opens refine neighborhoods and behave well under finite intersections. This is the practical entry point for the continuity theorem, because target bases let us test fewer inverse images without changing the topology.
Theorem 2.6

Continuity Is An Inverse-Image Test

Artifact: ../figures/preimage-continuity-test.png
Open-Set Criterion
\(f:X\to Y\) is continuous if and only if \(f^{-1}(O)\) is open in \(X\) for every open \(O\subseteq Y\).
Exact check: for \(f(x)=x^2\), the target band \((1/4,9/4)\) pulls back to \((-3/2,-1/2)\cup(1/2,3/2)\).
Failure mode: the jump map has an open target band whose preimage includes a boundary point, so the preimage is not open.

A single target open set with a non-open preimage disproves continuity.

Focus attention on the direction of inverse images. The target band is drawn in the codomain, but the answer to continuity lives in the domain. The square map creates two open intervals, while the jump map traps an endpoint. That endpoint is the whole obstruction, and it is enough to reject continuity.
Theorem 2.9

Equivalent Tests Form A Cycle Of Proof Obligations

Artifact: ../figures/concept-dependency-map.png
Equivalent Criteria
Continuity, base-open preimages, closure image behavior, closed preimages, and the inverse-image open-set test are interchangeable.
  1. Start with open preimages.
  2. Reduce to a base in the target.
  3. Translate neighborhoods into closure containment.
  4. Switch to closed sets by complements.
Graph check: the theorem cycle has 5 nodes and is strongly connected in the notebook artifact.
The implication graph is a theorem map, not a dependency graph for code alone. Its value is that it lets an instructor choose the most convenient continuity test for the situation. Base tests are efficient, closed-set tests are often simpler in metric spaces, and closure tests explain why limit behavior is preserved.
Theorems 2.7 And 2.8

Composition And Restriction Are Preimage Bookkeeping

Maps stay maps when tests are pulled back in stages.
Composition
For \(X\xrightarrow{f}Y\xrightarrow{g}Z\), an open \(O\subseteq Z\) satisfies \((g\circ f)^{-1}(O)=f^{-1}(g^{-1}(O))\).
Restriction
If \(A\subseteq X\), then \((f|_A)^{-1}(O)=A\cap f^{-1}(O)\), which is open in the subspace \(A\).

Both results are structural: once preimages preserve open tests, the algebra of inverse images does the work.

Composition and restriction are bookkeeping, but they are important bookkeeping. For composition, the target open set is pulled back through g and then through f. For restriction, the same preimage is simply intersected with the subspace. Both arguments teach students to trust inverse images as the algebraic engine behind continuous maps.
Homeomorphism Warning

A Continuous Bijection Need Not Have Continuous Inverse

Artifact: ../figures/circle-seam-preimage.png
Seam Test
The map \(t\mapsto e^{2\pi i t}\) from \([0,1)\) to the unit circle is continuous and bijective, but the inverse is discontinuous at the seam.
Check: circle distances to the seam decrease toward zero, while inverse parameters after the first sample stay above \(0.85\).
Quotient Intuition
The problem disappears only after the two interval ends are identified before mapping to the circle.
The circle example separates continuous bijection from homeomorphism. The forward map passes the base-open test, including arcs crossing the seam, because the subspace topology on the interval makes the split preimage open. The inverse fails because points approaching the seam on the circle can correspond to parameters approaching one, while the seam itself is assigned parameter zero.
Homeomorphism Model

Stereographic Projection Removes One Point From The Sphere

Original inline SVG diagram
Homeomorphism
A homeomorphism is a bijection whose forward and inverse maps are continuous. It preserves exactly the open-set structure.
Stereographic Projection
Removing one point \(p\) from \(S^n\) leaves a space homeomorphic to \(\mathbb{R}^n\).

The line from \(p\) through \(x\) meets the plane once; reversing the line gives the inverse.

Stereographic projection gives the positive model after the circle warning. Here the geometry supplies both directions: project from the missing pole to the plane, and recover a point of the sphere by reversing the same line. The proof is still topological, because open target sets pull back through the family of half-lines to subspace-open sets.
Disc Lemmas

Boundary Homeomorphisms Extend Across A Disc

Lemmas 2.10 and 2.11
Lemma 2.10
Any homeomorphism of a disc boundary to itself extends to a homeomorphism of the entire disc.
Conical Extension
Send each ray from the center to the ray prescribed by the boundary map, keeping the radial coordinate fixed.
Lemma 2.11
If two discs meet along boundary arcs, their union is again a disc.
These disc lemmas are included because continuity becomes usable in surgery arguments. A boundary map can be pushed inward along radial segments, which is a controlled homeomorphism of the full disc. The second lemma uses that extension idea twice to replace two discs sharing an arc by one standard disc.

2.4 Metric Separation

Distances To Closed Sets Build Continuous Separators

Artifact: ../figures/metric-separation-extension.png
Lemma 2.13
For a subset \(A\) of a metric space, the function \(x\mapsto d(x,A)\) is continuous.
Lemma 2.14 Separator
\[ s(x)=\frac{d(x,B)-d(x,A)}{d(x,A)+d(x,B)} \]
Checks: separator error is \(0\) on both closed sets, adjacent distance Lipschitz test passes, and the closed-set gap is \(1.4\).
Distances to closed sets are continuous numerical sensors. Once two closed sets are disjoint, the sum of their distances cannot vanish, so the normalized difference gives a separator. This slide should connect the geometric picture to the algebraic formula, because that formula is the engine used repeatedly inside the Tietze proof.
Theorem 2.15

Tietze Extension: Correct The Error By A Uniform Series

Final roadmap and checks
Tietze Extension Theorem
A real-valued continuous function on a closed subset of a metric space extends continuously over the whole metric space.
  1. First handle bounded data \(|f|\le M\) on the closed subset \(C\).
  2. Use separators to build \(g_1,g_2,\ldots\) that shrink the remaining error.
  3. The majorant \(\sum 2^{n-1}M/3^n=M\) gives uniform convergence.
  4. For unbounded data, compose with a homeomorphism from \(\mathbb{R}\) to \((-1,1)\), extend, then compose back.
Notebook checks: Tietze majorant sum is exactly \(1\), and the explicit one-dimensional extension agrees with closed data with max error \(0\).
End by turning Tietze into an algorithmic proof roadmap. The construction does not guess the extension at once. It repeatedly separates two closed error sets, adds a bounded correction, and makes the remaining error smaller by a fixed factor. Uniform convergence then makes the infinite correction a continuous function on the whole space.
