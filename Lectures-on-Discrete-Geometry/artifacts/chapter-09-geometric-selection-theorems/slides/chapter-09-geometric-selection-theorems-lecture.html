From One Point to Many Simplices

Counting simplices

An $n$-point set in $\mathbb{R}^d$ spans $\binom{n}{d+1}$ simplices.

The pigeonhole intuition

So many simplices over a bounded region must pile up somewhere.

Setup

$S \subset \mathbb{R}^d,\ |S|=n,\quad \#\text{simplices}=\binom{n}{d+1}$

Goal

Find $x$ with $x \in \sigma$ for a positive fraction of simplices $\sigma$.

Printed pp. 207-230From One Point to Many Simplices
A finite set of n points in d dimensions spans roughly n to the power d plus one simplices. The first selection lemma promises one location pierced by a constant fraction of them. We set up the counting that makes such a universal heavily covered point believable.

The First Selection Lemma

Theorem (First Selection)

$\exists\, x:\ \#\{\sigma : x \in \sigma\} \ge c_d \binom{n}{d+1}$

Reading

Some point pierces at least a $c_d$-fraction of all spanned simplices.

Constant

$c_d>0$ depends only on $d$, not on $n$.

Planar case

$c_2 = \tfrac{1}{27}$ is achievable for triangles.

Printed pp. 207-230The First Selection Lemma
The first selection lemma is the chapter's cornerstone. For every dimension there is a positive constant so that some point lies inside at least that fraction of all simplices spanned by the set. The constant depends only on dimension, never on the number of points.

Proof Idea via Centerpoints

Centerpoint

A point $p$ so every halfplane through $p$ holds $\ge \tfrac{n}{d+1}$ points.

Radon / Tverberg

Partitions force many simplices to wrap the centerpoint.

Printed pp. 207-230Proof Idea via Centerpoints
The planar proof routes through the centerpoint theorem. A centerpoint sits behind a constant fraction of points across every direction, and a Radon or Tverberg style partition then certifies that many spanned triangles must wrap around it, giving the desired deep point.

Order Types and Same-Type

Order type

Record only orientation signs of every $(d{+}1)$-tuple.

Same type

Two configurations agree on all those signs.

Orientation

$\operatorname{sgn}\det\!\begin{pmatrix}1&p_0\\\vdots&\vdots\\1&p_d\end{pmatrix}$

Why

Geometry becomes finite, checkable combinatorial data.

Printed pp. 207-230Order Types and Same-Type
To control configurations combinatorially we record only orientation signs, the order type. Two tuples have the same type when corresponding simplices share orientations. This discrete fingerprint lets us argue about geometry through finite, checkable data rather than exact coordinates.

The Same-Type Lemma

Theorem (Same-Type)

$\exists\, Y_i \subset X_i,\ |Y_i| \ge \beta|X_i|$

Transversals

Every transversal of the $Y_i$ has one fixed order type.

Positive fraction

The homogeneous subsets keep a constant share $\beta>0$.

Role

Supplies the regularity behind the second selection lemma.

Printed pp. 207-230The Same-Type Lemma
The same-type lemma says any large point set hides large subsets, one per color class, so that every transversal picks the same order type. Positive fractions survive, so the structure is not rare. This regularity is the engine behind the second selection lemma.

The Second Selection Lemma

Theorem (Second Selection)

$|\mathcal{F}| \ge \alpha\binom{n}{d+1}\ \Rightarrow\ \exists\, x \in c\,\alpha^{s}|\mathcal{F}|\ \text{simplices}$

Upgrade

Only a dense subfamily $\mathcal{F}$ of simplices is needed.

Printed pp. 207-230The Second Selection Lemma
The second selection lemma upgrades the first. Take only a dense family of simplices, an alpha fraction of all of them, and still some point is pierced by a positive fraction of that family. The covering bound degrades polynomially in alpha but never vanishes.

Hypergraph Regularity

Simplices as edges

$\mathcal{F}$ is a $(d{+}1)$-uniform hypergraph on $S$.

Decomposition

Split into dense homogeneous blocks of one order type.

Mechanism

$\mathcal{F} \rightsquigarrow \{B_1,\dots,B_m\},\ \ B_j\ \text{same-type}$

Payoff

A point from one block pierces a guaranteed share of $\mathcal{F}$.

Printed pp. 207-230Hypergraph Regularity
The proof packages simplices as a hypergraph and applies a geometric regularity decomposition. The same-type lemma supplies dense homogeneous blocks where every simplex behaves alike, so a single point inherited from one block pierces a guaranteed share of the dense family.

Positive-Fraction Selection

Positive-Fraction Tverberg

$\exists\, Z_1,\dots,Z_r,\ |Z_i|\ge\gamma n,\ \bigcap \operatorname{conv}(\text{transversals}) \neq \varnothing$

Bundles

Linearly many blocks share one common piercing point.

Robustness

Containment survives small perturbations of the points.

Strength

Not one deep point but a structured family of them.

Printed pp. 207-230Positive-Fraction Selection
Positive-fraction Tverberg sharpens the picture. Inside any large set there are linearly many disjoint blocks whose every transversal simplex contains one common point. We thus get not just one deep point but a robust, perturbation-stable bundle of containments to exploit.

Application to $k$-Sets

$k$-sets

Subsets of size $k$ cut off by a hyperplane.

Strategy

Many halving structures yield a heavily covered point.

Bound (plane)

$\#\,k\text{-sets} = O\!\big(n\,k^{1/3}\big)$

Link

Second selection turns abundance into a counting contradiction.

Printed pp. 207-230Application to k-Sets
Selection lemmas feed the k-set problem. Bounding how many ways a hyperplane can split n points into a fixed size part uses the second selection lemma to translate many halving structures into a heavily covered point, then counts the contradiction it forces.

The chain

  • Second selection: survives sparsity.
  • Positive fraction: robust bundles.
