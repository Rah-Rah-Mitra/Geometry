Lecture Question

From Acceleration To Normal-Plane Data

Unit Speed Input

The tangent field \(T=\gamma'\) has \(|T|=1\), so \(T'\) is always normal:

\(\langle T',T\rangle=\frac{1}{2}\frac{d}{ds}\langle T,T\rangle=0.\)

The Problem

The vector \(T'(s)\) belongs to \(T(s)^\perp\), but the normal plane changes with \(s\). Curvature data needs a fixed coordinate space.

The Chapter's Move

Build a twist-free identification \(T(a)^\perp \to T(s)^\perp\), then pull the bending vector back to \(T(a)^\perp\).

Input: unit speed curve in \(R^n\)Output: normal-plane curvature signal
Frame the whole lecture as a data compression problem. For a unit speed curve, the tangent already records speed, while its derivative points normally and records bending. The difficulty is that the normal plane moves with the curve, so a curvature signal cannot be compared at two parameter values until the normal planes have been identified.
Definitions 4.1-4.2

Normal Fields And Parallelness

Normal Field

A field \(Z(s)\) along \(\gamma\) is normal when \(\langle Z,T\rangle=0\). Its derivative splits into tangent and normal parts:

\(\displaystyle Z'=\lambda T+W,\qquad W(s)\in T(s)^\perp.\)

Tangent Coefficient

Differentiating \(\langle Z,T\rangle=0\) gives

\(\displaystyle \lambda=\langle Z',T\rangle=-\langle Z,T'\rangle.\)

Parallel Normal Field

Parallel means the normal-plane part vanishes: \(Z'=\lambda T\). The field changes only because the normal plane itself moves.

Diagnostic: no normal-plane derivativeMisread to avoid: constant vector field
Spend time on the derivative split. A normal field can change length, can rotate inside the normal plane, or can merely slide because the tangent direction changes. Parallel normal fields are the third behavior only: their derivative has no normal-plane component, so they avoid adding artificial twist to the curve.
Theorem 4.3 And Definition 4.4

Parallel Transport Is An Orthogonal Map

Initial Value Theorem

For every \(W\in T(a)^\perp\), there is a unique parallel normal field \(Z\) with \(Z(a)=W\).

\(\displaystyle Z'=\langle Z,T\rangle T'-\langle Z,T'\rangle T,\qquad Z(a)=W.\)

Metric Consequence

If \(Z\) and \(Y\) are parallel, then \(\langle Z,Y\rangle\) is constant. Transported bases remain orthonormal.

Parallel Transport

\(P(x):T(a)^\perp\to T(x)^\perp\) is the orientation-preserving orthogonal map obtained by solving these parallel fields.

Preserved quantities: lengths, angles, orientationNotebook check: Gram matrix stays identity
Present the existence theorem as an initial value problem rather than as a mystical transport rule. Choose one normal vector at the initial point, solve the linear ODE, and get a unique normal field. Applying the same construction to a basis preserves all inner products, so the normal planes are identified by an orthogonal map.
Definition 4.5

Parallel Curves: Offset Without Twisting

Parallel Offset

If \(Z\) is a parallel normal field and \(\widetilde{\gamma}=\gamma+Z\) is regular, then \(\widetilde{\gamma}\) is a parallel curve of \(\gamma\).

Small Radius Guardrail

For \(|Z|=\varepsilon\), a sufficient local check is

\(\displaystyle \varepsilon \max_s \left|\frac{dT}{ds}(s)\right| < 1.\)

Visual Meaning

A cross-section in the initial normal plane sweeps along the curve without spinning relative to the transport rule.

Transport is useful because it builds nearby curvesFailure mode: radius too large near high curvature
Use the offset curve as the geometric payoff of parallel transport. If a parallel normal field has small enough constant length, adding it to the curve produces a nearby curve with no extra spin around the tangent. The displayed inequality is a practical guardrail: the offset radius must be smaller than the local radius of curvature.
Theorem 4.6

Hasimoto Curvature

Definition By Transport

There is a unique \(\Psi(s)\in T(a)^\perp\) such that

\(\displaystyle P(s)\Psi(s)=-\frac{dT}{ds}(s).\)

Why It Is Useful

\(\Psi\) is a single curve in one fixed vector space. It records bending without a moving coordinate plane.

Inspection Target

Plot the normal-plane trace and ask which features are intrinsic, and which only come from the initial basis choice.

Moving vector field becomes fixed-plane signalNotation: \(\Psi\) before coordinates, \(\kappa\) after coordinates
Now pull the acceleration back to the initial normal plane. The tangent derivative is a vector in the moving normal plane, and parallel transport lets us encode it as a single curve Psi in the fixed normal space at the starting point. The minus sign is convention; the conceptual move is the fixed-plane encoding.
Definition 4.8 And Theorem 4.9

Curvature Function And Gauge

Choose A Positive Basis

For an oriented orthonormal basis \(W_1,\ldots,W_{n-1}\) of \(T(a)^\perp\), write

\(\displaystyle \Psi=\kappa_1W_1+\cdots+\kappa_{n-1}W_{n-1}.\)

The Coordinate Signal

The function \(\kappa:[a,b]\to R^{n-1}\) is the curvature function of the curve.

Gauge Freedom

A second positive basis rotates the whole signal by one fixed \(A\in SO(n-1)\):

\(\displaystyle \widetilde{\kappa}=A\kappa.\)
Plane curves: no gauge ambiguitySpace curves: curvature is vector-valued
Once the initial normal plane has an oriented orthonormal basis, Psi becomes a coordinate vector kappa. This is the space-curve analogue of signed curvature for plane curves. The important caveat is gauge freedom: a different positive basis rotates all coordinates by one fixed special orthogonal matrix.
Theorems 4.7 And 4.10

Reconstruction ODE

Frame Equations

\(\displaystyle Z_j'=\kappa_jT,\qquad T'=-\sum_{j=1}^{n-1}\kappa_j Z_j,\qquad \gamma'=T.\)

Initial Data

Choose a point \(p\), a unit tangent \(S\), and a positive orthonormal normal basis \(W_1,\ldots,W_{n-1}\).

Conservation Check

The coupled ODE preserves \(\langle T,T\rangle=1\), \(\langle T,Z_j\rangle=0\), and \(\langle Z_i,Z_j\rangle=\delta_{ij}\).

Curvature data determines the curveRigid motion is the only remaining freedom
This slide is the constructive theorem. Given kappa, an initial point, and an initial tangent, solve the frame equations and then integrate the tangent. Orthogonality is not an extra assumption after the solve; it is preserved by the skew-coupled system, which is why the reconstructed curve stays unit speed.
Section 4.3

Calculus In Normal Coordinates

Normal Matrix

Let \(N(s)\) be the \(n\times(n-1)\) matrix with transported normal columns \(Z_1,\ldots,Z_{n-1}\). A normal field becomes \(Y=Ny\).

Derivative Rule

\(\displaystyle Y'=\langle \kappa,y\rangle T+Ny'.\)

The first term is the tangential part forced by curvature; the second term is the actual coordinate change of the normal field.

Tangent Derivatives

\(\displaystyle T'=-N\kappa,\quad T''=-|\kappa|^2T-N\kappa'.\)
Normal data calculusUsed immediately for elastic curve equations
Explain why the curvature function is useful beyond reconstruction. Every normal field can be written in the transported basis as N y. Differentiating separates a tangential term, controlled by the inner product of kappa and y, from the normal derivative N y prime. This turns moving-frame calculus into fixed-coordinate bookkeeping.
Theorem 4.11

Elasticity Becomes A Vector ODE

Torsion-Free Elastic Criterion

A unit speed curve is torsion-free elastic exactly when its curvature function satisfies

\(\displaystyle \kappa''+\frac{|\kappa|^2}{2}\kappa+\lambda\kappa=0.\)

What Changed From The Plane?

The scalar \(k\) is replaced by a vector \(\kappa\); the nonlinear coefficient still depends only on its squared length.

Why Parallel Frames Matter

Without the transported normal coordinates, this clean vector ODE is hidden behind moving-frame derivative terms.

Variational geometry becomes normal-plane dynamicsParameter \(\lambda\) is constant along the curve
Connect back to the variational material from earlier chapters. For torsion-free elastic curves, the Euler-Lagrange condition becomes a second order equation for the curvature vector. In the plane this is a scalar equation; in higher codimension it is the same equation with the curvature vector moving in the normal data plane.
Theorem 4.12

Reading Shape From \(\kappa\)

\(\kappa=0\)
tangent is constant, so the curve is a line
\(\kappa\) constant and nonzero
the image lies on a circle
\(\kappa\) in a linear hyperplane
the curve lies in an affine hyperplane of \(R^n\)
\(\kappa\) in an affine hyperplane not through 0
the curve lies on a hypersphere

Prediction Habit

Look first at the trace of \(\kappa\). Its affine constraints predict the smallest ambient shape that can contain \(\gamma\).

Curvature data is not just local bendingIt predicts ambient containment
Use the classification table as a geometric dictionary. Zero kappa means the tangent never changes, a nonzero constant signal gives a circle, and linear constraints on the image of kappa force the curve into a hyperplane or sphere. The learner should read the curvature trace first and predict the ambient shape before seeing the curve.

Diagnostics And Takeaways

Four Takeaways

  1. Parallel normal fields remove unnecessary normal-plane twist.
  2. Parallel transport identifies all normal spaces by oriented isometries.
  3. Hasimoto curvature is acceleration stored in \(T(a)^\perp\).
  4. The curvature function reconstructs the curve up to rigid motion.

How To Check Your Picture

Change a curve parameter, rerun the frame and reconstruction checks, and inspect which invariants survive.

Common Failure Mode

A visually smooth curve can still have a bad sample, a near-zero speed, or a frame that slowly loses orthonormality.
