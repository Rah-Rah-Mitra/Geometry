The differential df is the coordinate-free first derivative of a real-valued function. It is a covector at each point, so its kernel is tangent to the level set. The notebook's residuals shrink with log-log order about 2.12, confirming that df is the first-order part.
Pullbacks

Dualizing \(dF\) Reverses Direction

\(F^*(dh)=d(h\circ F)\)

Chain-Rule Identity

Pullback of covectorsSlide 5 / 10
Pullbacks reverse direction because covectors compose with pushforwards. A map F pushes tangent vectors forward, so a covector on the target pulls back to the source by testing dF of the source vector. The symbolic chain-rule check gives zero residuals for F star dh equals d of h composed with F.
Line Integrals

Exact Fields Forget The Path; Angular Fields Remember Winding

Exact Field

Straight and curved paths with the same endpoints integrate to the same value within \(3.32e{-7}\).

Angular Field

The closed angular covector has loop integral approximately \(2\pi\) around the puncture, so it is not globally exact.

6.28319unit-loop angular integral
Line integralsSlide 6 / 10
Line integrals are pullbacks to an interval followed by ordinary integration. In the exact example, straight and curved paths have the same endpoint-controlled value up to tiny numerical error. In the angular example, loops around the missing point integrate to roughly 2*pi, so closed does not mean exact globally.

Connections To Bundles And Metrics

The cotangent bundle is the dual vector bundle to the tangent bundle, and metrics add an extra bridge. Cotangent Bundle Diagnostics

Measure

A covector is a linear measurement; kernel and unit hyperplanes visualize it.

Transform

Coordinate covectors pull back by Jacobian transpose.

Differentiate

\(df\) is a covector field and the first-order part of \(f\).

Pull Back

Every smooth map pulls target covectors back to source covectors.

Integrate

Line integrals test path independence and detect winding.
