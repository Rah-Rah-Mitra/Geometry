Embedded Submanifolds

Two requirements

Subspace topology, plus a smooth structure making the inclusion an embedding.

Codimension

The number $n-k$ of constrained ambient coordinates.

Definition

$S\subseteq M,\quad \iota:S\hookrightarrow M \text{ a smooth embedding}$

Why it matters

The smooth structure on $S$ is then unique and forced by $M$.

Printed pp. 98-124Embedded Submanifolds
An embedded submanifold carries the subspace topology and a smooth structure that makes the inclusion a smooth embedding. Stress both halves: the local model must look like a coordinate slice, and the topology must be inherited from the ambient space. Codimension is the number of constrained coordinates.

The Local Slice Condition

Normal form

In a suitable chart, $S$ is exactly a coordinate slice.

$k$-slice

$x^{k+1}=c^{k+1},\ \dots,\ x^{n}=c^{n}$

Criterion

A subset satisfying the local $k$-slice condition is an embedded $k$-submanifold, and conversely.

Printed pp. 98-124The Local Slice Condition
The slice criterion is the local normal form for embedded submanifolds. In a suitable ambient chart the subset is exactly the points whose last n minus k coordinates equal constants. Emphasize that producing one such chart at every point is equivalent to being an embedded submanifold.

Regular Level Set Theorem

Theorem

$c \text{ regular} \Rightarrow F^{-1}(c) \text{ embedded}$

Regular value

$dF_p$ is surjective at every $p\in F^{-1}(c)$.

Codimension

$\operatorname{codim} F^{-1}(c)=\dim N$, the target dimension.

Why

Surjective $dF$ gives submersion slice coordinates, so the level set is automatically a slice.

Printed pp. 98-124Regular Level Set Theorem
Here is the chapter's workhorse. If c is a regular value of a smooth map F, then the level set is an embedded submanifold of codimension equal to the dimension of the target. Regularity means the differential is surjective at every preimage point, supplying the slice coordinates automatically.

Tangent Space is the Kernel

Key identity

$T_p\big(F^{-1}(c)\big)=\ker dF_p$

One direction

Curves in the level set have velocities killed by $dF_p$.

Other direction

Dimension count $n-\operatorname{rank}dF_p$ forces equality.

Printed pp. 98-124Tangent Space is the Kernel
At a point of a regular level set the tangent space is precisely the kernel of the differential of the defining map. Walk through both inclusions: curve velocities tangent to the level set are annihilated by dF, and dimension counting forces equality. The gradient is the visible normal direction.

The Sphere as a Level Set

Defining map

$\rho(x)=|x|^2,\quad \mathbb{S}^{n-1}=\rho^{-1}(1)$

Differential

$d\rho_x=2x^\top$, nonzero for $x\neq 0$.

Conclusion

$1$ is a regular value; the sphere is an embedded hypersurface.

Printed pp. 98-124The Sphere as a Level Set
The unit sphere is the cleanest example: it is the level set of the squared norm at value one, and the differential is twice the position vector, never zero on the sphere. So one is a regular value and the sphere is an embedded hypersurface whose tangent plane is the orthogonal complement of the radius.

Matrix Group Examples

$SL_n$

Level set $\det^{-1}(1)$; the determinant has nonvanishing differential there.

Dimension

$\dim SL_n = n^2-1$

$O_n$

Level set of $A\mapsto A^\top A$ at $I$, valued in symmetric matrices.

Dimension

$\dim O_n = \tfrac{n(n-1)}{2}$

Printed pp. 98-124Matrix Group Examples
The same theorem builds Lie groups. The special linear group is a regular level set of the determinant at one, and the orthogonal group is the level set of the map sending A to A transpose times A at the identity, landing in symmetric matrices. Count dimensions to confirm the codimensions.

Immersed Submanifolds

Relaxed topology

The inclusion is only an injective immersion; $S$ may carry a finer topology.

Subtlety

Local rank is full everywhere, yet the subspace topology can fail.

Immersion

$d\iota_p \text{ injective for all } p$

Printed pp. 98-124Immersed Submanifolds
An immersed submanifold relaxes the topology requirement: the inclusion is only an injective immersion, so the subset may carry a topology finer than the subspace one. The figure-eight image of a line is the standard cautionary tale, where the self-crossing point breaks the subspace topology.

Embedded vs Immersed

Graph

Global parametrization with continuous inverse: embedded.

Singular zero set

Crossing or cusp fails the rank test: not a submanifold.

Figure-eight

Full rank, but wrong topology at the crossing: immersed only.

Printed pp. 98-124Embedded vs Immersed
Contrast the two side by side. Local rank behaviour is identical, so both are locally graphs, but global topology separates them. A graph is embedded; a singular zero set fails the rank test; a figure-eight has full rank yet the wrong topology at the crossing. Local data alone cannot certify embedding.

Tangent Space to a Submanifold

Subspace view

$d\iota_p\big(T_pS\big)\subseteq T_pM$

For a level set

$T_pS=\ker d\rho_p$, a concrete linear subspace.

Three agreeing views

  • Velocity of a curve in $S$.
  • Vectors with $\nabla\rho\cdot v=0$.
  • Annihilators of functions vanishing on $S$.
Printed pp. 98-124Tangent Space to a Submanifold
Once the inclusion is fixed we view the tangent space of S as a linear subspace of the ambient tangent space, via the injective differential of the inclusion. For a level set this subspace is the kernel of the defining differential. Three viewpoints agree: curve velocity, gradient-orthogonality, and annihilator of vanishing functions.

Restricting Maps

Domain restriction

Automatic: compose with the inclusion $S\hookrightarrow M$. Always smooth.

Codomain restriction

Subtler: a map into an immersed $S$ must also be continuous for the finer topology.

Embedded / weakly embedded

Pass the topology gate automatically for every smooth ambient map.

Printed pp. 98-124Restricting Maps
Restricting the domain of a smooth map to a submanifold is automatic: just compose with the inclusion. Restricting the codomain is subtler. A map into an immersed submanifold must also be continuous for the finer topology. Embedded and weakly embedded submanifolds pass this gate automatically for every smooth ambient map.

Submanifolds with Boundary

Half-slice model

At boundary points the local model is a half-slice, not a full slice.

Regular domain

The codimension-zero case with boundary, e.g. the closed disk.

Defining function

$b(x,y)=1-x^2-y^2$

Printed pp. 98-124Submanifolds with Boundary
At boundary points the local model is a half-slice rather than a full slice. A regular domain is the codimension-zero case with boundary, like the closed disk. A boundary defining function classifies directions by sign: positive points inward, negative outward, and zero stays tangent to the boundary.

Recap and the Rank-Drop Test

Logic chain

  • Slice condition $\Leftrightarrow$ embedded.
  • Regular value $\Rightarrow$ embedded level set.
  • $T_pS=\ker dF_p$.
  • Immersed relaxes topology only.
Rank-drop lab

$f_\epsilon(x,y)=x^2-y^2-\epsilon$

Watch the failure

$\nabla f$ vanishes only at the origin, which lies on the zero level exactly at $\epsilon=0$ — where the curve self-crosses.

Printed pp. 98-124Recap and the Rank-Drop Test
Recap the logic chain and end with the lab. In the family x squared minus y squared minus epsilon, the gradient vanishes only at the origin, which sits on the zero level exactly when epsilon is zero. At that single parameter the curve crosses itself and stops being an embedded submanifold. Always check regularity first.
