Tensor Products Build The Coordinate Basis

Two-Slot Product

(α ⊗ β)(v,w) = α(v)β(w)

The first covector reads the first vector; the second covector reads the second vector.

Basis Expansion

B = ∑i,j Bij ei ⊗ ej

The elementary products behave like coordinate unit matrices.

Check

Direct bilinear value: -2.0. Component sum: -2.0. Error: 0.

Rank-One Warning

For a pure product, every 2 × 2 minor of the component matrix vanishes; generic 2-tensors are sums of such products.

From Vector-Space Tensors To Tensor Fields

Type (r,s) Tensor At p

A multilinear rule that accepts r covectors and s vectors:

(Tp*M)r × (TpM)s → R

Tensor Field

A smooth assignment p ↦ Ap. In a chart it is a smooth array of coefficient functions, but the array is only a description.

Variance Rule Of Thumb

Covariant slots pull back along any smooth map. Mixed tensors require more structure, usually a diffeomorphism, to transport all slots naturally.

Chapter structure: tensor bundles and fieldsSlide 6 / 10
Now move from vector spaces to manifolds. At each point, tensor fields live in tensor spaces built from tangent and cotangent spaces; in a chart they become smooth arrays of functions. Stress the warning that component arrays are coordinate descriptions, while the tensor field is the coordinate-independent multilinear rule.

Pullback: Covariant Slots Move Backward

Slot Definition

(F*A)p(v,w) = AF(p)(dFpv, dFpw)

The map pushes vectors forward; the covariant tensor is therefore pulled back.

2-Tensor Matrix Rule

F*A = JFT A(F) JF

Symbolic Check

For the polar map F(r,θ)=(r cosθ, r sinθ), the pullback matrix stays symmetric and has sampled determinant bounded below by 1.29019.

Artifact: pullback-of-covariant-2-tensor.pngSlide 7 / 10
For pullbacks, keep the slot picture in front. A covariant tensor accepts tangent vectors, so a smooth map can pull it back by first pushing tangent vectors forward with dF and then feeding them into the original tensor. In coordinates for a 2-tensor, that slot insertion is the familiar J transpose A of F times J formula.

Lie Derivative: Flow Comparison Has Two Terms

Coordinate Formula For A 2-Tensor

(LVA)ij = Vk∂kAij + Akj∂iVk + Aik∂jVk

Notebook Model

V=(x,-y)

A = [[x2+1, xy], [xy, y2+2]]

Verified Output

LVA = [[4x2+2, 0], [0, -4y2-4]]

The flow derivative minus the coordinate formula is the zero matrix.

Recap: Six Checks For Tensor Literacy

1. Slots

A tensor is a multilinear rule. Name the slots before chasing coordinates.

2. Components

Basis-vector evaluations determine the whole rule by multilinearity.

3. Products

Tensor products of covectors build the coordinate basis for covariant tensors.

4. Projections

Symmetric and alternating parts encode different swap behavior.

5. Fields

Tensor fields are smooth pointwise tensor rules, not just arrays in one chart.

6. Operations

Pullback and Lie derivative are slot operations verified by coordinate formulas.

multilinearity → tensor products → symmetry type → tensor fields → pullback → Lie derivative
