Sets of Measure Zero

Definition

$A\subseteq\mathbb{R}^n$ is null if for every $\varepsilon>0$ a countable cover of cubes has total volume below $\varepsilon$.

Stability

Countable unions of null sets are null; this is reused all over Sard's proof.

Intuition

A long, wiggly graph can still have zero area.

Printed pp. 125-149Sets of Measure Zero
Measure zero is the chapter's word for thin enough to avoid. A subset is null when arbitrarily small total volume covers it. Stress the countable-cover-of-cubes definition and that countable unions of null sets stay null, since the proof of Sard repeatedly slices the critical set into countably many pieces.

Measure Zero on Manifolds

Chart definition

$A\subseteq M$ is null if $\varphi(A\cap U)$ is null in $\mathbb{R}^n$ for every chart $(U,\varphi)$.

Why it is consistent

The definition needs no metric and no chosen atlas.

Key lemma

$F:U\to V$ smooth, $\dim U=\dim V$ $\Rightarrow$ $F(\text{null})$ is null.

Consequence

Transition maps preserve nullity, so the chart test is chart-independent. Any positive-codimension submanifold is null.

Printed pp. 125-149Measure Zero on Manifolds
To speak of null sets on a manifold without a metric, declare a set null when every chart image is null in Euclidean space. The key lemma is that smooth maps between equal-dimensional opens send null sets to null sets, so the definition does not depend on which charts we picked.

Critical and Regular Values

Critical point

$p$ where $dF_p$ fails to be surjective.

Critical / regular value

A value is critical if hit by a critical point, regular otherwise (missed values count as regular).

Toy map

$F(u,v)=u^2-v^2$, critical pt $(0,0)$, critical value $0$.

Printed pp. 125-149Critical and Regular Values
A critical point is where the differential fails to be surjective; its image is a critical value. Everything else in the target is a regular value, including points missed entirely. Use the saddle u squared minus v squared: the origin is the only critical point and zero its single critical value, while nonzero levels stay clean.

Sard's Theorem

Theorem

$F:M\to N$ smooth $\Rightarrow$ the set of critical values has measure zero in $N$.

Reading

Almost every value of $F$ is regular.

The asymmetry

The critical point set can be large and intricate, yet the values it produces stay negligible.

Why it matters

This thinness is the lever for embedding, approximation, and transversality.

Printed pp. 125-149Sard's Theorem
State the theorem cleanly. For any smooth map the set of critical values has measure zero, so almost every value is regular. Emphasize the asymmetry: the critical point set can be large and complicated, yet the values it produces in the target remain negligible. This is the engine for everything that follows.

Proof Strata

Strategy

Reduce to charts, then slice $C$ by how many derivatives vanish.

The closing estimate

$K^m$ cubes, images $\sim K^{-n(k+1)}$; negative exponent $\Rightarrow$ volume $\to 0$.

Printed pp. 125-149Proof Strata
Walk the staged reduction. Pass to charts, then split the critical set. Where a first derivative survives, slice transversally; where the first k derivatives vanish but a later one survives, push into a hypersurface; where many derivatives vanish, Taylor's theorem forces tiny cubes into even tinier balls. Negative volume exponents close the estimate.

Regular Level Sets

Regular level set theorem

$c$ regular $\Rightarrow$ $F^{-1}(c)$ is embedded, $\operatorname{codim}=\dim N$.

Generic fibers are manifolds

Regular values are almost all values, so a typical level set is automatically a submanifold.

The trade

We accept that the critical fiber may be singular, because we only need the generic ones.

Example

For $F(u,v)=u^2-v^2$, every nonzero level is a smooth $1$-manifold; only the level $0$ is singular.

Printed pp. 125-149Regular Level Sets
The regular value theorem is Sard's immediate payoff. If c is a regular value the preimage is an embedded submanifold whose codimension equals the dimension of the target. Because regular values are almost all values, generic level sets are automatically manifolds, which is why we tolerate the critical fiber being singular.

Whitney Embedding

Embedding theorem

Every smooth $n$-manifold embeds in $\mathbb{R}^{2n+1}$.

Immersion theorem

Every smooth $n$-manifold immerses in $\mathbb{R}^{2n}$.

Mechanism

Start in a large $\mathbb{R}^N$, then lower the ambient dimension one step at a time.

Each step

Project along a direction outside a measure-zero bad set handed to us by Sard.

Printed pp. 125-149Whitney Embedding
Whitney's theorem says every smooth n-manifold embeds in Euclidean space of dimension two n plus one and immerses in dimension two n. The mechanism is repeated projection: lower the ambient dimension one step at a time, each step choosing a direction outside a measure-zero bad set supplied by Sard.

Avoiding Bad Projection Directions

Tangent directions

Projecting along a tangent destroys the immersion.

Secant directions

Projecting along a secant glues two distinct points together.

Sard's role

Both bad families are images of low-dimensional maps, hence measure zero. A good direction exists once $N>2n+1$.

Printed pp. 125-149Avoiding Bad Directions
Make the projection step concrete. A projection keeps an embedding embedded only if its kernel avoids tangent directions, which would destroy the immersion, and secant directions, which would glue two points together. Both families are images of low-dimensional maps, so by Sard they miss almost every direction once the ambient dimension is high enough.

Whitney Approximation

Approximation theorem

Continuous $f:M\to N$ is homotopic to a smooth map, and uniformly close to it.

Relative version

If $f$ is already smooth on a closed set, the approximation leaves it untouched there.

Move 1: smooth

Approximate $f$ inside an ambient Euclidean space by convolution / partitions of unity.

Move 2: retract

Use a tubular neighborhood to push the smooth map back onto $N$.

Printed pp. 125-149Whitney Approximation
Continuous maps are homotopic to smooth ones, and a continuous map already smooth on a closed set can be approximated without disturbing it there. The proof for manifold targets has two moves: approximate inside an ambient Euclidean space, then retract back through a tubular neighborhood to land on the manifold.

Tubular Neighborhood Retraction

Tubular neighborhood

An embedded $N\subseteq\mathbb{R}^k$ has a neighborhood that retracts smoothly onto it along normals.

Circle model

$r(x)=x/\lVert x\rVert$ on $0<\lVert x\rVert$, smooth near $S^1$.

Payoff

The retraction makes "smooth, then return" rigorous.

Printed pp. 125-149Tubular Retraction
The tubular neighborhood is what makes the second move legal. A smooth manifold sitting in Euclidean space has a neighborhood that retracts smoothly onto it along normal directions. The circle is the honest model: a nearby smooth curve stays inside the annulus, and normalizing radius back to one is the retraction.

Transversality

Definition

$S,S'$ transverse at $p$: $T_pS + T_pS' = T_pM$.

Preimage theorem

$F\pitchfork S \Rightarrow F^{-1}(S)$ is a submanifold, $\operatorname{codim}=\operatorname{codim} S$.

Vacuous case

Disjoint submanifolds meet transversally for free.

Printed pp. 125-149Transversality
Two submanifolds meet transversally when their tangent spaces together span the ambient tangent space at every shared point. The preimage theorem generalizes regular values: if a map is transverse to a submanifold, the preimage is a submanifold of the predicted codimension. Empty intersections count as transverse vacuously.

Genericity and Recap

Parametric transversality

In a family $F_a$, Sard forces almost every $a$ to be transverse.

Stability

Transverse intersections persist under small perturbations.

Example family

$F_a(x)=(x,x^2+a)$ vs the axis: only $a=0$ is tangent.

The chain, retraced

  • Critical values are thin (Sard).
  • Embed by avoiding bad directions.
  • Approximate by smoothing then retracting.
  • Transverse preimages are submanifolds.

Warning

Drop smoothness and the dimension-drop fails: continuous space-filling images break it.

Printed pp. 125-149Genericity and Recap
Transversality is generic and stable. Parametric transversality plus Sard shows almost every member of a family is transverse, and any map is homotopic to a transverse one. Close by retracing the chain: thin critical values, embedding by avoidance, approximation by retraction, and transverse preimages that behave like submanifolds.
