Measure Zero: Covers That Can Be Squeezed

Working Definition

A set has measure zero when, for every tolerance, it admits countable coordinate boxes whose total volume is below that tolerance.

Notebook Check

0.64, 0.44, 0.30, 0.20, 0.128, 0.08

These covering areas strictly decrease as the rectangle width is tightened.

Critical And Regular Values

Rank Test

F(u,v)=u^2-v^2,   dF=(2u,-2v)

Only (0,0) is critical, and its value is 0.

Regular Values

For a regular value, each preimage point has full differential rank, so the preimage theorem can create a clean submanifold.

Computed Evidence

Sampled nonzero levels have minimum gradient norms at least 1.348.

Artifact: critical-regular-values-map.pngSlide 3 / 10
This is the local bridge from differential calculus into Sard's theorem. For the toy map, the gradient is exactly (2u, -2v), so only the origin is critical. Nonzero level values have positive sampled gradient norms, which means the preimage theorem sees clean hypersurfaces there; the zero value is where rank failure is visible.

Sard's Theorem: What It Controls

Theorem Orientation

For a sufficiently smooth map F:M\to N, the set of critical values in N has measure zero.

bad target values = F(critical points)

Why Target Space Matters

A critical set in the domain may be large, but Sard controls the values one must avoid.

Core theoremSlide 4 / 10
State Sard as a target-space theorem, not merely a theorem about points in the domain. Critical points can be geometrically large or complicated, but their image values are small in the measure-zero sense. This is the piece that lets later arguments choose a regular value after avoiding all bad critical values at once.

Whitney Embedding: Avoid Bad Projection Directions

Avoidance Principle

A projection is good when its kernel misses the tangent and secant directions that would collapse immersion or injectivity.

Sampled Model

\gamma(t)=(t,t^2,t^3), \quad \ker \pi=(0,0,1)

Projected speed remains at least 1.0001.

Sard's Role

Bad directions form a thin image in projective space, so a nearby good direction can be chosen.

Artifact: whitney-projection-avoidance.pngSlide 6 / 10
Sard enters Whitney's theorem as an avoidance engine. A projection fails when its kernel meets a tangent or secant direction in the wrong way. The sampled model projects gamma(t)=(t,t^2,t^3) to the plane and records positive tangent and secant separation from the kernel, illustrating how most directions are good.

Transversality: Typical Preimages Behave Well

Family

F_a(x)=(x,x^2+a), \quad S=\{y=0\}

Preimages are roots of x^2+a=0.

Parameter Scan

Among 33 sampled parameters, only a=0 is bad.

Artifact: transversality-preimage-behavior.pngSlide 8 / 10
Use the parameter family as the classroom model for transversality. When a is negative, the curve crosses the x-axis in two transverse points; when a is zero, the curve is tangent and the determinant vanishes; when a is positive, the preimage is empty, which still counts as transverse. This sets up parametric transversality as a genericity theorem.

Why Smoothness Matters

Warning

Sard is not a dimension-counting slogan for arbitrary continuous maps. Smoothness prevents space-filling behavior.

Box Count Check

On a 32\times32 grid, the continuous Hilbert approximation occupies 1024 boxes; the smooth graph occupies 70.

Reading Diagnostic

Whenever Sard is invoked, identify the differentiability hypothesis and the critical-value set being avoided.

Artifact: continuous-vs-smooth-image-box-counts.pngSlide 9 / 10

The notebook's finite Hilbert-curve comparison occupies all 1024 boxes in a 32 by 32 grid, while the smooth graph occupies only 70 boxes, making the failure outside smoothness visible.
