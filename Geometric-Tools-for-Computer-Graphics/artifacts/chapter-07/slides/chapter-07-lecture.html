Intersection in 2D

A graphics intersection routine should return more than a Boolean: it should expose the parameter domain, contact type, numerical residual, and the convention used at degenerate boundaries.

Open by framing intersection as a classification problem rather than a yes-or-no test. The chapter moves from lines and segments to curves, convex polygons, and moving objects, but the same programming discipline keeps returning: represent the domain, compute candidates, reject impossible cases, and report enough contact information to debug a renderer or collision system.
Working Contract

Every Query Carries A Domain And A Certificate

Data Contract

An intersection result should record the primitive pair, the parameter values that produced the event, and the valid domain for each parameter.

QuestionTypical Answer
Where is the candidate?parameters \(s,t\), roots, or projected times
Why is it valid?domain membership plus small residual

Use the contract slide to give students a reusable template for the rest of the lecture. A robust routine separates candidate generation from acceptance. The candidate might come from a two-by-two linear solve, a polynomial root, or a projection interval. The certificate then says why that candidate belongs to the geometric objects actually requested.
Linear Components

The 2D Determinant Separates Unique Hits From Parallel Cases

Carrier Solve

For \(P_0+s d_0=P_1+t d_1\), the scalar determinant \(K(d_0,d_1)\) tells whether the carrier lines have a unique crossing.

\(K(u,v)=u_xv_y-u_yv_x\)

Domain Filter

  • line: \(s\in\mathbb{R}\)
  • ray: \(s\ge 0\)
  • segment: \(0\le s\le 1\)
Derive the determinant as the two-dimensional cross product that measures signed area. When it is safely nonzero, the carrier lines have one candidate point and the remaining work is parameter-domain filtering. When it is small, the routine changes character: it must distinguish parallel disjoint carriers from a shared carrier where interval overlap is the answer.
Segment-Segment Query

Segment Intersection Returns A Set, Not A Single Shape

Nonparallel Branch

Solve for \(s,t\), then accept only if both parameters lie in \([0,1]\). Otherwise the carrier lines cross outside at least one segment.

Collinear Branch

Project the second segment into the first segment's parameter and intersect intervals. The return is empty, one endpoint, or a subsegment.

ReturnGeometryDebug Meaning
0emptyrejected by domain or interval gap
1pointcrossing, touching endpoint, or tangent contact
2segmentcollinear overlap with positive length
Treat the segment slide as the first example of returning a geometric set. Students often write a segment intersection predicate and stop, but the chapter's pattern is richer. A point result and an interval result have different downstream behavior in clipping, collision response, and mesh repair, so the return type is part of the specification.
Polylines And Solid Polygons

Edge Scans Need A Containment Guard

Polyline Query

Iterate over edges and reuse the segment routine. A Boolean query can early-out; a find query collects and sorts events.

Polygon Solid Caveat

A segment can be fully inside a polygon without crossing any boundary edge, so endpoint containment is a required companion test.

Repeated Queries

Preprocessing or coarse culling is useful when many linear components query the same polygonal object.

Use this slide to prevent a common edge-loop bug. Intersecting a line or ray with polygon edges can be sufficient for many boundary queries, but a solid polygon changes the specification. A segment may lie entirely inside the polygon, so no edge reports a hit. Endpoint containment closes that hole before any acceleration structure is considered.
Linear Components And Curves

Substitution Turns Geometry Into A Root Problem

Implicit Quadratic Example

Substitute \(X(t)=P+td\) into \(X^TAX+B^TX+c=0\). The geometric query becomes a scalar polynomial.

\(q(t)=e_2t^2+e_1t+e_0\)

Root Classification

  • two real roots: two crossings of the carrier line
  • double root: tangent contact
  • domain filter: keep roots that belong to the ray or segment
The curve slide shifts the audience from determinants to root finding. The same line can intersect the carrier curve twice while the requested segment contributes only one valid point. That distinction is exactly why the notebook checks residuals after drawing the figure: a root is useful only when it satisfies both the equation and the parameter domain.
Quadratic And Polynomial Curves

Curve-Curve Intersection Is A Method Choice

Algebraic Route

Eliminate variables or solve a small system, then certify candidates by substituting them back into both curve equations.

Subdivision Route

Approximate by polylines or bounding boxes, refine only where boxes overlap, and convert local hits back to curve parameters.

Sampling Route

Raster or monotone decompositions can be enough for display-oriented queries when the requested output is a robust visual mask.

For curve-curve intersections, emphasize that the chapter is not asking students to worship one method. Algebraic elimination gives exact-looking candidates but still needs residual checks. Polyline and bounding approaches trade symbolic compactness for spatial pruning. Raster-style methods can be appropriate for visualization, provided the result is understood as a sampled certificate rather than exact geometry.
Method Of Separating Axes

Convex Intersection Becomes Interval Overlap

Separating-Axis Principle

Two convex polygons are disjoint exactly when some candidate line direction separates their projected intervals.

overlap on every axis \( \Longleftrightarrow \) intersect

Candidate Axes

For polygons, edge normals supply a finite test set. Each axis reduces a 2D question to two scalar intervals.

The separating-axis slide is the chapter's central compression trick for convex objects. Instead of searching for crossing edges first, project both polygons onto a candidate normal and ask whether the one-dimensional intervals overlap. If one axis has a gap, that axis is a certificate of nonintersection. If no candidate axis separates them, convexity supplies the positive answer.
Moving Convex Polygons

Motion Changes The Predicate Into A Time Interval

Relative Motion

Process the query as one stationary polygon and one moving polygon with relative velocity \(W=w_1-w_0\).

Per-Axis Time Window

Each projected gap closes or opens at speed \(d\cdot W\). Accumulate the latest entering time and earliest leaving time.

\([T_{\mathrm{first}},T_{\mathrm{last}}]\)

Rejection

If \(T_{\mathrm{first}}>T_{\mathrm{last}}\), the moving objects never overlap during the allowed time horizon.

The moving version is a clean example of why static predicates are not enough in collision detection. For each axis, a gap may close or widen according to relative speed. The algorithm preserves a global interval of times that have survived every axis so far. First contact is the latest entrance, not the first axis examined.
Contact Classification

At First Contact, Projection Extremes Identify The Geometry

Configuration Records

For each projection interval, store the min and max values plus whether each extreme came from a vertex or an edge.

Implementation Payoff

The first-contact time plus the saved projection configuration tells the response code which feature pair touched.

This is where the algorithm becomes useful for contact response. A Boolean collision time tells when something happened, but not what touched. By saving whether projection extrema were vertices or edges on the critical axis, the routine can construct a point or segment contact set. That feature pair is the bridge to impulse, clipping, or manifold generation.
Numerical Clinic

Robust Intersection Code Names Its Ambiguities

Common Failure Modes

  • tiny direction vectors make an absolute parallel test meaningless
  • endpoint contacts change under inconsistent open or closed intervals
  • near-tangent roots may be visually correct but algebraically unstable
  • initial overlap in moving queries is a different case from first contact later

Relative Parallel Test

Scale the determinant comparison by the direction lengths so that the threshold behaves like an angular tolerance.

\(K(d_0,d_1)^2 \le \varepsilon^2\|d_0\|^2\|d_1\|^2\)
Slow down on this slide because numerical ambiguity is not an implementation detail to hide at the end. A tolerance rule encodes a geometric convention. Relative determinant tests, explicit endpoint policies, and residual checks make the convention inspectable. The goal is not to remove degeneracy; it is to make the reported result reproducible and explainable.

Checks To Preserve

  • segment intersection is symmetric in both inputs
  • curve roots have small equation residuals
  • all separating-axis overlaps agree with the polygon predicate
  • first-contact time lies inside the reported interval

Instructor Recap

Intersection in 2D is a chain of reductions: 2D geometry to parameters, parameters to intervals or roots, and roots back to geometric contact sets.
