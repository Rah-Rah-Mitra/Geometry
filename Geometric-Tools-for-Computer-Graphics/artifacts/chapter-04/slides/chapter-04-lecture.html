Representation Contract

Homogeneous Weights Separate Locations From Directions

Data Contract

Use a homogeneous weight to tell the matrix whether the array is a point or a displacement.

\(p_h = (p,1)\), \(v_h = (v,0)\)
\[ \begin{bmatrix} A & t \\ 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ w \end{bmatrix} = \begin{bmatrix} Ax + wt \\ w \end{bmatrix} \]

Invariant To Assert

A pure translation should satisfy \(T(p,1)=(p+t,1)\) and \(T(v,0)=(v,0)\).

Point: affected by translationVector: measures displacement, not location
Emphasize that homogeneous coordinates are a contract, not decoration. A point carries weight one so translation affects it; a direction carries weight zero so the same matrix leaves its displacement part unchanged. Ask students to predict the result before reading the formulas.

Use this slide to clean up a common programming confusion: arrays alone do not know whether they are points or vectors. The permitted operations encode meaning. Subtracting points creates a vector, adding a vector to a point moves the point, and averaging points requires weights summing to one.
Vector Products As Queries

Dot, Cross, Tensor, And Perp Dot Answer Different Geometry Questions

Dot Product

Measures angle agreement and signed projection.

Cross Product

Builds a perpendicular direction with orientation.

Tensor Product

Creates rank-one linear maps from two vectors.

Perp Dot

Acts as the signed-area orientation test in 2D.

In graphics code these products are not abstract decoration: they drive incidence tests, shading angles, surface orientation, frame construction, and rank-one updates.

Products are geometry queriesChoose the product that matches the invariant
Frame vector products as query operators. The dot product answers length and angle questions, the cross product gives oriented area and a perpendicular direction, the tensor product builds linear maps from vectors, and the two-dimensional perp dot product is an orientation test in disguise.
Composition

An Affine Matrix Packages Linear Action Plus Translation

\[ F = \begin{bmatrix} A & t \\ 0 & 1 \end{bmatrix}, \qquad F_2F_1 = \begin{bmatrix} A_2A_1 & A_2t_1+t_2 \\ 0 & 1 \end{bmatrix}. \]

Notebook Check

Apply \(S\), then \(R\), then \(T\) to several points and compare with one multiplication by \(TRS\).

stepwise = T @ (R @ (S @ x_h)) combined = (T @ R @ S) @ x_h assert norm(stepwise - combined) <= tol
Affine composition is associativeOperation order remains a convention to document
Describe the affine matrix as a data structure that packages a linear action and a translation. Composition order matters because the rightmost operation acts first on column vectors. The invariant to test in code is that the combined matrix matches stepwise application to sample points.

Frames And Coordinates

Changing Basis Rewrites Coordinates Without Moving The Point

Passive Coordinate Change

If \(B\) stores basis vectors as columns, then \(x_E = Bx_B\) and \(x_B=B^{-1}x_E\).

Active Transformation

The object itself moves: \(x_E' = Ax_E+t\). The frame is fixed while the geometry changes.

Common Failure

Mixing active and passive interpretations can produce a visually plausible transform with the inverse matrix.

Same point, different coordinatesColumns-as-basis convention must be documented
Make the active versus passive distinction explicit. An active transform moves the geometric object in a fixed frame; a change of basis rewrites coordinates of the same object in a new frame. The matrices can look similar, so the diagram keeps the invariant point visible.

Projection is a controlled loss of information. The implementation question is not only where a point lands, but which affine, metric, or projective relationships survive the map.

Orthographic: affine ratios survive on parallel slicesPerspective: depth changes scale through division
Use the projection family to connect linear algebra to camera design. Orthographic projection forgets depth along parallel rays, oblique projection keeps a slanted direction, and perspective projection makes depth enter through division. The inspection question is which ratios survive the map.
Homogeneous Projection

Perspective Is A Matrix Followed By A Checked Division

Failure Mode

If \(w_c\) is near zero, the projected coordinates explode. Clipping and tolerances are part of the geometry.

\[ (x_c,y_c,z_c,w_c) \mapsto \left(\frac{x_c}{w_c},\frac{y_c}{w_c},\frac{z_c}{w_c}\right) \]
if abs(w_c) <= eps: classify as clipped or unstable else: ndc = clip_xyz / w_c
Matrix multiplication alone is not the full projectionThe denominator is a geometric diagnostic
Spend time on the denominator. Homogeneous projection is safe only when the implementation tracks the w coordinate and treats small values as geometry, not as an afterthought. Perspective division is where near planes, clipping, and numerical checks enter the otherwise elegant matrix story.
Normals As Constraints

Normals Transform By Inverse Transpose Because They Define Planes

\[ n^T u = 0 \quad \Rightarrow \quad (A^{-T}n)^T(Au)=n^T u=0. \]

Correct Rule

For an invertible linear part \(A\), transform normals by \(A^{-T}\), then renormalize for lighting.

Why The Naive Rule Fails

Nonuniform scale changes tangent directions differently, so applying \(A\) to the normal usually loses perpendicularity.

Normals behave like plane constraintsInverse transpose preserves annihilation of tangents
Present normals as constraints rather than little arrows glued to surfaces. If a plane is described by a normal covector, the transformed plane must still annihilate transformed tangents. That requirement forces the inverse-transpose rule and explains why nonuniform scaling breaks the naive transform.
Worked Example Pattern

Turn The Normal Rule Into A Residual

Experiment

Start with a tangent \(u\) and normal \(n\) satisfying \(n^Tu=0\). Apply a nonuniform scale \(A\).

\[ r_{\text{naive}} = |(An)^T(Au)|,\qquad r_{\text{correct}} = |(A^{-T}n)^T(Au)|. \]
A = diag(2.0, 0.5, 1.25) tangent_p = A @ tangent normal_bad = normalize(A @ normal) normal_ok = normalize(inv(A).T @ normal) assert abs(dot(normal_ok, tangent_p)) <= tol
Residuals convert visual claims into testsNaive normal transform fails under nonuniform scale
Walk through the residual as a production-style test. A transformed tangent and the corrected transformed normal should have zero dot product up to tolerance. Showing the failed naive normal beside the corrected one makes the inverse-transpose rule measurable instead of merely symbolic.
Chapter Summary

Implementation Checklist For Transform Geometry

Representation

Keep point, vector, coordinate, tangent, and normal types separate even when all are stored as arrays.

Invariant

Each transform should preserve something testable: weight, parallelism, angle, orientation, or plane annihilation.

Residual

Projection denominators, determinant signs, and normal-tangent dot products expose convention and stability errors.
