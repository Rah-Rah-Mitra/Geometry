Computational Contract

A Distance Query Is A Constrained Minimization Problem

Minimize \(F(u)=\|X(u)-Y\|^2\) subject to \(u\in D\).

Domain

Line: free parameter. Ray: lower bounded. Segment: clamped interval.

Feature

The minimizer may live on an endpoint, an edge, or an interior region.

Residual

The final vector should be perpendicular to every free direction.

Point To Linear Component

One Projection Formula, Three Domains

\(t_\ast=\dfrac{(Y-P)\cdot d}{d\cdot d},\qquad X(t)=P+t\,d\)

PrimitiveLegal parameterClosest parameter
Line\(t\in\mathbb{R}\)\(t=t_\ast\)
Ray\(t\ge 0\)\(t=\max(0,t_\ast)\)
Segment\(0\le t\le 1\)\(t=\min(1,\max(0,t_\ast))\)

The formula is the same until the domain interrupts it. Robust implementations make that interruption explicit.

Boundary Logic

Closest-Feature Regions Partition The Plane

Triangle And Polygon Pattern

  • Interior: closest point uses barycentric weights inside the primitive.
  • Edge: one inequality becomes active and the problem becomes point-to-segment.
  • Vertex: two neighboring inequalities are active and the endpoint is returned.
  • Medial boundaries are where small input changes can change the feature label.

Move from formulas to regions. For polygons, the question is which constraints are active at the minimizer. This is why closest-point code often looks like a decision tree: each branch is identifying a vertex, an edge, or an interior feature.

Implementation Risk

The scalar minimum can be correct while the feature label is unstable near a Voronoi boundary. That instability matters for contact normals and continuous collision logic.

Curved Primitives

Curve Distance Converts Geometry Into Root Finding

Quadratic And Polynomial Curves

  • For a curve \(C(u)\), minimize \(\|C(u)-Y\|^2\) over its parameter interval.
  • Interior candidates satisfy an orthogonality equation involving \(C'(u)\).
  • Polynomial curves can produce several roots; the algorithm must evaluate all legal candidates.
  • Endpoints matter because the parameter domain is still constrained.
Sections 6.4 and 6.5 orientationSame contract: objective, domain, residual, feature
For curves, the mental model should stay the same even though the algebra changes. The residual vector at an interior closest point is perpendicular to the tangent. What changes is that the stationary equation may have several legal roots.
Convex Distance

Minkowski Difference Moves Shape-Shape Distance To The Origin

Convex Rephrasing

\(d(A,B)=\min_{a\in A,\ b\in B}\|a-b\|=\operatorname{dist}(0,A-B)\)

  • If the origin lies inside \(A-B\), the convex sets intersect.
  • If not, the closest point of \(A-B\) to the origin encodes the separating direction.
  • Support mappings let algorithms search \(A-B\) without explicitly building it.
Notebook concept: Minkowski difference origin distanceBridge to GJK
Use this slide to explain why convex distance algorithms care so much about the origin. The shape pair becomes one derived convex set. Intersecting the origin means overlap, while the closest point to the origin gives a separating vector.
GJK Algorithm

GJK Searches The Minkowski Difference With A Small Simplex

1

Choose a search direction and request an extreme point of \(A-B\).

2

Keep the smallest simplex whose convex hull can improve the origin distance.

3

Stop when the simplex contains the origin or when no support point can reduce the distance.

Key Memory

GJK is not drawing the full Minkowski difference. It is asking only for support points that matter to the current origin-distance certificate.

Section 6.10 orientationNotebook visual: GJK simplex walk toward the origin
Keep GJK concrete. The algorithm never needs to construct the entire Minkowski difference. It samples support points, keeps a simplex, and repeatedly asks whether that simplex proves intersection or supplies a closest direction back to the origin.

What To Inspect

  • Flat endpoint plateaus: clamping has taken over from projection.
  • Kinks: the active feature changes and derivative-based code needs care.

Robust Return Values

Return The Certificate, Not Only The Distance

DistanceResult { squared_distance closest_point_a closest_point_b parameters feature_a, feature_b status }

A contact solver, picking tool, or curve editor usually needs the certificate more than the square root.

Certificate Checks

  • Parameters lie in the declared domain.
  • Interior residuals are orthogonal to free directions.
  • Boundary residuals point into the feasible normal cone.
  • Feature labels remain stable away from medial boundaries.
  • Degenerate primitives report a status instead of hiding a convention.
Notebook check list: four executable invariantsProduction habit: keep debug state
Stress that a production distance routine should return a certificate. The closest points, parameters, feature labels, and status flags are what make downstream debugging possible. Without them, correct distances can still produce unstable normals or broken caches.
Failure Modes

Tolerances Should Protect Geometry, Not Replace It

Zero Length

A segment can collapse to a point; the algorithm should route to point distance deliberately.

Parallel Lines

Small denominators require a branch that preserves the intended geometry.

Boundary Ties

Several features may be equally close; deterministic tie handling helps caching.

Multiple Roots

Polynomial curves can provide several stationary candidates inside the domain.

Debug Rule

Every tolerance branch should still produce a recognizable feature, a legal parameter, and a residual that explains why the branch was accepted.

3

4

Select the minimum by squared distance and attach feature labels.

5

Assert the residual, domain membership, and feature stability checks.

Recap

Distance in 2D Is Active Geometry Plus Verification

Core Ideas

  • Squared distance is minimized over explicit domains.
  • Boundaries create feature cases.
  • Curves add root finding but preserve the same residual idea.
  • Convex shape distance can be searched through \(A-B\).

Engineering Habits

  • Return closest points, parameters, features, and status.
  • Assert domain membership and orthogonality residuals.
  • Treat degeneracies as named branches.
  • Use diagnostics to reveal active-set transitions.

The durable pattern is: represent the primitive, minimize on its legal domain, name the active feature, and check the certificate.
