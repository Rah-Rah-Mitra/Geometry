Predicates Are Small Theorems With Return Values

Orientation

The sign of a 2D determinant reports whether \(C\) lies to the left, right, or on the directed line from \(A\) to \(B\).

\(\operatorname{orient}(A,B,C)=\det(B-A,\ C-A)\)

Containment

Halfspace signs, ray crossings, and winding contributions all classify a query point against a boundary, but each has different boundary conventions.

Empty Circle

Delaunay decisions use a lifted determinant: if a sample enters a circumcircle, the local triangulation is not yet stable.

Contract: sign first, tolerance secondEvery later algorithm calls these predicates repeatedly
Spend time on this slide because it is the vocabulary for the chapter. A predicate is not just a formula; it is a contract about what sign means, how zero is handled, and which convention is used on boundaries. Algorithms later in the lecture succeed or fail based on these small contracts.
Space Partitioning
preprocess now, query later

BSP Trees Turn Cutting Lines Into Query Logic

Data Structure

A BSP node stores a plane or line, a side convention, and links to subproblems. Leaves store regions, fragments, or visibility order.

Why It Helps

Point location, clipping, hidden surface ordering, and constructive modeling queries can avoid scanning every primitive after preprocessing.

Cost To Watch

Unlucky splitter choices duplicate fragments and deepen the tree. The visual diagnostic is fragmentation, not just node count.

BSP is a recursive halfspace classifierInvariant: each child owns one side of the splitter
Explain BSP trees as a controlled way to remember a sequence of spatial decisions. The geometric primitive at a node is simple, but the recursion turns many side tests into a spatial index. Emphasize that the danger is not only depth; bad splitters also create duplicated fragments that make later queries expensive.
Containment Tests
parity and winding are conventions

Point Containment Depends On Boundary Accounting

A graphics program needs an inside test that is explicit about edge hits, vertices, holes, and orientation. Two common summaries are crossing parity and winding number.

Parity Rule

Cast a ray and toggle inside when crossing a valid edge. Vertex handling must count a shared vertex once, not twice.

Winding Rule

Accumulate signed angle or signed edge crossings. Nonzero winding gives an orientation-aware containment test.

Boundary Policy

Production code usually returns one of three states: outside, inside, or on boundary. A single Boolean hides the hardest cases.

Sanity Check

If the query point is translated with the polygon, containment must not change. If the boundary order is reversed, parity is unchanged while winding changes sign.

Containment is a convention plus a predicateBoundary states should be first-class results
Use this slide to separate the mathematical region from the implementation policy. Parity and winding both answer containment, but they encode different information about orientation and holes. Students should leave knowing that vertex crossings and boundary points are not annoyances to hide; they are part of the API contract.
Set Operations
intersect, split, classify, traverse

Boolean Operations Are Arrangement Traversals

Pipeline

  • Find all segment or face intersections.
  • Split boundaries at those intersection events.
  • Classify each fragment against the other shape.
  • Traverse fragments selected by union, intersection, or difference.

Key Invariant

Every output boundary edge is a fragment of an input boundary with a label saying which side of the other object it lies on.

Failure Modes

Coincident edges, near tangencies, and tiny slivers create ambiguous labels unless the algorithm has a tolerance and a topological repair policy.

Boolean geometry is local classification plus global traversalLabels must survive splitting
Present polygon or solid Booleans as a graph problem induced by geometry. The visible overlapping shapes are only the first step; the real computation is the arrangement whose edges carry inside outside labels. Stress that robustness problems often appear after intersections, when short fragments and coincident pieces must be classified consistently.
Extreme Structure
supporting lines certify boundary vertices

Convex Hulls Expose The Points That Support The Shape

Object

The hull of a point set is the smallest convex set containing it. Computationally, the usual output is the cyclic list of boundary vertices.

Certificate

For each hull edge, every input point lies on the same side or on the edge. That local side test certifies the global boundary.

Algorithmic Families

Gift wrapping scans for the next support point, divide and conquer merges tangents, and stack methods maintain a legal turn invariant.

edge \(V_iV_{i+1}\) is valid when \(\operatorname{orient}(V_i,V_{i+1},P)\) has one allowed sign for all \(P\).

Hull algorithms differ in search strategy, not in certificateBoundary order is part of the answer
Connect hulls back to the orientation predicate from the beginning. The hull is a global object, but every edge can be checked with local side tests against all input points. This makes the hull a good example of the chapter theme: a data structure should carry a certificate that can be audited.
Triangulations
empty circumcircles prefer well-shaped triangles

Delaunay Triangulation Replaces Support With Emptiness

Local Rule

An edge shared by two triangles is locally Delaunay when the opposite vertex of either triangle is outside or on the circumcircle of the other.

Flip View

If a quadrilateral violates the empty-circle test, flip the diagonal. Repeated local repairs move toward a triangulation with larger small angles.

Degeneracy

Four cocircular points do not force a unique diagonal. The implementation must choose and record a tie policy.

Check

Sample each triangle circumcircle. No other input vertex should lie strictly inside it, up to the declared tolerance.

Delaunay is certified by empty circlesVoronoi adjacency is the dual viewpoint
Make the contrast with hulls explicit. A hull edge is certified by a support halfspace, while a Delaunay triangle is certified by an empty circle. The flip picture is useful because students can see a local repair: a bad diagonal is not morally bad, it simply violates the circumcircle predicate.
Dual Structure
extreme points and empty regions

Hulls And Delaunay Meshes Audit Different Extremes

Hull Boundary

Extreme points are visible from some direction. A support line moves until it first touches the data, producing a boundary vertex or edge.

Check: each reported edge has all points on the allowed side.

Delaunay Interior

Triangles are accepted when their circumcircles are empty. The strongest information is not only the boundary, but the adjacency among interior samples.

Check: each circumcircle excludes every nonincident sample.

Graphics Use

Hulls simplify collision and broad-phase bounds; Delaunay meshes support interpolation, remeshing, terrain models, and nearest-neighbor reasoning.

Check: downstream quantities should not depend on input order.

Hull and Delaunay routines are predicate amplifiersThe invariant determines the validation harness
This slide is a synthesis checkpoint. Hulls and Delaunay triangulations can look like different chapters, but both are ways to amplify local predicates into reusable structures. Ask students to name the certificate before naming the algorithm. If they can name the certificate, they can design a check and debug failures.
Polygon Partitioning
make hard regions into easy pieces

Partitioning Converts One Difficult Polygon Into Many Simple Ones

Why Partition

Many operations are easier on triangles, convex pieces, or monotone pieces than on an arbitrary simple polygon with reflex vertices.

Diagonal Rule

A candidate diagonal must connect visible vertices, stay inside the polygon, and not cross existing boundary edges or earlier diagonals.

Triangulation Check

For a simple polygon with \(n\) vertices and no holes, a triangulation has \(n-2\) triangles and \(n-3\) internal diagonals.

Area gives a useful residual: the sum of triangle signed areas should equal the polygon signed area up to tolerance.

Partitioning is controlled simplificationResidual: area of pieces equals area of original
Describe partitioning as a deliberate change of representation. The original polygon is not discarded; its boundary and area must be recoverable from the pieces. This is a good place to connect algorithms to validation: counting triangles is useful, but area preservation catches many wrong diagonals and orientation errors.
Bounding Primitives
fast filters with geometric certificates

Minimum Bounds Are Compact Certificates, Not Just Boxes

Rotating Calipers

For a convex polygon, candidate minimum rectangles occur when one rectangle side aligns with a hull edge. The hull reduces a continuous search to finitely many events.

Smallest Circle

A minimum enclosing circle is supported by either two antipodal boundary points or three boundary points defining the circle.

Use In Graphics

Bounds accelerate collision, culling, spatial indexing, and level of detail decisions. A bad bound is not wrong if it contains the object, but it may be expensive.

Bounds trade tightness against construction costSupport points explain why a bound is minimal
Emphasize that bounding primitives are part of the computational geometry toolbox because they sit between exact geometry and fast rejection tests. The minimal rectangle and minimal circle both have small support certificates. In practice, students should distinguish containment correctness from optimality, because a nonminimal bound can still be a valid accelerator.
Measurement
signed sums reveal orientation

Area And Volume Formulas Are Orientation Audits

Shoelace Area

\(A = \frac{1}{2}\sum_i (x_i y_{i+1} - x_{i+1} y_i)\)

The sign records boundary orientation. The magnitude records the enclosed area when the polygon is simple.

Polyhedral Volume

Closed oriented faces can be decomposed into signed tetrahedra. If face orientation is inconsistent, cancellations reveal the error.

Diagnostics

Measurement formulas are excellent final checks because they are invariant under translation, cyclic indexing, and triangulation choices when implemented correctly.

Measurement is a validation toolSign conventions make bugs visible
Treat formulas here as diagnostic instruments, not as isolated facts. Signed area and signed volume both expose orientation decisions. A figure may look right while its vertex order is inconsistent, but a signed sum will usually reveal the inconsistency. This connects measurement back to representation and boundary convention.
Degeneracy And Robustness
near zero is a design problem

Robust Geometry Starts By Naming Ambiguity

Common Ambiguities

  • Point nearly on an edge or plane.
  • Two intersections nearly coincide.
  • Four points nearly cocircular.
  • Duplicated or nearly duplicated input vertices.

Design Response

Return richer classifications, record tolerance, and make tie breaking deterministic. The caller should know when a result is exact, conventional, or uncertain.

Testing Response

Perturb the same geometric scene by translation, rotation, input order, and small noise. The intended invariant should survive.

Degeneracy is part of the specificationDeterministic conventions are easier to debug
This is the engineering hinge of the lecture. Exact mathematical statements often assume generic position, while graphics data arrives with duplicate vertices, nearly parallel edges, and finite precision arithmetic. The goal is not to scare students away from algorithms; it is to make them specify what happens near zero and test those choices.
From Chapter To Pipeline
modeling, rendering, collision, meshing

A Reliable Geometry Pipeline Keeps Certificates Nearby

Modeling

Boolean operations and containment tests decide what material remains. The certificate is a classified arrangement of boundary fragments.

Meshing

Triangulation and Delaunay checks convert samples into surfaces or domains. The certificate is local emptiness plus consistent adjacency.

Acceleration

BSP trees and bounding primitives reduce query cost. The certificate is containment of primitives in the regions or bounds that claim them.

Measurement

Area and volume residuals catch orientation, duplication, and missing-face errors after the visible geometry has been assembled.

Good geometry code reports why the result is geometricKeep predicates, structures, and residuals connected
Use this slide to translate the chapter into software architecture. A geometry pipeline should not throw away its reasons. When a modeler performs a Boolean operation, or a mesher builds triangles, the later stages need enough state to audit the result. This idea helps students design debuggable tools rather than opaque geometric black boxes.
Applied Lab
small scene, visible invariant, numeric residual

Lab Pattern: Build, Draw, Perturb, Check

1. Build

Choose a compact synthetic scene: a polygon with one reflex vertex, a point set with a cocircular quartet, or two overlapping polygons.

2. Draw

Show the active features: splitter lines, ray crossings, hull edges, triangulation edges, support points, or signed-area fans.

3. Perturb

Translate, rotate, reorder, and add small noise. The visual should change only in ways allowed by the geometric convention.

4. Check

Write an assertion that matches the concept: containment preserved, empty circle satisfied, pieces cover area, or bounds contain all points.

What To Carry Forward

Predicates

Orientation, side, crossing, and empty-circle tests are the atomic decisions. Their zero policy is part of the algorithm.

Structures

BSP trees, hulls, triangulations, and partitions organize many local decisions into reusable spatial data.

Bounds

Minimum rectangles, circles, boxes, and other bounds accelerate queries while carrying support or containment certificates.

Measurements

Area and volume formulas are final residuals that reveal orientation, coverage, and consistency problems.
