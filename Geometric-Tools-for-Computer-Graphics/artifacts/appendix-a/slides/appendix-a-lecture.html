Linear Solvers Need A Residual Contract

03
Algorithmic structure
What the solver must report
\(Ax=c,\qquad r = Ax-c,\qquad \|r\|_2 \le \tau\)
  • Pivoting is a numerical geometry choice: it changes arithmetic exposure while preserving the solution set.
  • Back substitution is only meaningful if small divisors are treated as signals, not surprises.
  • The displayed intersection, projection, or fit should cite the residual that certifies it.
Failure mode: plausible coordinates can still describe the wrong geometric object when roundoff dominates the pivot step.
A.1 Solving Linear Systemstriangular solve - Gaussian elimination - pivoting
This is the first concrete numerical contract. A linear solve is not done when a vector of unknowns appears; it is done when the algorithm can report a small residual, a defensible pivot history, and a warning when conditioning makes the displayed geometry unreliable.

Polynomial Intersections Are Candidate Pipelines

04
Eliminate, solve, substitute, reject
Graphics examples
  • Line or ray against polynomial patch: reduce to roots along a parameter.
  • Two implicit quadrics: eliminate variables, then validate candidate points.
  • Surface contact: a repeated or nearly repeated root is a geometric event.
Numerical contract

Elimination can introduce extraneous candidates and coefficient growth. A robust implementation keeps the algebraic candidate list separate from the final geometric classification.

\(p \text{ accepted when } \max_i |F_i(p)| \le \tau\)
A.2 Systems of Polynomialselimination is not the same as validation
Polynomial systems are shown as an elimination pipeline because graphics intersections often hide several variables. Emphasize that eliminating a variable can raise degree and introduce candidate roots that still need substitution checks. The solver therefore returns a set of candidates plus residual tests, not just roots.

Decompositions Expose What A Matrix Is Doing

05
QR

Use when triangular solves, least squares, or stable orthogonal bases are the object of interest.

SVD

Use when rank, anisotropic scale, or a best low-dimensional approximation matters.

Polar

Use when a transform should be interpreted as rotation plus symmetric stretch.

\(A = QR,\qquad A = U\Sigma V^T,\qquad A = QS\)
A.3 Matrix Decompositionsbasis - stretch - rank - reconstruction
Treat decompositions as geometric lenses. QR separates orthogonal directions from triangular coefficients, SVD exposes principal stretching and rank, and polar decomposition factors a general linear map into rotation plus symmetric stretch. The same matrix can be understood differently depending on the diagnostic question.

A representation is part of the algorithm state. Renormalizing, choosing a branch, or reorthogonalizing should be an explicit step.
A.4 Representations of 3D Rotationsmatrix - axis-angle - quaternion
This slide should prevent a common implementation mistake: rotation representations are not interchangeable storage formats. Matrices compose directly but drift from orthogonality, axis-angle is compact but has branch choices, and quaternions are efficient for interpolation when they are kept on the unit sphere.

Root Finding Balances Certificates And Speed

07
Brackets and Newton steps
Stable quadratic form
\(q=-\frac{1}{2}\left(b+\operatorname{sign}(b)\sqrt{b^2-4ac}\right)\)
\(x_1=q/a,\qquad x_2=c/q\)

Use the expression that avoids subtracting nearly equal numbers, then verify by substitution.

Stopping rule
  • small function value: \(|f(t)| \le \tau_f\)
  • small update: \(|\Delta t| \le \tau_t(1+|t|)\)
  • bounded iteration count with a declared fallback
A.5 Root Findingbrackets - Newton steps - stable quadratics
Root finding is about controlling a search, not hoping an iteration lands correctly. Brackets give a certificate that a sign change has been isolated, Newton steps give speed when derivatives behave, and the stable quadratic formula shows why algebraically equivalent expressions can differ numerically.

Minimization Adds Geometry To Search

08
Contours, directions, and curvature
Quadratic local model
\(f(x) \approx f(x_0)+g^T s+\frac{1}{2}s^T Hs\)

The Hessian shape explains why the same step length may be too timid in one direction and too aggressive in another.

One dimension bracket, sample, and refine along a parameter.
Many dimensions choose a direction, then run a line search.
Quadratic form eigenvalues describe curvature and conditioning.
Constraints residuals must include feasibility, not only objective decrease.
A.6 Minimizationobjective, direction, curvature, feasibility
Present minimization as root finding with geometry attached. The contour picture gives students a place to see line search, direction choice, and stopping rules. For quadratic forms, the eigenstructure determines curvature, so the algorithm should report both the candidate point and the residual in the gradient or constraints.

The residual is orthogonal to every allowed change in the fitted model. This is the geometric meaning of the algebra.

A.7 Least Squares Fittingmodel parameters plus residual geometry
Least squares fitting should be taught as a geometric projection problem. The model parameters are useful, but the residual arrows are the audit trail. A renderer or modeler needs to know whether the point cloud is close to the fitted primitive or whether the fit is hiding anisotropic error.

Contract

The curve drawing is not only a polyline. It is a polyline plus a declared tolerance and the stopping rule that made the tolerance meaningful.

A.8 Subdivision of Curvessampling rules encode geometric assumptions
Subdivision turns a continuous curve into a finite drawing, so the stopping rule is part of the geometry. Uniform samples are easy, arc length samples are perceptually steadier, midpoint distance catches chord error, and variation checks ask whether tangent direction has stabilized enough for the task.

Use the calculus slide to reconnect numerical methods with the earlier geometry chapters. Four Ways A Plausible Picture Can Be Wrong

12

Notebook artifact: a compact diagnostic that records the numerical invariant for the lesson.

Conditioning tiny perturbations of input produce large output changes.
Representation two encodings describe the same geometry but carry different branch choices.
Stopping rule an iteration stops because it ran out of budget, not because it converged.
Missing invariant the figure is drawn before the defining equation is checked.
Tolerance policy

A useful tolerance has units, scale, and a named residual. A Boolean result without those three pieces is a debugging liability.

Course-wide diagnostic habitpictures need residuals
This warning slide is about professional practice. Many bugs survive because the picture looks plausible while the residual is large or the coordinate convention changed. Ask students to classify each failure by the violated contract: conditioning, representation, stopping rule, or an invariant that was never checked.

The point is to make a small computation accountable: it must say what was modeled, what was perturbed, and why the resulting number supports the picture.

What Appendix A Carries Forward

14
Algorithmic contracts
  • Linear and polynomial solvers need residuals, rank information, and candidate validation.
  • Decompositions and rotations make representation choices visible.
  • Root finding and minimization need both convergence checks and geometric interpretation.
  • Fitting and subdivision must report the approximation error they control.
Reusable debugging questions
Object What geometric object is represented by the arrays?
Invariant What should remain true after the computation?
Residual Which number checks the claim?
Failure Which degeneracy or convention would break the answer?
