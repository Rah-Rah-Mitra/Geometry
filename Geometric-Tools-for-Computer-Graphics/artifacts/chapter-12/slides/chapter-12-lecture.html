Representation

Plane Equation As A Signed Test

The same four coefficients can describe a surface, a half-space classifier, or a distance oracle once the normal convention is fixed.

Plane Contract
$$P = \{X : n\cdot X + d = 0\}$$

If \(n\) is unit length, \(n\cdot X+d\) is signed distance. If not, divide by \(\lVert n\rVert\) for distance and by \(n\cdot n\) for vector correction.

What Must Be Stored

  • normal length convention
  • choice of positive side
  • units for returned angles
  • degeneracy tolerance
Query Output Residual Check
Project point \(Q\) Point \(Q'\) on the plane \(n\cdot Q' + d = 0\)
Project vector \(v\) Tangent vector \(w\) \(w\cdot n = 0\)
Construct from points Normal \((P_1-P_0)\times(P_2-P_0)\) all three plane values vanish
Keep the representation contract explicit before showing any computation. A plane equation is not just four numbers; the normal length, sign convention, and distance coefficient determine whether later projections and angles have the intended units and orientation.
Projection Of A Point Onto A Plane

Correct The Signed Plane Violation

The point moves only along the normal direction; tangential coordinates are preserved.

Projection Formula
$$Q' = Q - \frac{n\cdot Q + d}{n\cdot n}\,n$$

Why It Works

  • \(n\cdot Q+d\) is the signed equation error.
  • \((n\cdot n)^{-1}n\) scales that error into a vector correction.
  • The residual \(Q-Q'\) is parallel to \(n\).
Walk the point projection formula as a decomposition. The signed numerator measures how far the point violates the plane equation, and division by the squared normal length makes the correction vector independent of normal scaling. The invariant is that the corrected point satisfies the plane equation.
Projection Of A Vector Onto A Plane

Remove The Normal Component

A vector projection depends on the plane normal, not the plane offset \(d\).

Tangent Projection
$$w = v - \frac{v\cdot n}{n\cdot n}\,n$$

For a unit normal, this becomes \(w=v-(v\cdot \hat n)\hat n\).

No point \(Q\) is needed.
No plane offset \(d\) is needed.
Audit with \(w\cdot n=0\).
Emphasize that vector projection is translation-free. The plane offset does not appear because a vector has no anchored point to test against the plane equation. The useful check is perpendicularity: after removing the normal component, the remaining vector should dot to zero with the normal.
Angle Query Pipeline

Normalize, Clamp, Then Interpret

The dot product is a cosine only after nonzero inputs are normalized.

Robust Angle Core
$$c=\operatorname{clamp}\!\left(\frac{a\cdot b}{\lVert a\rVert\lVert b\rVert},-1,1\right),\qquad \alpha=\arccos(c)$$

The clamp is not a mathematical shortcut; it is a numerical guard for roundoff around \(-1\) and \(1\).

Zero-length guard: reject or classify before division.

Scale invariant: \(a\) and \(10a\) give the same angle.

Convention: decide degrees/radians and acute/oriented behavior.

For angle queries, the enemy is usually numerical drift near plus or minus one. Normalization makes the dot product interpretable as a cosine, clamping prevents invalid arccos input, and a clear convention decides whether the routine returns an oriented, obtuse, or acute answer.
Angle Between A Line And A Plane

Compute Against The Normal, Then Complement

A line parallel to the plane is perpendicular to the plane normal.

Two Angles
$$\phi=\arccos\!\left(\frac{n\cdot d}{\lVert n\rVert\lVert d\rVert}\right),\qquad \theta=\frac{\pi}{2}-\phi$$

Audit Cases

  • \(d\parallel n\): line is normal to plane, so \(\theta=90^\circ\).
  • \(d\perp n\): line is parallel to plane, so \(\theta=0^\circ\).
  • Scaling \(d\) or \(n\) should not change either angle.
Make the line-plane angle feel like a reuse of the normal-vector angle. First compute the angle between the line direction and the plane normal, then take the complement for the angle against the plane itself. This makes perpendicular and parallel cases easy to audit.
Angle Families

Flats Use Normals; Lines Use Directions

The algebra is the same dot-product core; the meaning changes with orientation conventions.

Plane-Plane Angle

$$\theta=\arccos\!\left(\frac{n_0\cdot n_1}{\lVert n_0\rVert\lVert n_1\rVert}\right)$$

Two planes are compared by their normals. If an undirected angle is desired, use the smaller angle between the two normal lines.

Line-Line Angle

$$\alpha=\arccos\!\left(\frac{d_0\cdot d_1}{\lVert d_0\rVert\lVert d_1\rVert}\right)$$

For lines rather than rays, reversing one direction may turn \(\alpha\) into \(\pi-\alpha\). The API must state the convention.

Here the common pattern is that angles between flats reduce to angles between their normals, while angles between lines reduce to angles between directions. The caution is semantic rather than algebraic: reversing one line direction may change an oriented answer even though the undirected geometry is unchanged.
Constructing Planes

Constraints Must Supply A Nonzero Normal

Different inputs become the same implicit object once a normal \(n\) and offset \(d\) are known.

Point + Normal

\(n\) is given. For point \(Q\), set \(d=-n\cdot Q\).

Check: \(n\cdot Q+d=0\).

Line + Point

The line direction becomes the plane normal through point \(Q\).

Check: line direction is perpendicular to the constructed plane.

Three Points

\(n=(P_1-P_0)\times(P_2-P_0)\), then \(d=-n\cdot P_0\).

Check: all three points evaluate to zero.

The construction panel should be read as a menu of data contracts. A point-normal pair supplies the plane directly, a line plus point uses the line direction as the plane normal, and three points use a cross product whose size warns about near collinearity.

Degeneracy And Tolerance

Short Formulas Still Need Guards

Most production bugs appear when a geometric precondition silently fails.

Failure Mode

  • Normal length is zero or below tolerance.
  • Three input points are coincident or nearly collinear.
  • Dot ratio drifts just outside \([-1,1]\).
  • Line direction is reversed but the API claims an oriented angle.
  • Degrees and radians are mixed in downstream code.

Measurable Guard

  • Check \(n\cdot n>\varepsilon^2\) before division.
  • Check \(\lVert(P_1-P_0)\times(P_2-P_0)\rVert\).
  • Clamp dot ratios before arccos.
  • Expose acute versus directed angle mode.
  • Store units next to returned scalar values.
Production Rule

Do not return a plausible geometric object without also making its convention and residual inspectable. A beautiful drawing can still be the wrong answer.

This is the production engineering slide. The formulas are short, but the failure modes are not: zero normals, almost collinear input points, mixed angle units, and unclamped dot products can all create plausible pictures with wrong classifications. Tie each failure to a measurable guard.
