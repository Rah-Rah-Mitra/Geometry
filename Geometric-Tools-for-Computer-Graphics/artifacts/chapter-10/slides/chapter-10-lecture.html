Core Pattern
squared distance first

The Parameter-Minimization Template

Distance Query

\( \min_{u \in U,\; v \in V} \|X(u)-Y(v)\|^2 \)

Use the squared norm for stable comparison; take a square root only when a metric value is required for reporting.

Return More Than A Scalar

  • closest points \(X(u^\star)\) and \(Y(v^\star)\)
  • parameters \(u^\star, v^\star\)
  • active feature labels: interior, edge, vertex, face
  • residuals and tolerances used to accept the result
All later cases specialize \(U\), \(V\), and the active constraintsNotebook check: residuals and feature tags
This slide supplies the reusable template for the chapter. Distance is minimized as a squared norm over a parameter domain because the square avoids unnecessary roots and exposes stationarity. The important implementation habit is to return the active domain feature together with the numerical distance.
Projection Plus Clamping
line, ray, segment, polyline

Point To Linear Components

Line Projection

\( t_0 = \dfrac{(P-A)\cdot (B-A)}{\|B-A\|^2} \)

Domain Rules

  • line: keep \(t_0\)
  • ray: use \(\max(0,t_0)\)
  • segment: clamp to \(0 \leq t \leq 1\)
  • polyline: evaluate each segment and keep the minimum

Implementation Check

If \(0 < t < 1\), the connector must be perpendicular to the segment direction. If \(t\) is clamped, endpoint status is the feature label.

Boundary conditions carry geometric meaningFeature label: interior, endpoint, or chosen polyline segment
Projecting a point onto a line is the cleanest case, but real graphics queries usually clamp that projection to a ray, a segment, or each segment of a polyline. Stress that the returned parameter is part of the answer because it identifies whether the closest feature is interior or endpoint constrained.
Planar Components
plane -> triangle -> boundary

Point To Triangle Feature Map

Plane Projection

\( P_{\Pi}=P-((P-A)\cdot n)n \)

Projection gives a candidate. Barycentric coordinates decide whether that candidate lies in the triangle or belongs to a boundary subproblem.

Feature Classification

  • \(\alpha,\beta,\gamma \geq 0\): interior or edge on zero coordinate
  • one negative coordinate: nearest edge candidate
  • two negative coordinates: nearest vertex candidate

Notebook check: barycentric coordinates classify triangle features, and the connector from the query point to the active feature is normal only for unconstrained plane projection.

Signed plane distance is not the whole triangle distanceBarycentric signs select the active feature
For point-to-triangle distance, first inspect the plane projection, then classify its barycentric coordinates. A projection inside the triangle gives an interior closest point. A projection outside delegates to an edge or vertex query. The notebook artifact makes that feature change visible without relying on a source figure.
Linear Component Pairs
two parameters, four boundaries

Segment-Segment Closest Connector

Two-Parameter Query

\( \min_{0\leq s,t\leq 1}\|A+sU-B-tV\|^2 \)

Interior Condition

When \(s\) and \(t\) are both interior, the connector is perpendicular to both \(U\) and \(V\). This is the geometric test behind the unconstrained linear solve.

Degenerate Cases

Parallel or nearly parallel directions make the unconstrained solve ill-conditioned. Robust implementations compare boundary candidates and record the tolerance branch used.

Active set: interior-interior, endpoint-interior, endpoint-endpointNotebook check: closest connector is perpendicular to active unconstrained features
Linear component pairs are two-parameter minimization problems. If both optimal parameters are interior, the connector is orthogonal to both directions. If either parameter clamps to a boundary, the problem becomes a lower-dimensional point-to-component query. This is the first place degeneracy and near-parallelism need explicit handling.

Coordinate Frames
make the hard box axis-aligned

Oriented Box Local Coordinates

Change Of Frame

\(p'=( (P-C)\cdot u,\; (P-C)\cdot v,\; (P-C)\cdot w )\)

Clamp In Local Coordinates

For each component, clamp \(p'_i\) to the interval \([-e_i,e_i]\). The local closest point \(q'\) is then mapped back by \(Q=C+q'_1u+q'_2v+q'_3w\).

Invariant

The squared distance \(\|P-Q\|^2\) must match \(\|p'-q'\|^2\). If it does not, the frame is not orthonormal or a transform convention is wrong.

Coordinate transforms should simplify geometry, not hide itNotebook check: local-frame and world-frame distances agree
Oriented boxes illustrate the power of choosing the right coordinate frame. Transform the point into box coordinates, clamp each component to the half-extent interval, and transform the closest point back. The sanity check is that world-space distance and local-frame distance agree to numerical tolerance.
Bounded 3D Regions
containment before distance

Polyhedron And Frustum Workflow

First Branch

If the point is inside the solid, the distance to the solid is zero. Only outside points need boundary feature evaluation.

Convex Polyhedron

Signed face tests identify whether the point lies inside all supporting halfspaces. Outside faces give a small candidate set; each candidate becomes a point-to-planar-component query.

Frustum Or View Volume

Choose a coordinate system where the planes or scale factors are simple, then reuse the same inside/outside and boundary candidate logic.

Interior is a distance answer, not a failed queryCandidate faces reduce work and improve diagnostics
For polyhedra and frusta, containment changes the answer before any minimization starts: an interior point has zero distance. Outside points are handled by candidate faces and boundary features. Students should notice the production pattern: cheap rejection or containment first, then exact feature distance only where needed.
Nonlinear Surfaces
normal equation plus solve

Quadrics And Ellipsoid Residuals

Implicit Surface Rule

For \(F(X)=0\), a smooth unconstrained closest point satisfies \(P-X=\lambda\nabla F(X)\).

General Quadric

Substituting the normal condition turns geometry into algebra. Depending on representation, the solver may face a high-degree polynomial or a constrained numerical root.

Ellipsoid Habit

Scale to a convenient frame, solve for the multiplier, then report both the point and the residual that verifies the normal condition.

Nonlinear distance needs convergence evidenceResiduals are part of the mathematical output
Quadrics shift from clamping to constrained stationarity. At a closest point on a smooth implicit surface, the displacement from the query point is normal to the surface. For ellipsoids this leads to a one-variable root or iterative solve, so residuals and convergence criteria become part of the lesson.
Numerical Diagnostics
domain, boundaries, stationarity

Polynomial Curves And Surfaces

Curve Stationarity

\( \frac{d}{dt}\|C(t)-P\|^2 = 2(C(t)-P)\cdot C'(t)=0 \)

Surface Stationarity

\( (S(u,v)-P)\cdot S_u=0,\quad (S(u,v)-P)\cdot S_v=0 \)

Audit Boundary Candidates

Stationary points inside the parameter domain must be compared with boundary curves, corners, and any constrained intervals. A low residual is not enough if the domain was wrong.

Numerical minimization must name its domainNotebook check: iterative residuals decrease for the shown surface example
Polynomial curves and surfaces are the chapter's reminder that exact geometry often becomes numerical optimization. The plotted diagnostic shows a valid parameter interval and a squared-distance profile. The minimum is trustworthy only when the parameter domain, stationarity residual, and boundary comparisons have all been checked.
Convex Bodies
support mapping and simplex

GJK As A Distance Certificate

Minkowski Difference

\( \operatorname{dist}(A,B)=\operatorname{dist}(0,A-B) \)

GJK Loop

  1. Ask for a support point in a search direction.
  2. Add it to a simplex in the Minkowski difference.
  3. Replace the direction by the vector toward the closest point on that simplex.

Certificate

The final simplex and closest point to the origin explain the distance or certify intersection when the origin is enclosed.

Convex distance without enumerating all feature pairsUseful for collision detection and conservative advancement
GJK reframes distance between convex bodies through the Minkowski difference. Instead of enumerating every pair of features, the algorithm asks support queries and keeps the simplex closest to the origin. The visible simplex should be read as an evolving certificate, not as a decorative convex hull.
Surface-Constrained Distance
ambient chord versus surface path

Geodesic Distance Is Intrinsic

Two Different Questions

Euclidean distance uses the straight chord in \(\mathbb{R}^3\). Geodesic distance restricts the path to the surface and minimizes path length there.

Computational Models

  • smooth surface: differential equation or variational solve
  • triangle mesh: graph path, unfolding, fast marching, or heat-style method
  • debug output: path length, residual, and mesh resolution sensitivity

Important Distinction

A point can be close through space but far along the surface when holes, folds, ridges, or constraints block the intrinsic path.

Ambient closest-point queries and intrinsic path queries should not be conflatedSurface constraints change the metric
Geodesic distance is intrinsic to a surface, so it can differ sharply from the ambient Euclidean chord. Use this slide to separate the two questions: closest point in three-dimensional space versus shortest path constrained to a surface. Mesh algorithms approximate the latter through graph or heat-style propagation.

Production Sanity Checklist

Applied Lab Prompt

Choose one primitive, one tolerance, and one coordinate frame. Perturb a nearly degenerate case, render the active features, and record which changes are geometric rather than representation artifacts.

  • Closest connector is perpendicular to active unconstrained features.
  • Barycentric or local coordinates classify the returned feature.
  • World-frame and local-frame distances agree after transforms.
  • Iterative residuals decrease or explain why they stop.
  • Interior, boundary, and degenerate branches are visible in the return state.
