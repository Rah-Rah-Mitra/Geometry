Closedness Is Not Automatic
relative interiors behave better

Why Closedness Can Fail

Stable Rule

\(\operatorname{ri}(A C)=A(\operatorname{ri} C)\).

One-Sided Closure

\(A(\operatorname{cl} C)\subseteq \operatorname{cl}(A C)\), and equality can fail.

Failure Mode

A sequence \(x_k\in C\) has \(A x_k\to y\), but \(x_k\) has no convergent subsequence in the source.

Two Repairs

  • Use a relative-interior qualification.
  • Use recession cones to rule out hidden escape.
Closedness is a compactness substituteRecession directions explain the missing compactness
Contrast relative interiors with closures before stating any test. Relative interiors behave almost functorially under linear maps, while closure has only a one-sided inclusion. That gap is not technical bookkeeping; it is the place where missing endpoints, nonattained infima, and lower semi-continuity failures appear.
Projection Warning
closed source, nonclosed image

A Closed Set Can Project To A Nonclosed Set

Model Set

\(C=\{(u,v):u>0,\ uv\ge 1\}\), \(A(u,v)=u\).

Projection

\(A C=(0,\infty)\), so \(0\in\operatorname{cl}(A C)\setminus A C\).

What Escapes?

The points \((1/n,n)\) stay feasible, their projections approach zero, and the \(v\)-coordinate runs off to infinity.

Lesson

The missing endpoint is not a geometric accident. It is a recession-direction certificate.

Artifact: assets/projection-closedness-warning.svgNotebook invariant: projection has infimum zero but no point with projected coordinate zero
Use the hyperbolic epigraph as the basic warning. The set is closed because no finite point sits over u equals zero, but the projection records only positive u values. The sequence u equals one over n approaches the missing endpoint while the forgotten coordinate goes to infinity.
Qualification I
relative interior anchor

Relative Interior Qualification

Finite Sums

\(\operatorname{cl}(f_1+\cdots+f_m)=\operatorname{cl}f_1+\cdots+\operatorname{cl}f_m\)

when the relative interiors of the domains meet.

Suprema

\(\operatorname{cl}\sup_i f_i=\sup_i \operatorname{cl} f_i\)

when a common relative-interior point has finite supremum.

Mechanism

From an anchor \(x_0\), radial limits toward \(y\) let closure pass through the operation term by term.

Artifact: assets/ri-qualification-map.svgQualification prevents boundary-only overlap
This is the first positive qualification. A shared relative-interior point lets closure be tested by radial limits from a genuine interior anchor. For function sums and suprema, the anchor prevents the operation from being supported only at incompatible boundary pieces.
Qualification II
Theorem 9.1 root test

Recession Cone Test

Root Criterion

If every \(z\in \operatorname{rec}(\operatorname{cl} C)\cap \ker A\) is lineality, then

\(\operatorname{cl}(A C)=A(\operatorname{cl} C)\).

Common Sufficient Test

\(C\) closed and \(\operatorname{rec} C\cap \ker A=\{0\}\quad\Longrightarrow\quad A C\text{ closed}.\)

Why Lineality Is Harmless

A reversible direction can be moved both forward and backward inside the closed set, so it can be quotiented away without creating an endpoint gap.

Check Record

assets/recession-closedness-test.json stores the counterexample and safe cases used in this deck.

Diagnostic: killed recession direction versus reversible linealityRecession cone notation follows the notebook translation guide
State the root test in operational language. A linear image loses closedness when a recession direction is invisible to the map and is not reversible lineality. If every killed recession direction is reversible, or if the kernel meets the recession cone only at zero, the image cannot hide escape to infinity.
Sums As Images
addition map

Sum Closedness

Reduction

C_1+\cdots+C_m=A(C_1\times\cdots\times C_m),

where \(A(x_1,\ldots,x_m)=x_1+\cdots+x_m\).

Closedness Test

If \(z_i\in\operatorname{rec} C_i\) and \(\sum_i z_i=0\), then each \(z_i\) must be lineality.

Two-Set Shortcut

If \(C_1\) has no recession direction opposite one of \(C_2\), then \(C_1+C_2\) is closed. A bounded summand automatically satisfies this.

Artifact: assets/sum-closedness-ledger.svgCorollaries 9.1.1 and 9.1.2, paraphrased as a diagnostic
Explain the sum rule by reducing it to the root test. Put the product set in the source and use the addition map. A null direction for the addition map is precisely a cancellation among recession directions, so closedness is protected when cancellations are only lineality.
Images And Fibers
fiber compactness without compactness

Linear Image Closedness

Checklist

  • Replace \(C\) by \(\operatorname{cl} C\) if needed.
  • Compute or bound \(\operatorname{rec}(\operatorname{cl} C)\).
  • Intersect with \(\ker A\).
  • Permit only reversible lineality directions.
Consequence

\(\operatorname{rec}(A(\operatorname{cl} C))=A(\operatorname{rec}(\operatorname{cl} C))\)

under the same root-test hypothesis.

Counterexample Diagnosis

The vertical direction is in \(\ker A\), is a recession direction, and is not reversible. That is exactly the hidden fiber escape.

Artifact: assets/linear-image-counterexample.svgThe theorem is a fiber-boundedness test in recession language
Turn the theorem into a checklist an analyst can use. First close the source if needed, then inspect recession directions, then intersect them with the kernel of the map. The quotient by lineality is the reason reversible directions are harmless while one-way directions create missing limits.
Cones And Hulls
homogeneous closedness

Cone Criteria

Cone Sum

Closed convex cones add cleanly when zero-sum recession cancellations are only lineality.

Generated Cone

\(\operatorname{cl} K=K\cup\operatorname{rec} C\)

for the cone \(K\) generated by a closed \(C\) not containing the origin.

Bounded Generator

If \(C\) is bounded and avoids the origin, then \(\operatorname{rec} C=\{0\}\), so the generated cone is closed.

Common Recession Hull

Closed sets with the same recession cone have a closed convex hull with that same recession cone.

Theorems 9.6 and 9.8, paraphrased for lecture useCones turn behavior at infinity into ordinary membership
Cones make the recession bookkeeping visible because the set already equals its own recession model. The section uses this to close sums of cones, to describe the closure of a generated cone, and to show why bounded generators away from the origin are a safe special case.
Functions Via Epigraphs
closedness becomes lower semi-continuity

Epigraph Perspective

Infimal Image

\((A h)(y)=\inf\{h(x):A x=y\}\).

Epigraph Map

B(x,\mu)=(A x,\mu),\qquad B(\operatorname{epi} h)=\operatorname{epi}(A h).

Danger Direction

A downward vertical recession in the image epigraph means the infimum is approached without being attained.

Positive Result

Under the recession condition, \(A h\) is closed and proper, its recession function is the image recession function, and each finite value is attained.

Theorem 9.2 recasts closed images as lower semi-continuity and existenceEpigraphs turn optimization into set geometry
Move from sets to functions by looking at epigraphs. The infimal image Ah is closed when the epigraph image is closed and has no downward vertical recession. That same condition gives attainment, because each vertical fiber over y then meets the epigraph in a closed lower half-line.
Counterexample Lab
repair the projection

Counterexample Lab

Baseline Failure

\(C=\{(u,v):u>0,\ uv\ge 1\}\) is closed, but \(A(u,v)=u\) forgets the unbounded coordinate and produces \((0,\infty)\).

Repair 1: Bound The Fiber

Add \(v\le M\). Then \(u\ge 1/M\), so the projection is a closed ray \([1/M,\infty)\).

Repair 2: Change The Map

Keep a coordinate that detects the escaping vertical direction. The null recession obstruction disappears.

Repair 3: Use A Qualification

For function operations, a shared relative-interior point can replace direct closedness of each intermediate expression.

Lab instruction: change one hypothesis, then predict the closureGood counterexamples identify which hypothesis was doing work
Invite students to modify the bad example rather than just memorize it. Bounding the forgotten coordinate, removing the vertical recession direction, or projecting along a different map repairs the pathology. Leaving the upward null recession direction in place keeps the missing endpoint.

Recap
closedness as diagnosis

Recap

1. Name The Operation

Image, sum, epigraph projection, cone generation, or convex hull.

2. Locate Escape

Find recession directions that the operation cannot see.

3. Check Qualification

Lineality, trivial kernel intersection, common relative interior, or bounded generator.

4. State Payoff

Closed image, closed sum, lower semi-continuity, attainment, or closed hull.
