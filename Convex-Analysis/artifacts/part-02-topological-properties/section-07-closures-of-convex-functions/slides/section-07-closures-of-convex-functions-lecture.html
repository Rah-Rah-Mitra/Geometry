Closures Of Convex Functions

Lower semicontinuity becomes geometric: close the epigraph, read the new lower boundary, and track which boundary values were forced by convex limits.

Epigraph First
closed hull = closed epigraph

Epigraph Closure

Definition

\(\operatorname{epi} f=\{(x,\mu):\mu\ge f(x)\}\).

Closure Rule

\(\operatorname{epi}(\operatorname{cl} f)=\operatorname{cl}(\operatorname{epi} f)\).

What Changes

The epigraph can gain limit points along its lower boundary; the associated function value can only decrease.

What Does Not Change

Interior samples remain fixed for proper convex functions. The repair is localized to relative boundary behavior.

Asset: epigraph-closure.svgKey invariant: \(\operatorname{cl} f\le f\)
Use the picture to separate graph intuition from epigraph intuition. The graph may look like a horizontal ray, but the mathematical object is the filled region above it. Closing that region inserts the missing endpoint and lowers the boundary value there without changing any interior sample.
No Downward Surprise
Theorem 7.1 lens

Lower Semicontinuity

Sequential Test

If \(x_k\to x\), then \(f(x)\le\liminf_k f(x_k)\).

Equivalent Pictures
  • sequential lower semicontinuity
  • closed sublevel sets \(\{x:f(x)\le\alpha\}\)
  • closed epigraph \(\operatorname{epi}f\)

Convex Analysis Use

For convex functions, this is the topological property that makes limiting arguments and level-set constraints stable.

Analytic statement, set statement, and epigraph statement agreeLower closure makes the three diagnostics true
Lower semicontinuity is the no downward surprise condition. If a sequence approaches x, the value at x must not sit above the limiting lower envelope. The useful theorem is that this analytic statement, closed sublevel sets, and closed epigraphs are three views of the same condition.
Relative Boundary
radial calculation

Boundary Limit Values

Boundary Formula

For \(x\in\operatorname{ri}(\operatorname{dom}f)\), \(y\in\operatorname{cl}(\operatorname{dom}f)\),

\((\operatorname{cl}f)(y)=\lim_{\lambda\uparrow 1} f((1-\lambda)x+\lambda y)\).

One-Dimensional Trace

Convexity turns the path from \(x\) to \(y\) into a convex function of \(\lambda\).

Boundary Discipline

The value at \(y\) is not freely chosen once the interior trace has a limiting height.

Asset: boundary-limit-values.svgEndpoint values are computed from inside the domain
Now specialize to a proper convex function and pick an anchor in the relative interior of the domain. Moving from the anchor toward any boundary point gives a one-dimensional convex trace. The closure value at the endpoint is the ordinary radial limit along that trace.
Operation
lower semicontinuous hull

Closed Hull Operation

Closed Hull

The closure of a convex function is the convex function read from the closed epigraph.

Order

\(\operatorname{cl} f\le f\), and \(f_1\le f_2\Rightarrow \operatorname{cl}f_1\le \operatorname{cl}f_2\).

Infimum

The original function and its closed hull have the same infimum over \(\mathbb{R}^n\).

Where It Acts

For proper convex functions, only relative boundary values can change.

Asset: closed-hull-operation.svgCheck record: closure-function-checks.json
The closed hull is not a smoothing algorithm and it is not a pointwise average. It is a geometric projection of the closed epigraph back to a function. That is why cl f is below f, has the same infimum, and changes values only where the epigraph had missing boundary.
Properness
avoid degenerate infinities

Proper Functions

Proper Convex Function

A convex function is proper when its effective domain is nonempty and it never takes the value \(-\infty\).

Closure Theorem

If \(f\) is proper and convex, then \(\operatorname{cl}f\) is closed, proper, convex, and agrees with \(f\) away from relative boundary defects.

Interior Agreement

\(\operatorname{cl}f=f\quad\text{on}\quad\operatorname{ri}(\operatorname{dom}f)\).

Improper Branch

If a convex function ever reaches \(-\infty\), it is forced to be \(-\infty\) on the relative interior of its domain.

Closed Improper Functions

The only closed improper convex functions are the constant \(+\infty\) and constant \(-\infty\) functions.

Proper: nonempty finite domain and no minus infinityImproper behavior is quarantined by convention
Pause on properness because it prevents two misleading edge cases. A proper convex function has a nonempty finite domain and no minus infinity values. Under closure it remains proper and agrees on the relative interior; functions that hit minus infinity belong to the special improper branch.
Examples
sets as functions

Indicator And Support Examples

Indicator

\(\delta_C(x)=0\) for \(x\in C\), and \(+\infty\) otherwise.

Closure Can Change It

If \(C\) is convex but open at its boundary, closing the epigraph turns \(\delta_C\) into \(\delta_{\operatorname{cl}C}\).

Support Function

\(\sigma_C(u)=\sup_{x\in C}\langle u,x\rangle\).

Closure Often Invisible

Continuous linear probes have the same supremum on \(C\) and \(\operatorname{cl}C\), so support functions already see the closed set.

Indicator closure changes boundary membershipSupport functions are insensitive to closure of the set
Indicators and support functions are a useful contrast. The indicator of an open convex set visibly changes when closure adds boundary points. A support function already takes suprema of continuous linear probes, so replacing a set by its closure leaves the support values unchanged.
Boundary Defect
closure changes the function

Discontinuous Convex Example

Model

\(f(x)=0\) for \(x>0\), and \(f(x)=+\infty\) for \(x\le 0\).

Convex But Not Closed

The epigraph is convex, but it misses the limiting point \((0,0)\).

Closed Hull

\((\operatorname{cl}f)(0)=0,\quad \operatorname{cl}f=f\text{ elsewhere.}\)

Inspection Target

A sequence \(x_k=1/k\) has values \(0\), so the endpoint value \(+\infty\) cannot be lower semicontinuous.

Asset: discontinuity-example.svgCheck: lsc-check-ledger.json
This is the smallest example where the operation has teeth. The function is zero on the open ray and infinite at the endpoint, so convexity alone does not force lower semicontinuity. Closing the epigraph adds exactly one endpoint value and leaves the rest of the ray alone.

Closure And Conjugacy Preview

Conjugate

\(f^*(u)=\sup_x(\langle u,x\rangle-f(x))\).

Later Destination

\(f^{**}=\operatorname{cl}f\)

for the closed convex representative under the closure convention.

Geometric Meaning

Conjugacy stores all affine lower support information; taking the biconjugate rebuilds the closed epigraph.

Why Section 7 Matters

Duality cannot remember artificial open-boundary assignments that disappear under epigraph closure.

Bridge to later conjugacy theoryClosure removes artificial boundary assignments before dual reconstruction
Do not develop conjugacy yet, but show why this section is not an isolated technicality. The conjugate sees supporting affine functions, and the biconjugate later returns the closed convex representative. The closure convention is chosen so that this duality statement keeps working cleanly.
Level Sets
horizontal slices

Slices Of Epigraphs

Level-Set Closure

\(\operatorname{cl}\{x:f(x)\le\alpha\}=\{x:(\operatorname{cl}f)(x)\le\alpha\}\)

for proper convex \(f\) and \(\alpha>\inf f\).

Relative Interior

\(\operatorname{ri}\{x:f(x)\le\alpha\}=\{x\in\operatorname{ri}(\operatorname{dom}f):f(x)<\alpha\}\).

Teaching Interpretation

A strict height cut through the relative interior gives the open part; closing the epigraph supplies the boundary of the slice.

Level set formulas require convexity and \(\alpha>\inf f\)Horizontal slice = inequality set
Horizontal slices translate epigraph geometry into level-set geometry. For levels above the infimum, the closed slice is controlled by cl f, while the relative interior of the slice is obtained by strict inequality inside the relative interior of the domain. This is a practical theorem for inequalities.

Guardrails
what not to infer

Failure Modes

Closed Function, Open Domain

The function \(f(x)=1/x\) on \(x>0\), with \(+\infty\) elsewhere, is closed even though its effective domain is open.

Domain Closure Is Not Enough

Closing a domain and guessing boundary values can break convexity or miss the epigraph closure value.

Improper Trap

A convex function with a \(-\infty\) value is not a mild exception; it is forced to \(-\infty\) on the relative interior of its domain.

Convexity Required

The level-set slice formulas are convex-function theorems. Convex-looking level sets alone do not make the function convex.

Use The Right Object

Close the epigraph, then read the lower boundary. Do not close only the graph, and do not replace a limit by a convenient value.

Failures are usually boundary, properness, or nonconvexity failuresDiagnostic object: epigraph
Use this as the guardrail slide. A closed function need not have a closed domain, and repairing a formula by hand is not the same as closing its epigraph. The level-set relative-interior formulas also need convexity; similar-looking nonconvex functions can defeat them.

Board Prompt

Given a convex function with a suspicious boundary value, decide whether the defect disappears after closing the epigraph.

Four Takeaways

  • Lower semicontinuity is closed epigraph geometry.
  • The closed hull is read from \(\operatorname{cl}(\operatorname{epi}f)\).
  • Proper convex functions change only at relative boundary points.
  • Level-set closures are horizontal epigraph slices.
