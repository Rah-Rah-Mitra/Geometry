Convex Functions

A function becomes convex when the geometry above its graph is convex: epigraphs, chords, Jensen mixtures, domains, level sets, and finite certificates all say the same thing from different angles.

Definition
epi f in R^{n+1}

Epigraph Test

Epigraph

\(\operatorname{epi} f=\{(x,r): r\ge f(x)\}\).

Convex Function

A function is convex when its epigraph is a convex set in the lifted space.

Geometry

Averaging two feasible lifted points must stay above the graph. The vertical coordinate stores the inequality.

Extended Values

Values \(+\infty\) remove points from the effective domain; values \(-\infty\) create vertical lines and spoil properness.

Artifact: assets/epigraph-chord.svgConvexity is inspected one lifted segment at a time
Present the epigraph as the master object. A function value is no longer just a height; it is a lower boundary for all admissible lifted points. If the epigraph is convex, then every segment between two admissible lifted points remains admissible. This gives the chord inequality after choosing boundary points.
Two-Point Certificate
boundary points

Chord Inequality

Chord Test

\(f((1-\lambda)x+\lambda y)\le (1-\lambda)f(x)+\lambda f(y)\), \(0<\lambda<1\).

Finite-Valued Use

On a convex domain with values in \((-\infty,+\infty]\), this two-point inequality is the working form.

Why Epigraphs Help

When both infinities are allowed, ordinary arithmetic can stumble over undefined combinations. The lifted set avoids that trap.

Affine Case

Affine functions satisfy the same displayed relation as equality for every pair and every weight.

Chord inequality is the boundary-point version of epigraph convexityThe epigraph definition handles extended values cleanly
Move from the epigraph to the familiar chord inequality. Choose two boundary points of the epigraph, average them, and read off the vertical coordinate. The graph value at the averaged input must lie no higher than the averaged endpoint values. This is the form students will use in calculations.
Effective Domain
projection of epi f

Domain Convexity

Effective Domain

\(\operatorname{dom} f=\{x:f(x)<+\infty\}\).

Projection Rule

The domain is the projection of \(\operatorname{epi} f\) onto the \(x\)-space, so it is convex whenever the epigraph is convex.

Proper Function

Proper convex functions have a nonempty domain, finite values on that domain, and no \(-\infty\) values.

Modeling Move

Extending by \(+\infty\) lets a domain constraint become part of the function instead of a separate side condition.

Check: assets/slide-checks.json records the domain-projection invariantDomain constraints become infinite values
Stress that the domain is not an afterthought. Once convexity is defined through the epigraph, the domain is forced to be convex because it is a linear projection of that epigraph. This also explains why the course allows functions on all of space with plus infinity values: the formula carries its own domain.

Examples
finite, infinite, homogeneous

Affine And Indicator Examples

Affine Functions

\(f(x)=\langle a,x\rangle+\alpha\). Convex and concave; chords are exact.

Indicator Functions

\(\delta_C(x)=0\) on \(C\), \(+\infty\) outside. It is convex exactly when \(C\) is convex.

Curvature Certificates

Quadratics use positive semidefinite matrices. Smooth real functions use nonnegative second derivative or PSD Hessian checks.

Artifact: assets/convex-function-gallery.svgIndicator functions bridge convex sets and convex functions
Use the gallery to connect familiar objects to the same epigraph language. Affine functions are the equality case. Indicator functions encode convex sets by sending points outside the set to plus infinity. Quadratics and smooth functions add differential certificates, where nonnegative curvature gives a local way to certify global chord behavior on convex domains.
Upper Envelopes
support-style examples

Maxima And Suprema

Envelope

\(f(x)=\sup_i\{\langle a_i,x\rangle+b_i\}\).

Epigraph View

The epigraph of an upper envelope is the intersection of the epigraphs of the functions underneath it.

Set-Function Bridge

The support function \(x\mapsto\sup_{y\in C}\langle x,y\rangle\) is a supremum of affine functions of \(x\).

Finite Max

A pointwise maximum of finitely many affine functions gives a polyhedral convex graph.

Artifact: assets/max-supremum-visual.svgSuprema explain many nonsmooth convex functions
Introduce maxima and suprema as upper envelopes rather than as a new theorem to memorize. Each affine function contributes one epigraph half-space, and the intersection remains convex. Support functions fit this template: for each set point, the pairing is affine in the query direction, and the support value takes the largest one.
Slices
levels and cones

Perspective / Slices

Level Sets

For convex \(f\), the sets \(\{x:f(x)<\alpha\}\) and \(\{x:f(x)\le\alpha\}\) are convex.

Slice Geometry

A sublevel set is a horizontal cut through the epigraph, then projected back to the original space.

Positive Homogeneity

If \(f(\lambda x)=\lambda f(x)\) for \(\lambda>0\), then the epigraph is a cone.

Subadditive Form

For positive homogeneous functions, convexity is equivalent to \(f(x+y)\le f(x)+f(y)\).

Horizontal sections produce convex level setsConic epigraphs encode positive homogeneous convex functions
Use this slide to connect epigraphs with two recurring constructions. Horizontal slices explain why sublevel sets of convex functions are convex. When a function is positively homogeneous, its epigraph stretches from the origin like a cone, and the convexity condition can be read as subadditivity. These are the first hints of support and gauge functions later in the course.
Variants
strictness is extra

Strict Versus Non-strict

Strict Convexity

\(f((1-\lambda)x+\lambda y)<(1-\lambda)f(x)+\lambda f(y)\) for distinct \(x,y\) in the domain.

Convex But Not Strict

Absolute value is convex, but each ray is affine. Indicator functions are rarely strict because they are flat on their set.

Strict Example

The quadratic \(x\mapsto x^2\) bends below every nontrivial chord on the real line.

Teaching Caution

Strictness is not needed for Jensen, epigraph convexity, domain convexity, or level-set convexity.

Strict convexity strengthens the chord inequalityOrdinary convexity allows flat faces and linear pieces
Draw a clear line between convexity and strict convexity. Convexity allows equality on chords, which is why affine functions and absolute value pieces are still convex. Strict convexity asks the graph to fall below every nontrivial chord. It is useful for uniqueness later, but it is not part of the basic epigraph definition.
Curvature Margin
strong variant

Strong Convexity Intuition

One Common Test

\(f\) is \(m\)-strongly convex when \(x\mapsto f(x)-\frac{m}{2}\|x\|^2\) is convex.

Visual Meaning

Strong convexity leaves a quadratic gap between the graph and any long chord.

Smooth Certificate

For twice differentiable \(f\), a typical check is \(\nabla^2 f(x)\succeq mI\) on the domain.

Not Required Here

Section 4 builds ordinary convexity first. Strong convexity is a sharper later diagnostic.

Artifact: assets/strong-convexity-bowls.svgStrong convexity is a curvature budget, not a new epigraph definition
Offer strong convexity as an intuition extension, not as a requirement for the section. Ordinary convexity lets flat regions survive. Strong convexity demands a uniform quadratic amount of bending. The picture should help students remember that a Hessian lower bound is a curvature margin, while the epigraph still supplies the underlying convexity language.
Warning
necessary is not sufficient

Sublevel Sets Warning

True Direction

If \(f\) is convex, then its strict and closed sublevel sets are convex.

False Converse

Convex sublevel sets only give a quasiconvex-style certificate; they do not force Jensen's inequality.

Diagnostic Example

The function \(f(x)=x^3\) has sublevel sets that are half-lines, yet a chord residual can be negative.

Check File

This is the important misconception slide. Convex functions always have convex sublevel sets, but that condition alone is weaker than convexity. The cubic example has half-line sublevel sets, yet its chord test can fail. This teaches students not to replace the epigraph or Jensen test with a one-way consequence.

Residual Convention

Positive means the chord sits above the function. Negative means the sampled chord certifies nonconvexity.

What A Test Can Prove

A symbolic PSD or algebraic chord proof can certify a family. A finite sample is evidence and a good bug detector.

Failure Gallery

Concave Cap

The midpoint can sit above the endpoint average, so the residual becomes negative.

Domain Gap

Two feasible points may average to a point where \(f=+\infty\), revealing a nonconvex domain.

Bad Sublevel Logic

Infinite Arithmetic

Avoid rules that require \(+\infty-\infty\). Use epigraph inequalities instead.

Recap

Recap

1. Lift

Replace the graph by \(\operatorname{epi} f\), where vertical coordinates store inequalities.

2. Average

Read convexity as a segment test, then as the chord inequality and Jensen's inequality.

3. Project

The effective domain and sublevel sets come from projections and slices of the epigraph.

4. Audit

Use residuals, Hessians, domain checks, and failure cases to test proposed certificates.
