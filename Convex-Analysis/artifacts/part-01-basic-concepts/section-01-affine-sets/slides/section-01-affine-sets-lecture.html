Affine Sets: Geometry Without An Origin

A lecture deck for making affine geometry computational: affine combinations, hulls, flats, dimension, independence, and certificates for points in or out of a flat.

Section Goal

Replace pictures of flats with testable data: coefficients sum to one, ranks give dimensions, residuals certify membership, and projection residuals are orthogonal to the direction space.

Computational Objects

  • Affine set \(A = a + L\)
  • Affine hull \(\operatorname{aff}\{p_i\}\)
  • Difference matrix \(D = [p_1-p_0 \ \cdots \ p_k-p_0]\)
  • Certificate residual \(\|D\mu - (x-p_0)\|\)

Closure Rules
linear remembers 0

Affine Versus Linear

Linear

\(L\) is linear when \(u,v \in L\) implies \(\alpha u + \beta v \in L\) for all scalars \(\alpha,\beta\). Taking \(\alpha=\beta=0\) forces \(0 \in L\).

Affine

\(A\) is affine when \(x,y \in A\) implies \((1-t)x + ty \in A\) for every scalar \(t\). Equivalently, \(A=a+L\).

Quick Check

If a translated line misses the origin, it cannot be linear; it can still be affine because all secants have the same direction space.

Invariant: affine combinations use coefficient sum 1section-01-affine-sets
Use the parallel lines to separate two closure rules. Linear structure lets every scalar multiple remain in the set, so zero is unavoidable. Affine structure only protects combinations whose coefficients add to one, which is why the translated line is legal even though the drawn origin is not on it.
Coefficient Algebra
sum lambda_i = 1

Affine Combinations

Definition

\(x = \lambda_1 p_1 + \cdots + \lambda_m p_m,\quad \lambda_1+\cdots+\lambda_m = 1.\)

Why The Sum Matters

Translate every point by \(b\). The combination moves by \((\sum_i \lambda_i)b\). It follows the translated configuration exactly when the sum is one.

Convex Is Stricter

Convex combinations add the extra requirement \(\lambda_i \ge 0\). Affine combinations may have negative weights.

Slide check: coefficient_sum = 1.0Asset: affine-combination-slider.svg
The coefficient-sum condition is the entire hinge of the section. Nonnegative coefficients give convex combinations, but affine combinations permit negative weights and can move beyond the segment or triangle. Emphasize that the sum equal to one preserves location relative to the chosen points, independent of the coordinate origin.
Flat Objects
A = a + L

Lines, Flats, And Translates

Line

\(a + t u,\ t \in \mathbb{R}\)

Plane Or k-Flat

\(a + \operatorname{span}\{u_1,\ldots,u_k\}\)

Hyperplane

\(H=\{x : n^\top x = c\}\)

Flat = translated linear direction spaceHyperplane = one independent affine equation
Introduce flats as shifted subspaces, not as new mysterious objects. A point a anchors the set, while the direction space L supplies all allowed displacements. Lines, planes, and hyperplanes differ by the dimension of L or by the number of independent equations used to describe the translate.
Smallest Flat
aff S = p0 + span differences

Affine Hull As Smallest Flat

Recipe

For \(S=\{p_0,\ldots,p_k\}\), form \(D=[p_1-p_0\ \cdots\ p_k-p_0]\). Then

\(\operatorname{aff} S = p_0 + \operatorname{range}(D)\).

Minimality Argument

  • Every affine set containing the points contains each difference direction.
  • Adding those directions to \(p_0\) gives an affine set.
  • Therefore no smaller flat can contain all points.

Slide-local ledger: rank \(2\), affine dimension \(2\), \(p_3\) lies in the same hull.

Asset: affine-hull-rank-ledger.jsonDimension check: rank(D) = 2
Frame the affine hull as a closure operation with a concrete recipe. Pick one base point, subtract it from the remaining points, span those differences, and shift the resulting linear subspace back by the base point. The rank ledger in the slide-local asset records exactly what dimension this produces.
Linear Solve Certificate
residual = 0 means in

Solving Membership By Linear Equations

Membership Test

Given \(A=p_0+\operatorname{range}(D)\), solve

\(D\mu = x-p_0.\)

If the residual is zero, \(x=p_0+D\mu\) lies in \(A\).

Affine Coefficients From The Solve

If \(\mu=(\mu_1,\ldots,\mu_k)\), then \(x=(1-\sum\mu_i)p_0+\sum\mu_i p_i\), and the coefficients automatically sum to one.

Outsider Certificate

A normal equation \(n^\top(x-p_0)\ne0\) proves the point is not on the flat.

Membership is not a matter of visual guesswork. After choosing a base point, solve the linear system whose columns are differences from that base. A zero residual gives coefficients for an affine combination; a nonzero normal-equation residual is a certificate that the candidate sits outside the flat.
Independence Test
translate first, rank second

Affine Independence

Criterion

\(p_0,\ldots,p_k\) are affinely independent iff \(p_1-p_0,\ldots,p_k-p_0\) are linearly independent.

Setrank of differencesexpectedstatus
\(p_0,p_1,p_2\)22independent
\(p_0,p_1,p_2,p_3\)23dependent

Equivalent Certificate

An affine dependence is a nonzero vector \(\lambda\) with \(\sum_i\lambda_i=0\) and \(\sum_i\lambda_i p_i=0\).

Independence lives in the direction matrixAsset: slide-checks.json
Affine independence is linear independence after translation. The test ignores absolute position by anchoring at p0 and asking whether the difference vectors are linearly independent. Three noncollinear points in space pass the rank two test, while adding a fourth point in their plane creates dependence.
Rank Ledger
dimension = rank(D)

Dimension From Rank

Dimension Formula

\(\dim(\operatorname{aff} S)=\operatorname{rank}[p_1-p_0\ \cdots\ p_k-p_0].\)

Interpretation

The dimension counts independent directions after the arbitrary base point has been removed.

Degenerate Cases

  • One point: rank \(0\).
  • Several collinear points: rank \(1\).
  • Noncollinear triple: rank \(2\).

Connect the geometric word dimension to an auditable matrix rank. A point has affine dimension zero, a line has dimension one, a plane has dimension two, and so on. The important habit is to compute rank from differences, because raw point coordinates would incorrectly remember the arbitrary origin.
Relative Coordinates
portable coordinates

Relative Coordinates / Barycentric View

Coordinate Story

\(x=0.20p_1+0.35p_2+0.45p_3,\quad \sum\lambda_i=1.\)

The weights describe the point relative to the anchors, so translating every \(p_i\) translates \(x\) by the same amount.

Inspection Rule

All weights nonnegative places \(x\) in the convex hull. Allowing negative weights gives the whole affine hull.

The same coefficient vector can be read as a reconstruction, a membership certificate, or an interpolation rule.

Asset: barycentric-affine-coordinates.svgConvex hull subset of affine hull
Barycentric coordinates make affine position portable. The same coefficients reconstruct the point after any translation of the whole configuration, because the coefficients sum to one. This is also the clean way to tell convex and affine stories apart: convex insists on nonnegative weights, affine does not.
Combining Equations
stack constraints

Intersections Of Affine Sets

Closure

If \(A_i=\{x: B_i x=d_i\}\) are affine, then

\(\bigcap_i A_i=\{x: Bx=d\}\)

after stacking the equations, provided the system is consistent.

Dimension After Intersection

For a consistent system in \(\mathbb{R}^n\), the direction space is \(\ker B\), so the dimension is \(n-\operatorname{rank}B\).

Only Failure

Parallel inconsistent flats have empty intersection; the empty set is usually treated separately from affine sets.

Equation view: stack rowsDirection view: intersect kernels
The intersection of affine sets stays affine because the combined equation system is still linear after translation. Demonstrate the practical test: stack the equations, check consistency, and read the dimension from the nullity of the stacked direction constraints. Empty intersections are the one failure case.

Projection Problem

The minimizer \(P_Ax\) satisfies \(x-P_Ax \perp L\).

Failure Mode
convex closure is weaker

Failure Modes: Convex Is Not Affine

Common Mistake

Convexity checks \((1-t)x+ty\) only for \(0\le t\le1\). Affineness checks the same expression for every real \(t\).

Convex Example

A filled triangle contains all segments between its points, so averages stay inside.

Not Affine

Extend a segment beyond an endpoint with \(t>1\) or \(t<0\); the result can leave the triangle.

This distinction is why convex hull and affine hull are different operations.

Convex: nonnegative affine coefficientsAffine: all coefficients summing to one
Use this as a diagnostic slide. A segment or filled triangle is convex because averages stay inside, but it is not affine because affine coefficients with a negative entry escape the set. Conversely, a full affine line is affine but usually not bounded or region-like. Closure rules decide the name.
Implementation Board

Computational Checklist

1. Normalize

Choose \(p_0\). Replace points by differences \(p_i-p_0\).

2. Rank

Compute \(\operatorname{rank}D\). This is the affine dimension of the hull.

3. Membership

Solve \(D\mu=x-p_0\). Record the residual and coefficients.

4. Orthogonality

For projection, verify the residual is perpendicular to every direction column.

Four Takeaways

  • Affine means translated linear.
  • Affine combinations are exactly coefficient-sum-one combinations.
  • Affine dimension is a rank of differences.
  • Membership and projection are certified by residuals.
