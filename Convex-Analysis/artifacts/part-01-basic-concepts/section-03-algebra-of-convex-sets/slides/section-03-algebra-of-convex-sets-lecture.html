Set Addition / Minkowski Sum

Definition

\(A+B=\{a+b: a\in A,\ b\in B\}\).

Preservation Rule

If \(A\) and \(B\) are convex, then \(A+B\) is convex.

Coefficient Proof

Average two sums \(a_1+b_1\) and \(a_2+b_2\) by averaging the \(A\)-parts and \(B\)-parts separately.

Support Probe

\(h_{A+B}(u)=h_A(u)+h_B(u)\).

Artifact: assets/minkowski-sum-polygons.svgCheck: support residuals are zero for three sample directions
Emphasize that A plus B contains every point formed by adding one point from each set. Convexity of the sum is not mysterious: average two sums by averaging their A parts and B parts separately. The support check gives a numerical handle on the same rule.
Scalar Multiplication
dilation, reflection, collapse

Scalar Multiplication

Definition

\(\alpha C=\{\alpha x:x\in C\}\), with \(\alpha\in\mathbb{R}\).

Convexity

\((1-t)\alpha x+t\alpha y=\alpha((1-t)x+ty)\), so a scalar image of a convex set is convex.

Dimension Watch

For \(\alpha\neq 0\), affine dimension is unchanged. For \(\alpha=0\), every set collapses to a single point.

Sign Watch

Negative scalars reflect through the origin before stretching. This changes orientation but not convexity.

Artifact: assets/scalar-set-dilation.svgRule: convexity survives all real scalars
Treat scalar multiplication as a map first and a picture second. Positive scalars dilate, negative scalars reflect and dilate, and zero collapses everything to one point. Convexity survives because multiplying a convex average is the same as averaging the multiplied endpoints.
Convex Averaging
nonnegative coefficients

Weighted Sums And Convex Averaging

Rule

If \(C_1,\ldots,C_m\) are convex and \(\lambda_i\ge 0\), then \(\sum_i \lambda_i C_i\) is convex.

Same Set Identity

\((1-t)C+tC=C\quad(0\le t\le 1)\).

Why It Matters

Convex averaging is the algebra behind segments, hulls, products, and proof certificates.

Coefficient Guardrail

Convex averaging uses nonnegative weights whose total is one. Outside that regime, affine combinations can leave the set.

Set algebra proof move: distribute the same weights through each input setConvexity is a coefficient invariant
The weighted-sum slide is the algebraic engine behind many later constructions. Show that nonnegative weights let us build new convex sets from old ones, and remind students that the special case of the same set returns the set itself rather than a larger object.
Products And Sections
coordinatewise averaging

Products And Slices

Product Rule

If \(C\subseteq X\) and \(D\subseteq Y\) are convex, then \(C\times D\subseteq X\times Y\) is convex.

Slice Rule

For convex \(E\subseteq X\times Y\), each slice \(\{x:(x,y_0)\in E\}\) is convex.

Proof Pattern

Average coordinates independently, then hold the fixed coordinate or affine constraint unchanged.

Artifact: assets/product-slice-visual.svgProducts add dimension; slices often reduce it
Use the product as the cleanest way to prove many rules at once. A product is convex because each coordinate can be averaged independently. A slice is convex because it is an intersection with an affine constraint, which keeps every segment satisfying the same constraint.
Forward Maps
image preserves convexity

Affine Images Preserve Convexity

Image Rule

If \(T(x)=Ax+b\) is affine and \(C\) is convex, then \(T(C)\) is convex.

One-Line Proof

\(T((1-t)x+ty)=(1-t)T(x)+tT(y)\).

Geometric Effects

Affine images may translate, shear, rotate, project, or collapse. Convexity remains even when dimension drops.

Boundary Caveat

The image of a closed convex set need not be closed. That is a topological issue, not a convexity failure.

Artifact: assets/affine-image-preimage.svgImages commute with convex averages
The image rule is the forward transport rule. If students remember only one line, make it the equation saying affine maps commute with convex averages. Mention that images can reduce dimension, so preservation of convexity is not preservation of ambient shape.
Backward Maps
preimage preserves convexity

Inverse Images Preserve Convexity

Preimage Rule

If \(D\) is convex and \(T\) is affine, then \(T^{-1}(D)=\{x:T(x)\in D\}\) is convex.

Feasibility Reading

A point is feasible when its image lands in the target. The average of feasible images remains in the convex target.

Common Use

Linear inequalities, norm balls under linear maps, and affine equality constraints define convex feasible regions through preimages.

Shape Effect

Preimages can lift a low-dimensional target into a strip, slab, cylinder, or affine fiber.

Backward rule: test after mappingFeasible-set construction: pull back a convex target
The inverse-image rule is the feasibility rule. Rather than drawing a set directly, define it by the requirement that a mapped point lands in a convex target. The average of two feasible points maps to the average of their images, so feasibility survives.
Hull And Maps
finite generator check

Convex Hull Commutes With Linear Images

Identity

\(A(\operatorname{conv}P)=\operatorname{conv}(A(P))\).

Coefficient Certificate

If \(x=\sum_i \lambda_i p_i\), then \(Ax=\sum_i\lambda_i A p_i\). The coefficients remain nonnegative and sum to one.

Finite Check

assets/hull-commutation-check.json records a zero-residual test for a four-point set and a \(2\times2\) linear map.

Hulls can be taken before or after a linear imageAffine translations add after the same argument
Present hull commutation as a finite certificate saver. We may first take all convex combinations and then map them, or map the generators and take combinations afterward. The coefficients do not change, which is why point-cloud checks are so reliable here.
Hull-Sum Interaction
all pairwise sums matter

Sum Of Hulls Versus Hull Of Sums

Correct Identity

\(\operatorname{conv}P+\operatorname{conv}Q=\operatorname{conv}\{p+q:p\in P,\ q\in Q\}\).

Common Undercount

\(\operatorname{conv}\{p_i+q_i\}\) may be too small when only matched pairs are added.

Reason

After expanding \(\sum_i\lambda_i p_i+\sum_j\mu_j q_j\), the coefficients become products \(\lambda_i\mu_j\) on all pairwise sums.

Use

This identity lets finite vertex lists represent Minkowski sums through a hull of generated sums.

Equality needs the full Cartesian product of generatorsPairing samples is not a Minkowski sum
Make the equality precise, because this is where students often undercount sums. Convex hulls commute with Minkowski sum only when the sum side contains all pairwise sums of generators. If we add only matched pairs, we usually get a smaller set.
Dimension And Direction Space
what convexity does not record

Dimension And Direction Space Bookkeeping

Direction Space

For a convex set \(C\), track \(\operatorname{lin}(C-C)\): the vector space parallel to its affine hull.

Translation

\(\dim(C+b)=\dim C\).

Nonzero Scalar

\(\dim(\alpha C)=\dim C\) for \(\alpha\neq 0\).

Product

\(\dim(C\times D)=\dim C+\dim D\).

Linear Image

\(\dim(A C)\le \min(\operatorname{rank}A,\dim C)\).

Sum Bound

The direction space of \(C+D\) sits in \(\operatorname{lin}(C-C)+\operatorname{lin}(D-D)\), so dimensions may add but can also overlap.

Check in assets/slide-checks.json: rank 1 projection of a 2D toy setBookkeeping prevents false geometric intuition
Pause for bookkeeping. Algebraic operations can preserve convexity while changing affine dimension, lineality, or direction space. This slide gives students a compact checklist: translation and nonzero scaling preserve dimension, products add, sums span combined directions, and linear maps are limited by rank.
Cone Algebra
homogeneous convexity

Algebra With Cones

Convex Cone

A set \(K\) is a convex cone when \(\alpha x+\beta y\in K\) for \(x,y\in K\) and \(\alpha,\beta\ge 0\).

Sum

\(C+K\) is a cone.

Scale

\(\alpha K\) is a cone for \(\alpha\ge 0\).

Linear Image

\(A(K)\) is a cone.

Preimage

\(A^{-1}(K)\) is a cone.

Translation Warning

A shifted cone is convex, but it is usually not a cone because the origin and scaling law are lost.

Ledger: assets/cone-algebra-ledger.jsonConic algebra uses nonnegative coefficients without a sum-to-one constraint
Cones are the homogeneous version of the story. Nonnegative scaling is built into their definition, so sums, linear images, preimages, and products stay conic. A translation is the useful warning: it can keep convexity but usually destroys the cone structure.
Closure Warning
boundary behavior

Closure Warning / Boundary Behavior

Warning

Linear images preserve convexity, but they do not always preserve closedness.

Example

The epigraph \(\{(x,y):y\ge \exp(x)\}\) is closed and convex. Its projection to the \(y\)-axis is \(\{y:y>0\}\).

What Failed

The value \(0\) is approached by taking \(x\) very negative, but no finite point in the epigraph maps to \(0\).

Safe Cases

Compactness, polyhedrality, and other hypotheses can restore closedness behavior. Convexity alone does not.

Artifact: assets/closure-warning.svgConvexity check passed; closedness warning observed
Use the epigraph example to separate convexity from closedness. The epigraph is closed and convex, but projecting it loses the limiting boundary value zero. This is the boundary behavior that makes closure hypotheses matter in set algebra.
