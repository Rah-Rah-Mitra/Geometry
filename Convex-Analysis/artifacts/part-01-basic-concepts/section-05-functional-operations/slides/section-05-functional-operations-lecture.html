Inspection Rule

For a proposed operation, prove convexity first, then separately decide whether the resulting function is proper, closed, or finite anywhere.

Three Columns To Fill

  • Where does the convex average go?
  • Which epigraph set operation explains it?
  • What is the effective domain after the operation?

Common Trap

Preserving convexity does not automatically preserve properness. Infima can be \(-\infty\), and sums can have empty finite domain.

Linear Operations
nonnegative coefficients

Weighted Sums And Nonnegative Scaling

Rule

If \(f_i\) are convex and \(\alpha_i\ge0\), then \(h=\sum_i\alpha_i f_i\) is convex wherever the extended-real sum is defined.

Proof Move

Multiply each Jensen inequality by \(\alpha_i\), add them, and keep the same pair of endpoints \(x,y\).

Domain Move

For positive coefficients, finite values require \(x\) to be in every participating effective domain.

Indicator Functions

Adding \(f+\delta_C\) is the standard way to restrict \(f\) to a convex constraint set \(C\).

Check: weighted_sum_midpoint in assets/operation-checks.jsonNonnegative left scaling preserves convexity
Use weighted sums as the clean algebraic prototype. The proof is exactly the same inequality repeated with nonnegative multipliers, which explains why a negative coefficient is dangerous. Then shift attention to domains: adding an indicator is not a penalty slogan, it is an extended-real domain restriction.
Inverse Image Operation
g(Ax+b)

Affine Precomposition

Rule

If \(g\) is convex and \(T(x)=Ax+b\) is affine, then \(g\circ T\) is convex.

One-Line Proof

\(T((1-t)x+ty)=(1-t)T(x)+tT(y)\).

Epigraph View

The epigraph of \(g\circ T\) is the inverse image of \(\operatorname{epi}g\) under \((x,\mu)\mapsto(Tx,\mu)\).

Rank Watch

Precomposition can flatten or duplicate directions. Convexity survives, but level-set geometry may change sharply.

Check: affine_precomposition_midpointSource theorem route: inverse image under a linear transformation
This is the inverse-image operation for functions. Do not ask whether the affine map is one-to-one; it does not matter for convexity because it commutes with averages. What can change is the shape of level sets and the domain, so the rank and pullback domain remain part of the ledger.
Envelope Operation
epigraph intersection

Pointwise Supremum

Rule

For any family of convex functions, \(f(x)=\sup_i f_i(x)\) is convex.

Reason

\(\operatorname{epi} f=\bigcap_i \operatorname{epi} f_i\), and intersections of convex sets are convex.

Examples

Support functions, maximum component functions, and many norms are suprema of affine functions.

Inspection Target

Watch where the active function switches. The switch is allowed; the envelope remains convex because the epigraph intersection stayed convex.

Artifact: assets/supremum-envelope.svgArbitrary family, not only finite maximums
Pointwise supremum is best taught visually as an upper envelope, but prove it by epigraphs. The active function can change from one point to another, and that switching is exactly where a graph-only argument feels shaky. Epigraph intersection removes the ambiguity and handles arbitrary families.
Finite Supremum
maximum as a model case

Max Of Functions

Finite Rule

\(\max\{f_1,\ldots,f_m\}\) is the pointwise supremum of a finite convex family.

Components

\(x\mapsto\max_j x_j\) is a max of linear forms.

Hinge

\(\max\{0,a^\top x-b\}\) is convex.

Norms

\(\|x\|_\infty=\max_j |x_j|\) is a max of signed coordinate forms.

Support

\(\sigma_C(u)=\sup_{y\in C}u^\top y\) is a supremum of linear functions.

Not The Same As Minimum

The pointwise minimum of convex functions is usually not convex. That failure returns on the counterexample slide.

Check: pointwise_max_midpoint in operation-checks.jsonFinite max is the classroom gateway to support functions
Use finite maxima as the practical version of supremum. Students see the active affine piece change, but the graph never bends downward. Stress the asymmetry: maxima preserve convexity, minima usually do not. That single contrast prevents many false closure claims later.
Image Operation
project an epigraph

Partial Minimization

Rule

If \(h(y,z)\) is jointly convex, then \(p(y)=\inf_z h(y,z)\) is convex.

Function Image

This is the image operation \(Ah\): minimize over all \(x\) satisfying \(Ax=y\).

Epigraph View

Project \(\operatorname{epi}h\) from \((y,z,\mu)\) to \((y,\mu)\), then read the lower boundary.

Properness Watch

Convexity can survive even when the infimum is never attained or drops to \(-\infty\).

Source route: image of a convex function under a linear transformationDomain: projection of dom h
Partial minimization is the operation behind eliminating variables from a convex problem. The proof is geometric: project the epigraph of a jointly convex function. Make the warning explicit, because students often confuse convexity of the value function with attainment or boundedness of the inner problem.
Epigraph Addition
best split of x

Infimal Convolution

Definition

\((f\square g)(x)=\inf_y\{f(x-y)+g(y)\}\).

Convexity Mechanism

Add epigraphs in \(\mathbb{R}^{n+1}\), then take the lower boundary at total position \(x\).

Intuition

The point \(x\) is a resource to split. The best split becomes a certificate for the output value.

Domain And Properness

\(\operatorname{dom}(f\square g)=\operatorname{dom}f+\operatorname{dom}g\) when the value is proper; the infimum may still be \(-\infty\).

Artifact: assets/infimal-convolution-lab.svgCheck: infimal_convolution_split
Define infimal convolution as a best decomposition of x. The point of the diagram is that the variable y is not extra decoration; it is the certificate that says how the total input is split between two convex costs. Convexity is inherited from adding epigraphs.
Right Scalar Multiplication
epigraph cone

Perspective Transform

Perspective

\(g(\lambda,x)=\lambda f(x/\lambda),\quad \lambda>0.\)

Source Language

Right scalar multiplication scales the epigraph itself: \((f\lambda)(x)=\lambda f(\lambda^{-1}x)\).

Why Convex

The graph is read from a convex cone generated by \(\operatorname{epi}f\). Slices at different \(\lambda\) are scaled copies.

Boundary Watch

The extension at \(\lambda=0\) is a recession or closure question. Do not invent it by plugging into \(x/\lambda\).

Artifact: assets/perspective-transform.svgCheck: perspective_midpoint
Connect the modern word perspective to the section's right scalar multiplication of epigraphs. For positive lambda, the formula is clear. At lambda zero, the formula is not a formula anymore; it is a cone boundary decision, which is why epigraph bookkeeping is safer than informal substitution.
Limit Operations
pass Jensen carefully

Closure Under Limits

Useful Consequence

If \(f_k\) are convex and \(f_k(x)\to f(x)\) pointwise with well-defined extended-real arithmetic, then the Jensen inequality passes to \(f\).

Increasing Limits

An increasing pointwise limit is a supremum, so convexity follows immediately from the supremum rule.

Decreasing Limits

Pointwise convergence can still pass the finite Jensen inequality, but closedness and lower semicontinuity require separate checks.

Epigraph Caution

Limit graphs can lose boundary points. Convexity is not the same as closed convexity.

Use with domain and closedness auditSupremum is the safest limit pattern
Treat limits as a careful consequence, not a magic closure rule. For each fixed pair of points and weight, the Jensen inequality can pass to a pointwise limit when the values are well defined. Then remind the class that lower semicontinuity and closed epigraphs are additional topological properties.
Epigraph-Level Bookkeeping
sets explain functions

Epigraph Arithmetic

Ordinary Sum

Same \(x\), add heights. Domain mostly intersects; convexity follows by adding inequalities.

Infimal Convolution

Add epigraphs as sets. The new \(x\) is \(x_1+x_2\), so the lower boundary minimizes over all splits.

Supremum

Intersect epigraphs. The graph becomes an upper envelope of the family.

Convex Hull Of Functions

Convexify the union of epigraphs, then read the greatest convex function below the input family.

Bookkeeping Principle

Convexity preservation answers the shape question. Effective-domain analysis answers whether the operation produced a useful proper convex function.

Indicator Trick

\(f+\delta_C\) keeps the same formula on \(C\) and assigns \(+\infty\) outside. This turns constraints into domain algebra.

Failure Modes
hypotheses matter

Counterexamples

Four Ways To Break A Rule

Drop a sign, reverse monotonicity, replace supremum by infimum, or forget lower-boundedness in a minimization.

Negative Scaling

If \(f(x)=x^2\), then \(-f\) is concave, not convex.

Wrong Envelope

\(\min\{(x-1)^2,(x+1)^2\}\) fails convexity near the middle.

Wrong Composition

A convex but decreasing outer function does not generally preserve convexity when composed with a convex inner function.

Wrong Infimum

Partial minimization preserves convexity as an extended-real function, but the result may be improper.

Check: counterexample_negative_scaling has expected failure statusCounterexamples identify missing hypotheses
Use this slide to sharpen the hypotheses. Each failure is a near miss: negative scaling looks like scaling, minimum looks like maximum, decreasing composition looks like composition, and partial minimization looks harmless until the value runs away. Ask students to name the missing assumption before reading the explanation.

Residual Convention

For sampled midpoint tests, residual means right side minus left side in Jensen's inequality. Positive values support the diagnostic; a negative value is a counterexample.

What Sampling Can Do

Sampling does not prove a theorem. It catches implementation errors and gives a concrete witness aligned with the proof.

Recap / Inspection Prompt
convex-function calculus

Recap

1. Follow Averages

Does the operation carry \((1-t)x+ty\) into a legal convex average of output data?

2. Draw The Epigraph

Is the operation an intersection, projection, sum, cone, or convex hull of epigraphs?

3. Track Domains

Where is the result finite, and can it become improper or unbounded below?

4. Test A Witness

What sampled residual or split certificate would reveal a sign or domain mistake?
