The Minimum Of A Convex Function

Convex minimization is governed by two visible questions: do the level sets trap a point, and does the subgradient certificate say that no descent direction remains?

Lecture Goal

Connect existence of minimizers with level-set geometry, recession behavior, and the first-order certificate \(0\in\partial f(x)\).

Core Invariant

The sampled minimizer has the smallest displayed objective value and a zero gradient or zero subgradient residual.

Main Caution

An infimum can be finite without being attained if level sets fail to close or if minimizing sequences escape along recession directions.

Problem Shape
infimum versus minimum

A Minimum Requires Attainment, Not Just A Low Value

Minimum

\(x^*\in\operatorname{argmin} f\) means \(f(x^*)=\inf_x f(x)\).

Value Question

Is the infimum finite, and what number are minimizing sequences approaching?

Attainment Question

Does some point actually realize that value, or do all near-minimizers drift away?

The infimum is a valueThe minimum is a value plus a point
Separate two questions that are often conflated. The infimum is a number; a minimum is a point that reaches that number. Convexity gives strong structure, but it does not by itself guarantee attainment. The rest of the section explains which level-set and recession checks make attainment possible.
Level Sets
existence geometry

Level Sets Trap Minimizing Sequences

Sublevel Set

\(L_\alpha=\{x:f(x)\le\alpha\}\).

Convexity

If \(f\) is convex, every sublevel set is convex. Closedness follows from lower semicontinuity.

Existence Route

A nonempty compact sublevel set containing a minimizing sequence has a convergent subsequence whose limit can attain the infimum.

Compact sublevel sets are existence machinesLower semicontinuity closes the limiting argument
Use sublevel sets as the existence picture. A minimizing sequence eventually lives in any level set just above the infimum. If one of those sets is closed and bounded in finite dimension, a convergent subsequence appears, and lower semicontinuity lets the limit inherit the minimum value.
Optimality Certificate
zero subgradient

The Zero Subgradient Certificate Marks Optimality

Unconstrained Condition

\(x^*\) minimizes \(f\) if and only if \(0\in\partial f(x^*)\), for proper convex \(f\).

Differentiable Case

The condition becomes \(\nabla f(x^*)=0\).

Nonsmooth Case

The subdifferential must contain the zero vector, so every directional first-order bound is nonnegative.

Diagnostic

A nonzero subgradient gives a separating hyperplane for descent or a direction that still lowers the function.

Zero subgradient is the first-order certificateIt applies beyond differentiable objectives
Present zero subgradient as the optimality certificate, not merely a calculus slogan. For differentiable functions it is the familiar zero gradient condition. For nonsmooth convex functions, the whole subdifferential matters, and containing zero means every supporting affine lower bound is compatible with no descent direction.
Recession
escape directions

Recession Directions Explain Nonattainment And Unboundedness

Escape Test

f(x+td)\ \text{as}\ t\to\infty \quad \text{reveals whether level sets stay bounded.}

Unbounded Below

If \(f\) decreases along a recession direction, no finite minimum exists.

Flat Escape

If \(f\) stays level along a nonzero direction, minimizers may form an unbounded face when a minimum is attained.

Recession analysis separates nonattainment from unboundednessLevel-set boundedness is a practical existence check
Use recession to explain the main failure mode. A minimizing sequence can leave every bounded region even while objective values decrease. Sometimes this means the function is unbounded below; sometimes the value is approached but not attained. Either way, the level-set picture reveals why a compactness argument cannot start.
Existence Checklist
trap and close

Existence Comes From Trapping A Minimizing Sequence

Proper

The function has at least one finite value and is never \(-\infty\).

Closed

Sublevel sets contain limits of convergent minimizing sequences.

Bounded Level

Some near-optimal level set prevents escape to infinity.

Finite Infimum

The values being approached do not run down without bound.

Once a minimizing sequence is trapped in a compact closed level set, a convergent subsequence can deliver the minimizer.

Existence is a compactness argument in geometric clothingEach checklist item blocks a specific failure mode
Give students a practical existence checklist. Properness avoids meaningless values, closedness supports limits, bounded sublevel sets stop escape, and a finite infimum gives the target value. The theorem-level argument is compactness, but the slide makes clear which geometric failure each assumption prevents.
Nonsmooth Minima
subdifferential contains zero

Nonsmooth Corners Can Be Optimal Without A Classical Gradient

Example Pattern

f(x)=|x| \quad\Rightarrow\quad \partial f(0)=[-1,1].

Zero Inside

The minimum occurs at the corner because zero belongs to the interval of subgradients.

Why Gradients Are Insufficient

A classical derivative may not exist at the minimizer, but the convex subdifferential still gives a complete optimality certificate.

Subgradient optimality includes nonsmooth convex objectivesHorizontal support is the visual certificate
Use the absolute value shape to make nonsmooth optimality concrete. There is no single derivative at the corner, but there are many supporting slopes. Since the interval of subgradients includes zero, the corner satisfies the optimality certificate and no directional descent is possible.
Executable Invariant
value and stationarity

The Notebook Check Audits Value And Stationarity

Residuals

\(r_g=\|\nabla f(x_k)\|,\quad r_v=f(x_k)-\min_{\text{sample}} f.\)

Pass Conditions

The sampled minimizer has the smallest displayed objective value and a small gradient or subgradient residual.

Fail Conditions

A lower sampled value or a clear nonzero descent certificate means the chosen point is not yet justified as a minimizer.

Source notebook invariant: zero gradient and smallest displayed objective valueResiduals separate existence from optimality
Tie this slide directly to the notebook invariant. The sampled minimizer should have both a low value and a small stationarity residual. The value test catches points that are stationary but not lowest in the sampled view, while the gradient or subgradient test catches points that still have a visible descent direction.
Learner Lab
modify level geometry

Lab: Change Growth, Recession, Or Smoothness

Experiment A

Add a small linear tilt. Watch the minimizer move and update the zero-gradient condition.

Experiment B

Flatten one direction. Decide whether minimizers form a line, a face, or disappear through recession.

Experiment C

Replace a quadratic term by an absolute-value term and audit the subdifferential at the corner.

A useful report names the changed parameter, the new level-set behavior, and the residual that confirms or rejects optimality.

Change one ingredient at a timeExistence and optimality should be checked separately
Frame the lab as a separation of existence from stationarity. Students should modify one term, inspect whether level sets still trap near-minimizers, and then compute the zero-gradient or zero-subgradient residual. A good explanation says whether the new behavior is a point minimum, a flat minimizer set, escape, or unboundedness.

Minimization Needs Existence And A Zero First-Order Certificate

Trap

Use closed bounded level sets to trap minimizing sequences.

Rule Out Escape

Inspect recession directions and unbounded level-set behavior.

Certify

Check \(0\in\partial f(x^*)\) or \(\nabla f(x^*)=0\).

Audit

Compare sampled values and stationarity residuals.

The durable mental model is compactness for existence, zero subgradient for optimality, and recession analysis for failure.
