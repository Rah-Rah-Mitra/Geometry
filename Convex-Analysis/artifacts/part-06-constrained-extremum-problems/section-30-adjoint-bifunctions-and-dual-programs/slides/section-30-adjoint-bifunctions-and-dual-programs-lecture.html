Perturbation Model
from program to value function

A Bifunction Records A Family Of Nearby Problems

Convex Program

\(F:u\mapsto F_u,\qquad (P):\ \inf_x F(0,x).\)

Perturbation Variable

The parameter \(u\) moves the constraints or data. The unperturbed problem is the slice \(u=0\).

Value Function

The map \(\varphi(u)=\inf_x F(u,x)\) measures how the best achievable value responds to perturbation.

Duality Target

Dual variables are slopes supporting the value function at the origin.

Primal objective: \(F_0\)Perturbation function: \(\inf F\)
Before introducing the adjoint, make sure the primal object is concrete. A bifunction is a family of objective functions indexed by a perturbation. The value function takes each perturbation and returns the best primal value. The geometric role of a multiplier is to provide a supporting slope to that value function at zero.
Concave Mirror
min becomes max

The Dual Side Uses The Same Language With Signs Reversed

Concave Program

\(G:v\mapsto G_v,\qquad (Q):\ \sup_y G(0,y).\)

Convex Side

Closedness means lower semicontinuity; value maps use infima; subgradients support from below.

Concave Side

Closedness means upper semicontinuity; value maps use suprema; subgradients support from above.

Why This Matters

The adjoint of a convex bifunction is concave, so the dual program is a maximization problem.

Convex programs minimizeConcave programs maximize
This slide sets up the sign discipline. The same convex analysis vocabulary has a concave counterpart: infimum becomes supremum, lower semicontinuity becomes upper semicontinuity, and supporting lower affine functions become supporting upper affine functions. That is why the adjoint dual program is naturally a maximization problem.
Adjoint Definition
conjugacy on the graph function

The Adjoint Couples Perturbations With Dual Variables

Adjoint Bifunction

\[ \begin{aligned} (F^*x^*)(u^*)=\inf_{u,x}\{&F(u,x)-\langle x,x^*\rangle\\ &+\langle u,u^*\rangle\}. \end{aligned} \]

Type Change

For convex \(F\), the adjoint \(F^*\) is a closed concave bifunction from the \(x^*\)-space to the \(u^*\)-space.

Graph Function View

If \(f(u,x)=F(u,x)\), then the adjoint is a signed conjugate of \(f\) evaluated at \((-u^*,x^*)\).

Adjoint means more than transpose, but transpose is the guiding analogyVariables and perturbations trade roles
Introduce the formula as a graph-function conjugacy with a sign convention. The infimum subtracts the dual pairing with the primal variable and adds the pairing with the perturbation. The output is no longer a convex bifunction in the same direction; it is a concave bifunction whose variables are the dual coordinates.
Fundamental Fact
closure after two adjoints

Taking Adjoints Twice Recovers The Closed Bifunction

Adjoint Involution

\[ F^{**}=\operatorname{cl}F. \]

Closed Case

If \(F\) is already closed, then \(F^{**}=F\). The dual of the dual returns the original program.

Properness

The adjoint is proper exactly when the original bifunction is proper, so meaningful programs remain meaningful after adjunction.

Polyhedral Case

Polyhedral bifunctions remain polyhedral under the adjoint, which explains the clean behavior of linear programming duals.

Closed proper convex bifunctions correspond to closed proper concave adjointsThe dual construction is reversible under closure
The adjoint is not merely a way to manufacture a new function; it is an involutive correspondence after closure. If the original bifunction has no missing boundary points, the second adjoint gives the same object back. This is the structural reason the dual of the dual can be identified with the original program.
Guiding Example
linear transformations

The Usual Transpose Is A Special Case Of The Adjoint

Indicator Bifunction

\(F(u,x)=\delta_{\{x=Au\}}(u,x)\)

Adjoint Relation

\(u^*=A^\mathsf{T}x^*\)

Meaning

A hard graph constraint in primal coordinates becomes a hard graph constraint for the transpose map in dual coordinates.

Takeaway

The bifunction adjoint extends the linear algebra adjoint from graphs of maps to graphs of convex relations.

Linear algebra is the mnemonicConvex algebra is the broader setting
Use the linear example to make the abstraction feel earned. If the bifunction only records the graph of a linear map, the adjoint records the graph of the transpose map. The general construction keeps that same geometry, but it allows convex relations and objective terms instead of only exact linear equations.
Dual Program
program associated with \(F^*\)

The Dual Program Maximizes The Adjoint Objective

Primal Program

\[ (P):\quad \inf_x F(0,x) \]

Primal Perturbations

Replace \(0\) by \(u\), then study \(\inf_x F(u,x)\).

Dual Variables

The dual variable \(u^*\) lives in the perturbation space and evaluates sensitivity at \(u=0\).

Dual Program

\[ (P^*):\quad \sup_{u^*}F^*(0,u^*) \]

Dual Perturbations

Replace \(0\) in the adjoint by \(x^*\), then study \(\sup_{u^*}F^*(x^*,u^*)\).

Bidirectionality

When \(F\) is closed, the program dual to \((P^*)\) is again \((P)\).

Primal minimizes a convex objective sliceDual maximizes a concave adjoint slice
This is the point where the adjoint becomes an optimization problem. The primal optimizes the zero perturbation slice of F, while the dual optimizes the zero perturbation slice of F-star. Perturbations also swap: primal perturbations live in u, and dual perturbations live in x-star.
Weak Duality
automatic bound

Every Dual Value Is A Lower Bound On The Primal Value

Weak Duality

\[ \sup_{u^*}F^*(0,u^*)\le \inf_x F(0,x). \]

Value Gap

The difference between the primal infimum and the dual supremum is the duality gap.

Notebook Check

Every displayed primal value is audited to be no smaller than the paired dual lower bound.

What Weak Duality Does Not Say

It does not guarantee equality or existence of optimizers. Those require normality and attainment hypotheses.

Weak duality is structuralStrong duality is a closure statement at the origin
Connect the theorem to the visual invariant in the notebook. Every dual feasible value is a valid lower bound for every primal feasible value, so the dual curve sits below the primal curve. The remaining question is whether the two curves meet at the unperturbed problem or leave a positive gap.
Normality
closure at zero perturbation

Normality Is The No-Jump Condition For The Value Function

Normal Program

\[ (\operatorname{cl}\inf F)(0)=(\inf F)(0). \]

Equivalent Signals

For a closed convex bifunction, primal normality, dual normality, and equality of primal and dual optimal values are equivalent.

Common Guarantees

Strong consistency, a finite value with a Kuhn-Tucker vector, or polyhedral consistency all force normality.

Failure Mode

If the value function jumps at zero, nearby perturbations predict a better limiting value than the original problem attains.

Normality converts weak duality into equalityIt is a local closure condition, not an ornamental assumption
Normality is the section's central stability condition. It says that the value at the original problem is the limit predicted by nearby perturbations. When this closure condition holds, the dual lower bound reaches the primal value. When it fails, the gap is a real discontinuity in the perturbation model.
Kuhn-Tucker Correspondence
multipliers become optimizers

Under Normality, Multipliers Are Dual Optimal Solutions

Correspondence

\(u^*\) is a Kuhn-Tucker vector for \((P)\) exactly when \(u^*\) solves \((P^*)\).

Sensitivity Reading

A multiplier is a supporting slope of the primal value function at the origin.

Dual Reading

The same vector is an optimizer of the concave adjoint objective.

Attainment Caveat

Equality of values does not by itself ensure that both sides attain their optima.

Kuhn-Tucker vectors certify sensitivityDual optimizers certify best lower bounds
The theorem identifies two things that can look unrelated. A Kuhn-Tucker vector is a sensitivity certificate for the primal perturbation function, while a dual optimal solution maximizes the adjoint objective. Normality lets the subgradient certificate pass through conjugacy and become an optimizer on the dual side.
Saddle Certificate
one inequality closes the gap

A Saddle Point Certifies Both Primal And Dual Optimality

Lagrangian Slice

\[ L(u^*,x)=\inf_u\{F(u,x)+\langle u,u^*\rangle\}. \]

Saddle Inequality

\[ L(u^*,\bar x)\le L(\bar u^*,\bar x)\le L(\bar u^*,x). \]

Fast Certificate

If a primal candidate value is no larger than a dual candidate bound, weak duality forces equality and both candidates are optimal.

Saddle point = primal optimizer + dual optimizer + normalityThe certificate is geometric and numerical
Read the saddle inequality in the correct directions. Holding the primal point fixed, the chosen dual variable is best for the maximization side. Holding the dual variable fixed, the chosen primal point is best for the minimization side. This single saddle picture explains why an apparent reverse inequality between candidate values closes the duality gap.
Ordinary Programs
inequality constraints

Classical Lagrange Duality Is The Ordinary-Program Face

Primal Template

\[ \min_{x\in C} f_0(x)\quad\text{subject to}\quad f_i(x)\le 0. \]

Basic Dual Bound

For \(\lambda_i\ge 0\), the expression \(f_0(x)+\sum_i\lambda_i f_i(x)\) is no larger than \(f_0(x)\) on feasible points.

Why Extra Perturbations Appear

Nonlinear constraints may require richer perturbations to expose a clean explicit dual problem.

Lagrange Dual Template

\[ \sup_{\lambda\ge 0}\inf_{x\in C}\left(f_0(x)+\sum_i\lambda_i f_i(x)\right). \]

The sign of multipliers follows the perturbation conventionRicher perturbations make nonlinear duals explicit
Close the abstract theory back onto the familiar constrained problem. For inequality constraints, nonnegative multipliers form lower bounds through the Lagrangian. Rockafellar's bifunction language explains why the familiar dual is sometimes only the visible part of a richer perturbation model, especially when nonlinear constraints need translations as well as right-hand-side shifts.

Package

Adjoint

Bound
