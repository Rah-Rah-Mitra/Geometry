Bifunctions And Generalized Convex Programs

A generalized program is an objective together with a specified family of perturbations. The central object is the value curve \(\phi(u)=\inf_x (F_u)(x)\), whose supporting slopes are generalized multipliers.

Motivation

The Objective Alone Does Not Determine The Lagrangian

Ordinary View

A program minimizes one convex objective over its feasible set. This view remembers the feasible set but forgets which perturbations should receive prices.

Section 29 View

A program is the unperturbed objective \(F_0\) together with a chosen family \(F_u\). Different families can share \(F_0\) while producing different multipliers and Lagrangians.

The data of a generalized program is the perturbation model, not merely the minimization problem at \(u=0\).

Multipliers price the permitted perturbationsTwo equal feasible objectives may have different economic interpretations
Use this slide to justify the new language. In earlier sections, Lagrange multipliers are attached to a particular list of constraints and perturbations. If two formulations have the same feasible objective but perturb different ingredients, they should not be forced to have the same Lagrangian. Bifunctions record exactly that missing information.
Definition
graph function controls convexity

A Bifunction Is A Function Organized By Fibers

Bifunction

\(F:\mathbb R^m\to\{\text{extended-real functions on }\mathbb R^n\}\), with fiber \(u\mapsto F_u\).

Graph Function

\(f(u,x)=(F_u)(x)\quad\text{on }\mathbb R^{m+n}.\)

Convexity Rule

\(F\) is convex exactly when its graph function \(f\) is convex in the joint variables \((u,x)\). Closedness and properness are inherited from the same graph function.

Domain Rule

The graph domain lives in \(\mathbb R^{m+n}\), while \(\operatorname{dom}F\) is its projection onto the perturbation space.

Bifunctions are not new data types; they are joint functions read fiberwiseConvexity is checked in \((u,x)\)
Define the object cleanly before attaching optimization language. A bifunction assigns a whole extended-real function to each perturbation vector. The graph function is the ordinary convex function behind the scenes, so students can use familiar epigraph and domain ideas. The projection picture explains why the perturbation domain is convex.
Interpretation
sets plus costs

A Bifunction Behaves Like A Valued Correspondence

Finite Fiber

For a fixed \(u\), the set where \(F_u\) is finite is the feasible fiber \(S_u\). The values of \(F_u\) are the costs assigned to points in that fiber.

Indicator Bifunction

If the cost is zero on \(S_u\) and \(+\infty\) outside, the bifunction reduces to a set-valued map \(u\mapsto S_u\).

Linear Map Bridge

The indicator of the graph of a linear transformation is a closed proper convex bifunction. This will later connect bifunction algebra with linear algebra.

Each perturbation supplies both a feasible fiber and a valuationIndicator fibers recover ordinary set-valued mappings
Give students a mental model that is less abstract than the definition. A bifunction can be read as a moving feasible set with a cost written on it. When the cost is just zero inside and infinity outside, the object collapses to a familiar set-valued mapping. This makes the terminology feel like a genuine extension rather than a new formal burden.
Ordinary Programs
constraints become perturbation fibers

An Ordinary Convex Program Has An Associated Bifunction

Perturbed Feasible Fiber

\(S_u=\{x:f_i(x)\le v_i,\ i\le r;\ f_i(x)=v_i,\ i>r\}\).

Associated Bifunction

\(F_u=f_0+\delta(\,\cdot\,|S_u)\).

Why It Is Convex

The graph function is assembled from \(f_0\) and indicator functions of convex epigraph or affine constraint relations.

Why It Remembers More

The list of relaxed inequalities and equations can be recovered from \(F\); therefore the perturbation semantics are not lost.

Ordinary programs fit the generalized frameworkThe perturbation vector \(u\) records right-hand-side changes
Connect the new language back to the previous section. In an ordinary convex program, perturbing the right-hand sides creates a family of feasible fibers. The associated bifunction is simply the original objective plus the indicator of that fiber. This construction explains why the generalized language preserves the constraint structure that produces Kuhn-Tucker vectors.
Generalized Program
objective and value function

The Program Associated With \(F\) Minimizes \(F_0\)

Objective And Feasible Points

objective \(=F_0\), feasible set \(=\{x:(F_0)(x)<+\infty\}\).

Perturbation Function

\(\phi(u)=(\inf F)(u)=\inf_x (F_u)(x)\).

Optimal Value

The number \(\phi(0)\) is the optimal value of the unperturbed program.

Consistency

The program is consistent when \(0\in\operatorname{dom}F\). It is strongly or strictly consistent when \(0\) lies in the relative interior or interior of that perturbation domain.

The value function is the projection of the graph-function epigraphSource invariant: midpoint convexity of the sampled value curve
Now name the optimization problem attached to a bifunction. The unperturbed objective is the zero fiber, while all other fibers describe allowed perturbations. Minimizing each fiber produces the perturbation value function. This function is the bridge from programs to subgradient theory, so it deserves to be drawn as its own convex curve.
Theorem 29.1
multipliers are value-function subgradients

Kuhn-Tucker Vectors Are Supporting Slopes Of \(\phi\)

Theorem 29.1

\(\phi=\inf F\) is convex, \(\operatorname{dom}\phi=\operatorname{dom}F\), and, if \(\phi(0)\) is finite, \(u^*\) is a Kuhn-Tucker vector exactly when \(-u^*\in\partial\phi(0)\).

Equilibrium Price

The vector \(u^*\) prices perturbations so no perturbed problem plus price term beats the unperturbed value.

Computational Test

Check the supporting inequality for sampled \(u\)'s. The multiplier is plausible only if the affine support never rises above the value curve.

Core formula: \(\phi(u)+\langle u^*,u\rangle\ge \phi(0)\)Subgradient theory becomes multiplier theory
This is the conceptual center of the section. Once the perturbation function is known to be convex, a Kuhn-Tucker vector is simply a negative subgradient at the origin. The sign is important: the price vector compensates for movement in the perturbation direction, so the supporting affine lower bound uses minus the multiplier.
Stability
consistency and directional derivatives

Existence And Uniqueness Of Multipliers Are Local Properties Of \(\phi\)

Strong Consistency

\(0\in\operatorname{ri}(\operatorname{dom}F)\); relative-interior room supports multiplier existence.

Strict Consistency

\(0\in\operatorname{int}(\operatorname{dom}F)\); all perturbation directions are locally feasible.

No Multiplier

A two-sided directional derivative equal to \(-\infty\) signals an infinitely advantageous perturbation.

Unique Multiplier

If \(\phi\) is differentiable at \(0\), the multiplier is determined by the gradient.

Geometrically: multipliers exist when the value curve has a finite supporting hyperplane at the origin.

Corollaries 29.1.1-29.1.5 translate derivative facts into multiplier factsStrict consistency gives a bounded closed multiplier set
Summarize the corollaries as stability diagnostics rather than as isolated statements. If the origin has enough room inside the perturbation domain, the convex value function has useful finite one-sided derivatives and supporting hyperplanes. Nonexistence corresponds to a perturbation direction where the optimal value drops with infinite speed, while differentiability leaves only one possible supporting slope.
Lagrangian
infimum over perturbations

The Generalized Lagrangian Eliminates The Perturbation Variable

Lagrangian

\(L(u^*,x)=\inf_u\{\langle u^*,u\rangle+(F_u)(x)\}\).

Saddle Characterization

For closed proper \(F\), \(u^*\) is a Kuhn-Tucker vector and \(x\) is optimal exactly when \((u^*,x)\) is a saddle point of \(L\).

Read The Saddle

At fixed \(u^*\), the chosen \(x\) minimizes the Lagrangian. At fixed \(x\), the chosen \(u^*\) maximizes the concave multiplier side.

The perturbation variable \(u\) is folded into an infimumTheorem 29.3 recovers optimality and multipliers together
After the value-function theorem, introduce the Lagrangian as the object that will connect this section to saddle-point and duality theory. The infimum over perturbations folds the chosen perturbation model into a function of multiplier and decision variables. For closed proper bifunctions, saddle points are precisely optimal solutions paired with Kuhn-Tucker vectors.
Polyhedral Programs
finite-dimensional certificates

Polyhedral Bifunctions Make The Certificates Polyhedral Too

Theorem 29.2

If \(F\) has a polyhedral graph function, then \(F_0\) and \(\phi=\inf F\) are polyhedral convex functions. Finite optimal value implies optimal solutions and Kuhn-Tucker vectors exist.

Linear Programs

Linear programs are important members of this class, but they are not the whole class because the perturbation model can move sets or other structural data.

Shape Of Solution Sets

Both the optimal-solution set and the multiplier set are polyhedral convex sets, so they are inspectable by faces, normals, and active inequalities.

Polyhedral graph functions survive the infimum/projection stepFinite value prevents the certificate sets from disappearing
Frame the polyhedral theorem as the clean finite-dimensional case. When the graph function is polyhedral, minimizing over the decision variable preserves polyhedral convexity of the value function. A finite optimal value then guarantees both primal attainment and multiplier existence, and both certificate sets can be studied as polyhedra.
Closure
regularizing a program

Closing The Bifunction Regularizes Without Changing Interior Values

Closure Of A Bifunction

\(\operatorname{cl}F\) is defined by closing the graph function of \(F\).

Interior Agreement

For \(u\in\operatorname{ri}(\operatorname{dom}F)\), the fiber \((\operatorname{cl}F)_u\) is the closure of \(F_u\), and the two fibers have the same infimum.

Strong Consistency

If the original program is strongly consistent, closing the bifunction preserves the local perturbation values near zero and therefore preserves the Kuhn-Tucker vectors.

Why It Matters

The saddle theorem and the next section's duality theory are cleanest for closed proper bifunctions.

Theorem 29.4 and Corollary 29.4.1 describe what closure preservesRegularization prepares the dual program
Close the technical arc by explaining why regularization appears. Some bifunctions are natural but not closed, and saddle-point theory asks for closed proper data. Closing the graph function repairs boundary behavior. Under strong consistency, the origin lies safely in the relative interior, so the value function and multiplier set near zero are unchanged.

Section 29 Turns Perturbation Geometry Into Multiplier Theory

1. Organize The Data

A convex bifunction is a joint convex graph function read as fibers \(F_u\).

2. Trace The Values

The perturbation function \(\phi(u)=\inf_x(F_u)(x)\) is convex and has domain \(\operatorname{dom}F\).

3. Read The Prices

Kuhn-Tucker vectors are exactly the negatives of subgradients of \(\phi\) at zero when the optimal value is finite.

4. Certify With Saddles

For closed proper \(F\), optimal solutions and multipliers are paired by saddle points of \(L\).
