Support Functions

A closed convex set can be read through all of its linear shadows: each direction asks how far the set reaches, and the answers form a set-to-function fingerprint.

Lecture Goal

Make \(h_C(u)=\sup_{x\in C} x\cdot u\) geometric, algebraic, and computational.

Source Spine

The section links support halfspaces, closed convex reconstruction, indicator conjugacy, positive homogeneity, boundedness, and norm-ball examples.

Guiding Question

What information about \(C\) is preserved when we replace the set by the function \(h_C\)?

Open by presenting the support function as a fingerprint of a set. Instead of listing all points of C, we ask every direction u how far C reaches under the linear probe x dot u. The lecture goal is to make that probing idea do real work: support lines, exposed faces, reconstruction, operations, and computation.
Definition / Probe
maximize a linear score

Linear Probe

Support Function

\(h_C(u)=\sup\{x\cdot u:x\in C\}\).

Read The Formula

Fix \(u\). Score every point \(x\in C\) by the linear functional \(x\cdot u\). The largest score is the support value.

Polytope Shortcut

On a polygon, the maximum is attained at a vertex or along an edge, so finite vertex checks are exact.

Sign Mirror

Linear minimization is the same data: \(\inf_C x\cdot u=-h_C(-u)\).

Artifact: assets/support-probe-polygon.svgCheck: support-sampling-checks.json
Use the polygon to make the definition tactile. For a fixed u, every point receives a score x dot u, and the support value is the largest score. On a polytope the maximum is found among vertices, which is why the finite sampling check in the slide-local JSON is meaningful for this example.
Halfspace View
number becomes geometry

Direction To Supporting Line

Containing Halfspace

\(C\subseteq\{x:x\cdot u\le h_C(u)\}\).

Supporting Boundary

\(H(u)=\{x:x\cdot u=h_C(u)\}\).

Operational Picture

Slide the line perpendicular to \(u\) until it first touches \(C\). The offset at first touch is \(h_C(u)\).

Infinite Value

If \(C\) is unbounded in direction \(u\), there is no last supporting line and \(h_C(u)=+\infty\).

Support values encode all containing support halfspacesThe boundary line is active exactly at maximizers
Translate the number h_C(u) into geometry. The inequality x dot u less than or equal to h_C(u) describes a closed halfspace containing C, and the boundary line is where the best score is achieved. Moving u rotates the halfspace and scans the boundary.
Maximizers
faces selected by directions

Exposed Face

Exposed Face

\(F_C(u)=\{x\in C:x\cdot u=h_C(u)\}\).

Two Outcomes

A generic direction usually exposes one vertex. A direction normal to a flat side exposes the whole side.

Data Returned

The support value tells how far; the exposed face tells where the farthest contact occurs.

Not Every Face

Support functions naturally reveal exposed faces. Later examples can separate exposed faces from arbitrary faces.

Artifact: assets/exposed-face-map.svgNormal directions sort boundary pieces
The exposed face is the set of all maximizers, not just a single point. A generic direction on a polygon exposes a vertex, while a normal direction perpendicular to an edge exposes the whole edge. This is the bridge from a function value back to visible boundary structure.
Computational Geometry
active maximizer changes by sector

Polygon Support Map

Piecewise Linear Fingerprint

For a polygon, \(h_C(u)\) is the maximum of finitely many linear functions \(v_i\cdot u\).

Vertex Formula

\(h_C(u)=\max_i v_i\cdot u\quad\text{when } C=\operatorname{conv}\{v_i\}\).

Active Region

Each vertex owns a cone of directions. Crossing a cone boundary switches the exposed face.

Graph Cue

Kinks in the support graph occur exactly when the active maximizer changes.

Finite model: max of vertex dot productsSupport map: directions to exposed faces
Read this as a support map rather than a picture of one direction. Each sector of directions has the same exposed vertex, and the support function is linear within that sector. Corners in the support graph mark changes in the active maximizer.
Operation Rule
Minkowski addition

Support Of Sum

Sum Rule

\(h_{A+B}(u)=h_A(u)+h_B(u)\)

Why

\(\sup_{a+b}(a+b)\cdot u=\sup_a a\cdot u+\sup_b b\cdot u\).

Function Fingerprint

Minkowski addition of sets becomes ordinary addition of support functions.

Slide-Local Ledger

assets/support-sum-ledger.json records this rule with companion operations.

Set operation: A+BFunction operation: h_A+h_B
The Minkowski sum identity is the cleanest operation rule. A linear probe of A plus B separates into one probe on A and one probe on B, so the two best values add. This is why support functions convert set addition into ordinary function addition.
Operation Rule
hull chooses the larger support

Support Of Convex Hull

Hull Rule

\(h_{\operatorname{conv}(A\cup B)}(u)=\max\{h_A(u),h_B(u)\}\).

Reason

A linear functional over a convex hull is maximized at an input point before averaging.

Computation

Probe both sets, keep whichever exposed value is larger, and expose the corresponding side of the hull.

Contrast With Sum

Sums add support values; hulls take the maximum of support values.

Operation: convex hull of a unionFunction operation: pointwise maximum
For a convex hull of a union, a linear function cannot improve by averaging two candidates unless one of them was already at least as good. The support value is therefore the maximum of the support values of the pieces. This slide prepares the operation ledger.
Conjugacy Link
support = conjugate of indicator

Indicator-Conjugate Link

Indicator

\(\delta_C(x)=0\) for \(x\in C\), and \(+\infty\) otherwise.

Conjugate

\(\delta_C^*(u)=\sup_x\{x\cdot u-\delta_C(x)\}=h_C(u)\).

Why The Notation Fits

Support functions are a special case of the conjugacy correspondence from Section 12.

Closed Convex Pair

For closed convex \(C\), the indicator and support function recover each other by conjugacy.

Section 12 link: conjugate functionsSection 13 link: support functions classify closed convex sets
Connect the section to the previous conjugacy section without turning the lecture into abstraction. The indicator function is zero on C and infinite outside C, so its conjugate keeps exactly the supremum of x dot u over C. This explains the notation and the closed-set reconstruction.
Reconstruction
closed convex sets are determined by h

Reconstructing Sets From Halfspaces

Reconstruction

\(C=\{x:x\cdot u\le h_C(u)\ \text{for every }u\}\)

When Exact?

Exact for closed convex \(C\). Without closedness, the same inequalities reconstruct \(\operatorname{cl} C\).

Comparison Test

\(\operatorname{cl} C_1\subseteq \operatorname{cl} C_2\) exactly when \(h_{C_1}\le h_{C_2}\) in every direction.

Fingerprint Meaning

The support function is not merely a statistic; it stores every containing support halfspace.

Artifact: assets/halfspace-reconstruction.svgAll probes together rebuild the closed convex set
State the reconstruction theorem as an intersection procedure. For a closed convex set, every support value gives one containing halfspace, and the intersection of all those halfspaces returns the set. If the set is not closed, the same data reconstructs its closure.
Domain Of h
barrier cone and boundedness

Boundedness And Finiteness

Barrier Cone

\(\operatorname{dom}h_C=\{u:h_C(u)<+\infty\}\).

Bounded Case

\(C\) bounded \(\Longleftrightarrow h_C(u)<+\infty\) for every \(u\).

Closedness Invariance

\(h_C=h_{\operatorname{cl}C}=h_{\operatorname{ri}C}\) for convex \(C\), so support sees the same outer halfspaces.

Unbounded Direction

A ray in \(C\) with positive dot product against \(u\) forces \(h_C(u)=+\infty\).

Effective domain of the support function = barrier coneFinite everywhere exactly detects boundedness
Separate three ideas that students often blur: finite support values, the barrier cone, and boundedness. The effective domain of h_C is the set of directions with finite upper bound. A nonempty convex set is bounded exactly when every direction has a finite support value.
Examples
dual norm geometry

Norm Balls

Euclidean Ball

\(h_B(u)=\sup_{\|x\|_2\le 1}x\cdot u=\|u\|_2\).

Dual Pairing

The support function of a unit ball is the corresponding dual norm.

Common Pairs

\(\ell_1\) ball supports to \(\ell_\infty\). \(\ell_\infty\) ball supports to \(\ell_1\).

Next Section Preview

Artifact: assets/norm-ball-support.svgSupport functions make dual norms visible
Use norm balls as familiar support functions. The Euclidean ball gives the Euclidean norm by Cauchy Schwarz, the l1 ball gives the infinity norm, and the infinity ball gives the l1 norm. This is the first concrete hint of polar and gauge geometry in the next section.
Lab / Checks

Numerical Probe Lab

Algorithm

Given vertices \(v_i\) and direction \(u\), compute \(v_i\cdot u\), take the maximum, and mark all maximizers.

for each direction u: scores = vertices @ u h = max(scores) face = vertices where score == h

Failure Mode To Try

Move one vertex inward or reverse the sign of \(u\). The exposed face should change before the formula changes.

Convex

\(h_C\) is convex as a supremum of linear functions.

Homogeneous

\(h_C(\lambda u)=\lambda h_C(u)\) for \(\lambda\ge0\).

Closed

Support functions determine closures, and exactly determine closed convex sets.

Finite?

Recap
set-to-function fingerprints

Recap

1. Probe

Use \(x\cdot u\) to ask how far the set reaches in direction \(u\).

2. Expose

The maximizers form \(F_C(u)\), a boundary face selected by the normal.

3. Reconstruct

Intersect all halfspaces \(x\cdot u\le h_C(u)\) to recover closed convex \(C\).

4. Compute

On polytopes, support is the max of vertex dot products.
