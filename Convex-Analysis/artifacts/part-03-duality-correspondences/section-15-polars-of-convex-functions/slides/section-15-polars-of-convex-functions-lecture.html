Polars Of Convex Functions

Function polarity is set polarity lifted to epigraphs: gauges become support functions, polar pairs give sharp multiplicative inequalities, and a second polar recovers the closed convex function.

set polar

Lecture Goal

Explain how polar duality transforms convex functions by reading their epigraphs as convex sets in one higher dimension.

Core Thread

Gauges are the clean model: a unit set \(C\) gives \(k=\gamma_C\), and polarity gives \(k^\circ=\sigma_C=\gamma_{C^\circ}\).

Caution Thread

The general polar requires \(f\ge 0\), convexity, and \(f(0)=0\); without closedness the bipolar returns \(\operatorname{cl} f\).

From Set Polarity To Epigraphs

From Set Polarity To Epigraphs

Set Polar

\(S^\circ=\{y:\langle x,y\rangle\le 1\ \text{for all }x\in S\}\).

Epigraph Route

\(\operatorname{epi} f^\circ=A((\operatorname{epi} f)^\circ)\), where \(A(x^*,\mu^*)=(x^*,-\mu^*)\).

Inspection Target

The polar epigraph consists of all certificates whose affine inequality dominates every point of the primal epigraph.

Why Reflection Appears

Polarity points downward in the epigraph coordinate; reflecting vertically turns the result back into an upper set.

Artifact: assets/epigraph-polar-map.svgFunction polarity is set polarity plus epigraph bookkeeping
Start from the picture rather than the formula. A convex function is represented by its epigraph, so polarizing functions means polarizing an epigraph in one dimension higher. The vertical reflection is the small but important bookkeeping step that turns the polar cone back into an epigraph.
Definition
least valid multiplier

Polar Function Definition

Extended Polar

\(f^\circ(x^*)=\inf\{\mu^*\ge 0:\langle x,x^*\rangle\le 1+\mu^*f(x)\ \forall x\}\).

Read The Formula

Choose a trial \(\mu^*\). It is feasible only if the same inequality works for every primal \(x\).

Sharp Inequality

\(\langle x,x^*\rangle\le 1+f(x)f^\circ(x^*)\).

Gauge Specialization

\(k^\circ(x^*)=\inf\{\mu^*\ge 0:\langle x,x^*\rangle\le \mu^* k(x)\ \forall x\}\).

When \(k\) Is Positive

\(k^\circ(x^*)=\sup_{x\ne 0}\frac{\langle x,x^*\rangle}{k(x)}\).

Two Normalizations

The gauge formula has no additive one because positive homogeneity lets every nonzero scale be tested at once.

Definition covers nonnegative convex \(f\) with \(f(0)=0\)Gauge polarity is the homogeneous case
Give students the definition as an inequality machine. For a proposed value mu star, every primal point must satisfy the displayed bound. The polar value is the smallest such multiplier, and for a gauge the additive one disappears because positive homogeneity lets the inequality be rescaled.
Gauge / Support Pair
unit ball viewpoint

Gauge And Support Pair

Gauge Of A Set

\(\gamma_C(x)=\inf\{\lambda\ge 0:x\in \lambda C\}\).

Polar Gauge

\((\gamma_C)^\circ=\gamma_{C^\circ}=\sigma_C,\quad \sigma_C(x^*)=\sup_{x\in C}\langle x,x^*\rangle.\)

Geometric Reading

The primal gauge asks for the scale of the unit body. The dual gauge asks how far a support line can be pushed.

Unit Sets

The sets \(\{x:k(x)\le 1\}\) and \(\{x^*:k^\circ(x^*)\le 1\}\) are polar convex bodies.

Artifact: assets/gauge-support-pair.svgGauge/support duality packages polar-set geometry into functions
Use the unit ball as the anchor. The gauge asks how far one must dilate C to catch x; the polar gauge asks how large the pairing can be on C. This is why a gauge and the support function of its unit set form the basic polar pair.

Norms And Quadratics
familiar inequalities

Quadratic / Norm Examples

Norm Pairs

\(\|x\|_2^\circ=\|x^*\|_2,\quad \|x\|_\infty^\circ=\|x^*\|_1,\quad \|x\|_p^\circ=\|x^*\|_q.\)

Polar Inequality

\(|\langle x,x^*\rangle|\le \|x\|_p\|x^*\|_q,\quad \frac1p+\frac1q=1.\)

Unit Ball Reading

The polar of a square is a diamond; the polar of an \(l_p\) ball is an \(l_q\) ball.

Quadratic Norm

\(k(x)=\sqrt{x^TQx},\quad k^\circ(x^*)=\sqrt{(x^*)^TQ^{-1}x^*}\).

Shape Lesson

Long axes become short axes in dual coordinates; the matrix inverse is the algebraic signature of polarity.

Checks: l-infinity/l-one and quadratic matrix rows in assets/polar-function-checks.jsonClassical inequalities are polar gauge inequalities
Emphasize that the familiar inequalities are not side examples; they are model cases of polar gauges. The Euclidean norm is self-polar, the max norm pairs with the one norm, lp pairs with lq, and an ellipsoid polar inverts the positive definite matrix.
Order Reversal
larger epigraph, smaller polar

Order Reversal

\(f\le g \quad\Longrightarrow\quad \operatorname{epi} f\supseteq \operatorname{epi} g \quad\Longrightarrow\quad f^\circ\ge g^\circ.\)

Set Logic

Larger primal sets impose more polar inequalities, so their polars are smaller.

Function Logic

A smaller function has a larger epigraph. After polarity and reflection, that becomes a larger polar function.

Audit Prompt

Before applying a rule, decide whether the operation enlarged an epigraph or enlarged a function value.

Order reversal is inherited from polar-set inclusionThe epigraph order is opposite the pointwise function order
Make the order reversal concrete. If f is below g, then epi f is larger than epi g, and larger sets have smaller polars. After returning to function order, the polar of f sits above the polar of g. This is the same reversal students saw for polar sets.
Bipolar Recovery
closure theorem

Bipolar Recovery

Bipolar Theorem For Functions

For nonnegative convex \(f\) with \(f(0)=0\), \(f^{\circ\circ}=\operatorname{cl}f\).

Closed Case

If \(f\) is closed, polarity is a symmetric one-to-one correspondence on this class.

Nonclosed Case

The second polar cannot remember a missing epigraph boundary point; it reconstructs the closed epigraph determined by all polar inequalities.

Gauge Case

For gauges, \(k^{\circ\circ}=\operatorname{cl}k\), matching the bipolar theorem for unit sets.

Artifact: assets/bipolar-function-recovery.svgSecond polar means closure, not merely undo
Connect the theorem directly to closure. The first polar keeps exactly the inequalities visible from the epigraph; the second polar reconstructs the closed convex epigraph those inequalities determine. Closed functions are recovered exactly, while nonclosed functions return with their epigraph boundary filled in.

Caveats
hypotheses do work

Domain And Positivity Caveats

1. Nonnegative

The extended polar is built for \(f(x)\ge 0\). Negative values change the geometry of the epigraph certificate.

2. Normalized At Origin

The condition \(f(0)=0\) anchors the epigraph so the polar again vanishes at the origin.

3. Convex

Convexity makes the epigraph a convex set, which is the object actually being polarized.

4. Closedness

If \(f\) is not closed, \(f^{\circ\circ}\) gives \(\operatorname{cl}f\), not the original boundary gaps.

5. Extended Values

Values \(+\infty\) are allowed; they restrict the domain and can make polar values infinite as well.

6. Gauge Extra

A gauge also needs positive homogeneity. Without it, use the extended definition with the additive \(1\).

Hypotheses: convex, nonnegative, \(f(0)=0\); closedness for exact bipolarityMost mistakes are normalization mistakes
Pause on hypotheses before examples hide them. The extended polar in this section is designed for nonnegative convex functions that vanish at the origin. Gauges add positive homogeneity. If a function is not closed, the bipolar recovers its closure, and if the positivity normalization fails the epigraph-polar formula is not the same transform.

Fenchel Conjugate Comparison
related, not identical

Comparison With Fenchel Conjugate

Fenchel

\(f^*(y)=\sup_x\{\langle x,y\rangle-f(x)\}\), so \(\langle x,y\rangle\le f(x)+f^*(y)\).

Polar

\(f^\circ(y)=\inf\{\mu\ge 0:\langle x,y\rangle\le 1+\mu f(x)\ \forall x\}\).

Obverse Bridge

For closed nonnegative \(f\) with \(f(0)=0\), an obverse function swaps two epigraph-cone coordinates and relates \(f^\circ\) to \(f^*\).

Example

For \(f(x)=|x|\), \(f^*\) is the indicator of the dual interval, while \(f^\circ(y)=|y|\).

Artifact: assets/conjugate-vs-polar.svgAdditive bound versus polar budget bound
Do not let students merge the conjugate and the polar. Fenchel conjugacy produces the best additive inequality; function polarity produces the best bound with a unit budget and a product term. For a norm, the conjugate is an indicator of the dual ball while the polar is the dual norm itself.

Recap

Recap

1. Lift To Epigraphs

Replace the graph by the upper convex set \(\operatorname{epi} f\).

2. Polarize Tests

Read \(f^\circ(x^*)\) as the least multiplier validating all pairings.

3. Recover By Closure

The second polar reconstructs \(\operatorname{cl}f\), exactly when \(f\) is closed.

4. Compare Carefully

Fenchel conjugacy gives additive bounds; polarity gives epigraph-polar budget bounds.
