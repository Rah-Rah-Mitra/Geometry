Polars Of Convex Sets

Polarity replaces a convex body by all linear tests that stay below level one: a geometry of reciprocal halfspace constraints, order reversal, and reconstruction.

Lecture Goal

Read every polar statement as a universal inequality: one dual vector must pass every point of the primal set.

Examples Thread

Balls, polytopes, cones, and gauges all become visible once support values are compared with the level \(1\) threshold.

Hypothesis Thread

Bipolar recovery is exact for closed convex sets containing the origin; without those assumptions, polarity repairs the set.

Manifest row 124, Section 14Source used for structure, terminology, theorem orientation, and page spans
Open by presenting polarity as a change in what is being stored. The primal set stores points, while the polar stores linear tests whose value never exceeds one on those points. Keep the phrase reciprocal halfspace constraints in view; every later theorem is a disciplined way of intersecting, reversing, or recovering from those tests.
Definition
support threshold

Inequality Definition

Polar Set

\(C^\circ=\{y:\langle x,y\rangle\le 1\ \text{for every }x\in C\}\).

Support Form

\(C^\circ=\{y:h_C(y)\le 1\},\qquad h_C(y)=\sup_{x\in C}\langle x,y\rangle.\)

Finite Polytope Shortcut

If \(C=\operatorname{conv}\{x_1,\ldots,x_m\}\), it is enough to test \(\langle x_i,y\rangle\le 1\) at the vertices.

Origin Reminder

If \(0\in C\), then \(0\in C^\circ\) and the level-one inequalities are naturally anchored.

Definition as a universal inequalityNotebook keyword: polar set
Do the definition slowly. A candidate y is not in the polar because it looks near the origin; it is in the polar only if the support value of C in direction y is at most one. For finite examples, students can test every vertex. For general closed convex bodies, the support function packages the same universal inequality.

Shape Translation

Wide in a primal direction means strict in the polar direction. Long axes become short axes.

Not A Shadow

Polytope Mechanics
vertices become inequalities

Polygon Polar

Finite Formula

C=\operatorname{conv}\{x_i\}\quad\Longrightarrow\quad C^\circ=\bigcap_i\{y:\langle x_i,y\rangle\le 1\}.

Active Constraint

A polar boundary point is where at least one primal point reaches the level-one bound.

Dual Reading

Facets in the polar are the visible records of primal vertices; polar vertices record competing active inequalities.

Computational Check

For a two-dimensional polytope, intersect the finitely many halfplanes and sort the resulting feasible vertices.

Artifact: assets/polygon-polar.svgReciprocal halfspaces are the construction rule
Read the polygon picture from left to right. Each primal vertex x_i contributes the halfspace of all y with pairing at most one. The polar polygon is the intersection of those reciprocal halfspaces. Point out that a facet of one side often corresponds to a vertex or active inequality on the other side.

Bipolar Theorem
recovery from all tests

Bipolar Theorem Picture

Bipolar Recovery

C=C^{\circ\circ}\quad\text{when }C\text{ is closed, convex, and }0\in C.

First Polar

Store all linear tests that the set passes at level one.

Second Polar

Intersect every halfspace certified by those tests.

Hypotheses Matter

The operation naturally closes, convexifies, and anchors at the origin when those features are missing.

Artifact: assets/bipolar-recovery.svgRecovery is halfspace reconstruction
State the bipolar theorem as a reconstruction promise with hypotheses attached. From C to C polar we keep all valid level-one tests. Applying the same operation again intersects all halfspaces supported by those tests. If C is closed, convex, and contains the origin, no information is lost; otherwise the operation repairs the set.
Cones
level one becomes sign

Cones And Dual Cones

Dual Cone

K^*=\{y:\langle x,y\rangle\ge 0\ \forall x\in K\}.

Set Polar Of A Cone

K^\circ=\{y:\langle x,y\rangle\le 0\ \forall x\in K\}=-K^*.

Why The Threshold Vanishes

If \(x\in K\), then \(\lambda x\in K\) for every \(\lambda\ge 0\); the bound must survive all scales.

Sign Convention

Always check whether a text names the nonnegative dual cone or the nonpositive polar cone.

Artifact: assets/cone-dual-polar.svgNotebook keyword: dual cone
For cones, let scaling do the algebra. The level-one bound can hold for all positive multiples only when the pairing has the correct sign. With the sign convention on the slide, the set polar of a cone is the negative of the usual nonnegative dual cone. That distinction prevents later sign errors.
Dimension Bookkeeping
pointedness trades with interior

Lineality And Full Dimension

Lineality Test

L\subseteq K\cap(-K)\quad\Longrightarrow\quad K^\circ\subseteq L^\perp.

Full Cone

If a cone fills the ambient space, its polar is forced toward a pointed shape.

Pointed Cone

If \(K\cap(-K)=\{0\}\), its nonnegative dual has room in all directions.

Flat Cone

Lineality in the primal removes polar directions by orthogonality.

Closed Cone Rule

For closed cones, pointedness and full dimension trade across duality.

Lineality is detected by sign tests in both directionsDimension bookkeeping prevents false separation claims
This is the rank and lineality bookkeeping slide. A line inside a primal cone forces the polar cone to live in the orthogonal subspace, because both directions along the line must satisfy the sign test. For closed cones, pointedness and full dimension trade places under duality. Pause here because many separation arguments secretly rely on exactly this bookkeeping.
Gauge And Support
function view

Gauge / Support Connection

Gauge

\(\gamma_C(x)=\inf\{\lambda>0:x\in \lambda C\}.\)

Polar Identity

\(\gamma_C(x)=h_{C^\circ}(x)\quad\text{for closed convex }C\text{ containing }0\text{ in the usual gauge setting}.\)

Two Directions

\(h_C(y)\le 1\) describes the polar; \(h_{C^\circ}(x)\) measures the scale needed to reach \(x\).

Practical Reading

The gauge is a radial membership meter, while support is a linear-testing meter.

Gauge and support are the functional face of polarityConnects this section to support functions and later polar functions
Connect polarity to quantities students have already seen. The support function h_C asks how far C reaches in a direction. The polar is the sublevel set where that reach is at most one. Conversely, when C is closed, convex, and absorbs the direction under study, the gauge of C is the support function of C polar.
Reconstruction
membership by all polar tests

Halfspace Reconstruction

Intersection Formula

C^{\circ\circ}=\bigcap_{y\in C^\circ}\{x:\langle x,y\rangle\le 1\}.

Database View

Store normals \(y\), not points \(x\). Membership becomes a pass/fail query over all stored tests.

Separation View

A point outside a closed convex \(C\) is rejected by at least one valid polar halfspace.

Teaching Move

Make students name the rejecting normal before invoking the theorem.

Halfspaces are the operational form of \(C^{\circ\circ}\)Separation supplies the missing test
Halfspace reconstruction is the operational version of the bipolar theorem. Imagine storing a set not by drawing it but by listing every valid polar normal. To query whether x belongs to the recovered body, test all those normals. If x sits outside a closed convex C containing the origin, separation supplies a polar normal that rejects it.

Failure Modes
what bipolar repairs

Failure Without Closure / Origin

Closure Failure

D=\{x:\|x\|_2<1\}\quad\Rightarrow\quad D^{\circ\circ}=\overline{D}.

Origin Failure

C=\{2e_1\}\quad\Rightarrow\quad C^{\circ\circ}=[0,2e_1].

Correct General Memory

The bipolar operation remembers the closed convex hull of \(C\cup\{0\}\) in finite-dimensional settings.

Lesson

Hypotheses tell us what polarity preserves exactly, not what it can never see.

Failure modes are hypothesis diagnosticsClosure and origin anchoring are not cosmetic
Use the two failures to show what the bipolar operation remembers. An open disk has the same polar as its closure, because support uses a supremum rather than an attained maximum. A set away from the origin reconstructs with the origin adjoined and convexified. The theorem is not failing; the hypotheses describe exactly what information polarity preserves.
