Set-Valued Maps
one input, many outputs

A Process Starts As A Set-Valued Map

Set-Valued Map

A map \(A:X\rightrightarrows Y\) assigns each input \(x\) a subset \(A(x)\subseteq Y\).

Graph Encoding

\(\operatorname{gph}A=\{(x,y):y\in A(x)\}\).

Teaching Translation

A fiber is useful for reading an example; the graph is the object that carries convexity.

Vocabulary

Domain, range, image, and inverse are all ordinary relation operations once the graph is visible.

Set-valued notation: \(A:X\rightrightarrows Y\)Graph first, fibers second
Spend a minute making the notation feel concrete. For a usual function, the vertical fiber over an input contains one point. For a set-valued map, that fiber can be an interval, a cone, or any other set. The graph collects all allowed input-output pairs and becomes the place where convex structure is tested.
Definition
graph cone criterion

A Convex Process Is A Map Whose Graph Is A Cone

Convex Process

\(A\) is a convex process when \(\operatorname{gph}A\) is a convex cone in \(X\times Y\).

Equivalent Closure Test

If \(y_i\in A(x_i)\) and \(\alpha_i\ge0\), then \(\alpha_1y_1+\alpha_2y_2\in A(\alpha_1x_1+\alpha_2x_2)\).

Interpretation

Positive scaling and convex addition happen simultaneously in the product pair \((x,y)\).

Closure is checked on pairs \((x,y)\)Convexity alone is not enough; the origin and rays matter
This is the main definition slide. The important point is that the cone property lives in product space, not separately in the input and output coordinates. Once two graph points are allowed, every nonnegative linear combination of the two pairs must also be allowed. That single condition packages positive homogeneity and convex additivity.

The Notebook Model: A Wedge Of Output Fibers

Example Process

For \(x\ge0\), let \(A(x)=\{y:0.5x\le y\le1.5x\}\); otherwise \(A(x)=\varnothing\).

Graph

The graph is a wedge between two rays, hence a convex cone.

Fibers

Each positive input has an interval of feasible outputs, and the interval scales with \(x\).

At The Origin

The cone property forces the origin pair \((0,0)\) to be part of the graph when the process is nonempty.

Model from the notebook invariantGraph wedge: \(0.5x\le y\le1.5x,\ x\ge0\)
Use the wedge as the reliable running example. The fibers are vertical intervals, but the graph is the triangular cone between two rays. Scaling an input from one to two scales the whole interval of outputs. This makes the formal definition visible without requiring a high-dimensional example.
Process Images
push sets through fibers

Images Are Unions Of Output Fibers

Image Of A Set

\(A(C)=\bigcup_{x\in C}A(x)\).

Domain And Range

\(\operatorname{dom}A=\{x:A(x)\ne\varnothing\}\), \(\operatorname{rge}A=A(\operatorname{dom}A)\).

Cone Transfer

If \(C\) is a convex cone and \(A\) is a convex process, then \(A(C)\) is a convex cone in the output space.

Inspection Question

Which output values are reached by at least one input in the selected set?

Image means union, not pointwise evaluationFor a process, cone inputs produce cone outputs
Images are where set-valued notation pays off. For an ordinary map, the image of C is the collection of all values f of x. For a process, every input contributes a whole fiber, so the image is a union of sets. The graph-cone closure explains why cone-shaped input families produce cone-shaped output families.
Inverse Process
flip the graph

The Inverse Process Swaps Input And Output Roles

Inverse

\(A^{-1}(y)=\{x:y\in A(x)\}\).

Graph Relation

\(\operatorname{gph}A^{-1}=\{(y,x):(x,y)\in\operatorname{gph}A\}\).

Consequence

Flipping coordinates takes convex cones to convex cones, so the inverse of a convex process is again a convex process.

Example Fiber

For the wedge model, \(A^{-1}(1)=[2/3,2]\).

Inverse is a relation operationThe cone property survives coordinate exchange
The inverse process should feel less exotic than it first appears. It asks for all inputs that could have produced a chosen output. In graph language, nothing is recomputed; the two coordinates are exchanged. Because a coordinate flip preserves conic convexity, the inverse process stays inside the same algebraic category.
Process Algebra
scaling and addition

Convex Processes Are Stable Under Positive Algebra

Positive Scaling

\((\lambda A)(x)=\lambda A(x)\), \(\lambda\ge0\).

Convex Addition

\((A+B)(x)=A(x)+B(x)\).

Conic Combination

Scale graph pairs and add them in product space.

Image Closure

Images of cones remain cones when the process graph is a cone.

Closure Principle

If \(A\) and \(B\) are convex processes, then their positive scalar multiples and fiberwise sums are convex processes.

Bookkeeping

The input must be shared in \((A+B)(x)\); the output is a Minkowski sum of the two fibers.

Positive algebra keeps graphs conicFiberwise addition is Minkowski addition at each input
This slide connects the section back to the algebra of convex sets and bifunctions. Positive scaling of a process scales each output fiber, while addition combines two output fibers at the same input. The reason these operations preserve convex processes is not a new trick; it is the same graph-cone closure applied to the resulting pairs.

Failure Modes
what the graph catches

Graph-Cone Tests Expose Hidden Hypothesis Failures

Missing Boundary

A limit pair can be approached by feasible graph pairs but fail to belong to the process graph.

Wrong Sign

Using negative coefficients is not part of cone closure unless the graph also contains the opposite ray.

Fiber Illusion

Convex fibers alone do not guarantee a convex process; the graph must be conic in both coordinates.

Input Mismatch

When adding processes, combine fibers over the same input, not unrelated fibers over unrelated inputs.

Process proofs often reduce to graph membershipClosures and domains decide whether limiting certificates survive
Use this slide to prevent overgeneralization. A process is not certified by nice-looking fibers alone. Boundary pairs, sign restrictions, and input alignment all matter. The product-space graph catches these failures because every algebraic step becomes a concrete membership question for a pair rather than a vague visual impression.
