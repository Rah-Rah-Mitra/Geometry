Directional Derivatives And Subgradients

Nonsmooth convex functions still have directional slope data. Subgradients organize that data as supporting hyperplanes to epigraphs.

Lecture Goal

Turn the formal objects \(f'(x;y)\), \(\partial f(x)\), and \(N_C(x)\) into diagrams and checkable inequalities.

Core Dictionary

Directional derivatives are support values; subgradients are affine certificates; normal cones are subgradients of indicator functions.

Guiding Question

When a tangent plane is not unique, what set of supporting planes replaces the gradient?

Directional Derivative
lambda approaches 0 from above

Convexity Makes The Forward Slope Settle

Definition

\(f'(x;y)=\lim_{\lambda\downarrow 0}\dfrac{f(x+\lambda y)-f(x)}{\lambda}\).

Convex Secant Rule

For fixed \(x\) and \(y\), the forward difference quotient is monotone in the step length, so the one-sided limit exists in the extended real line.

Derivative Function

The map \(y\mapsto f'(x;y)\) is convex and positively homogeneous. It behaves like a support function even when no unique gradient exists.

Two-Sided Test

Ordinary directional differentiability requires the opposite directions to agree: \(f'(x;-y)=-f'(x;y)\).

Artifact: assets/directional-slope.svgOne-sided slope is the local input to subgradient geometry
Use the secant picture to separate one-sided information from ordinary differentiability. For convex functions, the forward difference quotients settle monotonically as the step length shrinks. The limit can be infinite, but it exists, and as a function of the direction it is convex and positively homogeneous.

A Subgradient Supports The Epigraph

Subgradient

\(x^*\in\partial f(x)\) when \(f(z)\ge f(x)+\langle x^*,z-x\rangle\) for every \(z\).

Geometric Meaning

The graph of \(z\mapsto f(x)+\langle x^*,z-x\rangle\) is a nonvertical supporting hyperplane to \(\operatorname{epi} f\) at \((x,f(x))\).

Normal Vector

The support hyperplane has normal \((x^*,-1)\). The negative last component is what makes it nonvertical and readable as an affine function.

Global Contact

Touching at \(x\) is not enough. The affine plane must stay below the whole function, not just near the point of contact.

Artifact: assets/subgradient-support-plane.svgSubgradient inequality = epigraph support certificate
The epigraph view is the geometric heart of the section. A subgradient at x is not merely a local slope; it draws a nonvertical affine hyperplane that touches the epigraph at the boundary point and leaves the whole epigraph on one side.
Certificate
one vector, all comparison points

The Inequality Is A Global Lower-Support Test

Checkable Form

\(x^*\in\partial f(x)\quad\Longleftrightarrow\quad f(z)-f(x)-\langle x^*,z-x\rangle\ge 0,\ \forall z.\)

What Is Being Tested?

One proposed slope vector is tested against infinitely many comparison points. A single violation rejects the candidate.

Why Convexity Matters

For convex \(f\), a global affine floor can touch the graph and still leave all other values above it.

Classroom Move

Ask students to pick \(z\), compute the residual, and watch which proposed slopes survive the test.

Subgradient inequality is both algebra and a visual residual testEvery surviving candidate is a global support plane
Present the inequality as a certificate that can be checked against every possible comparison point. Once a candidate vector passes the global inequality, the affine function through the base point is a lower support to the graph, so local visual contact becomes a global guarantee.
Set Of Certificates
closed convex set

The Subdifferential Collects Every Supporting Slope

Subdifferential

\(\partial f(x)=\{x^*: f(z)\ge f(x)+\langle x^*,z-x\rangle\ \hbox{for all }z\}\).

Shape

Each comparison point \(z\) cuts out a closed halfspace of allowed \(x^*\). Their intersection is closed and convex.

Existence

For a proper convex function, points in \(\operatorname{ri}(\operatorname{dom} f)\) have nonempty subdifferentials.

Possibilities

The set may be empty, a singleton, a line segment, a polytope, or a smooth convex body depending on the local geometry.

Subdifferentiable at x means this set is nonemptyClosed convexity comes directly from linear inequalities in x*
The subdifferential collects all valid certificates at a point. Because each comparison point contributes a closed halfspace condition in the candidate slope variable, the resulting set is closed and convex. It may be empty, a singleton, an interval, or a higher-dimensional body.
Example
cusp = interval of slopes

The Cusp Turns One Gradient Into A Whole Interval

Absolute Value

For \(f(t)=|t|\), \(\partial f(0)=[-1,1]\).

Outside The Cusp

If \(t>0\), \(\partial f(t)=\{1\}\). If \(t<0\), \(\partial f(t)=\{-1\}\). Smooth pieces give singleton subdifferentials.

At The Cusp

Every slope \(s\in[-1,1]\) gives the affine floor \(h(z)=sz\) and satisfies \(|z|\ge sz\) for all \(z\).

Directional Values

The one-sided derivative at zero is \(f'(0;y)=|y|\), the support function of the interval \([-1,1]\).

Artifact: assets/abs-subdiff.svgCusp geometry gives many valid supporting lines
The absolute value cusp is the cleanest nonsmooth example. Away from zero the subdifferential is a singleton matching the ordinary derivative. At zero, every slope between minus one and one supports the graph, so the subdifferential is the whole interval.
Example
active pieces generate slopes

For A Max Of Affine Pieces, Only Active Slopes Matter

Max Rule

If \(f(z)=\max_i(\langle a_i,z\rangle+b_i)\), then \(\partial f(x)=\operatorname{conv}\{a_i:i\in I(x)\}\).

Active Set

\(I(x)\) contains the affine pieces that actually attain the maximum at \(x\). Pieces below the envelope are inactive.

Polyhedral Geometry

Polyhedral convex functions have polyhedral subdifferentials, and their directional derivatives are support functions of those polytopes.

At A Corner

Two or more active affine pieces create a kink. The allowed supporting slopes fill the convex hull between their gradients.

Artifact: assets/max-affine-subdiff.svgActive gradients produce the local slope set
For a pointwise maximum of affine functions, inactive pieces sit strictly below the envelope and do not constrain the local support. The active affine pieces determine the kink, and the subdifferential is the convex hull of their slopes.
Indicator Functions
subgradients become normals

The Indicator Function Recovers The Normal Cone

Indicator Case

\(\partial \delta_C(x)=N_C(x)=\{x^*: \langle x^*,z-x\rangle\le 0,\ \forall z\in C\}\).

Why It Works

The indicator is zero on \(C\) and \(+\infty\) outside. The subgradient inequality only has content against feasible comparison points.

Level Sets

For a subdifferentiable \(f\), normals to a strict sublevel boundary are generated by nonnegative multiples of subgradients.

Optimization Language

Normal cones are the geometric form of constraints; subgradients are the geometric form of nonsmooth objective slopes.

Indicator subdifferential = normal coneConstraint geometry and nonsmooth calculus share the same certificate
Indicator functions translate subgradient language into normal cone language. If the function is zero on a convex set and infinite outside it, the subgradient inequality says precisely that the candidate vector forms a nonpositive angle with every feasible displacement.
Dual Geometry
support function of partial f(x)

Directional Derivatives Read The Subdifferential By Linear Probes

Support Formula

When the usual closed proper interior hypotheses apply, \(f'(x;y)=\sup_{x^*\in\partial f(x)}\langle x^*,y\rangle\).

Subgradient Test

A vector \(x^*\) is a subgradient if and only if \(\langle x^*,y\rangle\le f'(x;y)\) for every direction \(y\).

Meaning

The one-sided derivative is the support function of the subdifferential set. A nonsmooth point is read by probing all its supporting slopes.

Closure Caveat

At relative boundary directions, the closed support-function picture can differ from the raw directional derivative values.

Directional derivative function is convex and positively homogeneousIts closed form is the support function of the subdifferential
This slide closes the loop between directional derivatives and subgradients. Under the standard closed proper interior hypotheses, the directional derivative in direction y is obtained by maximizing the linear probe against the subdifferential set. Emphasize the inspection target: the support-function picture turns a possibly one-sided slope into an optimization problem over all supporting hyperplanes at the base point.
First-Order Condition
zero is a certificate

A Convex Minimum Is Detected By \(0\in\partial f(x)\)

Optimality Criterion

For convex \(f\), \(x\) minimizes \(f\) exactly when \(0\in\partial f(x)\).

Forward Direction

If \(0\in\partial f(x)\), the subgradient inequality becomes \(f(z)\ge f(x)\) for every \(z\).

Reverse Direction

If \(x\) is a minimizer, the constant affine function \(h(z)=f(x)\) is a global supporting floor.

Fenchel View

The condition \(x^*\in\partial f(x)\) is equivalent to equality in \(f(x)+f^*(x^*)=\langle x,x^*\rangle\).

Subgradient inclusion replaces gradient equals zeroWorks for nonsmooth convex objectives
The first-order condition becomes almost literal. If zero is a subgradient at x, then the subgradient inequality reduces to saying every other point has value at least f of x. Conversely, a minimizer makes the zero affine floor valid.

Finite Value Does Not Always Mean A Subgradient Exists

Smooth Interior

If \(f\) is differentiable near \(x\), the subdifferential collapses to one vector.

\(\partial f(x)=\{\nabla f(x)\}\)

Nonsmooth Interior

A kink can have many affine supports, but still every support is nonvertical and globally valid.

\(\partial |0|=[-1,1]\)

Boundary Failure

At some domain boundary points the only support behavior is vertical, so no vector \(x^*\) can define a global affine minorant.

\(\partial f(x)=\varnothing\)

Practical Rule

Interior of the effective domain is safe; boundary points require inspection.

Existence Window

For a proper convex function, subgradients exist on \(\operatorname{ri}(\operatorname{dom} f)\), and outside the domain the subdifferential is empty.

Differentiable Contrast

When differentiability holds in a neighborhood, the subgradient machinery reduces to the classical gradient picture.

Contrast slide: differentiable, nonsmooth, and empty casesBoundary geometry explains why subdifferentials can fail to exist
End the examples by warning that finite value at a point is not the same as subdifferentiability. Interior points of a proper convex domain have subgradients, while certain boundary points can force vertical support behavior and leave no nonvertical affine minorant.
