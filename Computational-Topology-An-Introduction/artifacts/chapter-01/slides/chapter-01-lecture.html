Graphs As Topological Objects

A graph is finite combinatorial data, a one-dimensional topological space, and sometimes a geometric embedding. The lecture asks which facts survive when the drawing changes.

Invariant 1Connected components ignore the drawing.

The First Invariant: Connectedness

Definition
Path And Component
Vertices \(u\) and \(v\) are connected when a finite edge path joins them. This equivalence relation partitions \(V\) into connected components.
Algorithmic check: \( \mathrm{components}(G) = \{C_1,\ldots,C_k\} \)

Notebook sanity route: compare union-find labels with networkx.connected_components.

Intrinsic: path existence in the abstract graph.Extrinsic: where the vertices were drawn.
Use the highlighted components as the first invariant students can certify algorithmically. A drawing may stretch, bend, or reorder the vertices, but the question of whether one can travel from one vertex to another through edges is intrinsic to the graph.
CertificatesConnectivity with no cycle slack.

Trees Are Minimal Connectivity Certificates

Equivalent Tests For A Finite Graph

  • Connected and \(m = n - 1\).
  • No cycles and maximal under adding edges.
  • Exactly one simple path between any two vertices.
  • A spanning tree is a subgraph certificate for a larger connected graph.
tree check: \( |E(T)| = |V(T)| - 1 \)
Minimal means every edge is doing work.Adding one more independent edge makes a cycle witness.
Present the tree as a certificate rather than merely a type of graph. It proves connectivity with the fewest possible edges, and the moment one adds an extra edge a cycle appears. The numerical test m equals n minus one should be paired with the unique-path inspection.
Separation LanguageFinite graph version of a topological cut.

No Separation Means Connected

Criterion
Graph Separation
A graph is disconnected exactly when its vertices split as \(V=A\sqcup B\), with \(A,B\neq \emptyset\), and no edge has one endpoint in each part.

Connectedness can be tested by trying to build such a split. Failure of every split is positive evidence.

Graph separation is a finite partition test.Topological separation will replace vertices by open sets.
This slide connects the graph definition to the topological language of separations. A disconnected graph admits a partition with no crossing edge, while a connected graph defeats every attempted cut. The visual test prepares the later continuous version without requiring new machinery yet.
From Graphs To SpacesBases, subspaces, paths, and connected sets.

Continuous Connectedness

Topological Space

A topology declares which subsets are open. A basis is a smaller observable collection whose unions generate the opens.

Subspace

If \(Y\subset X\), the open sets in \(Y\) are \(Y\cap U\) for opens \(U\) in \(X\). The ambient space lends its observations.

Path vs Connected

Path-connected gives an explicit curve between points. Connected only forbids a separation; it is weaker in general spaces.

A graph path is discrete evidence.A continuous path is a map from an interval.
Shift from finite graphs to spaces by asking what replaces an edge path. A basis tells us which local observations count as open, the subspace topology inherits those observations, and path-connectedness supplies explicit curves. The important distinction is that connectedness can survive even when no path witness exists.
Algorithmic CertificateEdges arrive; components merge.

Union-Find As A Running Certificate

Operations

  • make_set(v): start a singleton component.
  • find(v): return the component representative.
  • union(u,v): merge two components if an edge connects them.

Surfaced check: after all edges, labels match the connected components from NetworkX.

Union-find is a dynamic certificate for graph connectedness.Redundant edges become cycle evidence.
Introduce union-find as a live connectivity certificate. Each edge insertion either merges two components or certifies that the edge is redundant for connectivity. The slide should feel like the algorithmic version of the component coloring from earlier in the lecture.
Near Constant TimeWeighted union plus compression flattens evidence.

Why Path Compression Matters

Performance Story

  • Weighted union attaches the smaller tree below the larger tree.
  • Path compression rewires every searched vertex to the root.
  • A sequence of \(m\) operations on \(n\) elements takes \(O(m\,\alpha(n))\) amortized time.
\(\alpha(n)\) grows so slowly that it behaves as a tiny constant in practice.
The data structure changes after a query.Future proof obligations become cheaper.
The point is not only that path compression is faster; it changes the shape of future evidence. After a find operation, a long ancestry chain becomes nearly flat, so later connectivity queries see a much shallower forest. Weighted union and compression explain the inverse Ackermann behavior together.
Jordan Curve TheoremA simple closed curve separates the plane.

Closed Curves And Inside/Outside

Theorem Orientation
Jordan Separation
A simple closed curve in the plane has exactly two complementary regions, one bounded and one unbounded, and the curve is their shared boundary.

The theorem is qualitative; the next slide turns it into a point-location predicate.

Topology gives the promise.Algorithms choose a finite crossing test.
Use the Jordan curve theorem as a topological promise with computational consequences. A simple closed curve separates the plane into an inside and an outside, and any crossing from one side to the other must meet the curve. That promise is exactly what point-location tests exploit.
Point-In-PolygonCount crossings modulo 2.

Parity Test For Point Location

Robust Predicate Rules

  1. Cast a ray that avoids ambiguous vertex hits when possible.
  2. Toggle the state on every proper boundary crossing.
  3. Classify boundary points separately before parity is applied.
inside iff \( \#(\mathrm{ray}\cap \partial P) \equiv 1 \pmod 2 \)
Computational check: parity agrees with orientation-based boundary handling.Topology becomes a branch.
Walk through the ray test carefully because it is the first place topology becomes a branching algorithm. A generic ray from the query point toggles state each time it crosses the polygon boundary. Odd means inside, even means outside, and vertex cases need a consistent convention.
Local DecompositionEars certify the count.

Triangulating A Polygon

Counting Contract

  • Every simple polygon with \(n\) vertices can be triangulated.
  • Ear clipping removes one triangle and preserves simplicity.
  • For \(n=9\), expect \(6\) diagonals and \(7\) triangles.
check: diagonals = n - 3; triangles = n - 2
Triangulation converts a region claim into small local pieces.All visuals are synthetic redraws.
Triangulation turns a global polygon into local triangles while preserving the same region. Ears are the visible certificate: clip an ear, recurse on the smaller polygon, and count the result. For n vertices the sanity check is n minus three diagonals and n minus two triangles.
Signed EvidenceParity loses orientation; winding remembers it.

Winding Number Beyond Simple Curves

Algebraic Crossing Count

Winding number is the degree of the map from the curve to directions around a query point.

\( \mathrm{wind}_\gamma(q) = \frac{1}{2\pi}\int_\gamma d\arg(z-q) \)

Regions with the same integer label are indistinguishable by winding.

Parity: modulo 2.Winding: signed integer.
Parity forgets orientation, but winding number remembers how many signed turns the curve makes around the query point. This is why it works beyond simple curves. The regions in the diagram should be read as accumulated algebraic evidence, not as ordinary inside and outside labels.
Knot DiagramsA plane curve plus over-under data.

Knots Need Projection Data

Projection Data

  • The knot is an embedded circle in three-dimensional space.
  • The diagram is a projection with crossing annotations.
  • Without over-under data, different knots can share the same shadow.
Intrinsic object: embedded circle up to deformation.Extrinsic record: a useful planar diagram.
A knot diagram is not just a plane curve with crossings. Each crossing stores over-under information, and that extra data records a spatial embedding of a circle in three dimensions. The trefoil motif should make students inspect where the projection alone would be ambiguous.
Diagram MovesLocal rewrites; global knot type unchanged.

Reidemeister Moves Preserve Tricolorability

Tricolorability Test

Color arcs with three colors so that at every crossing either all incident arcs have one color, or all three colors appear. The property survives Reidemeister moves.

An invariant is useful when it can be checked on any diagram.It need not classify everything.
Explain the moves as local rewrites that do not change the knot type. Tricolorability is useful here because it is easy to test on a diagram yet survives all three moves. It is not a complete invariant, but it is a clear certificate that some diagrams cannot be equivalent.
Link InvariantsSigned crossing information becomes a number.

Links And Signed Crossings

Three Related Counts

  • Linking number: global interaction between two components.
  • Writhe: signed self-crossings in a chosen diagram.
  • Twist: local rotation of a ribbon or framing.
\( \mathrm{lk}(L_1,L_2)=\frac{1}{2}\sum \mathrm{sign}(c) \)
Crossing signs add algebra to topology.Only the allowed move set decides what is invariant.
For links, crossings between different components carry signed contributions to the linking number. Writhing and twisting describe local signed behavior of a diagram or ribbon, while linking is global and survives allowed deformations. Keep the focus on what is counted and what is invariant.
Planar EmbeddingsFaces are embedding data.

Euler Relation For Planar Graphs

Ledger For A Connected Planar Embedding

\( n - m + f = 2 \)
  • \(n\): vertices.
  • \(m\): edges.
  • \(f\): faces, including the unbounded face.

Computational check: a valid planar embedding reports face walks that satisfy the ledger.

The same abstract graph may have several embeddings.Euler sees the embedded cell structure.
Return to graphs, now with an embedding in the plane. Vertices and edges alone are intrinsic to the graph, but faces depend on the embedding. Once the embedding is planar and connected, the ledger n minus m plus f equals two becomes a strong topological check.
Non-Planarity CertificatesCounting rules out impossible drawings.

Why K5 And K3,3 Cannot Be Planar

\(K_5\)

Planar simple graphs with \(n\ge 3\) satisfy \(m\le 3n-6\). For \(K_5\), \(m=10\) but \(3n-6=9\).

\(K_{3,3}\)

A planar bipartite graph with \(n\ge 3\) satisfies \(m\le 2n-4\). For \(K_{3,3}\), \(m=9\) but \(2n-4=8\).

NetworkX check to surface: check_planarity(K5) = false and check_planarity(K3,3) = false. Kuratowski's theorem says every non-planar graph contains a subdivision of one of these obstructions.

Counting is a proof certificate.Kuratowski upgrades examples into a complete obstruction theorem.
Use the two obstruction panels to show how counting defeats impossible drawings. For K5, every face would need length at least three, which conflicts with the Euler edge bound. For K3,3, bipartiteness forbids triangular faces, giving an even stricter bound. These are certificates of non-planarity.
Constructive EmbeddingConvex boundary plus sparse linear system.

Tutte's Theorem: Straight Edges From Averages

Barycentric Equations

Pin the outer face to a convex polygon. For every interior vertex \(i\), solve

\( x_i = \frac{1}{\deg(i)}\sum_{j\sim i} x_j,\quad y_i = \frac{1}{\deg(i)}\sum_{j\sim i} y_j \)

Sparse linear solve check: straight edges have no crossings except shared endpoints.

Topology supplies the planar embedding.Linear algebra supplies straight geometry.
End the constructive arc with Tutte's theorem. Pin the outer face as a convex polygon, place every interior vertex at the average of its neighbors, and solve the sparse linear system. The barycentric equations turn a topological embedding certificate into straight-line geometry.
