Adjacent Transpositions

A Local Swap Can Switch Two Persistence Pairs

repair \(R\) and \(U\)
then read the new lows
Critical Case
After swapping neighboring simplexes, the matrix may fail to be reduced. A single column addition restores the ledger, and the pairing endpoints can exchange partners.
  • Non-switch: the low entries remain attached to the same pairs.
  • Switch: two pairs trade partners at the crossing time.
  • The update is local, but the vineyard records the global path.
Check: transposition pairing update = switchOne local crossing, two affected pairs
Emphasize that a generic one-parameter family changes the order only by adjacent transpositions. Most swaps merely rename neighboring columns, but the critical cases force a column addition and switch two persistence pairings. That local repair is the engine behind vineyards.

VIII.2 - Stability Theorems

Filtration Stability Is A Bound On Diagram Motion

monotone functions
finite simplicial complex
Stability Theorem For Filtrations
For monotone \(f,g:K\to\mathbb R\), in every dimension \(p\), \[ W_\infty(Dgm_p(f),Dgm_p(g))\le \|f-g\|_\infty . \]
Proof Lens
Move from \(f\) to \(g\) by \(f_t\). Vines connect matched endpoint points, and no vine can move faster than the maximum simplex-value perturbation.
monotone filtration functions straight-line homotopy connected vines bottleneck bound
Core theorem: filtration stabilityMeasurement promise: small input change, small diagram change
State the theorem as a measurement guarantee. The proof idea is visible from the vineyard: each simplex value moves with slope bounded by the endpoint infinity norm, so every vine endpoint moves by at most that bound in birth and death coordinates.
Tame Functions

Sublevel Sets Generalize Finite Filtrations

critical values
finite homological ledger
Tame Function
A continuous function is tame when it has finitely many homological critical values and finite-rank homology for all sublevel sets.
Stability For Tame Functions
For triangulable \(X\) and tame \(f,g:X\to\mathbb R\), \[ W_\infty(Dgm_p(f),Dgm_p(g))\le \|f-g\|_\infty . \]
Why The Diagonal Is Infinite
The diagonal supplies harmless matches for features that are born and die under perturbation.
Generalization: finite filtration theorem to tame functionsCritical values replace simplex insertion times
Move from finite filtrations to functions by looking at sublevel sets. Tameness says there are only finitely many homological event levels and finite ranks, so the diagram remains a finite off-diagonal ledger plus the diagonal reservoir needed for matching.
Diagram Metric II

more sensitive
needs more hypotheses
Definition
\[ W_q(X,Y)=\left(\inf_{\eta:X\to Y}\sum_{x\in X}\|x-\eta(x)\|_\infty^q\right)^{1/q}. \]
Wrinkle Warning
Many tiny bumps can stay within a small vertical epsilon while producing many short persistence points. Bottleneck stays small; Wasserstein can accumulate a large total cost.

Contrast Wasserstein with bottleneck carefully. Bottleneck ignores how many small wrinkles appear if the largest displacement stays small, while Wasserstein sums all those costs. This is why extra hypotheses are needed before a Wasserstein stability statement can be trusted.
Wasserstein Stability

Total Persistence Controls Accumulated Matching Cost

Lipschitz functions
polynomial growth domains
Total Persistence
\[ \Phi_k(X)=\sum_{x\in X}\operatorname{pers}(x)^k. \]
Lipschitz Stability Form
For suitable metric spaces and \(q\ge k>j\), \[ W_q(Dgm_p(f),Dgm_p(g))\le C\|f-g\|_\infty^{1-k/q}. \]
  • Lipschitz regularity limits how fast values change over the domain.
  • Polynomial triangulation growth limits how many small features can accumulate.
  • Total persistence converts worst-case stability into summed-cost stability.

sets the budget
Technical bridge: polynomial growth implies bounded total persistenceThen \(q\)-Wasserstein stability follows for \(q\ge k\)
The Lipschitz theorem uses geometry of the domain to prevent infinitely many meaningful wrinkles from accumulating. Polynomial growth of triangulations gives bounded total persistence, and that bound converts the bottleneck control into a Wasserstein estimate with an exponent depending on q and k.
VIII.3 - Length Of A Curve

A Direction Turns A Curve Into A Persistence Diagram

height function
\(f_u=g_u\circ\gamma\)
Height Function
For \(u\in S^1\), \(g_u(x)=\langle u,x\rangle\). The composition \(f_u=g_u\circ\gamma\) converts the curve into a scalar function on \(S^1\).
Persistence Reading
The number of alive zero-dimensional classes at height \(z\) counts sublevel arcs; integrating that count gives total persistence.
\[ \int_{\mathbb R}\operatorname{card}(f_u^{-1}(z))\,dz = 2\Phi(f_u) \]
Artifact ledger: curve-height-persistenceCurve geometry becomes height persistence for each direction
For the curve application, fix one direction and turn a closed curve into a height function on the circle. The zero-dimensional diagram counts sublevel components, and total persistence measures how long those components remain alive as horizontal lines sweep across the curve.

VIII.4 - Bipartite Graph Matching

Distance Computation Is A Perfect Matching Problem

off-diagonal points
plus diagonal copies
Reduction Lemma
Bottleneck distance is the smallest \(\epsilon\) for which the threshold graph \(G(\epsilon)\) has a perfect matching.
Wasserstein Version
The \(q\)-Wasserstein distance is the \(q\)-th root of the minimum total \(q\)-cost perfect matching.
\[ c_\infty(x,y)=\|x-y\|_\infty,\qquad c_q(x,y)=\|x-y\|_\infty^q \]
Artifact ledger: bipartite-matching-stepsDiagonal copies make the graph balanced
Now make the metric computational. Off-diagonal points from one diagram, off-diagonal points from the other, and their diagonal copies form a balanced bipartite graph. Bottleneck asks for the smallest threshold with a perfect matching; Wasserstein asks for minimum total cost.
Matching Algorithms

Augmenting Paths Turn Diagram Metrics Into Computations

maximum matching
minimum cost matching
Augmenting Path
Orient unmatched edges from \(U\) to \(V\), matched edges from \(V\) to \(U\), and search from an unmatched source to an unmatched target. Flipping along the path increases the matching size by one.
