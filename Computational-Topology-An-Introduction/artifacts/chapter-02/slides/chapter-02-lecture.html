Local Surface Model

Computational Test

A triangulated closed surface is locally valid when each edge has two incident triangles and each vertex star has a circular link.

\[ \operatorname{Lk}(v)\cong S^1 \quad \text{or} \quad [0,1]\text{ at boundary} \]

Use the disk and half-disk models to separate the abstract surface from any drawing in three-space. Interior points must have disk neighborhoods, boundary points have half-disk neighborhoods, and in a triangulation the same condition becomes a statement about vertex links. The computational habit is to test local neighborhoods before trusting any global classification.

Orientability

Triangulated Version

\[ M \text{ orientable} \Longleftrightarrow \text{all adjacent triangles can agree} \]

DFS will turn this sentence into a linear-time certificate.

Transport along closed curves detects orientation reversal.Intrinsic criterion; no outside normal required.
Orientability is best taught as a transport test. Move a small oriented frame around a closed curve and ask whether it returns with the same sense. In a triangulation, the same idea becomes an edge-by-edge consistency problem: adjacent triangles must induce opposite directions on their shared edge. A failed return is a certificate, not a vague visual impression.

Polygonal schemas are finite encodings of a surface, so the slide should feel like data rather than paper folding. Edge labels and directions specify which boundary arcs are identified. The standard orientable schema pairs commutators, while the non-orientable schema pairs same-direction edges. Later algorithms replace this symbolic boundary data with triangle adjacency data.

Keep Euler characteristic tied to both counting and classification. For any finite triangulation of a fixed surface, n minus m plus ell is unchanged, so the number survives refinement. Validity Gate

Every later routine assumes a surface triangulation. Verify edge incidences and vertex links before using classification, DFS orientation, intersection tracing, or contraction.

Local failures become global algorithm failures.Closed surface: edge links are pairs; vertex links are circles.
This slide is the local quality gate for every later algorithm. A valid surface triangulation does more than put two triangles on each edge; every vertex link must look like a circle for a closed surface, or an interval at boundary. The invalid cases explain why edge counts alone cannot certify a two-manifold.

An ordered triangle is a triangle node plus a three-bit orientation index.

Data structure: six ordered versions per triangle.Search uses fnext after sym/enext choices.
Introduce ordered triangles as a tiny navigation algebra. A triangle has six ordered versions, split into two cyclic orientations. The enext operation advances the lead edge, sym reverses the lead edge, org reads the lead vertex, and fnext crosses to the neighboring triangle across that directed edge. These four moves make surface traversal mechanical.

DFS Orientation Algorithm

Recursive Skeleton

isOrientable(mu, i):
  if mu unmarked:
    mark mu
    choose orientation containing i
    bx = isOrientable(fnext(sym(mu, i)))
    by = isOrientable(fnext(enext(sym(mu, i))))
    bz = isOrientable(fnext(enext2(sym(mu, i))))
    return bx and by and bz
  else:
    return orientation(mu) contains i
Linear time: each triangle adjacency is inspected a constant number of times.DFS check data: contradiction_edge [T5, T0]
Explain the algorithm as depth-first search with orientation assignments attached to first visits. When a triangle is reached for the first time, it receives the orientation forced by the incoming edge. When an already marked triangle is revisited, the stored orientation is checked against the incoming one. One contradiction is enough to prove non-orientability.

Embeddings And Immersions

Map Into Space

\[ f:M\to \mathbb{R}^3,\qquad J=\begin{bmatrix} \partial f_1/\partial s_1 & \partial f_1/\partial s_2\\ \partial f_2/\partial s_1 & \partial f_2/\partial s_2\\ \partial f_3/\partial s_1 & \partial f_3/\partial s_2 \end{bmatrix} \]

Rank is coordinate-independent. Self-intersections are properties of the map, not of the abstract point set alone.

Smooth language prepares the PL crossing classifier.Self-intersections may be forced or accidental.
Shift from intrinsic topology to mappings into R3. An immersion keeps rank two locally, while an embedding is also one-to-one onto its image. Generic smooth maps exhibit double points, triple points, and branch points. The pedagogical distinction is that some self-intersections are accidents of the map, while others are forced by the surface type or by the chosen model.

PL Self-Intersection Tests

Orientation Predicate

\[ \Delta(a,x,y,z)= \begin{bmatrix} 1&a_1&a_2&a_3\\ 1&x_1&x_2&x_3\\ 1&y_1&y_2&y_3\\ 1&z_1&z_2&z_3 \end{bmatrix} \]

A sign test decides which side of the plane through \(x,y,z\) contains \(a\).

Edge stabs triangle

Endpoints have opposite plane signs, and directed side tests agree around the triangle.

General position makes the finite case list small.Classifier stored in surface-inspection-checks.json
For a piecewise-linear surface, self-intersection recognition becomes a finite orientation test. The determinant sign says on which side of a triangle plane a point lies. An edge stabs a triangle only when endpoints lie on opposite sides and the directed side tests agree. Two triangle crossings are then classified by which edges perform the stabs.

Interpretation

A double-covering preimage loop reverses orientation after two passes, so it can occur only in non-orientable behavior.

Trace in space and trace in the domain at the same time.Intersection curves become topological evidence.
The important move is to trace an intersection curve in space and simultaneously trace its preimage on the surface. A spatial path gives two arcs with common endpoints, a closed curve can give two loops, and the most revealing case is one loop covering the image twice. That double cover signals orientation reversal and therefore non-orientable behavior.

Edge Contraction And Link Condition

Link Condition

\[ \operatorname{Lk}(ab)= \operatorname{Lk}(a)\cap \operatorname{Lk}(b) \]

The contraction of \(ab\) preserves topological type exactly when no hidden common link data remains beyond the two opposite vertices.

local topological required before error priority
Edge contraction is an edit; link condition is the topological guard.Surface simplification, printed pages 42-45
Surface simplification is allowed only when the contraction preserves topology. Contracting edge ab removes the two incident triangles and merges endpoints, but this is safe exactly when the common part of the endpoint links is the edge link itself. Extra shared vertices or edges create non-manifold incidences after contraction, so the link condition is a local topological certificate.

Quadric Error And Recap

Geometry Priority

\[ d(x,h)=x^T u+\delta,\qquad E_H(x)=\sum_{h_i\in H} d(x,h_i)^2=x^TQx \]

Each candidate contraction chooses the merged vertex that minimizes accumulated squared distance to original incident planes.
