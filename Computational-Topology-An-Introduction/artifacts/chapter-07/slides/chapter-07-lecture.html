Open by positioning persistence as a scale-aware extension of homology. Homology tells us which components, loops, and voids exist at one scale; persistence asks when those classes appear, how long they remain visible, and which disappear as the filtration grows. Motivationscale is data plus point of view

Scale, Noise, Feature

Persistence does not decree what is noise. It records the scale at which each homology class exists, so the judgment can be made explicitly.

Small Scale

Many components and short loops appear. Some are meaningful, some are sampling artifacts.

Middle Scale

Classes that remain across several thresholds become visible as long bars or high diagram points.

Large Scale

Fine structure is filled in or merged. Essential classes are the ones that survive the whole filtration.

Use this slide to separate the philosophical motivation from the calculation. Noise is not a theorem-level category, so the chapter offers measurements rather than a universal decision rule. The key promise is that a long interval in a diagram is evidence for a feature at the chosen scale, while short intervals mark candidates for scale-dependent noise.
Components firstmerge tree path decomposition

Elder Rule

Rule

At a merge, the older component continues and the younger component dies.

Persistent Component Count

\( \beta(a,b) = \# \{ \hbox{merge-tree paths spanning } [a,b] \}. \)

Why This Convention?

Without the Elder Rule, the path decomposition can disagree with the actual component count between thresholds.

Read the merge tree from bottom to top. Components can merge but they do not split in a sublevel filtration of a connected space. At a merge, the component born earlier keeps its identity and the younger component receives a death time. This convention is what makes component counts over every interval match the path decomposition.
From geometry to algebramonotone function on simplices

Filtration From A Function

Monotone Requirement

If \( \sigma \leq \tau \), then \( f(\sigma) \leq f(\tau) \).

Every threshold sublevel set is then a subcomplex.

Filtration

\( \emptyset = K_0 \subseteq K_1 \subseteq \cdots \subseteq K_n = K \)

Each \(K_i\) collects all simplices with value at most \(a_i\).

Inspection Asset

Open the threshold lab to verify that every visible state is closed under taking faces.

This is the first formal contract. A function on simplices can drive a filtration only when it is monotone on face inclusions; otherwise a higher-dimensional simplex might arrive before its boundary and the sublevel set would fail to be a complex. The threshold lab asset uses the triangle order to make that monotonicity inspectable.
Persistent homology groupsimages of inclusion-induced maps

Homology Through The Filtration

Definition

\(H_p^{i,j} = \operatorname{im}\big(H_p(K_i) \to H_p(K_j)\big)\)

\( \beta_p^{i,j} = \operatorname{rank} H_p^{i,j}\)

Birth

A class in \(H_p(K_i)\) is new if it is not inherited from \(K_{i-1}\).

Death

A born class dies entering \(K_j\) when its image first merges into an older image.

Shift attention from spaces to vector spaces connected by inclusion-induced maps. Birth means a class is not inherited from the previous stage. Death means its image first becomes explained by an older class or by a boundary in a later stage. This is the Elder Rule translated from components to homology classes.

Persistence Diagram Read-Off

Point

birth \(a_i\), death \(a_j\), persistence \(a_j-a_i\)

Persistent Betti Number

\(\beta_p^{k,l} = \#\{(a_i,a_j): i \leq k,\ j > l\}\)

Memory

The diagram encodes all ranks of all image groups \(H_p^{i,j}\).

Make the diagram do computational work. A point records a birth value and a death value, and vertical distance from the diagonal is persistence. To recover a persistent Betti number, count points born no later than the left threshold and dying after the right threshold. Emphasize the closed vertical and open horizontal convention.
Algorithmic coreone reduced boundary matrix

Matrix Reduction

Compatible Ordering

Faces precede cofaces, and lower function values precede higher values.

Boundary Matrix

\(\partial[i,j]=1\) when \(\sigma_i\) is a codimension-one face of \(\sigma_j\).

Pairing Rule

If \(i=\operatorname{low}(j)\), then \((a_i,a_j)\) is a finite diagram point in the dimension of \(\sigma_i\).

R = boundary
for j = 1 to m:
  while some j0 < j has low(j0) = low(j):
    add column j0 to column j over F2

zero column  -> birth
pivot column -> death

Invariant

No two nonzero reduced columns have the same lowest row.

Present matrix reduction as a single algebraic sweep that recovers all finite persistence pairs. Columns are reduced from left to right over F2 until no two nonzero columns share the same lowest one. A zero reduced column signals birth; a nonzero reduced column with lowest row i pairs that birth simplex with the current death simplex.

Efficient implementationslists replace dense columns

Sparse Implementation

Data Structure

Array entries store sorted lists. The top element is the current lowest one.

Collision

When the target entry is occupied, add lists and cancel duplicate simplex indices over F2.

Runtime Lens

For a \(p\)-simplex with index persistence \(j-i\), list work is bounded by a dimension factor times \((j-i)^2\).

The sparse version stores only active columns as sorted lists, so the picture changes from a dense matrix to migrating linked lists. Every collision cancels the current top simplex and moves the list leftward. This monotone movement is the source of the output-sensitive runtime estimates based on nested birth-death intervals.

Zeroth Persistence Via Union-Find

Vertices

Every vertex births a component. Name a component by its oldest vertex.

Edge Case: Two Components

The edge kills the younger component and unions the two sets.

Edge Case: Same Component

The edge does not affect Dgm0; it creates a graph cycle for the next dimension.

union-find-0d-check.json matches the triangle reduction pairs.

Dimension zero deserves a separate mental model. Vertices always create components, and an edge either joins two different components or closes a graph cycle. Union-find names each component by its oldest vertex, so the Elder Rule is built into the data structure. The JSON check confirms that the union-find pairs match the reduction pairs.
Surfaceslower-star filtration of a PL function

PL Surface Filtration

Vertex Values

Assume distinct vertex heights \(f(v_1)<\cdots<f(v_n)\).

Lower Star

\(\operatorname{St}^- v_i=\{\sigma\in\operatorname{St} v_i: x\in\sigma \Rightarrow f(x)\leq f(v_i)\}\)

Equivalence

The sublevel set and the lower-star subcomplex have the same homotopy type between critical vertex values.

For a piecewise linear height function on a triangulated surface, thresholds between vertex heights have the same homotopy type as lower-star subcomplexes. This is why a continuous surface problem can be fed to a finite simplicial algorithm. The important implementation detail is to add an entire lower star at the vertex value.
Surface shortcutDgm1 from Dgm0 of negative height

First Diagram From The Complement

Reflection Rule

\((a,b)\in \operatorname{Dgm}_1(f) \iff (-b,-a)\in \operatorname{Dgm}_0(-f)\)

Reason

A finite loop event for \(f\) is a component event in the complementary superlevel evolution.

Infinite Points

Edges not used as death events in either lower-star pass become infinite one-dimensional classes.

Explain the dimension-one shortcut by turning the surface upside down. A finite one-dimensional class of f corresponds to a component event for the complement, equivalently to a zero-dimensional event for negative f. Reflecting points across the minor diagonal converts the zero-dimensional diagram of negative f into the finite part of the one-dimensional diagram of f.
Beyond ordinary diagramsall classes eventually die

Extended Persistence

Ordinary Pass

\(0=H_p(M_{b_0})\to\cdots\to H_p(M_{b_n})\)

Relative Return

\(H_p(M,M^{b_n})\to\cdots\to H_p(M,M^{b_0})=0\)

Consequence

Essential ordinary classes are paired during the relative part of the sequence.

Ordinary persistence leaves essential classes unpaired because they survive to the complete space. Extended persistence solves this by continuing with relative groups as the complementary superlevel set grows downward. The resulting sequence begins at zero and ends at zero, so every class receives a death event and every critical point can be paired.

Duality And Symmetry

Duality

\(\operatorname{Ord}_p(f)=\operatorname{Rel}_{d-p}(f)^T\)

\(\operatorname{Ext}_p(f)=\operatorname{Ext}_{d-p}(f)^T\)

Symmetry For \( -f \)

Ordinary and relative pieces reflect across the minor diagonal; extended pieces rotate centrally.

Use this slide as a theorem-level organizing view rather than a proof. Lefschetz duality relates absolute and relative homology in complementary dimensions, which becomes reflection across the main diagonal in diagrams. Comparing f with negative f introduces minor-diagonal and central reflections. The visual checks that ordinary, extended, and relative pieces move by the stated maps.

P

Permutation block matching original simplices with cone simplices: extended pivots.

Now connect the abstract extension to computation. Matrix A is the ascending lower-star pass. Matrix B is the descending upper-star pass. The permutation block P glues them by matching each simplex with its cone partner. After reduction, pivots in the three quadrants become ordinary, extended, and relative subdiagram points.
