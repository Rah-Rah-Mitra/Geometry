Model-To-Domain Routing

Grid signal: translations matter, so use convolutional sharing before dense readout.

Graph or set: labels are arbitrary, so aggregation or attention must respect permutation.

Point cloud or surface: rigid motion and local frames decide whether E(3) or mesh methods are needed.

Sequence: order carries information, so recurrence, dilation, masking, or positional structure becomes part of the geometry.

Treat the routing diagram as a decision aid, not a taxonomy poster. Images route to grid convolutions because translations are meaningful. Graph data routes to message passing because labels are arbitrary. Point clouds, meshes, sets, and sequences each carry a different notion of locality and transformation.

CNNs On Grids

Domain

A regular grid gives a canonical notion of neighboring pixels and translations.

Operation

The same kernel is reused at each position, creating local measurements with shared parameters.

Check

Shift the image, convolve, and compare with shifting the original response.

Grid promise: local sharing plus predictable response under translation.
Emphasize that convolution is the grid case of a local shared rule. The same stencil is applied at every pixel or lattice site, so translating the input should translate the response. The formula is less important than the commuting behavior that the notebook checks with a tiny signal.

Ordinary CNN

Group CNN

Indexes features by position and group element, so transformations act by moving mass across the feature stack.

Graph neural networks
Permutation equivariant message passing

GNNs Respect Relabeling

Why Permutation Matters

Graph node IDs are not physical coordinates. Relabeling them should only relabel the features.

How Message Passing Helps

Each node uses neighbor features through an aggregation rule that ignores arbitrary ordering.

2.78e-16
GNN permutation equivariance error in the notebook ledger

Changing edges is different from relabeling nodes; it changes the domain, so the output may legitimately change.

Keep the graph drawing subordinate to the algebraic idea. Node names are bookkeeping, so relabeling every node should relabel the output in exactly the same way. Message passing achieves this by aggregating neighbor information through symmetric operations tied to the adjacency structure.
Sets and attention
Attention as learned adjacency

Attention Builds A Soft Graph

\( \mathrm{Attn}(Q,K,V) = \mathrm{softmax}(QK^\top / \sqrt{d})V \)

Set Behavior

Without position information, permuting tokens permutes queries, keys, values, and outputs in the same organized way.

Sequence Behavior

Order enters through position encodings, causal masks, or recurrence-like restrictions.

1.11e-16
attention row sum error
Connect attention to graph neural networks without claiming they are identical. The attention matrix is a learned dense adjacency whose rows form probability weights. For sets, permutation behavior matters; for sequences, positional or temporal information is deliberately added because order carries meaning.
Transformers
Set core, sequence add-on

Transformers: Set Core, Sequence Add-On

Permutation-Equivariant Core

The token interaction rule is shared. Reordering tokens reorders the attention rows and outputs.

Geometry Injection

Position encodings, causal masks, rotary features, or graph biases tell the same block which relations should matter.

Readout Choice

A pooled set representation is invariant; a token-level prediction remains equivariant to token order.

This slide should prevent a common confusion. Self-attention by itself treats tokens through pairwise compatibility and can be permutation equivariant. Sequence modeling becomes ordered only after position, time, or causal masking is injected. The architecture therefore exposes which geometry is built in and which is supplied.
E(3) equivariant models
Rigid-motion sanity checks

E(3) Message Passing

Scalar messages can use \(||x_i - x_j||\); vector messages must transform with coordinates.

Invariant Part

Distances, angles, and scalar edge features survive translations and rotations.

Equivariant Part

Coordinate updates or vector features should rotate and translate predictably with the input.

4.44e-16
E(3) distance preservation error
Present E(3) message passing as the point-cloud version of the same contract. Distances and scalar features can be invariant under rigid motion, while coordinate-like vectors must rotate and translate predictably. The notebook check preserves pairwise distances after a rigid transform, which is the minimal sanity test.
Meshes and surfaces
Local frames replace image coordinates

Mesh CNNs Need Surface Neighborhoods

The Domain Is Not Flat

Faces and vertices form an irregular surface, so local neighborhoods need mesh connectivity and often a chosen frame.

Feature Transport Matters

Comparing features across adjacent cells requires an alignment rule, otherwise the same vector can mean different directions.

Common Check

Perturb the mesh or rotate local frames and inspect whether the response changes in the intended way.

Meshes add a subtlety that ordinary grids hide: neighbors live on a surface, and local coordinates may change from face to face. A mesh CNN must choose a neighborhood, transport or align features, and pool across cells without pretending that the surface is a flat image grid.

Comparing receptive fields
Local rules become global through depth

Locality And Scale

CNN

Stencil neighborhoods expand layer by layer across the grid.

GNN

Messages expand by graph hops and depend on the chosen edge set.

Attention

Every token can communicate immediately unless a mask restricts it.

RNN

State carries information along the ordered sequence, with gates controlling persistence.

Stress that locality is not the same in every architecture. A convolutional stencil expands through depth, a GNN expands through graph hops, attention can connect every token immediately, and recurrent models expand through time. Pooling and readout then decide which information becomes invariant.
Vocabulary cleanup
Three different promises

What Changes And What Stays Fixed

Invariant

The prediction ignores an allowed transformation.

\(F(gx) = F(x)\)

Example: a graph-level class does not depend on node ordering.

Equivariant

The output transforms in a matching representation.

\(F(gx) = \rho(g)F(x)\)

Example: node features relabel when graph nodes are relabeled.

Stable

Small domain changes cause controlled output changes.

\(d_Y(Fx,Fx') \leq C d_X(x,x')\)

Example: a mesh perturbation should not create a wild feature jump.

Architectures often combine these: equivariant intermediate features, invariant pooling, and stability checks around the domain perturbations the data actually experiences.

Use the three columns as a vocabulary cleanup. Invariance means the answer should stay fixed, equivariance means the output should move in a predictable representation, and stability means small domain perturbations should not cause uncontrolled output changes. Many mistakes come from blending these requirements.

Common mistakes
Break the contract deliberately

Failure Modes To Catch Early

Overbuilt Symmetry

Making a model invariant to orientation, order, or position can erase the very signal the task needs.

Underbuilt Symmetry

Ignoring label arbitrariness or coordinate frames forces training data to teach conventions that should have been structural.

Hidden Boundary Choices

Padding, graph edge construction, frame alignment, and positional encodings can silently define a different problem.

Make this slide practical. Overbuilding symmetry can erase useful orientation or order, while underbuilding symmetry forces the model to relearn coordinate conventions from data. Padding, graph construction, local frames, and positional encodings are all places where a good-looking architecture can quietly break its contract.
