Geometric Priors: Domains, Symmetries, Stability

A lecture on turning informal architectural instincts into precise transformation claims: signals live on domains, groups act on those domains, and useful neural layers respect or relax those actions.

Notebook: Geometric-Deep-Learning/chapter-03-geometric-priors/03-geometric-priors.ipynb · Source span: printed pages 9-29; PDF pages 13-33.

Open by telling the room that this chapter is the hinge between generic high-dimensional learning and geometric deep learning. The lecture will not start with a layer name. It starts by asking what object indexes the data, which transformations are semantics-preserving, and what a model should do when those transformations are applied.
1 · Signals On Domains

The First Prior Is Where Values Live

pp. 9-11
Definition Lens
A datum becomes geometric when it is a function on a structured index set.
Write a signal as \(x:\Omega\to C\). The domain \(\Omega\) may be a grid, graph, point set, surface, group, or sequence; \(C\) stores scalar, vector, categorical, or feature values.
A layer is not just a formula on arrays. It is a rule that should respect the way the domain can be re-indexed, moved, coarsened, or slightly deformed.
Use this slide to slow down the basic vocabulary. A grid, graph, point cloud, and surface do not merely store values in different file formats. They define different neighborhoods and admissible coordinate changes, so the same vector of numbers can demand different models depending on its domain.
2 · Group Actions

A Transformation Of The Domain Induces One On Signals

§3.1
Group Action
A group element \(g\) moves a domain point \(u\) to \(g\cdot u\).
The compatibility rule \(g\cdot(h\cdot u)=(gh)\cdot u\) is what lets a transformation calculus become an architecture constraint.
Representation
On finite signals, the induced action is a matrix or permutation operator \(\rho(g)\). On continuous signals, it is a linear operator on a function space.
Keep the triangle deliberately small. The point is not that every domain is triangular, but that a concrete action exposes the bookkeeping. Once the domain points move, signal coordinates must be pulled back so the same physical information is described after the transformation. That pullback is the representation.
3 · Representations

The Prior Lives Between Three Spaces

§3.1
Architecture Constraint
A prior is a restriction on the function class.
Rather than learning over all maps \(X(\Omega)\to Y\), choose maps whose behavior under \(\rho(g)\) is already correct by construction.

Frame this as the chapter's main diagrammatic habit. The same group can be discussed at three levels: it acts on the physical domain, it induces a representation on signal coordinates, and it restricts the functions we are willing to learn. This is why priors become statistical help rather than decorative terminology.
4 · Invariance And Equivariance

Two Commuting Claims, Two Output Types

§3.1
Invariant
A map \(f:X(\Omega)\to Y\) is \(G\)-invariant when \(f(\rho(g)x)=f(x)\). The group action disappears at the output.
Equivariant
A map \(f:X(\Omega)\to X(\Omega)\) is \(G\)-equivariant when \(f(\rho(g)x)=\rho(g)f(x)\). The output moves with the input.
Misconception to catch: equivariance is not weaker invariance. It is a different contract for outputs that still carry domain coordinates.
Ask students to read each square along both paths. For invariance, the right vertical edge is intentionally idle: transforming the input should not change a scalar decision. For equivariance, both vertical edges are active: the output is still a signal on a domain, so it must transform in step with the input.
5 · Isomorphisms And Automorphisms

Adding Structure Shrinks The Symmetry Group

§3.2
Hierarchy
More domain structure means fewer allowed transformations. A bare set has all bijections; a metric space keeps distance-preserving maps; a graph keeps adjacency-preserving maps.
Notebook Check
The chapter ledger records zero residual for a path-graph relabeling test and twelve automorphisms for the cycle example, turning the visual claim into a finite audit.
Use the relabeling picture to separate isomorphism from automorphism. An isomorphism may compare two differently named copies of the same structure. An automorphism maps a structure back to itself. This distinction is essential for graph learning, because node names are rarely semantic while adjacency usually is.
6 · Deformation Stability

Exact Symmetry Is Too Brittle For Real Data

§3.3
Soft Prior
Near a symmetry, output change should be controlled.
\(\|f(\rho(\tau)x)-f(x)\|\le C\,c(\tau)\,\|x\|\)
The cost \(c(\tau)\) is zero on the exact group and positive nearby. Stability generalizes invariance without pretending that small deformations form a closed group.
If the deformation carries semantic information, do not force stability. The task decides which changes are harmless.
Explain why the ring is not a new symmetry group. Small deformations compose into larger deformations, so closure fails if we only keep the small ones. The move is to measure distance from the exact group and ask for a Lipschitz-like response, which is a softer and more realistic geometric prior.
7 · Stability Of Domains

Sometimes The Domain Moves, Not Just The Signal

§3.3
Graph And Manifold View
A signal can stay comparable while the underlying graph or surface changes. The model then needs a correspondence \(Q\) or metric between domains, not merely an action on a fixed coordinate set.
Inspection Target
Ask whether the deformation preserves the information the task cares about: connectivity pattern, pairwise distances, local tangent frames, or a coarser neighborhood relation.
Distinguish two stability settings. If only the signal changes, we can keep the domain fixed and use the representation of a deformation. If the graph, mesh, or manifold itself changes, the model needs a way to compare outputs across domains. That comparison is often where geometry enters most concretely.
8 · Scale Separation

Local Computation Becomes Global Information

§3.4
Scale Separation Prior
Build a hierarchy of domains and preserve task-relevant information while discarding coordinates that no longer matter at the current scale.
Why It Helps
Local maps keep parameter sharing tractable; pooling increases the effective receptive field and moves toward invariant summaries.
Connect this picture to the computational reason deep architectures help. Local neighborhoods are cheaper and more stable than arbitrary global interactions, but the task may require long-range information. Coarsening and composition let a model grow its receptive field while carrying forward the geometric constraints established at fine scale.
9 · Multiscale Locality

Local Features Are A Stability Mechanism

§3.4
Fourier Versus Localized Views
Global frequency coordinates can react strongly to small spatial warps. Localized multiscale features trade exact diagonalization for spatial robustness and compositional structure.
Localfeatures inspect bounded neighborhoods
Equivariantintermediate fields move predictably
Pooledscale increases while detail compresses
Stablesmall deformations cause small changes
Treat this as intuition rather than a theorem proof. The point is that global coordinates can make a tiny warp look like a complicated change everywhere, while local multiscale measurements compare nearby structure first. This is why geometric deep learning often combines local equivariant maps with pooling instead of jumping straight to a global invariant.
10 · Architecture Priors

The Blueprint: Local Equivariance, Coarsening, Invariant Readout

§3.5
Blueprint
Use geometry to choose three reusable building blocks: local equivariant maps, coarsening operators, and global invariant maps. The architecture is the composition pattern.
CNNtranslation equivariant filters plus pooling
GNNpermutation equivariant messages plus graph pooling
Groupsrepresentations determine feature transformation rules
Manifoldslocal frames require transport or gauge handling
Present the blueprint as a design pattern rather than a single architecture. CNNs, GNNs, group networks, and manifold networks differ in their domains and representations, but the scaffold is recognizable: local equivariant processing, optional coarsening, and a final invariant decision when the task demands a coordinate-free output.

12 · Design Exercise

Break One Assumption And Predict The Failure

Lab
Exercise
Choose one chapter 03 check. Modify the domain transformation, padding convention, graph edge set, or pooling map. Predict whether the residual becomes nonzero, unstable, or unchanged.

Invariant?

The output should ignore an allowed transformation.

Equivariant?

The output should transform in the corresponding representation.

Stable?

The output may change, but only in proportion to a deformation cost.

Make the exercise predictive, not just experimental. Students should first name the intended prior, then name the residual, then decide what should happen when an assumption is broken. If they cannot predict the failure mode, they probably have not yet separated invariance, equivariance, stability, and locality in their own model.
13 · Recap

Geometric Priors Are Design Contracts

Takeaways

Signals

Start with \(x:\Omega\to C\). The domain decides which transformations and neighborhoods are meaningful.

Symmetry

Represent group actions by \(\rho(g)\), then choose invariant or equivariant maps according to the task output.

Stability

Relax exact symmetry by bounding output change under deformations near the allowed group.

Scale

Compose local equivariant maps with coarsening and an invariant readout when global decisions are needed.

Close by returning to the design contract language. A geometric prior is useful only when it identifies the right domain, the right transformation group or deformation family, and the right output behavior. The chapter's vocabulary is therefore practical: it tells us what to build, what to test, and when a popular architecture is the wrong match.
