Representation Learning

Learning Useful Coordinates, Not Merely More Coordinates

Working Definition
A model learns \(h_\theta : X(D) \to Z\), then predicts \(\hat y = r_\phi(h_\theta(x))\).
  • The domain \(D\) tells us which samples are comparable.
  • The feature space \(Z\) should compress without erasing the intended task signal.
  • The readout chooses what should remain invariant or move predictably.
Design Question

Which changes in \(x\) are nuisance coordinates, and which changes are semantic information?

Emphasize that representation learning is useful because the raw coordinates are rarely the final explanatory space. A model learns a feature map, but the geometric question is what the map is allowed to forget, what it must preserve, and how the downstream readout uses that organized information.
Structured Data

The Domain Is Part Of The Sample

The same ambient array length can hide different mathematical objects. GDL starts by naming the object that indexes the signal.

Grid Signal

Pixel meaning depends on neighbors, translations, and scale choices.

Typical behavior: translation equivariance before pooling.

Graph Signal

Node names are coordinates; edges define the information paths.

Typical behavior: permutation equivariance or invariance.

Point Cloud

Distances and relative orientation carry more meaning than list order.

Typical behavior: rigid-motion invariance or equivariance.

Sequence Or Surface

Order, metric, chart, or frame choices decide what counts as nearby.

Typical behavior: stability to small deformations.
Make the contrast with ambient vectors concrete. The same number of coordinates can describe pixels, graph nodes, sampled points, or time steps, but those coordinates come with different adjacency, motion, and relabeling rules. The domain is therefore part of the data, not decoration around the data.
Symmetry Preview

Predict What Happens When The Input Is Transformed

Equivariance
\(f(\rho_{\mathrm{in}}(g)x)=\rho_{\mathrm{out}}(g)f(x)\)
Invariance
The output action is identity, so \(f(gx)=f(x)\).
  • For graph node labels, relabeling the input should relabel node outputs.
  • For graph-level labels, relabeling the input should leave the answer unchanged.
  • The check is a residual between the two paths around the square.
Use the commuting square as the first durable mental model. If an input is transformed, an equivariant map transforms the output in the matching way, while an invariant map makes the output unchanged. The lecture only previews the formalism, but students should already see the residual as a testable claim.
Locality And Sharing

Architecture Priors Control How Information Moves

Local Rule

A layer updates a site from a neighborhood before later layers enlarge the receptive field.

Sharing

The same parameters are reused wherever the domain says the local situation is comparable.

Risk

Too little prior wastes samples; too much prior erases task information.

Connect locality to parameter discipline rather than to a single architecture. A local rule sees a neighborhood, and sharing applies the same rule across comparable neighborhoods. This explains why convolutions, message passing, and attention variants can all be read as ways to control how information moves.
GDL Design Loop

A Repeatable Loop For Geometric Models

1. Domain What object indexes the signal?
2. Transformations Which changes preserve the task meaning?
3. Behavior Should the output be invariant, equivariant, stable, or deliberately sensitive?
4. Check What residual would falsify the intended geometric claim?
Walk through the loop clockwise and ask for a decision at each stop. Identify the domain, name the transformations, choose invariant or equivariant behavior, build a local shared operator, and then check the residual. The point is that geometric deep learning is a design loop with audits.
Design Consequences

Different Tasks Require Different Geometric Readouts

Image Classifier

Small translations should not change the class after enough spatial evidence is pooled.

Readout: invariant scalar label.

Graph Node Predictor

Renaming nodes should rename the predictions in the same way.

Readout: equivariant node field.

Point Cloud Energy

Rigid motion should preserve energy, while vector forces would rotate with the cloud.

Readout: invariant scalar or equivariant vector.
Lecture Rule

The architecture follows the target behavior: do not ask one model head to serve every notion of sameness.

Read the three examples as different answers to the same design questions. A classifier wants invariance to image translation, a node predictor wants equivariance to graph relabeling, and a point cloud energy wants rigid motion invariance. The model family changes because the target behavior changes.
Failure Mode

When The Geometry Claim Is False, The Residual Should Move

Diagnostic
\(\| f(gx) - g f(x) \|\) should be small when equivariance is intended.
  • A high residual means the architecture, data augmentation, or training objective did not enforce the intended symmetry.
  • A zero residual for the wrong transformations can be just as bad: the model may have erased meaningful information.
  • Chapter 1 treats residuals as small laboratory instruments for design claims.
Use this warning as a practical diagnostic. If relabeling a graph changes a graph-level answer, the network has learned from names instead of structure. If rotation changes a molecular energy, the representation is leaking coordinates. The residual gauge turns a vague modeling worry into a visible failure.
