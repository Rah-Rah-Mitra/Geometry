Open by naming the chapter problem as a pressure test for modern learning. Interpolation is easy for expressive models, but choosing the interpolant that behaves well away from the training set requires a bias. Formal object

The Supervised Setup

High ambient dimension \(d\)

The learner sees finitely many pairs and chooses a function from a parameterized class.

Data and model
\(D=\{(x_i,y_i)\}_{i=1}^{N}\), with \(x_i\in X\subseteq \mathbb{R}^{d}\), \(y_i=f(x_i)\), and \(f_\theta\in \mathcal{F}\).
Generalization target
\(R(f_\theta)=\mathbb{E}_{x\sim P}\,L(f_\theta(x),f(x))\)

Exact fit on \(D\) is only a constraint. The learning question is which exact fit remains reliable for new draws from \(P\).

Concepts: data domain, function class, interpolation, riskSource span: printed pages 5-8; PDF pages 9-12
Set up the formal language without dwelling on statistical learning theory. We have samples in a large ambient space, a target function, a parameterized class, and a risk measured on fresh points. The main danger is that matching every observed pair does not by itself say what happens between or beyond those pairs.

Inductive bias

Bias Is A Restriction

Representable is not selectable

A dense function class gives possibility. A bias gives selection.

Two separate claims

Approximation: the class is rich enough to express many continuous targets.

Regularization: a cost or procedure ranks the functions that fit the data.

Prior: the preferred functions match the structure expected in the task.

Bayesian reading

A complexity score can be read as a negative log prior: functions with lower cost are treated as more plausible before seeing the labels.

Core distinction: representation capacity versus selection ruleNext: the optimizer can also select
Present inductive bias as a narrowing of possible functions, not as a vague taste for simpler answers. Universal approximation says many targets are representable, while the complexity map says which representatives the learner is willing to prefer. This distinction prepares the later shift from hand-written penalties to architecture-level priors.
Implicit bias

This slide is about implicit regularization. In an underdetermined linear system, there are infinitely many exact solutions, but gradient descent from the origin follows a path that lands at the minimum Euclidean norm solution. Treat this as a small, transparent model for a broader question: what preference does the training procedure secretly impose?
Local smoothness

Lipschitz Error Needs Fill Distance

How close is every query to data?

For a 1-Lipschitz target, nearest-neighbor control is only as good as the largest uncovered hole.

Fill distance
\(h_D=\sup_{x\in X}\min_i \|x-x_i\|\)
Error transfer
If \(|f(x)-f(x')|\le \|x-x'\|\), then a nearby sample gives \(|f(x)-f(x_i)|\le h_D\).

This is a clean guarantee in principle. Its sample cost is where high dimension enters.

Visual: original fill-distance diagramBridge to covering number growth
Define the fill distance visually. If every new point is close to a training sample, a Lipschitz assumption transfers observed values to nearby unobserved values with a controlled error. The trouble is geometric: keeping the largest uncovered hole small becomes brutally expensive as the ambient dimension grows.

Special low-dimensional structure

Projection Priors Help Only When True

A prior is a bet

A projection prior can break ambient dimension when the target really depends on a few directions.

Works when
\(f(x)\approx \phi(a_1^\top x,\ldots,a_k^\top x)\), with \(k\ll d\).
Fails when

The label depends on structured interactions distributed across coordinates, neighborhoods, or relations.

Artifact: projection-prior-success-failure.pngChecks: projection_target_variance, interaction_target_variance
Use the projection artifact to separate a useful prior from a magical one. If the target depends on a few low-dimensional projections, a sparse or ridge-like model can reduce the apparent dimension. If the target uses long-range interactions across coordinates, the same prior can miss the signal while still looking beautifully simple.
Geometric priors

Geometry Replaces Ambient Smoothness

Locality + symmetry + stability

The escape route is not generic smoothness on \(\mathbb{R}^{d}\). It is task-specific structure.

Geometric prior

Specify the domain, transformations that preserve meaning, and how outputs should transform.

Locality: use nearby elements before global aggregation.

Equivariance: move features predictably when the input is transformed.

Invariance: discard nuisance coordinates at the readout.

Stability: small meaningful deformations should not cause wild outputs.

Visual: original geometric-prior mapBridge to Chapter 03: Geometric Priors
This is the pivot toward geometric deep learning. Instead of asking a function on raw Euclidean coordinates to be smooth everywhere, we ask which transformations of the domain are meaningful and how signals should respond. Locality, symmetry, and stability become sources of regularity that match the data-generating structure.

Turn the chapter into a design checklist. The learner should identify the domain, specify allowed transformations, choose equivariant or invariant layers, restrict information flow locally, and keep a diagnostic residual. This checklist is the bridge from the abstract curse of dimensionality to concrete architectures in the following chapters.
