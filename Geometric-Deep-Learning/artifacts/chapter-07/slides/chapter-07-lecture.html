Symmetry History As A Model Contract

Invariant Readout

A scalar prediction ignores nuisance transformations: \(R(gx)=R(x)\).

Equivariant Field

A structured output moves in the corresponding representation: \(F(gx)=gF(x)\).

Visual teaches: historical vocabulary becomes a model contractInspection target: how each stop narrows the word symmetry
Frame the timeline as a change in vocabulary. Classical symmetry starts as visible regularity, becomes group action in mathematics, becomes conservation and gauge principle in physics, and then becomes a machine learning contract: an allowed transformation should either leave the output unchanged or move it predictably.
Original visual - architecture lineage

Early Equivariance In Machine Learning

Architectural Pressure

A model asked to learn every transformed copy wastes capacity. A model with the right equivariance can spend capacity on the signal rather than on coordinates.

Shift Case

Local filters plus weight sharing make the grid case concrete: translation changes feature location, not feature identity.

\((T_a x) * \psi = T_a(x * \psi)\)
Visual teaches: CNNs are one branch of a broader equivariance lineageInspection target: where locality, sharing, and hierarchy enter
Emphasize the architectural lesson rather than the chronology alone. Single-layer invariance has sharp limitations, so useful models distribute the symmetry burden across local filters, hierarchy, pooling, and representation structure. CNNs are therefore not isolated inventions; they are one successful answer to the shift-symmetry problem.

Original visual - harmonic analysis

Harmonic Analysis Explains Filtering Beyond Grids

Grid Intuition

Convolutional filters analyze a signal by local patterns and frequency content. Wavelet and scattering views make stability to small deformations explicit.

Graph And Mesh Lift

\(L u_i=\lambda_i u_i,\qquad x=\sum_i \widehat{x}_i u_i\)

The Laplacian basis becomes a non-Euclidean Fourier coordinate system.

Design Warning

Spectral filters are elegant, but changing the domain changes the basis. Localized or polynomial filters help make the operator transferable.

Visual teaches: filtering survives when the right basis is changedInspection target: where stability and transferability enter
Connect the picture to the course's earlier grids, graphs, groups, and manifolds. Wavelets, scattering, and graph Fourier bases all ask how to decompose a signal into stable components. The historical importance is that convolutional success could be studied as filtering, not only as parameter fitting.
Original visual - geometry processing

Geometry Processing Supplies Intrinsic Operators

Mesh CNN Idea

Use geodesic patches and shared local filters so the operator follows the surface rather than the embedding coordinates.

Point Cloud Idea

Use permutation-invariant set processing or build a nearest-neighbor graph that can change across layers.

Gauge Idea

Local tangent frames are choices. Features must transform consistently when those choices are changed.

Visual teaches: intrinsic processing precedes and shapes neural mesh/point modelsInspection target: coordinate nuisance versus geometric signal
Treat meshes and point clouds as domains where coordinates are often nuisance data. Geometry processing contributed Laplacian spectra, geodesic patches, intrinsic descriptors, and local frames before these appeared as deep layers. The neural versions learn parts of the pipeline while still relying on the same intrinsic tests.
Architecture bridge

Attention Recasts A Complete Graph As A Layer

Complete Graph View

Every token can send a message to every other token, and attention weights decide which messages matter for this input.

\(y_i=\sum_j \operatorname{softmax}_j(q_i^\top k_j)\,v_j\)

Careful Interpretation

A complete graph computation is not automatically geometric. The geometric claim depends on whether the layer respects the task's transformations, ordering, masking, or relational structure.

Bridge

Language, simulation, multi-agent reasoning, and relation networks all reuse the same question: which interactions should the model infer?

Visual teaches: attention as learned dense message passingInspection target: edge weights are input-dependent relations
Make the Transformer connection precise without overclaiming. A self-attention layer can be read as message passing on a complete graph whose edge weights are inferred from features. That does not make every Transformer a geometric model automatically, but it explains why graph language and attention language keep meeting.
Original visual - algorithmic reasoning

Algorithmic Reasoning Uses Invariants Over Time

Algorithmic Geometry

Edges can encode data dependencies, not physical nearness. The structure is a recipe for information flow.

Alignment

A learned processor aligns with an algorithm when its repeated local updates preserve the intended invariant.

Extrapolation Test

The model must keep the predicate true on larger graphs, longer sequences, or different input distributions.

\(P_k(x)\Rightarrow P_{k+1}(\operatorname{step}(x))\)
Visual teaches: invariance can be temporal, not only spatialInspection target: predicate preservation across rollout depth
Shift from spatial geometry to computational geometry of information flow. In an algorithm, edges may describe data dependencies rather than similarity or proximity. The invariant is temporal: after each step, a predicate about partial progress should remain true, and a learned processor must preserve that predicate outside the training sizes.

Blueprint Formula

domain + transformation + local operator + readout + residual

Design Principle

Do not call a model geometric because it has an impressive diagram. Call it geometric when its assumptions are explicit enough to test.

Takeaways and lab prompt

Takeaway: Geometry Is The Audit Trail

Break A Symmetry

Relabel a graph without relabeling features, rotate coordinates without rotating vector features, or change a local frame without transporting components.

Inspect The Residual

The failure should appear as an equivariance error, a mismatched histogram, a spectral instability, or an algorithmic predicate violation.

Repair The Architecture

Add the missing representation, aggregation, frame rule, positional signal, or rollout constraint only after the failure mode is visible.

The chapter closes the book by making geometry operational: assumptions should leave artifacts, checks, and failure cases.
