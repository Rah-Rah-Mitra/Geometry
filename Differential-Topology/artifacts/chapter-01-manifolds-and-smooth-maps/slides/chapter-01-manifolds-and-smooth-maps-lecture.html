Smooth Structure
Coordinates are instruments, not the object

Charts Are Local Measuring Devices

Definition Shape

A smooth \(m\)-manifold is covered by coordinate maps \(\varphi:U\to \mathbb{R}^m\) whose overlap changes \(\psi\circ\varphi^{-1}\) are smooth.

Inspection Target

The invariant object is the compatible atlas, not any one drawing of the grid.

Stress that a manifold is not a preferred coordinate grid. A chart is a temporary measuring device, and the overlap maps are the real compatibility test. Once the overlap maps are smooth, calculus done in one coordinate window translates coherently to calculus done in another.
Tangent Space
Direction, derivation, coordinate column

Tangent Vectors Live Before Coordinates

Invariant Reading

A tangent vector \(v\in T_pM\) acts on germs of smooth functions by \(g\mapsto v(g)\), satisfying the product rule.

  • A chart turns \(v\) into a column vector.
  • A different chart changes the basis, not the tangent direction.
  • The tangent plane picture is useful only after the invariant meaning is clear.
Present the tangent vector first as a direction that differentiates functions, then as a coordinate column only after a chart is chosen. This avoids the common misconception that the tangent space is literally the ambient picture; the diagram only records one faithful local measurement.

Make the derivative the central instrument of the chapter. A smooth map may be globally curved and folded, but at a point it sends infinitesimal source directions to infinitesimal target directions by a linear map. Rank, kernel, and image are the data read from that local model.
Inverse Function Theorem
Full rank is a local statement

Full Rank Gives Local Invertibility

Local Test

If \(d f_p:T_pM\to T_{f(p)}N\) is an isomorphism and \(\dim M=\dim N\), then \(f\) is a diffeomorphism from some neighborhood of \(p\) onto a neighborhood of \(f(p)\).

Do Not Overread It

The theorem says nearby, not everywhere. A map can pass the derivative test at many points while still wrapping globally.

Explain the inverse function theorem as a local statement, not a global promise. When the derivative is an isomorphism, nearby coordinates can be chosen so the map is reversible near the point. The global map may still fail to be one-to-one or onto elsewhere.
Immersions And Embeddings
Injective derivative versus faithful image

Immersions Keep Source Directions Distinct

Immersion

\(f:M^m\to N^n\) is an immersion when \(d f_p\) is injective for every \(p\). Thus \(\operatorname{rank} d f_p=m\).

Embedding Adds Global Control

Embedding = immersion + homeomorphism onto the image. It forbids distant source points from being confused in the target.

Use the curve picture to separate three ideas that are often blended together. An immersion only requires the differential to be injective at every point. An embedding asks for the map to identify the source with its image topologically as well as smoothly, which rules out hidden self-overlap.
Submersions And Level Sets
Surjective derivative gives smooth slices

Submersions Produce Regular Level Sets

Submersion

\(f:M^m\to N^n\) is a submersion when \(d f_p\) is surjective for every \(p\). Thus \(\operatorname{rank} d f_p=n\).

Regular Level Set

If \(c\) is a regular value, then \(f^{-1}(c)\) is a smooth submanifold of dimension \(m-n\).

For a scalar map, a nonzero differential means the kernel is a codimension-one tangent direction. The level set is then locally a smooth slice. Emphasize the practical test: regular values are values where every point in the preimage has full target rank.
Rank Theorem
Normal forms turn rank into coordinates

Constant Rank Gives Normal Forms

Local Diffeomorphism

\(r=m=n\)

All source directions survive and all target directions are reached.

Model: \((x_1,\dots,x_m)\mapsto(x_1,\dots,x_m)\)

Immersion

\(r=m\le n\)

The source sits locally as the active coordinate plane in the target.

Model: \(x\mapsto(x,0)\)

Submersion

\(r=n\le m\)

The target reads off active coordinates and ignores the fiber directions.

Model: \((x,y)\mapsto x\)

Connect the inverse, immersion, and submersion theorems through one organizing principle. If the rank is constant near a point, suitable source and target coordinates make the map look like a coordinate projection with inactive coordinates. The geometry is in the stable rank.
Transversality
Stable intersection by tangent spanning

Transversality Is The Rank Test For Meetings

Submanifold Version

At \(p\in A\cap B\), require \(T_pA + T_pB = T_pX\).

Map Version

A map \(f:M\to N\) is transverse to \(Z\subset N\) when \(d f_p(T_pM)+T_{f(p)}Z=T_{f(p)}N\) at every relevant point.

Frame transversality as the condition that two tangent descriptions jointly fill the ambient tangent space. A transverse intersection is stable under small perturbations because the missing directions are supplied. A tangency is fragile because both objects try to move through the same infinitesimal channel.
Sard Theorem
Critical values are exceptional in measure

Sard Theorem Makes Regular Values Abundant

Conceptual Statement

The set of critical values of a sufficiently smooth map has measure zero in the target.

  • Regular values can be selected without fine tuning.
  • Level sets at regular values inherit manifold structure.
  • Generic arguments become legitimate geometric tools.
State the conceptual role of Sard theorem without dwelling on the measure proof. Critical values may be complicated, but they occupy a negligible part of the target. Therefore regular values are not rare accidents; they are plentiful enough to support generic constructions.
Morse Functions
Controlled critical points

Morse Functions Stabilize Critical Points

Definition Shape

A critical point is Morse when the Hessian is nonsingular in local coordinates.

Why It Matters

Nondegenerate critical points persist under small perturbations and carry index data, so the function becomes a controlled probe of the manifold.

Move from regular values to controlled critical points. A Morse critical point has an invertible Hessian in local coordinates, so the function looks quadratically stable near that point. On a compact manifold, such functions give a manageable finite diagnostic for topology.
Embeddings
Local rank plus global separation

Embeddings Need Separation As Well As Rank

Two Tests

An embedding is a smooth map whose differential is injective and whose image carries exactly the source topology.

Return to the distinction between local and global tests. Rank detects whether a map is locally faithful on tangent directions, but it does not by itself prevent distant points from colliding. Embedding arguments add separation data so the smooth model is a genuine copy.
Applied Lab Habit
A repeatable reading of smooth maps

A Smooth Map Diagnostic

  1. Choose charts near the source point and target point.
  2. Compute \(d f_p\) as a matrix in those temporary coordinates.
  3. Read rank, kernel, and image before naming the theorem.
  4. Check whether the target condition is local, generic, or global.
  5. Record what should survive under perturbation.
Use this slide as a repeatable workflow for students. First choose local coordinates, then compute the differential, read the rank condition, decide whether the local model is inverse, immersed, submersed, or transverse, and finally test whether global embedding or genericity requirements remain.
Warnings
Where correct calculations still mislead

Common Failure Modes

Coordinate Artifact

A singular-looking formula may become regular after changing charts. Test overlap behavior before diagnosing the manifold.

Local Versus Global

Full rank near a point gives a local inverse, not a global inverse. Covering and wrapping phenomena remain possible.

Tangency

Nonempty intersection is weaker than transverse intersection. Tangent spaces must jointly supply the ambient directions.

Critical Value

A level set at a critical value can change dimension, acquire a singularity, or fail the expected local model.

Morse Degeneracy

Vanishing Hessian determinant means the quadratic model is not stable enough to classify the critical point.

Embedding Gap

Injective differentials do not eliminate distant self-collisions or topology lost in the image.

The warning slide is meant to reduce overgeneralization. Coordinates can hide the invariant object, full-rank conclusions are local, transversality is stronger than nonempty intersection, Sard theorem says almost every value is regular rather than every value, and embeddings require topology as well as injective derivative.
