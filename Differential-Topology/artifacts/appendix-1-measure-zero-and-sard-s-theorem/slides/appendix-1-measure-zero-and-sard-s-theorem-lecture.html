Measure Zero
the quantifier order is the theorem

Measure Zero Is A Cover Budget

Definition
A set \(A \subset \mathbb{R}^n\) has measure zero if for every \(\varepsilon > 0\) there are boxes \(B_i\) with
\[A \subset \bigcup_i B_i,\qquad \sum_i \operatorname{vol}(B_i) < \varepsilon.\]

The cover is allowed to change when the budget changes. Thinness means arbitrary volume control, not visual sparseness.

Stress the quantifier order in the definition. The rectangles may depend on epsilon, and there is no requirement that the cover be efficient or unique. What matters is that every positive volume budget can be beaten by a countable rectangular cover.
Cover Mechanics
low dimensional sets become ambient-volume invisible

Null Covers Survive Refinement

Refinement principle

Split a curve into short arcs. Cover each arc by a narrow rectangle. The area is controlled by width times length, and the width can be chosen after the budget is fixed.

\[\sum_j \operatorname{area}(R_j) \leq 2\delta \sum_j \ell_j < \varepsilon.\]
Use the shrinking tube picture to explain why low dimensional sets can be invisible to ambient volume. A curve in the plane is not small because it has short length; it is small because its tubular cover can be narrowed until the total area is below any target.
Fubini Slices
ambient volume from one-dimensional sections

Fubini Reads Thinness By Slices

Slice estimate
For a measurable-looking cover \(E\), the visual rule is
\[\operatorname{area}(E) \approx \int \operatorname{length}(E_x)\,dx.\]

The appendix uses this idea to reduce some null-set statements one dimension at a time, with exceptional slices handled by a second cover budget.

Present Fubini as a way to turn many one dimensional estimates into one ambient estimate. The slide is deliberately schematic: if vertical sections have tiny total length for most x values, integrating those lengths gives an area bound for the whole set.
Smooth Image Control
bounded derivative means bounded cover inflation

Smooth Images Need Compact Control

Local Lipschitz rule
On a compact patch \(K\), if \(\|DF\| \leq L\), then each small cube \(Q\) maps into a target box with diameter at most \(L\,\operatorname{diam}(Q)\).

This is the bridge from null sets in a source chart to null sets in a target chart.

The important local hypothesis is compactness of the coordinate patch. On such a patch, bounded derivatives give a Lipschitz constant, so each small box maps into a controlled enlarged box. The source budget is multiplied, not destroyed, by the smooth map.
Critical Values
rank failure lives in the derivative, not just the picture

Critical Values Are Images Of Rank Failure

Diagnostic
For \(f:M^m\to N^n\), a point \(p\) is critical when
\[\operatorname{rank}(df_p) < n.\]
A value \(y\) is critical if \(y=f(p)\) for at least one such \(p\).
Common confusion

The critical set is in the domain. The exceptional values live in the target.

Separate three spaces that students often merge: the domain point, the derivative at that point, and the value in the target. A point is critical when the derivative loses rank; a value is critical only if at least one critical point maps to it.
Local Model
the fold map makes rank failure visible

Fold Model: Rank Drops Along A Line

Model map
\[F(x,y)=(x,y^2),\qquad DF=\begin{pmatrix}1&0\\0&2y\end{pmatrix}.\]
Critical data

The determinant vanishes exactly when \(y=0\). The critical image is the horizontal axis in the target.

The fold is the simplest local warning sign. Its critical set is a clean line in the domain, and its critical values lie on a clean line in the target. This example makes the theorem believable without pretending that every critical image is so orderly.
Local Model
critical images may be singular but still null

Cusp Model: Critical Images Can Bend Sharply

Model map
\[C(x,y)=(x,\,y^3+xy),\qquad \det DC=3y^2+x.\]
Critical curve

The critical locus is \(x=-3y^2\). Its image has a cusp in the target, yet remains a one-dimensional trace inside the plane.

The cusp keeps the same diagnostic structure while making the image more singular. The derivative determinant cuts out a parabola in the domain, and mapping that parabola produces a pointed curve in the target. Sard measures this curve by ambient area, not visual complexity.
Proof Scaffolding
localize, stratify, estimate, sum

Mini-Sard Works In Local Coordinates

Local Euclidean task

For \(f:U\subset\mathbb{R}^m\to\mathbb{R}^n\), show \(f(C_f)\) has measure zero.

Charts and compact exhaustion reduce the manifold theorem to countably many such local estimates.

Frame the proof strategy as localization plus bookkeeping. Charts reduce the problem to Euclidean boxes, compact pieces make derivative bounds finite, and the critical set is sorted by how much derivative information vanishes. The theorem is then assembled from countably many null pieces.
Taylor Decay
higher-order vanishing turns many cubes into tiny images

Taylor Decay Beats Cube Counting

Budget heuristic
If derivatives through order \(k\) vanish, an \(m\)-cube of side \(r\) has image diameter like \(r^{k+1}\).
\[\#\text{cubes}\cdot(\text{image size})^n \sim r^{-m}r^{n(k+1)}.\]
Winning condition

The exponent \(n(k+1)-m\) must be positive for the budget to vanish as \(r\to 0\).

This is the quantitative heart of the argument. A cube of side r has many neighbors, but if enough derivatives vanish, the image diameter shrinks like a higher power of r. The exponent inequality records exactly when the volume budget tends to zero.

Manifold Version
Euclidean null sets transported through charts

Manifold Measure Zero Is Chart Local

Definition on a manifold

A subset \(A\subset M\) has measure zero when every chart image \(\phi(A\cap U)\subset\mathbb{R}^m\) has measure zero.

Why this is consistent

Transition maps are smooth. On compact subpatches, they preserve null sets by the same smooth-image control.

The manifold definition is not a new measure theory; it is Euclidean measure zero transported through charts. Compatibility matters because smooth transition maps preserve the null condition on compact subpatches, letting the statement survive changes of coordinates.
Course Use

Why Differential Topology Keeps Using Sard

SubmanifoldsA regular value of \(f:M\to N\) makes \(f^{-1}(y)\) a submanifold with the expected codimension.
TransversalityBad parameters usually form a thin set, so perturbations can be chosen outside the exceptional values.
Intersection theoryRegularity turns geometric counts into stable local models rather than singular accidents.
DegreeA regular target value makes inverse images discrete and countable with signs or mod 2 weights.
Homotopy argumentsOne chooses regular levels for maps on cylinders to control boundary behavior.
Generic reasoningThe phrase almost every value becomes a precise statement about the complement of a null set.
Connect the appendix back to the main course. Regular values give submanifolds, transversality arguments need avoidable bad values, and degree or intersection constructions often require choosing a value away from a thin exceptional set. Sard supplies the permission to choose generically.
