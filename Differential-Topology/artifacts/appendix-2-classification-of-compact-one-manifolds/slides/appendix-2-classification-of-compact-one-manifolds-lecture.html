Compact One-Manifolds Have Two Shapes

Every connected compact smooth one-manifold is smoothly modeled by a closed interval or a circle; disconnected cases are finite unions of those components.

Classification Target

connected compact \(1\)-manifold \(M\) ≅ \([0,1]\) or \(S^1\)

Open the appendix as a classification theorem rather than a bag of special cases. The local hypothesis says every point sees a line or half-line, while compactness forces only finitely many pieces after cutting, so the global answer collapses to interval or circle.
Proof Route
from smooth cuts to a finite graph

The Proof Route

The appendix converts smooth one-dimensional geometry into a finite incidence problem, then converts the answer back into smooth coordinates.

1. Smoothrepair monotone coordinates while keeping positive derivative
2. Cutrecord boundary points and finitely many critical points
3. Identifyeach complement component as an open interval
4. Graphuse closure endpoints as incidence data
5. Classifydegree at most two gives a path or a cycle
Use this route slide to give students a mental map before details arrive. The proof begins analytically with smooth coordinates and Morse cuts, then deliberately forgets most geometry and records only which interval components attach to which special points.

Local Consequence

If interval pieces later meet at a point \(p\), at most two local arms can be incident to \(p\).

Emphasize that one-dimensional manifold means a very small menu of neighborhoods. Interior points have two local directions, boundary points have one local direction, and that single observation will later prohibit a three-armed graph from being a manifold.
Smoothing Lemma
analytic repair step

Smooth Repair Keeps Direction

Invariant To Preserve

coordinate \(u(t)\) is usable when \(u'(t) > 0\)

Why It Matters

  • Piecewise interval coordinates may have rough joins.
  • Smoothing is harmless only if monotonicity survives.
  • Positive derivative returns a local diffeomorphism.
The smoothing lemma should be presented as a quality-control step. If a coordinate is assembled from monotone pieces, smoothing is allowed only when the repaired derivative stays positive, because positive derivative is what keeps the coordinate locally invertible.
Morse Cuts
finite special set \(S\)

Morse Cuts Make Finitely Many Pieces

Compactness Enters

\(S = \partial M \cup \operatorname{Crit}(f)\) is finite, so \(M \setminus S\) has finitely many interval components.

Connect compactness to finiteness here. A good height function has only finitely many critical points on a compact one-manifold, and boundary points are also recorded, so removing the special set produces finitely many open interval components.
Complement Components
closures remember endpoints

Each Remaining Piece Is An Open Interval

After Cutting

\(M \setminus S = I_1 \sqcup I_2 \sqcup \cdots \sqcup I_k\)

Closure Bookkeeping

  • Each \(I_j\) is locally a standard open interval.
  • The closure \(\overline{I_j}\) can touch \(S\) at one or two ends.
  • Those touches become graph incidences.
After the cuts, the hard smooth object becomes a list of standard interval pieces. The closure of one piece can meet the special set in one or two endpoint points, and this endpoint bookkeeping is exactly what becomes the incidence graph.
Component Coordinates
inverse function theorem viewpoint

Coordinates On Components Are Monotone

Local Coordinate

\(f|_{I_j}: I_j \to (a_j,b_j)\) is monotone after choosing orientation.

Inspection Target

  • Nonzero derivative gives local inverse charts.
  • The image is an open interval.
  • Only endpoint attachments remain undecided.
Make the inverse function theorem visible through this monotone coordinate picture. On a component away from critical points the derivative of the chosen coordinate does not vanish, so the component can be parameterized as a standard open interval.
Incidence Graph
vertices from \(S\), edges from components

Turn Closures Into An Incidence Graph

Graph Encoding

For each component \(I_j\), draw an edge joining the points of \(S\) lying in \(\overline{I_j}\).

What Is Forgotten

  • exact coordinate formulas
  • the height function values
  • parametrization speed along each interval

What Is Kept

Only endpoint incidence remains, and that is enough for the classification.

The graph is not extra structure pulled from nowhere; it is the memory of how interval closures touch the finite cut set. Vertices are special points, edges are interval components, and each endpoint relation is a closure relation in the manifold.
Degree Constraint
branching violates the chart condition

No Vertex May Branch

Forbidden Local Type

A neighborhood with three punctured arms cannot be charted by \((-1,1)\) or \([0,1)\).

Graph Bound

\(\deg_G(s) \le 2 \quad \text{for every } s \in S\)

Why This Is Enough

The classification has become a theorem about finite connected graphs with maximum degree two.

This is the decisive local-to-global constraint. If three interval components met at one special point, every small neighborhood would have three punctured arms, which cannot be homeomorphic to a line neighborhood or a half-line boundary neighborhood.
Finite Graph Lemma
connected, max degree two

Degree At Most Two Forces Path Or Cycle

Path Case

Cycle Case

Graph Lemma

Finite connected graph \(G\) with \(\deg(v)\le 2\): either \(G\) is a path, or every vertex has degree \(2\) and \(G\) is a cycle.

Once the incidence graph is finite, connected, and has maximum degree at most two, there are no hidden graph types left. A connected graph with degree-one vertices is a path, while all vertices degree two gives a cycle.
Boundary Detection
degree-one vertices are interval ends

Endpoint Count Detects Boundary

Interval Component

\(\partial [0,1] = \{0,1\}\)

The incidence graph has exactly two degree-one vertices.

Circle Component

\(\partial S^1 = \varnothing\)

Every vertex is degree two, so there is no boundary end.

Relate the graph endpoints back to manifold boundary. A path has exactly two degree-one ends and models a compact interval with two boundary points, while a cycle has no degree-one vertex and models a boundaryless circle component.
Path Gluing
from graph path to \([0,1]\)

Gluing A Path Gives A Closed Interval

Constructive Model

Choose positive lengths \(L_j\), place each edge consecutively, and smooth the transition charts near glued vertices.

Result

path component \(\cong [0,1]\)

Describe the path case constructively. Give each open interval edge a coordinate length, concatenate the coordinates along the chain, and use the smoothing repair near glued vertices so the resulting map is a smooth diffeomorphism onto a closed interval.
Cycle Gluing
coordinates modulo total length

Gluing A Cycle Gives A Circle

Cyclic Coordinate

\(t \in \mathbb{R}/L\mathbb{Z}\), where \(L=\sum_j L_j\)

No Distinguished Endpoint

Going around the cycle returns to the starting chart. Smoothing the final join removes the last piecewise artifact.

Result

cycle component \(\cong S^1\)

For the cycle case, stress that there is no preferred first endpoint. The same edge-length coordinate is taken modulo the total length, and the smoothing repair closes the seam so the component is smoothly modeled by a circle.
Componentwise Classification
finite disjoint union

Disconnected Manifolds Are Componentwise

Classification Statement

\(M \cong \bigsqcup_{a=1}^{r} [0,1] \;\sqcup\; \bigsqcup_{b=1}^{s} S^1\)

Algorithmic View

  1. Split \(M\) into connected components.
  2. Build the cut incidence graph on each component.
  3. Read path as interval and cycle as circle.
Extend the connected classification without adding a new proof. Compactness gives finitely many connected components in this setting, and the argument applies to each component separately, so the whole manifold is a finite disjoint union of intervals and circles.
