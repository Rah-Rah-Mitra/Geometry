Measures Start With Admissible Sets

Definition Schema

\[ \mu:\mathcal A\to[0,\infty],\qquad A_i\cap A_j=\varnothing \]

A measure is meaningful only after the family \(\mathcal A\) has closure properties strong enough for countable decomposition.

Hull

Replace a rough set by a measurable envelope with the same outer size.

Null Change

Arguments often tolerate changes on sets whose measure is zero.

Measure theory begins with an admissibility decision.Later integration depends on this decision.
Frame a measure as a disciplined way to assign size after deciding which sets are admissible. The diagram lets students see the outer candidate, the measurable core, and the null boundary. Emphasize that most later theorems protect this decision under countable unions, restrictions, and hull replacements.

Borel, Suslin, Radon

Why The Vocabulary Matters

  • Borel families are generated from open sets by countable operations.
  • Suslin operations keep analytic projections in the measurable universe.
  • Radon measures make approximation by compact or closed subsets usable.
  • Image measures rely on these classes when mass is transported by maps.
Regularity Pattern
\[ \mu(A)\approx\mu(K),\qquad K\subset A,\quad K\text{ compact} \]

Approximation turns abstract measurability into finite inspection.

Descriptive set language controls approximation.Radon regularity is the geometric default.
Use this slide to organize the set vocabulary before functions appear. Borel sets are generated by open sets, Suslin operations enlarge the descriptive reach, and Radon measures add compact approximation and local finiteness. The point is not taxonomy for its own sake; it is knowing which approximations survive geometric maps.

Measurable Functions Are Probes

Preimage Test

\[ f:X\to Y,\qquad B\subset Y\ \text{Borel} \]

The function is measurable when \(f^{-1}(B)\) belongs to the chosen measurable family on \(X\).

Stable Under Limits

Pointwise limits of measurable real functions remain measurable under standard hypotheses.

Approximate

Simple functions make integrals finite and inspectable before limits enter.

Measurability is tested by inverse images.Approximating functions prepares integration.
Measurable functions should feel like probes of the underlying measure space. Rather than asking whether the graph is nice, test inverse images of target sets and then exploit closure under algebraic operations and limits. This prepares the approximation logic behind simple functions, monotone convergence, and dominated convergence.

Lebesgue Integration

Three Integrator Moves

Positive First
\[ \int f\,d\mu=\sup_{\ 0\le s\le f}\int s\,d\mu \]
Subset

\(\int_A f\,d\mu=\int 1_Af\,d\mu\)

Limit

Monotone and dominated convergence protect passage to limits.

Norm

Lebesgue spaces package size through \(\|f\|_p\).

Integrals are built by approximation.The limiting theorem names the required hypothesis.
Present the integral as a stable limiting procedure from positive simple functions. The visible staircase under the curve is deliberately schematic: it asks what quantity is being accumulated and why monotone refinement is safe. Then separate three roles: integrate on subsets, pass to limits, and measure functions by Lp size.

Product And Image Measures

Fubini And Pushforward

\[ \int_{X\times Y} g\,d(\mu\times\nu) =\int_X\int_Y g(x,y)\,d\nu(y)\,d\mu(x) \]
\[ T_{\#}\mu(B)=\mu(T^{-1}(B)) \]

Products slice mass; image measures transport mass. Both operations are indispensable once sets become parametrized surfaces or projected pieces.

Products allow iterated integration.Pushforwards turn maps into measures.
Product and image measures are the first major transportation rules. Product measures let an integral be evaluated by slicing in either order when hypotheses permit, while image measures record what a map does to mass. In geometric measure theory, this is the bridge from abstract integration to areas, projections, and parametrized objects.

Linear Functionals

Reversing The Construction

Measure theory can begin with a functional \(L\) on functions, then recover a measure when positivity and continuity conditions are strong enough.

Daniell Route

Build the integral first, extend it, then read off the measure.

Riesz Route

Represent positive functionals by regular measures on suitable spaces.

\[ L(f)=\int f\,d\mu,\qquad L(f)\ge 0\ \text{if}\ f\ge 0 \]
Functionals give integration an algebraic face.The notebook diagnostic behaves like a tiny functional check.
The linear functional viewpoint is a useful reversal. Instead of starting with a measure and building an integral, begin with a positive linear rule on a lattice of functions and ask when a measure represents it. Tie this to Riesz-type representation and to the notebook habit of recording a functional diagnostic.

Coverings, Derivates, Densities

Local Mass Ratios

\[ \Theta^m(\mu,a)= \lim_{r\downarrow 0} \frac{\mu(B(a,r))}{\alpha_m r^m} \]

Covering theorems select controlled subfamilies of balls; derivates ask what mass looks like when the balls shrink.

Vitali relation centered balls density approximate continuity
Covering choices turn local balls into global statements.Densities are pointwise measure derivatives.
Covering theorems and derivates are a hinge to the next chapter. Shrinking balls test local mass ratios, Vitali-style selections control overlap, and density statements translate a global measure into pointwise behavior. The slide should make students anticipate differentiation theory, not memorize every covering lemma.

Failure Modes

Countability

Finite additivity intuition is not enough. Measure arguments need countable unions, countable approximations, and explicit limiting hypotheses.

\[ \mu\left(\bigcup_{i=1}^\infty A_i\right) \]

Null Sets

Changing a function on a null set is safe only when the target statement lives in the right almost-everywhere equivalence class.

\[ f=g\quad \mu\text{-a.e.} \]

Boundary Mass

Geometric restrictions can fail when a boundary, singular fiber, or exceptional image carries positive mass.

\[ \mu(\partial A)\ne 0 \]

Repair Pattern

Name The Hypothesis

sigma-finiteness, regularity, dominance, or local finiteness.

Localize The Claim

Restrict to compact sets, finite-measure pieces, or good balls.

Record The Residual

A finite diagnostic should say what would fail if the hypothesis is removed.

Failures usually expose missing hypotheses.Warnings become better proof statements.
This warning slide collects the most common ways measure arguments fail. Countability matters, null-set changes must be tracked through the right equivalence class, product measures need hypotheses, and geometric boundaries can carry mass. Each failure should be framed as a missing hypothesis rather than as a mysterious exception.
