From Boolean Predicate To Classified Event

Event Contract

An intersection routine should return the event type, the witness point or interval, and the parameters that certify where the event occurs.

Boolean Layer

Enough for collision rejection: "do these objects meet?"

Classified Layer

Needed for clipping, containment, arrangements, and boundary conventions: "how do they meet?"

Consequence

Endpoint touches and overlaps are not numerical annoyances; they are topological events that later algorithms consume.

Predicate signs are the raw materialClassified events are the reusable API
Pause on the distinction between yes-or-no and useful output. For downstream geometry, an intersection routine should explain what happened: proper crossing, endpoint contact, overlapping edge, or miss. That richer event vocabulary is what lets polygon containment, clipping, and search structures agree about boundary cases.

Parametric Segment Intersection

Parametric Test

\(a+s(b-a)=c+t(d-c),\quad 0\le s,t\le1\)

Unit Square View

The algebra finds one point in \((s,t)\)-space. It is a segment intersection only when that point lies inside the unit square.

Parallel Warning

A small cross-product denominator makes the solve unstable; the branch should switch to parallel or collinear interval logic.

Proper case check: s = 0.524, t = 0.457Both are inside the closed unit interval
Introduce the parameter square before discussing code. Each segment contributes one parameter, and the intersection is valid exactly when both parameters land in the closed unit interval. This turns geometry into a constrained solve, while parallel and nearly parallel directions become visible as denominator warnings.

Robustness
branch policy is part of the algorithm

Degeneracy And Numeric Caution

Small Denominator

When \(\det(b-a,d-c)\) is near zero, the parameter solve should not decide the event alone.

Collinear Interval

Overlap is a one-dimensional interval problem after the supporting line has been identified.

Endpoint Policy

A closed segment includes endpoints, but a polygon crossing count often treats vertices with special half-open conventions.

Arithmetic Choice

Integer predicates avoid roundoff but can overflow; floating predicates need documented tolerances.

Implementation Warning

The mathematical predicate is exact; the implementation branch is not unless the arithmetic and degeneracy conventions are explicit.

Degenerate cases change the returned event, not the geometric vocabularyRobustness belongs in the API contract
Treat robustness as part of the specification, not an implementation afterthought. The determinant and parameter formulas are simple, but zero denominators, collinear intervals, and roundoff near zero decide which branch is taken. Students should leave with the habit of documenting an epsilon or exact-arithmetic policy.

Barycentric Classification

Barycentric Coordinates

\(p=\alpha a+\beta b+\gamma c,\quad \alpha+\beta+\gamma=1\)

Inside

All three weights are positive.

Boundary

One zero weight gives an edge; two zero weights give a vertex.

Outside

At least one weight is negative, so the point lies across the opposite edge.

Triangle classification mirrors segment return codesWeights are both coordinates and certificates
Use the barycentric diagram to make classification visual. Inside means all three weights are nonnegative and sum to one; an edge hit has one zero weight; a vertex hit has two zero weights. This is the triangle analogue of returning a classified segment event instead of a bare Boolean.

When There Are Many Segments

Sweep Principle

Move a vertical line through event points; maintain the active segments ordered by their intersection height with the sweep line.

Local Neighbor Tests

New intersections can be found by checking adjacent active segments after insertions, deletions, and swaps.

Degenerate Events

Shared endpoints, overlapping segments, and equal x-coordinates must be ordered before the data structure can behave predictably.

Data structure: balanced order of active segmentsEvents: endpoints and discovered crossings
Shift from one pair of segments to a set of segments. A sweep line keeps a status order of active segments, because possible intersections are discovered locally among neighbors as the sweep advances. The key teaching point is that global intersection search becomes a sequence of ordered local updates.
