Definition Slide

Voronoi Cell

For a finite site set \(S\) and site \(p_i \in S\), the cell is \[V(p_i)=\{x\in\mathbb{R}^2:\|x-p_i\|\le \|x-p_j\|\text{ for every }p_j\in S\}.\]

Region, Site, Edge, Vertex

A region belongs to one site. Edges are equal-distance bisector pieces. Vertices are points equidistant from three or more sites in general position.

Diagram

The Voronoi diagram is the collection of all cells and their shared boundaries.

Distance ties belong to shared boundariesGeneral position avoids four-site Voronoi vertices
Start from the inequality, then translate every symbol into geometry. A point belongs to the cell of p_i if no other site is closer. Equality with one other site makes an edge; equality with two other sites makes a vertex in the usual nondegenerate setting.
Construction
cells as intersections

Half-Plane Construction

Convexity

Each comparison \(\|x-p\|\le \|x-q\|\) is one linear half-plane after squaring and canceling \(x\cdot x\).

\[2x\cdot(q-p)\le q\cdot q-p\cdot p\]

Algorithmic Baseline

A single cell can be built by intersecting the \(n-1\) half-planes induced by the other sites.

Cost Warning

Repeating that construction independently for every cell is clear but not the fastest chapter algorithm.

Half-plane intersection proves cells are convexPer-cell construction is definition-driven
Derive the half-plane only far enough to show why the boundary is linear. Squaring the distance comparison cancels the x dot x term, leaving a linear inequality. This single cancellation explains convex cells, polygonal boundaries, and the baseline half-plane-intersection algorithm.
Cell Geometry

Bounded And Unbounded Cells

Hull Criterion

A Voronoi cell is unbounded exactly when its site lies on the convex hull of the site set.

Checked Artifact

Hull sites \(0,1,4,5,6,9\) have unbounded regions; interior sites include bounded regions.

Geometric Reason

A hull site has an outward direction in which no other site can overtake it; an interior site is blocked in every direction.

Check: hull_sites_have_unbounded_regions = trueCheck: some_interior_region_is_bounded = true
Connect this to the previous convex hull chapters. A hull site has a supporting line, so moving outward normal to that line keeps the site nearest forever and the cell is unbounded. Interior sites have competitors in every direction, so their regions can close up.
Degeneracy

Degeneracy And Delaunay Flip

What Breaks

If four sites are cocircular, a Voronoi vertex has degree four and the Delaunay triangulation is not unique.

Implementation Policy

A robust implementation must choose a tie convention, perturbation, or exact symbolic rule before comparing triangulations.

Flip View

Moving one site across the empty-circle boundary swaps one diagonal for the other while preserving the same quadrilateral boundary.

The notebook data is in general positionThe lab asks students to move a site toward cocircularity
Use this as the chapter's robustness checkpoint. In general position, three sites define a Voronoi vertex and a Delaunay triangle. With four cocircular sites, the empty-circle test is tied, and either diagonal can be selected. The flip is the visible symptom of crossing that degeneracy.

Combinatorics

Linear Size Roadmap

Size Thesis

Voronoi diagrams in the plane have linear combinatorial complexity because their Delaunay dual is planar.

Proof Roadmap

  1. Build the straight-line Delaunay dual.
  2. Use planarity and Euler's formula.
  3. Transfer edge and vertex counts back to Voronoi features.

Degenerate Cases

Cocircularities may merge vertices or create nonunique triangulations, but a consistent triangulation still gives the same linear-size intuition.

The argument is combinatorial, not metric-heavyPlanarity is the key accounting device
Give students the counting strategy rather than a wall of formulas. Once the Delaunay dual is planar, Euler-style accounting controls the number of edges and triangular faces. The Voronoi diagram inherits that linear bound because its ridges and vertices correspond to dual features.

Empty-Circle Theorem

Empty-Circle Theorem

A Delaunay triangle has a circumcircle with no input site strictly inside it. Conversely, empty circles certify Delaunay adjacency under the usual general-position assumptions.

Notebook Evidence

All 12 Delaunay circumcircles are empty, and circumcenters are recorded in the table artifact.

Small Clearance

Some clearances are small, so numerical tests need an explicit tolerance or exact predicate strategy in production code.

Check: all_delaunay_circumcircles_empty = trueTable: empty-circle-checks.csv
Treat empty circles as certificates students can inspect. The center is a Voronoi vertex because it is equidistant from the triangle sites; emptiness says no other site is closer. That is exactly the local condition needed for the triangle to belong to the Delaunay triangulation.

Fortune Sweep Intuition
beach line of parabolas

Fortune Sweep Intuition

Beach Line

For a moving sweep line, the frontier consists of points whose distance to a seen site equals their distance to the sweep line.

Site Event

A new site inserts a new parabolic arc into the beach line.

Circle Event

When an arc disappears, a Voronoi vertex is created and two edges meet.

Data Structure Burden

The sweep is fast because it schedules local events rather than recomputing every cell after each site.

Same distance rule, now against a moving lineEvents turn a continuous sweep into a finite algorithm
Avoid drowning the class in implementation details on the first pass. The key intuition is that a point on the beach line is equally far from a site and from the sweep line, so the arcs are parabolas. Breakpoints between arcs trace Voronoi edges; site and circle events are the moments when the combinatorial beach line changes.
