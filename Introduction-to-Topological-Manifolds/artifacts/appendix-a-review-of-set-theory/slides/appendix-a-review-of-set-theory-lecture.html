Sets and Membership

Extensionality

A set is determined by its elements alone.

Specification needs a universe

Complements are meaningful only inside an ambient set $U$.

Equality of sets

$A = B \iff \forall x\,(x \in A \leftrightarrow x \in B)$

Empty and power

$\varnothing \subseteq A$ always; $\mathcal{P}(A)$ collects all subsets.

Lee, Introduction to Topological Manifolds · pp. 381-394Sets and Membership
A set is determined entirely by which elements belong to it, so equality means matching membership status across the whole ambient universe. Complements only make sense once that universe is declared, which is why specification always carves a new set out of an already available ambient set.

Operations and De Morgan

De Morgan

$U\setminus(A\cup B) = (U\setminus A)\cap(U\setminus B)$

Distributive law

$A\cup(B\cap C) = (A\cup B)\cap(A\cup C)$, a truth-table identity.

Lee, Introduction to Topological Manifolds · pp. 381-394Operations and De Morgan
Union, intersection, difference, and complement are Boolean operations on membership predicates, turning distributive and De Morgan laws into row-by-row truth-table identities. Verifying them on a finite universe exposes the same local logic that an infinite proof applies one arbitrary element at a time.

Ordered Pairs and Cartesian Products

Order matters

$(a,b)$ remembers first and second coordinates.

Projections recover them

$\pi_1(a,b)=a$ and $\pi_2(a,b)=b$.

Cartesian product

$X\times Y = \{(x,y): x\in X,\ y\in Y\}$

Choices multiply

$|X\times Y| = |X|\cdot|Y|$ for finite factors.

Lee, Introduction to Topological Manifolds · pp. 381-394Ordered Pairs and Products
An ordered pair remembers a first and second coordinate, unlike an unordered set, and the Cartesian product collects every such pair. Projection maps recover the coordinates, and the product cardinality multiplies, which is exactly why product spaces multiply the choices available later in topology.

Relations

A relation is a subset

$R \subseteq X\times X$ records which pairs relate.

Adjectives are tests

Reflexive, symmetric, transitive, antisymmetric.

Four properties

$x R x;\quad xRy\Rightarrow yRx;\quad xRy\wedge yRz\Rightarrow xRz$

Antisymmetry

$xRy\wedge yRx \Rightarrow x=y$ separates orders from equivalences.

Lee, Introduction to Topological Manifolds · pp. 381-394Relations
A relation on a set is simply a subset of the Cartesian square, broad enough to encode adjacency, containment, or identification. Adjectives like reflexive, symmetric, transitive, and antisymmetric are extra tests on the ordered pairs, and each adjective restricts which structures the relation can describe.

Equivalence Relations and Partitions

Quotient set

$X/{\sim} = \{[x] : x\in X\}$

Partition theorem

Equivalence relations and partitions are the same data.

Lee, Introduction to Topological Manifolds · pp. 381-394Equivalence and Partitions
An equivalence relation is reflexive, symmetric, and transitive, and its classes partition the set into nonempty, pairwise disjoint, covering pieces. In a finite generated model the classes are precisely the connected components, and the quotient set is nothing more mysterious than the collection of those classes.

Partial Orders and Maximality

Reflexive, transitive, antisymmetric

Subset inclusion on $\mathcal{P}(X)$ is the model order.

Maximal ≠ maximum

A maximal element has nothing strictly above it; a maximum dominates all.

Lee, Introduction to Topological Manifolds · pp. 381-394Partial Orders
A partial order is reflexive, transitive, and antisymmetric, with subset inclusion on a power set as the model to remember. The Hasse diagram makes incomparability visible and clarifies the trap that a maximal element, having nothing strictly above it, need not be a maximum above everything.

Functions: Injective, Surjective, Bijective

Three properties

$f\text{ inj}: f(x)=f(x')\Rightarrow x=x';\ \ \text{surj}: f(X)=Y$

Bijection

Injective and surjective together; only then is $f^{-1}$ a function.

Lee, Introduction to Topological Manifolds · pp. 381-394Functions
A function assigns exactly one codomain output to every domain input, and both domain and codomain are part of the data. Injectivity means distinct inputs give distinct outputs, surjectivity means every output is attained, and a bijection, being both, is exactly what an inverse function requires.

Images and Preimages

Push forward, pull back

$f(S)\subseteq Y$ images $S$; $f^{-1}(T)\subseteq X$ preimages $T$.

Images are fussier

$f(S\cap S')\subseteq f(S)\cap f(S')$, equality needs injectivity.

Preimage commutes

$f^{-1}(T\cup T') = f^{-1}(T)\cup f^{-1}(T')$

$f^{-1}(T\cap T') = f^{-1}(T)\cap f^{-1}(T')$

Why it matters

Continuity is phrased through preimages of open sets.

Lee, Introduction to Topological Manifolds · pp. 381-394Images and Preimages
Images push subsets of the domain forward while preimages pull subsets of the codomain back. Preimages commute with union, intersection, and difference because membership reduces to the predicate that the image lies in the target set, whereas images only reliably preserve unions, failing intersections without injectivity.

Indexed Families and Disjoint Unions

Family as a map

$\{A_\alpha\}_{\alpha\in I}$ is a function $\alpha \mapsto A_\alpha$.

Disjoint union by tags

$\coprod_\alpha A_\alpha = \{(x,\alpha): x\in A_\alpha\}$.

Arbitrary union and intersection

$x\in\bigcup_{\alpha} A_\alpha \iff \exists\alpha,\ x\in A_\alpha$

$x\in\bigcap_{\alpha} A_\alpha \iff \forall\alpha,\ x\in A_\alpha$

Tags separate copies

Equal-looking points stay distinct across the index.

Lee, Introduction to Topological Manifolds · pp. 381-394Indexed Families and Disjoint Unions
An indexed family is a function from an index set, and arbitrary unions and intersections quantify membership over that index. Tagging elements with their index builds an abstract disjoint union, keeping equal looking points in separate copies, which is the construction behind later wedge and coproduct spaces.

Countability and Cardinality

Same cardinality

$|A| = |B| \iff \exists\,\text{bijection } f:A\to B$

Cantor

$\mathbb{Q}$ is countable; diagonalization makes $\mathbb{R}$ uncountable.

Lee, Introduction to Topological Manifolds · pp. 381-394Countability and Cardinality
Two sets share cardinality when a bijection exists, which for infinite sets becomes a constructive listing problem. The diagonal enumeration of the integer lattice and the reduced fraction listing of the rationals show countability, while Cantor diagonalization shows the reals are strictly uncountable.

Axiom of Choice, Zorn, Well-Ordering

Choice

A choice function selects one point from each nonempty $A_\alpha$.

Zorn's lemma

If every chain has an upper bound, a maximal element exists.

Logical equivalence

$\mathrm{AC} \iff \text{Zorn} \iff \text{Well-Ordering}$

Where it appears

Bases, maximal ideals, and existence proofs in later chapters.

Lee, Introduction to Topological Manifolds · pp. 381-394Choice, Zorn, Well-Ordering
The Axiom of Choice supplies a simultaneous selection from arbitrarily many nonempty sets, and it is logically equivalent to Zorn's lemma and to the well-ordering theorem. These tools justify maximal ideals, bases of vector spaces, and the existence proofs that recur throughout the topology chapters.
