Incidence geometry

Before Distance, a Line Is an Incidence Object

Definition schema

An incidence model has a point set \(X\), a family of lines \(\mathcal L\), and a membership predicate \(P \in \ell\).

\((X,\mathcal L,\in)\quad\text{with}\quad \ell \subseteq X\)
Axiom checklist
  • There are enough points to avoid a one-line universe.
  • Each line contains at least two points.
  • Two distinct points determine exactly one line.
  • At least one triple of points is noncollinear.
incidence alone has no length, angle, or betweenness\(P \in \ell\) is the primitive test
For incidence, slow down on the word primitive. Points and lines are not yet coordinate pairs and equations; the only formal question is whether a point lies on a line. The usual incidence axioms become a compact checklist: enough points, enough lines, and uniqueness of a line through two distinct points.

Finite Incidence Models Make the Contract Inspectable

Artifact: incidence-models-side-by-side.png. Inspect which point-line memberships are actually being asserted.

Inspection targets
  • For each pair of points, identify the proposed line.
  • Check whether the model duplicates or omits a joining line.
  • Ask which statements use only incidence and which secretly use distance.
Useful failure modes

A diagram can fail by missing a line, putting too few points on a line, or allowing two different lines through the same point pair. None of these failures needs a ruler.

finite examples expose hidden assumptionssource span grounded in Chapter 2 model comparison
Read the finite models as state diagrams rather than polished pictures. Ask students to name which point pairs are joined, where a proposed line membership relation succeeds, and where a missing or duplicated line would break the incidence contract before any distance is mentioned.
Metric geometry

A Distance Function Adds Quantitative Structure

Metric axiom box

A function \(d:X\times X\to \mathbb R\) is a metric when all points \(P,Q,R\in X\) satisfy:

\(d(P,Q)\ge 0,\quad d(P,Q)=0\Leftrightarrow P=Q\)
\(d(P,Q)=d(Q,P),\quad d(P,R)\le d(P,Q)+d(Q,R)\)
What becomes meaningful
  • metric balls and nearest-point questions
  • length comparison along a named line or curve
  • triangle inequality as a model sanity check
Common trap

A formula that returns a nonnegative number is not automatically a metric. The triangle inequality is often where plausible candidates fail.

incidence tells what touches whatmetric tells how far apart points are
The metric slide is the pivot. Once a distance function is present, statements about nearest points, balls, and triangle inequalities become meaningful. Emphasize that a distance-looking formula is only a candidate until positivity, identity of indiscernibles, symmetry, and the triangle inequality have been checked.

Proof-state diagram

Metric Claims Need an Audit Trail

Artifact: metric-axiom-checks.png. Model claims depend on definitions, axioms, and explicit checks.

Counterexample check

On the real line, the squared rule \(\delta(x,y)=(x-y)^2\) fails the triangle inequality:

\(\delta(0,2)=4>1+1=\delta(0,1)+\delta(1,2)\)
Passing is global

Testing examples can find failures quickly. A proof is still needed to certify all triples of points in the model.

numeric checks find sharp counterexamplesproof certifies every case
Treat the proof graph as a workflow: definitions feed lemmas, lemmas feed theorems, and theorems authorize model claims. The squared-distance counterexample is useful because it looks harmless, passes some easy tests, and then fails the triangle inequality on a three-point sample.
Special coordinate systems

Coordinates Are Interfaces, Not the Geometry

Artifact: coordinate-system-atlas.png. One point can move through Cartesian, polar, and disk descriptions.

Chart translations
\(P=(x,y)=(r\cos\theta,r\sin\theta)\)
\(\text{disk chart: } x^2+y^2<1\)
Model discipline
  • A coordinate formula has a domain.
  • A chart may describe the same point in more than one way.
  • A simple equation can hide a geometric restriction.
coordinate systems turn predicates into equationsdomain restrictions carry geometry
Coordinates are introduced as interfaces, not as the geometry itself. The same point can be described in Cartesian, polar, or disk language, but each chart has domains and degeneracies. The lecturer should keep asking what remains invariant when the coordinate description changes.
Pitfalls

Algebraic Convenience Can Hide Model Conditions

Three useful warnings
Formula habitModel check
slope \(m\)Vertical lines need a line equation or parameter.
polar angle \(\theta\)Angles repeat; coordinates can be many-to-one.
disk radiusThe boundary may be visible but excluded from the model.
Safer line test
\(ax+by+c=0\)

This form handles vertical and nonvertical lines uniformly.

Safer point test
\(r\ge 0,\quad \theta\sim\theta+2\pi k\)

The equivalence relation is part of the coordinate system.

coordinates are useful because they are partialevery formula has a domain
This warning slide turns common algebra habits into model checks. A vertical line is not defective geometry; it is a defective slope formula. A repeated polar angle is not a new point; it is a reminder that coordinates can be many-to-one.
Worked example

A Four-Point Affine Plane Can Be Checked by Hand

Point set
\(X=\mathbb F_2^2=\{00,10,01,11\}\)
Line inventory

In this tiny affine plane, each line has exactly two points, and each pair of distinct points determines exactly one line.

What is absent

No length has been assigned. The picture supports incidence claims only until a metric is added and checked.

small models make every assumption visiblefinite audit before metric measurement
The affine four-point example is deliberately small. With only four points, every claimed line can be listed and every pair of points can be tested. The example teaches that a model check is a finite audit trail, not a gesture toward a familiar picture.
Applied lab

Diagnose a Candidate Distance Rule by Sampling Triples

Lab recipe
  • Choose a point set \(X\) and a candidate rule \(d\).
  • Check \(d(P,P)=0\) and whether zero ever occurs for distinct points.
  • Swap arguments to test symmetry.
  • Sample triples \(P,Q,R\) to hunt for triangle inequality failures.
  • Turn the first failure into a precise counterexample.
Broken rule to test
\(\delta(x,y)=(x-y)^2\)

It is nonnegative and symmetric, but the triple \(0,1,2\) breaks the triangle inequality.

Takeaways

Chapter 2 Builds the Model-Checking Habit

Incidence

Records what touches what through the predicate \(P\in\ell\). It does not yet measure length, angle, or betweenness.

Metric

Adds distance through a rule \(d\) that must satisfy the metric axioms for every relevant point sample.

Coordinates

Translate geometric predicates into computable equations while carrying domain restrictions and identifications.
