From Description To Test

A Line Formula Is A Membership Predicate

Implicit Test

\(L=\{(x,y): ax+by+c=0\}\)

Best when the line is already known by an equation. It handles vertical and nonvertical lines uniformly.

Parameter Test

\(L=\{P+t\,v:t\in\mathbb R\}\)

Best when a starting point and direction are visible. It becomes the natural language for rays and segments.

Legality Check

\(m=\dfrac{y_2-y_1}{x_2-x_1}\)

This only exists when \(x_2\ne x_1\). The failure is geometric information, not a nuisance.

description + domain = usable predicate

  • Know which inputs the formula accepts.
  • Check equality or parameter existence, not visual nearness.
  • Carry edge cases forward before defining figures from the line.
Use the left box as the formal predicate and the right box as the implementation habit. A point is on a line when the equation or parameter test says so. The important teaching move is to ask what data are required before a formula is legally available.
Betweenness

Between Means Equality In The Metric, Interval Membership In Coordinates

Metric Predicate

\(B\) is between \(A\) and \(C\) when \(d(A,B)+d(B,C)=d(A,C)\).

This expression is independent of a particular coordinate chart.

Affine Implementation

\(B=A+t(C-A)\), with \(0\le t\le 1\).

Strict betweenness uses \(0\lt t\lt 1\); endpoints use \(t=0\) or \(t=1\).

Introduce betweenness twice: first as a metric equality that makes sense without coordinates, then as an affine parameter test in Euclidean coordinates. The interval diagram gives students a fast way to classify endpoints, strict interior points, and points on the same carrier line but outside the segment.
Elementary Figures From One Carrier Line

Segments And Rays Differ By Parameter Restrictions

Closed Segment

\(\overline{AB}\) keeps the carrier line but accepts only parameters between the two endpoints.

Ray With Direction

\(\overrightarrow{AB}\) starts at \(A\), passes through \(B\), and continues with \(t\ge 0\).

Boundary Habit

Always test endpoint, direction, and interval. Collinearity alone is too weak for both objects.

Make the distinction between segment and ray entirely about parameter restrictions. The carrier line is unchanged, but the accepted values of t change. Ask students to locate the boundary cases t=0 and t=1 before considering a point with the correct direction but the wrong endpoint.
Angles

An Angle Is Two Rays With A Common Vertex

Undirected Measure

\(\cos\theta=\dfrac{u\cdot v}{\lVert u\rVert\,\lVert v\rVert}\), with \(0\le\theta\le\pi\).

Directed Measure

\(\theta=\operatorname{atan2}(\det(u,v),u\cdot v)\).

The coordinate formulas do not replace the geometry. They reveal which ray, vertex, and orientation convention is being used.

Present an angle as two rays with a common vertex, not as a floating number. The dot product gives the ordinary undirected measure, while the determinant paired with the dot product gives an oriented measurement. This slide prepares students to separate geometry from drawing convention.
Triangles

A Triangle Packages Three Vertices, Three Segments, And Nonzero Area

Noncollinearity Test

\(\operatorname{area}(A,B,C)=\dfrac12\,\lvert\det(B-A,C-A)\rvert \gt 0\).

Point TestCoordinate Reading
Interiorbarycentric weights all positive
Boundaryone weight zero, the others nonnegative
Exteriorat least one weight negative

Treat a triangle as a compatibility package: three noncollinear vertices, three side segments, positive area, and membership tests for interior or boundary points. The barycentric panel is not meant as a new theorem; it is a coordinate dashboard for assumptions that pictures often hide.
Worked Example Thread

Audit One Small Triangle From Coordinates

Given Data

\(A=(0,0),\quad B=(5,0),\quad C=(1,3)\)

  1. Line \(AB\): \(A+t(B-A)=(5t,0)\).
  2. Midpoint \(M=(2.5,0)\) has \(t=0.5\), so \(M\in\overline{AB}\).
  3. Area: \(\frac12|\det((5,0),(1,3))|=7.5\), so the vertices are not collinear.
  4. Ray \(AC\): \(A+t(C-A)=(t,3t)\), with \(t\ge 0\).
Angle At A

\(\cos\angle BAC=\dfrac{(5,0)\cdot(1,3)}{\lVert(5,0)\rVert\lVert(1,3)\rVert}=\dfrac{1}{\sqrt{10}}\).

Each number certifies one earlier definition: line, segment, ray, angle, or triangle.

Work this example slowly and let each computation point back to a definition. The midpoint is a betweenness certificate, the area rejects degeneracy, the ray formula records direction, and the angle formula uses vectors based at the common vertex. Keep the arithmetic small enough to audit aloud.
Common Mistakes

Four Places Where The Picture Can Be Right But The Predicate Fails

Slope Trap

A vertical line is a line even though \(m\) is undefined.

Use implicit or parametric form
Collinear Is Not Between

A point can lie on \(AC\) and still have \(t\lt0\) or \(t\gt1\).

Check \(0\le t\le1\)
Ray Direction

\(\overrightarrow{AB}\) and \(\overrightarrow{BA}\) share a line but not an endpoint or direction.

Track the first letter
Triangle Degeneracy

Three named points do not form a triangle when signed area is zero.

Test nonzero determinant

A diagram proposes a relation; a predicate verifies it.

Use the warning slide as a diagnostic checklist. Each mistake is plausible because it agrees with part of the picture, but fails one predicate. The lesson is not to distrust diagrams; it is to pair every diagram with the algebraic or metric test it is supposed to satisfy.

Exercise

Classify Each Claim By Naming The Predicate

1

On \(A+t(C-A)\), a point has parameter \(t=1.4\). Is it between \(A\) and \(C\)?

2

For the ray \(\overrightarrow{AB}\), a point has representation \(A-0.2(B-A)\). Is it on the ray?

3

Three points satisfy \(\det(B-A,C-A)=0\). Which triangle condition fails?

4

Two vectors use different initial points. What must be fixed before measuring the angle?

Discussion rule: answer with the relevant predicate first, then the conclusion.

Give students two minutes to decide each item individually, then have them name the predicate used rather than only the answer. The exercise is intentionally coordinate-light: the goal is to practice translating words into parameter intervals, distance equalities, and signed area tests.
Recap

Elementary Figures Are Sets With Rules

Core Principle

figure = carrier set + membership predicate + invariant to check

  • Line descriptions are interchangeable only when their domains are respected.
  • Betweenness becomes a metric equality or a parameter interval.
  • Segments and rays are line predicates with boundary and direction restrictions.
  • Angles and triangles combine smaller predicates into inspectable figures.
Close by compressing the lecture into a working rule: elementary figures become mathematical objects when their membership rules and invariants are explicit. The next chapters will build stronger theorems on this foundation, so students should leave seeing betweenness and rays as tools, not vocabulary.
