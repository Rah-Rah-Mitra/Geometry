Axiomatic language

Primitive Terms Are Controlled By Use

Definition Pattern

Primitive words are terms whose behavior is governed by axioms before a concrete interpretation is selected.

Common Misread

Undefined does not mean vague. It means the word is disciplined by relations, rules, and model tests instead of an informal picture.

formal role first, interpretation second
Visible concept: primitive vocabulary becomes exact through constraints.Inspection target: where meaning enters the system.
Pause on the phrase primitive term. The point is not that point, line, or distance are mysterious forever; the point is that a formal development postpones their meaning until a model supplies one. Ask students to watch how use, not vocabulary definition, creates mathematical discipline.
Axioms and models

An Axiom System Behaves Like A Rule Checker

Axiom System

A list of allowed relationships among primitive terms. It gives a grammar for reasoning before selecting a particular world.

Model

An interpretation of the primitive words in which every axiom is true. A model is evidence that the rules can coexist.

Computational View

Replace each axiom by a predicate. The candidate model passes only when all predicates return true under the same interpretation.

model \(M\) satisfies axiom list \(A\) when \(M \vDash A_i\) for every rule \(A_i\)

Visible concept: models are interpretations that satisfy rules.Audit habit: check every axiom under one interpretation.
Frame axioms as tests rather than slogans. A candidate world is a model only after every rule has been checked under the chosen interpretation of the primitive words. This is the first place where the metric approach feels computational: many definitions become predicates with pass or fail behavior.

Model comparison

Do Not Judge Models By Appearance Alone

Same Rule List

Two candidates must be checked against the same primitive vocabulary and the same axioms.

Different Interpretations

Points may be coordinates, graph nodes, ordered pairs, or something stranger, as long as the rules are respected.

Visual Trap

A drawing can suggest a model, but the drawing is not the proof that the interpretation satisfies the axioms.

QuestionModel Check
What are the objects?Interpret primitive terms.
What must be true?Evaluate every axiom.
Visual teaches: candidate worlds are compared axiom by axiom.Inspection target: separate geometry from drawing style.
Compare the two candidate pictures as worlds being tested under the same rule list. Their visual similarity is not enough, and visual difference would not automatically disqualify either one. The relevant question is whether incidence, distance, or whatever primitive relation is being interpreted satisfies the stated axioms.
Equivalence relations

Equivalence Relations Compress Data Into Blocks

Three Tests

  • Reflexive: every element is related to itself.
  • Symmetric: a relation can be read in both directions.
  • Transitive: linked chains close into one block.

\(x\sim x,\quad x\sim y \Rightarrow y\sim x,\quad x\sim y\ \text{and}\ y\sim z \Rightarrow x\sim z\)

Geometric Use

An equivalence relation lets later geometry treat objects as the same when a chosen property is all that matters.

Visual teaches: relation data becomes a partition of the set.Inspection target: chains merge into complete blocks.
Introduce equivalence relations as machines that turn pairwise information into blocks. Reflexive means every object stays with itself, symmetric means links can be read both ways, and transitive means chains close up. Once all three hold, the relation behaves like equality after information has been intentionally forgotten.
Classes and quotient sets

Work With Classes, Not Favorite Representatives

Equivalence Class

The class \([x]\) is the set of all elements equivalent to \(x\), not merely the element \(x\) with a label attached.

Quotient Set

The quotient \(S/{\sim}\) is the set of all equivalence classes. It stores blocks as the new objects.

Representative Warning

Calculations may choose representatives, but correct conclusions cannot depend on which representative was chosen.

\([x]=[y]\) exactly when \(x\sim y\)

Visible concept: quotienting turns a sameness rule into new objects.Inspection target: representatives disappear into blocks.
Use the quotient slide to separate representatives from classes. A class is not a preferred element with decorations; it is the whole block of elements equivalent to one another. This distinction is essential later when models identify points, directions, transformations, or figures up to a chosen notion of sameness.
Functions and fibers

A Function Carries Its Domain, Codomain, Image, And Fibers

DomainEvery allowed input must have one output.
CodomainThe declared target set is part of the function data.
ImageOutputs actually hit by the function.
FiberAll inputs that land at one chosen output.

Diagnostic Question

Which codomain points are missed, and which image points receive more than one input?

\(\operatorname{fiber}_f(y)=\{x\in X:f(x)=y\}\)

Visual teaches: a function is a structured assignment, not just a loose arrow sketch.Inspection target: image points and fiber collisions.
The function slide should slow students down on domain and codomain. A function is more than a collection of arrows that happen to land somewhere. Its codomain is part of the data, its image may be smaller, and its fibers reveal where different inputs become indistinguishable.
Composition and map tests

Composition Tracks Information Flow

\((g\circ f)(x)=g(f(x))\)

Order Matters

The input starts in \(X\), moves through \(f\), and then moves through \(g\), even though \(g\circ f\) is written with \(g\) first.

Injective Check

No two distinct inputs collide at one output. The diagram makes collisions visible as merged arrows.

Surjective Check

Every declared codomain point is hit. This depends on the codomain, not only on the arrows drawn.

Visible concept: composition is process order plus codomain bookkeeping.Inspection target: collision and coverage behavior under a second map.
Composition is the first algebra of processes in the chapter. Emphasize order: apply f first, then g, even though the written expression g composed with f starts with g. The diagram lets students inspect how injective failures, missing outputs, or fiber collisions propagate through a second mapping.
Notebook workflow

Definitions Become Predicates, But Proof Still Does The Heavy Lifting

Rule Checker

all(ax(M) for ax in axioms)

Model status is a universal claim over the active rules.

Relation Checker

reflexive and symmetric and transitive

Equivalence is visible only when all three tests hold.

Function Checker

image = {f(x) for x in X}

Fibers and missed codomain points are computable diagnostics.

Proof Boundary

Finite checks can expose mistakes and guide conjectures, but the theorem must cover every permitted case.

Visible concept: computational checks support, but do not replace, mathematical proof.Notebook checks: chapter-checks.json and final-sanity.json.
Connect the formal vocabulary back to the notebook workflow. The chapter does not claim that computation replaces proof. It shows how a proof object can leave an audit trail: a rule checker, a graph, a partition, a fiber table, or a sanity assertion that catches an invalid interpretation.
Common failure probes

Four Early Mistakes That Later Geometry Punishes

Drawing Equals Model

A diagram can guide intuition, but the model is the interpretation that satisfies the rules, not the picture alone.

Pairwise Links Equal Equivalence

A relation with self-links and reversible links can still fail transitivity, so it may not produce valid blocks.

Image Equals Codomain

Surjectivity is a statement about the declared codomain. Changing the codomain changes the claim.

Composition Read Left To Right

The notation \(g\circ f\) means follow \(f\) first and only then apply \(g\).

Visible concept: preliminary vocabulary is a debugging toolkit.Inspection target: replace visual confidence with a precise check.
Use this slide as a diagnostic pause before the recap. Each mistake looks small in Chapter 1 but becomes expensive in later metric geometry: confusing drawings with models, treating incomplete relation data as equivalence, ignoring codomains, or reading composition in the wrong operational order.
Takeaways and board exercise

Preliminary Notions Become The Course Checklist

Checklist

  1. Name the primitive terms and active axioms.
  2. State the intended model and verify each rule.
  3. Identify when objects are equivalent and form classes.
  4. Track functions through domain, codomain, image, fibers, and composition.

Board Exercise

Given a small incidence table, a relation matrix, and an arrow diagram, decide which one is a model, which one gives a quotient, and which map properties hold.

The rest of the course repeatedly asks: what structure is being preserved, identified, measured, or transported?
