A curve is a moving point with a clock. This lecture builds the first toolkit: tangent vectors, speed, regularity, arc length, reparametrization, and the bridge between parametrized and implicit descriptions.

Orientation2 / 16
Use this as the map for the hour, and slow down on the word trustworthy. The main through-line is that every later construction asks whether the parameter supports differentiation and measurement. Tell students that most mistakes in this chapter come from reading the picture before checking the clock.
Image is not motion

One trace can hide many clocks

A level equation describes a set. A parametrization describes a visit to that set, including order, repetitions, and speed.

Same image, different motion
γ₁(t) = (cos t, sin t) and γ₂(t) = (cos 2t, sin 2t) draw the same circle over suitable intervals, but their clocks report different velocities.
Parametrized curves3 / 16
Separate the set of points from the motion that visits them. The same circle can be traced once, twice, or with a changing speed, so the image is only one layer of the data. Ask students what changes if they close their eyes to the arrows and only remember the locus.
Definition

A parametrized curve is a differentiable map from an interval

Working model
γ: I → ℝⁿ, t ↦ (γ₁(t), …, γₙ(t))

The parameter t is a clock. The image γ(I) is the trace left behind.

Definition layer4 / 16
State the definition operationally: a parametrized curve is a differentiable vector-valued function on an interval. The interval matters because endpoints, periodic identifications, and local neighborhoods all affect what we are allowed to claim. This is also the first place to make the image versus parametrization distinction precise.
Velocity and speed

The tangent vector is a derivative, not a decoration

At a parameter value
γ′(t₀) = lim h→0 [γ(t₀+h) − γ(t₀)] / h
The speed is ‖γ′(t₀)‖.
  • Direction comes from the vector γ′(t₀).
  • Rate of travel comes from its norm.
  • Both belong to a parameter value, not just to the visible point.
Tangent data5 / 16
The velocity vector is the first local measurement attached to the clock. Secants show why this is a limiting direction, while the speed norm records how fast the parameter is moving through the trace. Emphasize that the tangent vector belongs to a parameter value, even when two parameter values land on the same point.
Regularity

The nonzero-speed test is the gatekeeper

Regular point

γ′(t₀) ≠ 0, so the tangent line is well defined.

Singular parameter

The image may look smooth while the first derivative stops giving direction.

Repeated point

A self-intersection can carry multiple tangent vectors at one location.

Rule of thumb
Before using a tangent line, an arclength inverse, or a local graph argument, ask whether the relevant derivative is nonzero.
Regularity6 / 16
Regularity is the point where the chapter becomes geometric rather than merely algebraic. If the velocity vanishes, the plotted trace may still exist, but tangent direction and length-by-clock arguments need extra care. This slide should feel like a checklist: before using a tangent line, inspect the speed.
Warning example

A cusp exposes a failed first-order test

For γ(t) = (t², t³), both coordinate derivatives vanish at t = 0. The point exists, but the ordinary velocity vector does not choose a direction.

Speed check
γ′(t) = (2t, 3t²), ‖γ′(0)‖ = 0.
Singularities7 / 16
Use the cusp as the warning case and keep the discussion local near the marked point. The parameter value t equals zero is not harmless: the curve reaches the point with zero first-order motion, so the ordinary tangent test has stalled. The visual target is the mismatch between a visible point and a usable first derivative.
Arc length

Length is accumulated speed

Length on an interval
L(γ; [a,b]) = ∫ₐᵇ ‖γ′(t)‖ dt
  • The integrand is speed.
  • Positive speed makes s(t) = ∫ₐᵗ ‖γ′(u)‖ du increase.
  • Increasing arclength can be inverted to make distance the parameter.
Arc length8 / 16
Arc length is the accumulated distance traveled along the path, not a new kind of coordinate imposed from outside. The formula is simple, but its meaning is important: the integrand is speed, and regularity makes the accumulation strictly increasing locally. This prepares the inverse function step on the next slide.
Unit speed

Distance traveled can become the clock

When arclength is invertible, define β(s) = γ(t(s)). Then the new velocity has norm one.

Preferred parameter
‖β′(s)‖ = 1
Equal steps in s correspond to equal distance along the curve.
Unit-speed parametrization9 / 16
Unit-speed parametrization replaces an arbitrary clock with distance traveled. Emphasize that this is not a new curve in space; it is the same trace read with a better measuring tape. The equal-spacing dots give the concrete visual reason unit speed is so useful for later curvature formulas.
Reparametrization

Changing clocks is chain-rule bookkeeping

Clock change
γ̃(u) = γ(φ(u))
γ̃′(u) = γ′(φ(u)) φ′(u)
Length survives
For a regular monotone clock change, speed rescales locally, but the integrated length over corresponding intervals is unchanged.
Reparametrization10 / 16
The chain rule is the bookkeeping device for changing clocks. Speed scales by the absolute derivative of the new clock, while total length over corresponding intervals remains unchanged. Point out that a valid reparametrization must itself have a nonzero derivative, or it can manufacture singular behavior.
Curves in space

The definitions do not care whether n = 2 or n = 3

Twisted cubic sanity check
γ(t) = (t, t², t³)
γ′(t) = (1, 2t, 3t²)
The first component of velocity is always 1, so the curve is regular.
Space curves11 / 16
Plane curves are not the whole story, and the same definitions work in three dimensions. The twisted cubic is useful because every coordinate changes with the same parameter, but the speed never vanishes. Have students read regularity from the first component of the velocity before thinking about the spatial shape.
Implicit and parametrized local views

A nonzero gradient gives a local normal direction

Local passage test
If ∇F(p) ≠ 0, the level set near p has a well-defined normal direction. A local parametrization must move perpendicular to that gradient.
Orthogonality ledger
d/dt F(γ(t)) = ∇F(γ(t)) · γ′(t) = 0
Local implicit-parametric passage12 / 16
Implicit and parametrized descriptions answer different questions. A nonzero gradient supplies a normal to a level curve, while a nonzero coordinate derivative lets a local parametrization behave like a graph. The dot-product identity is the small computation that keeps the two descriptions synchronized.
Closed curves and repeated points

Global language needs parameter bookkeeping

  • Closed: the parametrization returns to its starting point after a period.
  • Simple: no repeated image points except the allowed endpoint match.
  • Self-intersection: distinct parameters share one image point and may have distinct tangents.
Do not collapse parameter values too early
A single plotted point can represent several local passages through the curve.
Global curve language13 / 16
Closedness and self-intersection are global properties of the image and parameter interval together. At a repeated point, the same visible location may carry two different velocity directions. This is where students should stop saying the tangent at the point and start asking which parameter value is meant.

In-class diagnostic

Given a new parametrized curve, ask five questions

Diagnostic checklist

  • What is the image, and is it fully covered?
  • Where does γ′(t) vanish?
  • Can arclength be used as a local clock?
  • Does a proposed period close the curve?
  • Do repeated points carry different tangents?
Small lab prompt
For γ(t) = (t² − 1, t(t² − 1)), sample the image, compute speed, and locate repeated points. Decide which observations are geometric and which depend on the clock.
The point of the lab is not a polished formula; it is learning which tests must run before geometric language is safe.
Exercise15 / 16
Treat this as an in-class diagnostic rather than a long exercise. Students should decide what is known from the formula, what is known from samples, and what is only true after checking regularity. The prompt is deliberately modest because the real goal is building the habit of running the tests in the right order.
