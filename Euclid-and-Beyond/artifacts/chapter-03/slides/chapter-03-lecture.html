Coordinate Plane over a Field

Incidence Is Already Linear Algebra

Definition Block

For a field F, the affine plane has points (x, y) in F². A line is a solution set

a x + b y + c = 0, with (a,b) not equal to (0,0).

Two points determine one such equation, and parallelism is a slope condition.

The picture looks real-valued, but the algebraic statement works over any field.

Fields support incidence and parallels3 / 16
Start with the minimum coordinate model. A point is a pair in F squared, and a line is the solution set of a nonzero linear equation. Incidence and parallels are linear-algebraic statements, so they make sense over every field, including fields with only finitely many elements.

Ordered Fields

Betweenness Needs Inequalities

Coordinate Test

A point P lies between A and B when

P = (1 - λ)A + λB, with 0 < λ < 1.

The formula uses field arithmetic, but the phrase 0 < λ < 1 uses an order.

Order turns collinearity into segments and rays5 / 16
This slide introduces order as the first genuine geometric upgrade. A parameter lambda between zero and one lets us say that a point lies on the segment from A to B rather than merely on the same line. The visual target is the colored interval on the parameter line: without inequalities, the middle part has no algebraic meaning.
Betweenness Axiom in Coordinates

Pasch Becomes a Sign-Crossing Statement

Coordinate Logic

  • A crossing of side UV means the linear expression has opposite signs at U and V.
  • For a vertical line x = k, the sign expression is x - k.
  • Exactly one of the remaining sides must absorb the second sign change.
Pasch depends on order, not topology alone6 / 16
Pasch-style behavior becomes a sign computation once an order exists. A line crosses a triangle by changing the sign of a linear expression along an edge. The important point is that this proof uses order repeatedly, while the underlying incidence picture still came from plain field arithmetic.
Congruence First Pass

Compare Lengths before Taking Square Roots

Segment Congruence

Two segments are congruent when their squared distances match:

AB² = (x_B - x_A)² + (y_B - y_A)².

This test lives entirely inside field arithmetic. It compares lengths without requiring the length itself to be an element of the field.

Congruence starts with squared distance7 / 16
Segment congruence begins more cheaply than students may expect. Equality of squared distances avoids square roots, so many fields can compare lengths without containing all actual length values. This distinction prepares the class for the next slide, where copying a segment onto a prescribed ray forces a square-root demand.
Congruence Gates

Copying a Segment May Demand a New Number

Rational Failure

In Q², the segment from (0,0) to (1,1) has squared length 2. Copying it onto the x-axis would need √2, which is not rational.

Two Gates

  • Pythagorean: square roots of 1 + a² support key length transfers.
  • Euclidean: every positive element has a square root, supporting circle intersections.
Square roots control construction strength8 / 16
The square-root gates are the chapter's sharpest algebraic diagnostics. The segment from (0,0) to (1,1) has squared length two, so copying it onto the rational x-axis would require sqrt(2), which is not rational. Pythagorean fields and Euclidean fields are not ornamental names; they mark exactly which construction and intersection moves are legal.

The hierarchy is a proof map, not a taxonomy exercise9 / 16
Read the hierarchy from left to right as a ladder of promises. A field plane handles incidence, an ordered field handles betweenness, a Pythagorean ordered field handles enough segment transfer and rigid-motion behavior, and a Euclidean ordered field supports the usual circle-intersection story. The slide is deliberately conservative: each added property should be justified by a geometric task.
Rigid Motions and Superposition

Transformations Replace Primitive Motion

Coordinate Motions

T_v(P) = P + v
R(P) = [[c, -s], [s, c]] P, with c² + s² = 1
reflection across a line reverses side while preserving distance

A rational rotation example uses (c,s) = (3/5,4/5).

Rigid motion is an algebraic construction10 / 16
Rigid motions translate superposition into a theorem about transformations. Translations are easy over any field, while rotations require c squared plus s squared equal to one, and reflections use perpendicular structure. The rational pair (3/5, 4/5) is a friendly example because it supplies a nontrivial rotation without leaving a Pythagorean setting.
SAS as a Structural Theorem

Superposition Becomes a Proof about Enough Motions

Proof Roadmap

  • Translate the first chosen vertex to the matching vertex.
  • Rotate one side onto its matching side.
  • Use the included angle to place the third vertex on the correct ray.
  • Reflect if orientation is reversed.

Earlier algebraic gates are not background machinery. They are exactly what licenses the triangle-moving argument.

SAS rests on motion, not on a hidden physical act11 / 16
SAS is presented here as a dependency argument rather than a primitive permission to move triangles. If two sides and the included angle match, suitable translations, rotations, and possibly reflections place one triangle onto the other. Stress that this is exactly the moment where earlier algebraic gates pay off in a familiar Euclidean theorem.
Diagnostic Model I

Finite Fields: Incidence without Order

What Works

  • Every pair of distinct points has one joining line.
  • Parallel classes are clean and finite.
  • Algebraic counting replaces visual continuity.

What Fails

  • No compatible order can make addition and multiplication respect positivity.
  • Segments cannot be intervals in the ordinary sense.
  • Rays and sides of lines need extra language or a different model.
Finite fields are clean but non-ordered12 / 16
Finite fields are excellent incidence laboratories and poor order laboratories. The left side of the slide shows a valid affine-plane phenomenon: every pair of distinct points determines a unique line. The right side explains why cyclic arithmetic cannot support a compatible positive cone, so between-ness and ray orientation cannot be imported for free.
Diagnostic Model II

Ordered Does Not Mean Archimedean

Rational Functions Ordered at Infinity

Declare a rational function positive when it is eventually positive for large real t.

t - n > 0 for every integer n
1/n - 1/t > 0 for every positive n
Order and Archimedes are different commitments13 / 16
The non-Archimedean model separates order from the Archimedean axiom. Rational functions can be ordered by eventual sign for large t, making t larger than every integer and 1/t smaller than every positive reciprocal. Teach the ladder as a scale diagram, not as a real number line: the point is growth class, not ordinary position.

Instructor-Led Exercise

Diagnose the First Failure

Prompt A

In Q², can every segment be copied onto every rational ray?

Target: identify the square-root obstruction.

Prompt B

In F₅², which part of triangle geometry survives?

Target: separate incidence from betweenness.

Prompt C

In a non-Archimedean ordered field, what happens to repeated unit steps?

Target: find the Archimedean assumption.

Answer format: name the algebraic property, name the geometric operation, then give one concrete witness.

Use failures as tests, not as exceptions15 / 16
The exercise slide is meant for live diagnosis. Students should pick one row, name the algebraic property that fails or succeeds, and then state a geometric consequence in plain language. This keeps the field hierarchy from becoming a memorized table and turns it into a method for testing proposed geometries.
Takeaways

Coordinates Expose the Algebra under Euclid

  • Every field gives a strong incidence geometry through linear equations.
  • Betweenness requires an order, not merely coordinates.
  • Squared distance compares segments before square roots are available.
  • Rigid motions and SAS require enough square-root structure.
  • Finite and non-Archimedean fields calibrate the limits of Euclidean intuition.
