Primitive Data

Incidence Keeps Only Points, Lines, And Lies-On

Definition

An incidence model is a set of points, a set of lines, and a relation \(I(P,\ell)\) saying that point \(P\) lies on line \(\ell\).

What Is Absent

No distance, angle measure, betweenness, coordinate chart, or continuity principle is available by default.

This deliberately lean vocabulary is why small finite worlds can teach real logical lessons.

Incidence vocabularypoints, lines, lies-on
Slow down here and deliberately remove metric habits. In incidence geometry, the primitive data are points, lines, and the lies-on relation. No length, angle, betweenness, or coordinate measurement is available unless a later axiom family or model adds it explicitly.
Logic Translation

A Sentence Becomes A Predicate Over The Model

Ordinary Sentence

Any two distinct points determine exactly one line.

Predicate Shape

\(P \ne Q \Rightarrow \exists! \ell \; [I(P,\ell) \;\text{and}\; I(Q,\ell)]\)

The quantifier \(\exists!\) is the uniqueness demand; it is stronger than merely finding one witness.

Predicate logic as a model queryexistence and uniqueness
Translate a familiar geometric sentence into a testable predicate. Students should hear that the symbols are not decoration: they specify inputs, quantifiers, and a relation. This is the point where informal diagram reading becomes an auditable statement about a structure.
Model Truth Versus Proof

One True Model Does Not Make A Theorem

Model Check

Evaluate a sentence inside one specific incidence table.

Theorem Check

Show the sentence follows in every model satisfying the assumptions.

Warning

A beautiful diagram can be a special model, not a proof of the general claim.

Model truth is localTheoremhood is universal over assumptions
Emphasize the central distinction of the chapter. A sentence may be true in the model on the screen because that model has special features. A theorem must survive every model satisfying the stated assumptions, so one successful finite check is evidence, not final permission.

Applied Lab

Truth Tables Show Which Assumption Changed

Lab Habit

Change one assumption at a time, then record which sentence flips truth value.

Interpretation

A false entry is often more valuable than a true one: it points to the exact axiom the proposed proof needed.

The table is finite, but the habit scales to later Euclidean, hyperbolic, and elliptic models.

Truth-table labmodel diagnostics, not theorem replacement
Connect this slide to the notebook's truth-table lab. A diagnostic table does not prove a theorem by itself, but it shows which sentences separate candidate worlds. The most useful table is often the one that reveals exactly which assumption changed the truth value.
Same Geometry, New Names

An Isomorphism Preserves Every Lies-On Fact

Definition

A map of points and lines is an isomorphism when \(I(P,\ell)\) is true exactly when \(I(f(P),f(\ell))\) is true.

Operational Test

Permute labels, rebuild the table, and compare the yes-or-no pattern.

Isomorphism as incidence-preserving relabelingmodel identity up to names
Define isomorphism operationally as a relabeling that preserves the yes-or-no incidence relation. The visual shows the same table before and after a permutation, so the key question is not whether the drawing looks different but whether every lies-on fact is carried to another lies-on fact.
Symmetry Of A Model

Automorphisms Are Isomorphisms From A Model To Itself

Automorphism

Same model, renamed internally, with every incidence claim still true after translation.

Do Not Overread The Drawing

Visual symmetry may depend on how the model is embedded on the slide. Incidence symmetry depends on the table.

This is why finite geometry treats names as temporary handles, not geometric substance.

Automorphismsymmetry of incidence data
After isomorphism, name automorphisms as symmetries of a model with itself. The important teaching move is to separate visual symmetry from incidence symmetry. A redrawn model can look less symmetric while the underlying automorphism group still preserves the same incidence data.
Projective Incidence

Projective Planes Make Every Pair Of Lines Meet

Projective Habit

Parallel-looking directions are completed by ideal points so that the incidence rule has one uniform form.

Logical Payoff

The model removes a case distinction from the language of line intersections.

Projective plane behaviorno parallel exception
Use projective behavior as an incidence decision rather than as a perspective trick. When every pair of lines meets, the language has no exceptional parallel case. The line at infinity is a model device that turns parallel directions into ordinary incidence points.
Affine From Projective

Deleting A Line Creates Parallel Classes

Model Move

Start with a projective plane, remove one line and all points incident with it, then read the remaining incidence structure.

Result

Parallelism appears as a relation among remaining lines that would have met on the removed line.

Affine model constructionparallel classes from deletion
Show the affine plane as a deliberate deletion from the projective picture. Removing one line and its points restores parallel classes in the remaining world. This makes parallelism look less like visual obviousness and more like a structural feature produced by the chosen model.
Independence Habit

A Countermodel Shows What The Axioms Do Not Force

Diagnostic Question

Can two models satisfy the same current assumptions while disagreeing on the proposed conclusion?

If Yes

The conclusion is not licensed by those assumptions alone; the proof needs a stronger axiom or a narrower model class.

Countermodel methodlogical independence preview
Frame countermodels as diagnostic instruments. If two axiom packages both satisfy the stated incidence rules but disagree on a proposed conclusion, the conclusion was not licensed by those rules alone. The model is therefore doing logical work, not merely providing an example.
Diagram Discipline

A Picture Can Suggest More Structure Than The Model Contains

Unsafe Inference

The line looks long, the angle looks acute, or the curve looks circular.

Safe Incidence Inference

Only the point-line membership relation is part of the current structure.

The model decides which visual properties are mathematical and which are merely presentation choices.

Diagram dangervisual convention versus invariant data
Use this warning to discipline visual reasoning. A drawing may make a line appear curved, straight, long, short, or parallel, but incidence geometry only records which points lie on which lines. The safe question is always which visual feature is an invariant of the model.
Instructor Lab

Audit A Tiny Model Before Proving With It

Task

Given a line table, verify the pair axiom and then test whether a proposed relabeling is an isomorphism.

  1. Pick two distinct points.
  2. Find all lines containing both.
  3. Record whether the witness is unique.
  4. Apply the relabeling and repeat the check.
Classroom exercisefrom table check to proof habit
Assign the lab as an active lecture moment. Students can choose any two points, find the line witnessing their incidence claim, and then try a relabeling. The exercise is intentionally finite so that theorem-like language remains tied to a checkable table.
