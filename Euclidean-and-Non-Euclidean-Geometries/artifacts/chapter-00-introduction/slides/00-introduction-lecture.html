The central experiment

A point, a line, and a counting question

Working observable

\(N(P,\ell)\) counts lines through \(P\) that avoid \(\ell\).

This count is not a proof by itself. It is a compact way to ask which geometry is being modeled and which parallel axiom is in force.

Observable: parallel count 3 / 16
Use the counting notation as a teaching device, not as a replacement for the synthetic statement. Students should notice that the same drawing contains several candidate curves, but the geometry decides which objects are lines and when two such objects meet. That is the first separation between picture and axiom.
Three answers to one question

Parallel behavior names a regime

Euclidean

\(N(P,\ell)=1\)

Exactly one line through the external point avoids the given line.

Hyperbolic sample

\(N(P,\ell)>1\)

More than one geodesic through the point avoids the reference geodesic.

Elliptic

\(N(P,\ell)=0\)

Line pairs meet, so the parallel question has no avoiding line.

The count depends on the model and axiom package. 4 / 16
Make the contrast brisk and memorable: one, many, none. The important point is not that students have already mastered these geometries. The point is that a single structural question splits the landscape, so later chapters can ask which assumptions force the Euclidean answer and which assumptions leave alternatives open.
Syntax and semantics

Axioms state permissions; models interpret them

Axiom side

Undefined words such as point, line, between, congruent, and parallel receive legal roles inside a proof system.

Model side

A coordinate plane, disk model, finite incidence table, or spherical interpretation gives those words concrete objects to inspect.

Syntax is the formal statement; semantics is a model. 5 / 16
Pause on the words syntax and semantics because they will become useful throughout the course. An axiom is not a picture; it is a rule inside a formal language. A model is not the theorem; it is an interpretation that lets students test whether the stated assumptions are being used honestly.

Why the parallel question is hard

Local constructions do not settle global structure

Local

A construction copies a length, draws a circle, or marks an intersection in a small neighborhood.

Global

The parallel question asks what happens when a relation is extended across the whole plane.

Parallelism is a global constraint. 7 / 16
Distinguish the comfort of a local construction from the difficulty of a global axiom. A compass arc can be verified near the page, but the parallel postulate speaks about all the way out. That difference explains why the issue survived so many attempted proofs and became a foundation for alternative geometries.
Regime I

Euclidean geometry: one avoiding line

Coordinate witness

If \(\ell\) has slope \(m\), the line through \(P=(a,b)\) with slope \(m\) is the unique coordinate parallel.

\(y-b=m(x-a)\)

Euclidean coordinate intuition is powerful, but it is one model. 8 / 16
Give students one familiar anchor before moving away from it. In a coordinate plane, equal slope is a concrete way to see the unique parallel. Then immediately name the limitation: coordinates make the Euclidean regime easy to inspect, but they should not be mistaken for the only possible semantics of line.
Regime II

Hyperbolic preview: many avoiding geodesics

Model warning

The disk is drawn on a Euclidean screen, but its geodesics and distances are interpreted by hyperbolic rules.

Course promise

Later chapters make this preview rigorous through consistency models and distance formulas.

A model can be familiar as a picture and unfamiliar as a geometry. 9 / 16
Treat the disk drawing as a preview, not as a theorem. The key teaching move is to separate the Euclidean display surface from the hyperbolic interpretation. Students should see why the model is useful and also why a later chapter must define its geodesics and distance before proof can begin.
Regime III

Elliptic preview: line pairs meet

Spherical intuition

Great circles give a useful image: two distinct great circles meet, so there is no parallel line in this regime.

The course later treats elliptic and Riemannian viewpoints as extensions, but the introduction already prepares the comparison.

The introduction opens the comparison before proving the details. 10 / 16
Use the sphere only as a controlled intuition. Great circles help students imagine a geometry with no parallels, but the phrase line still has to be interpreted carefully. The aim is to broaden the class's expectations before the book begins its systematic historical and axiomatic development.

Worked example

One input question separates three geometries

Input

Place \(P\) off \(\ell\). Ask for lines through \(P\) that do not meet \(\ell\).

Interpretation changes
  • Euclidean line means coordinate straight line.
  • Hyperbolic line means model geodesic.
  • Elliptic line means great-circle class.
The construction is shared; the licensed inference is not. 13 / 16
Work this example aloud as a proof-reading exercise. The same words, point and line, travel through three interpretations. Ask students to identify where the construction stops and where the inference begins. That boundary is the boundary the course will keep testing whenever a familiar theorem becomes suspect.
Applied lab habit

Change one assumption at a time

Lab rule

Vary one assumption, then watch which conclusion moves. Changing two assumptions at once hides the reason a theorem fails.

Instructor prompt

Ask learners to predict the diagnostic before the model is revealed.

The notebook's model-comparison lab uses this discipline. 14 / 16
This is the practical bridge into the notebook activities. The model lab is not trying to mechanize a proof. It trains a habit: alter one assumption, inspect the diagnostic, and record what stayed stable. That habit makes the historical story mathematically useful instead of merely chronological.
Common traps

Three ways to misread the introduction

Trap 1

A good drawing is a proof

A drawing can guide attention, but it may smuggle in Euclidean assumptions.

Trap 2

A model is the whole theory

A model interprets axioms; the proof still has to say which assumptions were used.

Trap 3

History is only background

The historical attempts reveal hidden assumptions and motivate cleaner axiom systems.

The introduction is a discipline for reading geometry. 15 / 16
Use these traps as diagnostic questions for discussion. If a student says the picture obviously settles the issue, ask which axiom authorized the inference. If a student says the disk is just a Euclidean circle, ask what the model is interpreting. If history seems decorative, point to the hidden assumptions it exposes.
