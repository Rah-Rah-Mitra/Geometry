Infinite Metrics Split Space Into Components

Finite-Distance Relation

Define \(x \sim y\) when \(d(x,y) < \infty\). The metric axioms force this to be an equivalence relation.

Component Metrics

Each class carries finite distances internally. Distances between classes are recorded as infinity.

classes: \(\{A,B,C\}\) and \(\{D,E\}\)
notebook section: infinite distances and componentsfinite relation: reflexive, symmetric, transitive
Explain why allowing infinity is not a defect in this chapter. Finite distance defines components, and the metric inside each component behaves normally. The dashed cross-component separations mark that no finite path of distance information connects the two pieces.
Zero distance can identify points

Semi-Metrics Become Metrics After a Quotient

Problem

A semi-metric may have \(d(x,y)=0\) even when \(x\ne y\).

Repair

Collapse every zero-distance fiber into one class. Then measure distances between classes.

\(d([x],[y]) = d(x,y)\)

The notebook checks that the quotient metric has no off-diagonal zero distances and satisfies the triangle inequality.

quotient coordinate: c = x + ypreview: quotients return in later chapters
The quotient slide should slow the room down. A semi-metric can say that two different points are at zero distance. The repair is not to pretend they are distinct, but to identify each zero-distance fiber and measure the resulting classes.

The Shape Changes

The Topology Survives

On finite-dimensional spaces, constants compare the norms in both directions.

Use the nested norm balls to distinguish shape from topology. In finite-dimensional spaces the balls look different, but each norm bounds the others after changing constants. That is the bi-Lipschitz lesson: the topology survives even when the unit geometry changes.
Section 1.3

Metric Topology Begins With Balls

Definition

A set \(U\) is open when every point \(x\in U\) has a radius \(r>0\) with \(B(x,r)\subset U\).

Metric Dependence

Change the metric and the balls change. The topology may stay equivalent, become finer, or become coarser.

\(B(x,r)=\{y : d(x,y)<r\}\)
topology is read from small ballsmetric first, topology second
Turn topology into a concrete observational rule. Around every point, the metric supplies balls, and those balls decide which sets are open. The slide should make students inspect how changing the metric changes the neighborhoods before any theorem is invoked.
Section 1.4

Lipschitz Maps: One Constant Controls All Distances

Hierarchy

  • continuous: local control
  • Lipschitz: global linear control
  • nonexpanding: constant \(C=1\)
  • bi-Lipschitz: control both ways
\(d_Y(fx,fy) \le C\,d_X(x,y)\)

The distance-to-set function is nonexpanding: moving the input by \(h\) changes the output by at most \(h\).

distance to a set is nonexpandingcontinuity follows from Lipschitz control
Emphasize Lipschitz maps as controlled functions. Continuity only asks that nearby inputs eventually give nearby outputs; Lipschitz control gives a single global rate. The distance-to-a-set example is useful because the slope bound is visible.
Section 1.5

Completeness: Cauchy Tails Need a Landing Point

Cauchy Condition

For every \(\epsilon>0\), sufficiently late terms are within \(\epsilon\) of each other.

Completeness

Every Cauchy sequence converges to a point in the same space.

Fixed-Point Preview

Contractions generate Cauchy tails. Completeness supplies the landing point.

model: R minus {0}missing limits expose incompleteness
Define completeness as an internal landing guarantee. A Cauchy sequence can behave as though it is converging using only distances among its terms. If the proposed landing point is missing, as in a punctured space, the metric record exposes the gap.
Section 1.6

Compactness: Finite Nets at Every Resolution

Total Boundedness

For each \(\epsilon>0\), finitely many \(\epsilon\)-balls cover the whole space.

Metric Compactness

compact \(\Longleftrightarrow\) complete + totally bounded

Recorded Check

The notebook's greedy separated set on the sampled circle is also an epsilon-net.

epsilon = 0.7greedy separated count: 8
Compactness should feel finite-resolution rather than mystical. At every epsilon scale, finitely many balls see the whole space, and completeness prevents Cauchy tails from escaping. The circle example gives the audience something to inspect at a fixed resolution.
Proof scaffold

Compact Self-Isometries Cannot Lose Distance Data

Idea

A distance-preserving map \(f:X\to X\) keeps separated sets separated. If \(X\) is compact, there is a maximum size for any \(\epsilon\)-separated set.

\(d(fx,fy)=d(x,y)\)

Contradiction Route

  • Assume a point \(p\) is missed by \(f(X)\).
  • Compactness gives a positive gap from \(p\) to the image.
  • Add \(p\) to a maximal separated set.
  • The larger set contradicts maximality.
proof role: finite nets bound separated-set cardinalityoriginal proof scaffold from notebook checks
Use this proof scaffold as a story about not losing distance data. If a distance-preserving self-map of a compact space missed a point, a positive gap would let us add one more separated point than compactness permits. That is the contradiction.
Section 1.7

Hausdorff Measure: Pay for Covers by Diameter

Covering Cost

\(\sum_i \operatorname{diam}(U_i)^d\)

For Cantor Stages

\(2^k(3^{-k})^d\)

The exponent \(d\) determines whether small intervals become too cheap or still expensive.

Inspection Target

Track whether the covering weight grows, stays level, or shrinks as \(k\) increases.

measure as scale bookkeepingfrom covers to dimension
Hausdorff measure is introduced as paying for a cover. The exponent d changes the price of a small set: small intervals become cheap faster when d is larger. This prepares the critical exponent without requiring a full measure theory detour.
Critical exponent

Hausdorff Dimension: Where the Weight Switches

Cantor Dimension

\(d_H = \frac{\log 2}{\log 3}\)

Recorded Regime Check

At the critical exponent, the stage weights stay constant. Below it, they grow; above it, they shrink.

Lipschitz Monotonicity

Lipschitz images cannot increase Hausdorff dimension. Distance control has scale consequences.

critical weight check: truedimension as a threshold
The Cantor calculation is the memorable endpoint. At d equal to log two over log three, the stage weights stay level; below it they grow, above it they shrink. This is the operational meaning of dimension in this first lecture.
