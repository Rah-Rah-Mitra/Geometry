Formula family

Sign Changes Are Small But Expensive

Compact Formulas

$$\widetilde{X_r}=(-1)^{r(r-1)/2}X_r$$
$$\widehat{X_r}=(-1)^rX_r$$
$$\overline{X_r}=(-1)^{r(r+1)/2}X_r$$

Common Failure Mode

Using the reverse where Clifford conjugation was intended, or forgetting that a bivector reverses sign.

Notebook check: bivectors and trivectors reverse sign in the saved basis-blade table.PDF pages 618-622
Treat the sign table as a debugging device. Reversion, grade involution, and Clifford conjugation look harmless, but a single wrong sign changes rotor inverses, dual formulas, and sandwich operations. The displayed patterns should be checked before trusting longer derivations.
Preconditions

Inverse And Dual Need Preconditions

Before Inverting

Ask whether the blade has a nonzero squared norm in the active metric.

Before Dualizing

Ask whether the pseudoscalar is invertible and whether the orientation convention has been fixed.

Small Check

Pass: \(e_{12}^{-1}=-e_{12}\), \(e_{12}e_{12}^{-1}=1\), and undual recovers the blade up to orientation.

Rule: formulas using division, inverse, dual, or undual must name the metric assumption.Appendix D
Emphasize that inverse and dual equations are not universally available commands. A blade must be non-null before inversion is meaningful, and the pseudoscalar must be invertible before duality behaves cleanly. These assumptions are where many elegant derivations become runtime bugs.
Operator identities

Operators: Projection, Reflection, Rotor

Projection / Rejection

$$x_{\parallel}=(x\rfloor B)B^{-1},\qquad x_{\perp}=(x\wedge B)B^{-1}$$

Use when a vector must split relative to an invertible blade.

Reflection

$$x'=-nxn\quad\text{for unit }n$$

Use when the normal component should flip and tangential components stay fixed.

Shortest Rotor

$$R=\frac{1+ba}{\sqrt{2(1+a\cdot b)}}$$

Use for unit, non-opposite vectors \(a\) and \(b\).

Notebook check: projection + rejection recomposes; rotor sends \(e_1\) to a target direction.PDF pages 618-622
Present the three operator formulas as a progression from decomposition to motion. Projection and rejection split a vector relative to a blade, reflection flips one component, and a rotor applies an even transformation while preserving norm and orientation constraints.
Special cases

Exponentials Split Into Three Regimes

Negative Square

$$B^2=-\alpha^2$$
$$e^B=\cos\alpha+\frac{B}{\alpha}\sin\alpha$$

Use for Euclidean bivector rotations.

Zero Square

$$N^2=0$$
$$e^N=1+N$$

Use for nilpotent generators and translation-like cases.

Positive Square

$$H^2=\alpha^2$$
$$e^H=\cosh\alpha+\frac{H}{\alpha}\sinh\alpha$$

Use for hyperbolic motions or positive-square vectors.

Regime test first: compute the square of the generator.Appendix D
The exponential cases are best remembered by the square of the generator. Negative square gives circular functions, zero square truncates after the linear term, and positive square gives hyperbolic functions. The regime test is more important than memorizing every Taylor term.
Model equations

Model Equations: Homogeneous And Conformal

Homogeneous Model

$$X\mapsto X+t\wedge(e_0^{-1}\rfloor X)$$

Use when translation and incidence of flat objects must be represented without leaving blade language.

Conformal Model

$$P(x)=o+x+\frac{1}{2}\lVert x\rVert^2\infty$$
$$-2P(x)\cdot P(y)=\lVert x-y\rVert^2$$

Use when Euclidean points, spheres, flats, and distances should live in one null-space model.

Model equations are safe only after the model and normalization convention are named.PDF pages 618-622
Separate model equations from core algebra equations. Homogeneous formulas manage translations and incidence for flat objects, while conformal formulas embed Euclidean points as normalized null objects. The model must be named before the identity can be trusted.
Common pitfalls

Common Pitfalls Checklist

Wrong Grade

A selected product can be zero because the requested grade is impossible.

Check: grade target before interpreting zero.

Null Inverse

Projection, rejection, duality, meet, and join may hide an inverse.

Check: squared norm and pseudoscalar.

Rotor Ambiguity

The shortest rotor formula assumes unit vectors and no exact antipodal case.

Check: inputs and denominator.

Model Drift

Conformal distance formulas assume normalized null point embeddings.

Check: \(P(x)^2=0\) and scale.

Pause before use: a correct equation can still be the wrong equation for the object at hand.Appendix D
Use the pitfalls slide as a pause point before examples. Most mistakes are not arithmetic mistakes; they are hidden assumption failures. Check grades, invertibility, unit inputs, normalization, and model conventions before interpreting a compact equation as a geometric truth.

Takeaway

Formula Sheet Discipline

1

Name The Formula Family

Product filter, sign operation, inverse, operator, exponential, or model equation.

2

Name The Precondition

Grade, metric, unit length, invertibility, normalization, or model convention.

3

Name The Check

Recompose, preserve norm, recover distance, match target direction, or return identity.

Final rule: no identity enters a geometry engine without a cheap invariant test.Appendix D - Common Equations
Close by making the method portable. Students should leave with a personal rule: every reused equation needs a named family, a visible precondition, and one cheap test. That rule makes the appendix useful across rotors, duals, projections, and conformal constructions.
