Open by naming the change in scale: the chapter is no longer only about circles and spheres. The observations may be rotations, frames, subspaces, hyperboloid points, or manifold points, so the first statistical decision is to identify the sample space before computing a summary.

Lecture Route: Statistics After The Sample Space

1. Name the object

Is the observation a rotation, ordered frame, subspace, point on a hyperboloid, or more general manifold point?

2. Write the constraint

The defining equation is a statistical precondition, not just a numerical detail.

3. State invariance

Decide which coordinate changes, internal bases, or group actions should leave the answer unchanged.

4. Route the model

Choose a canonical statistic that survives the chosen invariance.

Use the route slide as a discipline for the whole lecture. Each step prevents a familiar mistake: treating a constrained object as an ordinary vector, forgetting an invariance, or fitting a model whose statistic changes when the same observation is represented in another valid way.

A Small Inventory Of Non-Spherical Directional Data

Rotation

\(R \in SO(3)\) records a complete oriented frame: \(R^T R = I\), \(\det R = 1\).

Stiefel frame

\(X \in V_r(\mathbb R^p)\) records \(r\) ordered orthonormal columns: \(X^T X = I_r\).

Grassmann subspace

\(\operatorname{span}(X)\) ignores the chosen basis; use \(P = XX^T\) when \(XQ\) is equivalent.

Hyperboloid and beyond

\(x_0^2-x_1^2-x_2^2 = 1\) changes the metric signature; general manifolds require their own checks.

This slide separates the main object types. The point is not that every example needs a different computational library; it is that each example carries a different identity check, and those checks decide whether a proposed average, score, or test is meaningful.

Rotations Are Complete Oriented Frames

Sample space

\(SO(3)=\{R\in\mathbb R^{3\times 3}: R^T R=I,\det R=1\}\).

Local coordinates

A skew matrix \(A(v)\) moves through the exponential map: \(R=\exp A(v)\).

Model route

Matrix Fisher style scores can use the oriented frame itself: \(\operatorname{tr}(F^T R)\).

Present rotations as complete oriented frames. The matrix has nine entries, but the statistical object lives on a three-dimensional curved group cut out by orthogonality and determinant constraints. This is why the matrix Fisher score sees the whole oriented frame.

Stiefel Data Keep Ordered Orthonormal Columns

Definition

\(V_r(\mathbb R^p)=\{X\in\mathbb R^{p\times r}:X^T X=I_r\}\).

Interpretation

The columns are part of the observation. Swapping or rotating them changes the recorded frame unless the application says otherwise.

Computation

Use a polar or QR step to project noisy matrices back to the Stiefel constraint before fitting.

Move from rotations to partial frames. A Stiefel point keeps only r orthonormal columns, so the data retain directional order inside the frame. Polar or QR projection is useful computationally because it repairs a noisy full-rank matrix back onto the constraint set.

Grassmann Data Forget The Internal Basis

Equivalence

\(X\) and \(XQ\) describe the same \(r\)-plane whenever \(Q\in O(r)\).

Projection record

\(P=XX^T\) is symmetric, idempotent, and has \(\operatorname{tr}P=r\).

\(P(XQ)=XQQ^T X^T=XX^T=P(X)\)
Consequence

A statistic that changes under \(X\mapsto XQ\) is not a statistic on the subspace.

Stress the difference between a chosen basis and the subspace it spans. The projection matrix is the coordinate-free record of the subspace, so replacing X by XQ should not change the answer. This is the practical reason Grassmann data route through P equals X X transpose.

Matrix Fisher Or Matrix Bingham?

Frame or rotation

If ordered columns are observed, score the matrix itself: \(\operatorname{tr}(F^T X)\).

Subspace or axis

If the basis is arbitrary, score the projection: \(\operatorname{tr}(A P)\).

Test

Re-base \(X\) inside its plane. A valid Grassmann statistic should not move.

Use the two score curves to make model routing visible. The frame score changes when the internal basis rotates, so it is appropriate only when the basis is observed. The projection score stays flat, which is exactly the behavior wanted for subspace or axial data.

Hyperboloids Change The Metric Signature

Constraint

\(H^2=\{x:x_0^2-x_1^2-x_2^2=1,\ x_0>0\}\).

Bilinear form

Distances and model scores depend on the Minkowski product, not the Euclidean dot product.

Probability warning

The full upper sheet is noncompact, so there is no finite uniform analogue of the spherical uniform law.

The hyperboloid example breaks the habit of using the Euclidean dot product everywhere. Points satisfy an indefinite quadratic identity, and the relevant symmetry preserves the Minkowski bilinear form. Also note that a full hyperboloid is noncompact, so a finite uniform model is not available.

The General Manifold Habit

Membership

What equation, chart, embedding, or constraint says the point belongs to the sample space?

Local model

When using a tangent approximation, state the base point and the map back to the manifold.

Symmetry

Specify the group action or quotient so equivalent representations have equal statistical meaning.

Audit

Save checks that verify constraints and invariances after the computation runs.

General manifold data do not require a single universal algorithm, but they do require a repeatable contract. Before averaging or testing, record membership, tangent or chart information, metric or geodesic structure, and the group action or quotient that should leave the scientific answer unchanged.

Invariant Checks Are Part Of The Statistic

Rotation

\(\lVert R^T R-I\rVert\) small and \(\det R\) close to \(1\).

Stiefel

\(\lVert X^T X-I_r\rVert\) small after projection or estimation.

Grassmann

\(P^T=P\), \(P^2=P\), \(\operatorname{tr}P=r\), and \(P(XQ)=P(X)\).

Hyperboloid

\(x_0^2-x_1^2-x_2^2=1\), \(x_0>0\), and scores use the correct bilinear form.

Turn the geometry into executable checks. These identities are not cosmetic tests; they are the evidence that an array still represents the intended sample space after numerical construction, perturbation, projection, or model fitting. When a check fails, the statistical interpretation should pause before the estimator is interpreted.

Applied Lab: Classify Before Computing

Observation type. Name whether the data are vectors, axes, rotations, frames, subspaces, hyperboloid points, or manifold points.
Membership test. Write the constraint in code before computing summaries.
Invariance. Identify coordinate changes or internal re-basing that should not change the answer.
Canonical statistic. Route through \(X\), \(XX^T\), a Minkowski product, or a chart/geodesic-aware summary.
Audit trail. Save one visual artifact and one numerical check for later inspection.
This checklist is the applied workflow for new data. Students should be able to say what the observation is, what constraint defines membership, what transformations leave it unchanged, and which canonical statistic survives those transformations before any estimation routine is trusted.

Routing principle

If a permitted coordinate change alters the numerical answer, the statistic is still attached to the representation rather than to the sample space.

The table compresses the chapter into a routing rule. Rotations and frames keep ordered columns, so the statistic can use the matrix itself. Subspaces and axes forget the basis, hyperboloid data use Minkowski products, and general manifolds need local or geodesic summaries.

One Data Pipeline: From Array To Inference

Example: local plane

A sensor returns two fitted orthonormal directions, but the plane is the scientific observation.

Route

Convert \(X\) to \(P=XX^T\) so internal rotations of the fitted basis disappear.

Report

Fit and diagnose a subspace model; attach \(P^2=P\) and re-basing checks.

Use the pipeline as a worked design pattern rather than a numerical example. A recorded object first passes a membership audit, then the invariance is stated, then the statistic is selected, and only afterward does the model score or inference step become interpretable.

Common Pitfalls In General Sample Spaces

Flattening too soon. A chart can help, but a final statistic must return to the intended sample space.
Keeping a fake basis. Grassmann data lose their meaning if the chosen \(X\) is treated as observable when only \(\operatorname{span}(X)\) matters.
Using the wrong product. Hyperboloid calculations need the indefinite bilinear form, not the Euclidean dot product.
Assuming uniformity exists. Noncompact spaces do not inherit finite uniform laws from compact directional spaces.
Use the pitfalls slide as a quality-control pass. Most errors in this chapter come from losing an invariance: flattening a curved space too early, keeping a basis that should have been quotiented out, or using a compact-space intuition on a noncompact sample space.

Recap And Instructor Prompt

Takeaways
  • Every manifold-valued observation needs a membership constraint.
  • Model routing is governed by invariance, not by storage format.
  • Frames use ordered columns; subspaces use projections.
  • Hyperboloid data require Minkowski geometry and noncompact caution.
  • Checks are part of the final statistical report.
