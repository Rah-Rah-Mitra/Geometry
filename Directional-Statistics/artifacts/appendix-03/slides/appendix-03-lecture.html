Fisher Quantiles

A Quantile Is A Spherical Cap Radius

For a Fisher model centered at a pole, the lookup asks how wide the cap must be to contain probability \(q\).

\(P_\kappa(\Theta\leq t)=\dfrac{e^\kappa-e^{\kappa\cos t}}{e^\kappa-e^{-\kappa}}\)
Calculator

Given \(\kappa\) and \(q\), solve \(P_\kappa(\Theta\leq t)=q\). The output is an angle, not a Euclidean length.

Interpretation Check

As concentration rises, the same probability fits inside a smaller angular cap.

Make the first replacement geometric. A Fisher quantile table is not a generic probability chart; it reports the angular radius of a cap around a specified pole, so the output should be read in degrees or radians on the sphere.

Fisher Concentration Lookup

Estimating \(\kappa\) Is A One-Dimensional Inverse Problem

The spherical mean resultant length is connected to concentration by \(A_3(\kappa)\).

\(A_3(\kappa)=\coth(\kappa)-\dfrac{1}{\kappa}\), hence \(\widehat\kappa=A_3^{-1}(\bar R)\)
Numerical Step

Given \(\bar R\), solve \(A_3(\kappa)-\bar R=0\) and report the round-trip residual.

Model Guard

A large \(\bar R\) suggests concentration only after the data look directional rather than axial or girdle-like.

Explain that the concentration table is really an inverse function table. The executable notebook solves the equation directly and then recomputes A3 at the solution, so the residual becomes a compact audit of the lookup.
Resultant Geometry

The Mean Vector Is A Spherical Diagnostic

Resultant length measures directional agreement; resultant direction is meaningful only when the length is not near zero.

\(R=\left\|\sum_{i=1}^n x_i\right\|,\quad \bar R=R/n,\quad \hat\mu=\dfrac{\sum_i x_i}{R}\)
Diagnostic Meaning

Large \(\bar R\) is first-moment evidence for a preferred direction. Small \(\bar R\) does not prove uniformity; it may also indicate an axial pattern.

Implementation Check

Every generated observation must have unit norm before resultant statistics are computed.

Pause on the resultant because it drives several spherical table entries. The sum of unit vectors gives both a direction and a length, but the direction becomes unstable when the length is small, so the diagnostic must be interpreted before it is passed into a Fisher calculator.
Watson Geometry

Axial Tables Are Not Directional Tables

The Watson model treats an axis as the object, so antipodal points can be equivalent.

\(f(x\mid u,\kappa)\propto \exp\{\kappa (u^\top x)^2\}\)
Positive Kappa

Mass concentrates near both \(u\) and \(-u\), giving a bipolar axial pattern.

Negative Kappa

Mass concentrates around the great circle perpendicular to the axis, creating a girdle.

Contrast Fisher and Watson visually before introducing any Watson lookup. The sign of Watson concentration changes the geometry, so a table user must know whether the application is directional, bipolar axial, or girdle-like. Ask learners to point to the relevant panel before they name a formula.
Watson Calculator

Axial Concentration Uses A Second-Moment Equation

The lookup is driven by squared projection onto an axis, not by the mean resultant vector.

\(D_3(\kappa)=\dfrac{d}{d\kappa}\log M\!\left(\tfrac12,\tfrac32,\kappa\right)\)
Moment Match

Estimate \(\kappa\) by matching the observed axial moment \(n^{-1}\sum_i (u^\top x_i)^2\) to \(D_3(\kappa)\).

Bound Check

The diagnostic verifies that computed moment values stay in a valid probability range.

Explain that the Watson table is based on second-moment information along an axis. This is why it can detect structure that the resultant vector may miss, especially when antipodal or girdle patterns cancel the first moment.
Reference Distributions

Critical Values Are Model-Based Quantiles

The notebook regenerates thresholds by simulating the null model on the unit sphere.

\(T_R=3n\bar R^2,\quad c_\alpha=Q_{1-\alpha}(T_R\mid H_0)\)
Uniformity Threshold

Sample independent points from the uniform sphere, compute \(T_R\), and store the upper quantile.

Two-Sample Threshold

Generate paired null samples and compare the separation of their mean vectors.

Connect critical values to the null model instead of treating them as magic constants. A simulation table is reproducible when it records the statistic, sample size, alpha level, random seed, and number of repetitions. Those details are what let another notebook rebuild the same reference distribution.
Interactive Surface Logic

Rows And Columns Become A Computed Surface

Sample size and alpha define a critical-value landscape; interpolation should respect its monotone directions.

Finite Sample Movement

Small sample sizes can move the simulated threshold away from its limiting reference behavior.

Alpha Direction

As alpha decreases, the upper critical value should increase. The notebook records this ordering check.

for alpha, n: samples = uniform_sphere(reps, n) z[alpha, n] = quantile(stat(samples), 1-alpha)
Use the surface to explain why interpolation is a statistical decision, not just a formatting task. If a requested sample size or alpha level is between printed entries, the reproducible response is to recompute or interpolate with the monotone behavior in view.
Diagnostics

Every Replacement Needs A Failure Sensor

The appendix notebook stores compact checks that would catch common table or simulation mistakes.

Fisher Monotonicity \(A_3(\kappa)\) increases with \(\kappa\), and cap radii shrink at fixed probability.
Inverse Round Trip Compute \(A_3(A_3^{-1}(\bar R))-\bar R\) and require a small residual.
Unit Norms Simulated observations must remain on \(S^2\) before any resultant statistic is trusted.
Watson Bounds Axial moment calculations should stay in a valid probability range.
Quantile Ordering Upper critical values should increase as alpha decreases.
Artifact Existence Saved charts and JSON checks prove the notebook regenerated the reference lab.
Emphasize that diagnostics are part of the table replacement, not optional decoration. A calculator without a failure sensor can silently return a number under the wrong geometry, the wrong null, or a broken simulation. The check list is therefore a statistical claim about trust, not merely software hygiene.

Common Mistakes

What Can Go Wrong When Tables Are Read Mechanically

The executable version is useful because it makes these mistakes visible.

Wrong Geometry

Using a Fisher concentration lookup for an axial sample turns cancellation into false dispersion.

Unrecorded Interpolation

Manual interpolation between rows loses the assumptions and cannot be audited later.

Missing Monte Carlo Error

A simulated critical value should carry repetitions, seed, and an error-awareness check.

Use this slide as a quality-control checklist. The biggest danger is not arithmetic error; it is applying the right-looking table to the wrong geometric object or reporting a simulated threshold without enough information to reproduce it.

Prompt
