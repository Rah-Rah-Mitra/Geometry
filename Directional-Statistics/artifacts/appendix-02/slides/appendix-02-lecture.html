From Static Cells To Statistical Queries

Table-style question

Executable version

Represent the entry as \(q_{1-\alpha}\{T_n \mid H_0\}\), \(A_1^{-1}(\bar R)\), or a simulated interval for \(\hat\kappa\).

Inspectable output

The answer is accompanied by a curve, surface, or band that reveals interpolation and finite-sample behavior.

Lookup becomes a function call

The important move is not interpolation alone; it is exposing the assumptions behind the number.

Pause on the phrase table entry as query. A lookup table hides its construction, while an executable replacement makes the random variable, tail probability, model assumption, and numerical tolerance visible to the learner. That visibility is what allows students to critique the answer instead of merely locating it.

Von Mises Reference Widths

Central probability around the mean direction
Model

\(f(\theta;\mu,\kappa) = \{2\pi I_0(\kappa)\}^{-1}\exp\{\kappa\cos(\theta-\mu)\}\)

Replacement task

For a chosen mass level, solve for the angular half-width around \(\mu\) rather than reading a printed chart.

Sanity check

As \(\kappa\) increases, the half-width for the same probability must decrease.

This slide connects the first replacement to model geometry. The number that used to live in a chart is the angular half-width needed to hold a selected probability under a von Mises density with a given concentration.

The \(A_1\) Inverse Is A Table Replacement

\(A_1(\kappa)=I_1(\kappa)/I_0(\kappa)\)
Estimation bridge

The sample resultant length \(\bar R\) is mapped to \(\hat\kappa\) by solving \(A_1(\kappa)=\bar R\).

Notebook invariant

The inverse is checked by round-tripping \(A_1(A_1^{-1}(r))\) across the usable range of \(r\).

Monotone concentration map
Here the table replacement is an inverse function. Students should see that concentration estimation is stable only because the Bessel ratio is monotone, and that the notebook checks this property numerically instead of trusting a black-box interpolation.

From \(\bar R\) To A Concentration Report

Estimator

Compute \(\bar R = n^{-1}\left|\sum_j e^{i\theta_j}\right|\), then solve the one-dimensional equation \(A_1(\hat\kappa)=\bar R\).

Interpretation

Small \(\hat\kappa\) means weak concentration around any mean direction; large \(\hat\kappa\) means a narrow von Mises reference distribution.

Failure mode

A large estimate is meaningful only if the sample actually resembles a single circular mode.

Same mean direction, different concentration
The reporting slide translates an inverse calculation into language a statistician can use. The estimate is not just a number; it tells how tightly a unimodal circular model would concentrate probability near the fitted direction.

Uniformity Critical Values By Simulation

Reference distribution for a test statistic
Rayleigh example

\(T_R = 2 n \bar R^2\), reject for large values under a mean-shift alternative.

Notebook calibration

For each \(n\), simulate uniform angles, compute \(T_n\), and report the empirical \(1-\alpha\) quantile.

Ordering check

Critical values must increase as \(\alpha\) decreases for the same statistic and sample size.

This is the cleanest example of replacing a table by a reproducible reference experiment. The simulation creates the null distribution at the requested sample size, and the critical value is just the appropriate tail quantile.

Concentration Confidence Chart Replacement

Simulated spread of \( \hat\kappa \)
Chart replacement

Simulate samples at selected true \(\kappa\), estimate each sample, then plot quantile bands for \(\hat\kappa\).

Expected pattern

The larger-sample band should be narrower, giving a direct visual check on estimator precision.

Notebook check

The generated diagnostics assert that the mean band width for \(n=40\) is smaller than for \(n=15\).

The concentration chart is useful because it turns estimator variability into a visible band. The lesson is not a particular printed value; it is how the uncertainty in kappa estimation contracts with more observations. Ask students to compare the two bands before naming any formula.

Interactive calculation anatomy
This slide names the interface contract for a good table replacement. The user should never receive a naked number; they should receive the inputs, the computed answer, the visual context, and enough provenance to rerun or audit the calculation.

Numerical Guardrails For Table-Free Work

Monotone inverse

\(A_1^{-1}\) should preserve ordering: larger \(\bar R\) maps to larger \(\hat\kappa\).

Round trip

Applying \(A_1\) after the inverse should recover the input resultant within numerical tolerance.

Tail ordering

For upper-tail tests, the 0.01 critical value should exceed the 0.05 value, which should exceed the 0.10 value.

Band contraction

Confidence bands for \(\hat\kappa\) should shrink as the sample size increases, all else equal.

checks = { "A1_monotone": true, "critical_quantile_ordering_ok": true, "bands_shrink_with_larger_n": true }
The guardrails are the reason an executable appendix can be more trustworthy than a copied table. If an interpolation, simulation, or inversion routine breaks a basic ordering property, the notebook should fail loudly before a learner uses the result.

Mini Lab: Answer A Table Question Without A Table

Question

For a circular uniformity test at \(n=20\) and \(\alpha=0.05\), what is the Rayleigh cutoff?

Procedure
  • Simulate many uniform circular samples of size 20.
  • Compute \(2n\bar R^2\) for each replicate.
  • Take the empirical 0.95 quantile.
  • Check that stricter alpha gives a larger cutoff.
Interpretation

The result is a finite-sample reference for this exact statistic, not a generic normal approximation.

Decision sketch
The mini lab is deliberately framed as a recipe students can rerun. It separates the statistic, the null simulation, the quantile extraction, and the decision comparison, so the old table is replaced by a transparent computational experiment.
