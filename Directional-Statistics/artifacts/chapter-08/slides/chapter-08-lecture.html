What Distribution-free Means On A Circle

Unsafe line habit

  • Pick a zero direction and treat the sorted sample as linear.
  • Forget that first and last observations are neighbors.
  • Hide ties inside a rank table.
  • Interpret a test as though a von Mises density had been fitted.

Safe circular objects

  • Side of a proposed axis.
  • Cyclic order and rank after a declared cut.
  • Uniform scores \(z_r=\exp(2\pi i r/n)\).
  • Closed label sequence and run transitions.

Rotation Test

If every angle becomes \(\theta_j+\phi\), the scientific conclusion should stay the same.

Stress that distribution-free does not mean structure-free. A circular procedure still has to respect rotation, wraparound, and the absence of a natural first observation. The safe objects are side, order, rank, score vector, and label sequence, because these objects can be recomputed after changing the cut point.

L-fold Symmetry By Rotation Copies

Construction

\(\Theta^{(\ell)}=\{\theta_j+2\pi m/\ell: j=1,\ldots,n,\ m=0,\ldots,\ell-1\}\)

Closure Check

The expanded set should be unchanged by one generator rotation. The chapter notebook verifies this for \(\ell=3\).

For l-fold symmetry, the computational move is to generate rotated copies separated by 360 over l degrees. If the expanded set is closed under the generator, a subsequent uniformity or score diagnostic can examine whether the data respect that repeated rotational pattern rather than only a single reflection axis.

Rank transport
Roots of unity replace observed spacings

Uniform Scores Replace Spacings

Definition

rank \(r\quad\mapsto\quad z_r=\exp(2\pi i r/n)\)

Zero-sum Invariant

\(\sum_{r=1}^{n} z_r = 0\)

The transformation forgets the original gaps but keeps the cyclic ordering and makes rank effects visible as vectors.

Uniform scores are the key rank transport. After ordering the combined sample, rank r is placed at the r-th root-of-unity position, so observed arc lengths are discarded while cyclic order is retained. The complete score set sums to zero, which later explains a useful two-sample symmetry.
Two-sample comparison
Subset resultants in rank-score space

Two Samples As Score Resultants

Group Resultant

\(R_A=\left|\sum_{j:g_j=A} z_{r_j}\right|\)

Two-sample Symmetry

Because the full score set sums to zero, the two group resultants have the same length in a two-sample split.

Once each observation has a uniform score, a labeled subset receives a resultant vector. If sample A and sample B are thoroughly interleaved, their resultants tend to be short. If the labels occupy different arcs, the subset resultant length grows and flags a distributional difference.

Closed label sequence
Run count is transition count

Runs Read Label Clustering

Run Count

\(r=\#\{j:g_j\ne g_{j+1}\},\quad g_{n+1}=g_1\)

Circle Check

For two labels on a closed circle, transitions from A to B are paired with transitions from B to A. Therefore \(r\) is even.

Runs are a deliberately simple diagnostic for separation. On a closed circle the run count is the number of label transitions, so a two-sample circular run count is even. Long arcs occupied by one label create few transitions even when the exact angular spacings are ignored.

Interpretation Rule

Do not swap test names mechanically. Match the statistic to the geometric evidence the data actually display.

Use the comparison board to prevent a common mistake: these procedures are not interchangeable names for the same signal. Score resultants emphasize first-moment separation in rank space, EDF methods inspect the whole ordered discrepancy, runs isolate clustering, and symmetry tests ask a one-sample reflection question.

Failure modes
How rank tests go wrong

Pitfalls In Circular Rank Tests

Cut-point artifact

A visual split at zero can make adjacent observations look far apart. Always check rotation invariance.

Silent ties

Tied directions can change ranks. Report tied blocks and repeat a sensitivity rule when needed.

Asymptotic overconfidence

Small circular samples may not justify a chi-square or normal reference without caution.

Close the technical part with failure modes. A cut point can create a false sense of first and last observations, a tie rule can decide a marginal rank statistic, and a small sample can make asymptotic references look more precise than the data justify. The remedy is explicit reporting.
Takeaways
Operational workflow for chapter 08

Operational Checklist

1. State the null geometry.Axis symmetry, l-fold symmetry, two-sample equality, or q-sample equality.
2. Rotate only for convenience.Changing the zero direction should not change the conclusion.
3. Declare cut and ties.Rank construction is transparent only when these choices are visible.
4. Choose the evidence type.Signs, scores, EDF contrast, runs, or grouped resultants answer different questions.
5. Run invariance checks.Rotation, label swap, tie sensitivity, and closed-order parity catch implementation mistakes.
6. Interpret without a fitted model.The conclusion is rank-based distribution-free evidence, not a parametric density estimate.
