From Analytic Support To Cohomology

Cycle Class Pattern

If \(Z \subset X\) has codimension \(k\), its fundamental support determines

\([Z] \in H^{2k}(X,\mathbb{Z})\)

after orienting the local normal data and passing through duality.

The point is not that a singular analytic set is automatically smooth. The class is built by passing through local regular pieces, excision, or equivalent duality language, so the singularities do not erase the global cohomology class. Stress the codimension-degree conversion: codimension k contributes degree two k, which is the first place students often lose the diagonal.

The Kahler Constraint Is A Type Statement

Type Theorem

For a compact Kahler manifold, an analytic cycle of codimension \(k\) has class in \(H^{k,k}(X)\).

Geometric Meaning

Integration over \(Z\) pairs nontrivially only with the complementary Hodge type, forcing the Poincare dual onto the diagonal.

This is the slide where the analytic construction meets Hodge decomposition. The diagonal is not a decorative feature of the diamond; it is the exact bidegree target forced by the Kahler identities and positivity arguments behind the chapter. Ask students to say aloud what would go wrong without compactness or without the Kahler package.

Chern Classes Provide Canonical Diagonal Classes

\(c_i(E) \in H^{2i}(X,\mathbb{Z}) \cap H^{i,i}(X)\)
Why This Matters

Vector bundles turn holomorphic geometry into stable cohomology classes. In the Kahler setting those classes land exactly where cycle classes are allowed to land.

Chern classes are a bridge object. They are topological invariants, but in the holomorphic Kahler context their representatives can be read through curvature with type one-one behavior. This prepares the later examples: classes can be visibly diagonal for reasons that are not initially phrased as subvarieties, yet they still behave like geometric cohomology.

Hodge Classes: The Diagonal With Rational Structure

Definition

A rational Hodge class of codimension \(k\) is a class

\(\alpha \in H^{2k}(X,\mathbb{Q}) \cap H^{k,k}(X)\)
Do Not Conflate
  • Cycle class: constructed from an analytic or algebraic cycle.
  • Hodge class: detected by bidegree plus rationality.
  • Hodge conjecture: asks whether projective rational Hodge classes are generated by algebraic cycles.

The Hodge conjecture is powerful precisely because it asks whether these two modes of recognition coincide after restricting to smooth projective varieties and rational coefficients.

The Hodge Conjecture As A Visibility Problem

Clean Statement

For a smooth projective complex variety, every rational Hodge class should be a rational linear combination of algebraic cycle classes.

Boundary Of Knowledge

The theorem already gives one inclusion: cycles land among Hodge classes. The difficult direction is to construct cycles from cohomological diagonal data.

Phrase the conjecture as a missing construction. The earlier slides established that algebraic cycles produce rational Hodge classes, so the visible arrow from geometry to cohomology is not the mystery. The conjectural arrow goes backward: starting with a rational diagonal class, one wants actual algebraic subvarieties whose classes span it.

Correspondences Act By Pull, Intersect, Push

Operator View

For \(\Gamma \subset X \times Y\), a cohomology class on \(X\) is transformed by

\(\Gamma_*(\alpha)=p_{Y*}(p_X^*\alpha \smile [\Gamma])\)
Correspondences let the chapter move from classes on one variety to operations between cohomology theories. The formula is worth reading in order: pull a class from X to the product, cup with the class of the correspondence, then push down to Y. This makes degree shifts and Kunneth components unavoidable rather than optional notation.

Kunneth Components Locate The Part That Acts

Decomposition

\(H^*(X \times Y)\) splits into pieces \(H^a(X) \otimes H^b(Y)\), and a correspondence class can be inspected component by component.

Notebook Check

Matrix composition in a toy pull-push model remains associative, matching the operator picture.

This slide turns the word correspondence into a finite bookkeeping task. A class on the product may have several Kunneth components, but only components with the right degrees contribute to a chosen cohomological operation. The toy matrix check from the notebook is not a proof of the theorem; it is a compact way to see why composition should be tracked carefully.

Three Pitfalls To Interrupt Early

Pitfall 1

Forgetting Degree

Codimension \(k\) means cohomological degree \(2k\), not \(k\).

Pitfall 2

Overstating The Conjecture

The conjecture is not known in general; do not treat every Hodge class as already algebraic.

Pitfall 3

Ignoring Shifts

Correspondences carry degree shifts because pull, cup, and push each change the bookkeeping.

cycle support \(\Rightarrow\) degree \(2k\) class \(\Rightarrow\) type \((k,k)\) \(\not\Rightarrow\) automatic converse
Use this as a mid-lecture reset before students start solving examples. The first pitfall is purely numerical, but it can ruin every later statement. The second is conceptual: the chapter is building toward an open problem. The third is operational and becomes important as soon as correspondences are composed or decomposed into Kunneth pieces.
