Topology

Hyperplane Sections Constrain Algebraic Topology

Topological Control

  • Hyperplane section \(Y \subset X\) inherits lower-degree topology.
  • Lefschetz hyperplane theorem: \(H^i(X, Y) = 0\) for \(i < n\).
  • Vanishing theorems restrict the cohomology of ample line bundles.

Lefschetz Consequences

  • The restriction map \(H^i(X) \to H^i(Y)\) is an isomorphism for \(i < n-1\).
  • The kernel of the restriction map is isolated in the middle dimension \(n-1\).
  • Primitive cohomology is localized to this middle degree.
Lefschetz Hyperplane Theorem

\(H^i(X, \mathbb{Z}) \longrightarrow H^i(Y, \mathbb{Z})\) is an isomorphism for \(i \le n - 2\), and injective for \(i = n - 1\).

Topology of varietiesHyperplane Cuts
We begin by cutting varieties with hyperplane sections. The Lefschetz hyperplane theorem states that the restriction map from X to Y is an isomorphism for degrees below the middle dimension. This forces all primitive topological information to live in the middle degree of the section Y.
Topology

Weak and Hard Lefschetz Organize Cohomology Rings

The Symmetric Structure

  • \(L(\alpha) = [\omega] \wedge \alpha\) acts as a raising operator.
  • Hard Lefschetz: \(L^{n-i} : H^i(X) \cong H^{2n-i}(X)\).
  • Primitive Decomposition: \(H^i = \bigoplus_r L^r H^{i-2r}_{prim}\).
  • Conjugation and Lefschetz operators commute, preserving type splits.
Hard LefschetzRing Decompositions
Lefschetz theory does more than restrict sections; it shapes the entire cohomology ring. The Lefschetz operator, which is cup product with the Kahler class, acts as a raising operator. By iterating this operator, we get an isomorphism between opposite degrees, allowing us to decompose the ring into primitive, non-raised pieces.
Topology

Leray Spectral Sequences Organize Fiber Cohomology

Fibration Bookkeeping

  • A map \(f: X \to Y\) decomposes global topology into fiber data.
  • Leray filtration: \(E_2^{p,q} = H^p(Y, R^q f_* \mathbb{Q})\).
  • Differentials \(d_r\) measure obstruction to lifting local cycles.
  • For smooth projective morphisms, the sequence degenerates at \(E_2\).
Leray spectral sequenceFiber Mappings
When we study maps between varieties, we use the Leray spectral sequence. It acts as a bookkeeping grid that computes the cohomology of X by looking at the cohomology of Y with coefficients in the cohomology of the fibers. Under smooth projectivity, the sequence degenerates immediately, simplifying this accounting.
Variations

Hodge Filtrations Rotate in Smooth Families

Moving Decompositions

  • Smooth proper family \(\pi: \mathcal{X} \to B\) gives flat bundles of cohomology.
  • Topological vector spaces are constant, but complex structures vary.
  • The Hodge filtration \(F^p \mathcal{H}_\mathbb{C}\) varies holomorphically.
  • Gauss-Manin connection \(\nabla\) differentiates sections of these bundles.
Variations of Hodge structureMoving Filtrations
A smoothproper family of algebraic varieties gives a topologically constant family of cohomology spaces. However, because the complex structure on the fibers changes, the Hodge filtration rotates within this constant vector bundle. We track this motion using the Gauss-Manin connection.
Variations

Griffiths Transversality Restricts Filtration Derivatives

Transversality Formula

\(\nabla(F^p) \subseteq F^{p-1} \otimes \Omega^1_B\)

The derivative of a class in the \(p\)-th filtration level can have components only down to the \((p-1)\)-th level.

Geometric Implication

  • Filtrations do not move randomly in flag manifolds.
  • Horizontality restricts period maps to tangent distributions.
  • Kodaira-Spencer maps govern the first-order rotation of \(F^p\).
Rigidity of VHS

This transversality is the analytic core that forces variations of Hodge structure to be highly rigid, leading to global algebraicity results.

Griffiths TransversalityHorizontal Bundles
Griffiths transversality is the central rigidity condition for variations of Hodge structures. It states that differentiating a class in the p-th filtration level using the Gauss-Manin connection can only produce components down to the p-minus-one level. This horizontal constraint limits how Hodge structures can move.
Variations

Period Maps Send Families to flag Domains

Orbits and Loci

  • The Period Map \(\Phi: B \to D / \Gamma\) classifies Hodge filtrations.
  • Monodromy group \(\Gamma\) acts by rational automorphisms.
  • Hodge locus: points in \(B\) where extra Hodge classes appear.
  • Cattani-Deligne-Kaplan theorem: the Hodge locus is algebraic.
Period domainsMonodromy and Loci
The period map classifies Hodge structures by sending the parameter space B into a period domain D modulo monodromy. The Hodge locus represents points where extra diagonal classes emerge. Thanks to the rigidity of variations, this locus is always a union of algebraic subvarieties.
Cycles

Algebraic Cycles and the Hodge Conjecture

The Diagonal Target

  • An algebraic cycle \(Z\) of codimension \(p\) has a cycle class.
  • The class \([Z]\) lies in \(H^{2p}(X, \mathbb{Q})\).
  • Integration respects type: \([Z]\) occupies the diagonal \(H^{p,p}(X)\).
  • Hodge Conjecture: every class in \(H^{p,p}(X) \cap H^{2p}(X, \mathbb{Q})\) is algebraic.
Hodge ConjectureCycle Classes
We now return to geometry. Codimension p algebraic cycles map to cohomology, and their classes must live in the diagonal H-p-p subspace. The Hodge conjecture asks whether every rational diagonal class is a linear combination of algebraic cycles, posing a major open question in mathematics.
Cycles

When the Primary class Vanishes, Periods Remain

Secondary Invariants

  • Two cycles homologous to each other define a difference cycle.
  • Its primary cycle class vanishes: \([Z_0 - Z_1] = 0\).
  • Integration over a bounding chain \(\Gamma\) defines a period.
  • Intermediate Jacobian: \(J^{2p-1}(X) = H^{2p-1}(X, \mathbb{C}) / (F^p + H^{2p-1}(X, \mathbb{Z}))\).
Abel-Jacobi MapIntermediate Jacobians
If an algebraic cycle is homologically trivial, its primary class vanishes. But it is not geometrically invisible. By integrating forms over a bounding chain, we obtain a secondary invariant. The Abel-Jacobi map projects this period data into the intermediate Jacobian torus.
Cycles

Deligne-Beilinson Integrates Primary and Secondary Data

Unified Cohomology

  • Deligne-Beilinson cohomology \(H^*_\mathcal{D}(X, \mathbb{Z}(p))\) unifies data.
  • Defined via a hypercohomology complex.
  • Packages both the integral class and the period quotient.

The Exact sequence

  • Fits into a fundamental exact sequence.
  • Maps directly to the intermediate Jacobian.
  • Forms the correct target for refined cycle classes.
Deligne-Beilinson Sequence

\(0 \longrightarrow J^{2p-1}(X) \longrightarrow H^{2p}_\mathcal{D}(X, \mathbb{Z}(p)) \longrightarrow H^{p,p}_\mathbb{Z}(X) \longrightarrow 0\)

Deligne-BeilinsonRefined Classes
Deligne-Beilinson cohomology provides a unified home for these invariants. Defined via a hypercohomology complex, it fits into an exact sequence that maps directly to the intermediate Jacobian. This provides the correct target for refined algebraic cycle classes.
