Chapter Route

One Invariant Habit Across Five Objects

1. Affine Layer

Points are primitive; vectors appear as differences. The metric sees \(Q-P\), not an arbitrary origin.

2. Rigid Motions

Affine maps \(x \mapsto Ax+b\) are isometries exactly when \(A^T A=I\).

3. Reflection Tools

Plane isometries and billiard paths are organized by reflection identities and unfolding.

4. Sets And Measure

Hausdorff distance compares compact sets; Steiner symmetrization preserves fibers and area.

Lecture Question

When a Euclidean construction changes coordinates, positions, paths, or shapes, which measurement certifies that the intended geometry survived?

Affine Bookkeeping

Coordinates Are Labels; Differences Carry the Metric

The same points have different coordinate arrows from \(O\) and \(O'\), but the black vector \(Q-P\), midpoint, and distance are invariant.

Definition Pattern

A Euclidean affine space has points, free vectors between points, and a Euclidean norm on those vectors.

$$d(P,Q)=\|Q-P\|$$

Origin Change Test

  • new coordinate labels: \(P-O'\), \(Q-O'\)
  • same difference: \((Q-O')-(P-O')=Q-P\)
  • same metric: \(\|Q-P\|\)
The affine warning: a point is not a vector until a comparison point has been chosen.

Affine Isometries

The Metric Lives in the Linear Part

Coordinate Model
$$f(x)=Ax+b,\qquad A^T A=I$$

Translation \(b\) repositions the map. Orthogonality of \(A\) preserves all pairwise distances.

Fixed-Set Equation

$$(I-A)x=b$$

Solvability distinguishes rotations and reflections from translations and glide reflections.

Group View

Reflection Algebra

One Formula Explains Mirrors, Orientation, And Billiards

Reflection Through a Line

For a unit direction \(u\), the reflection matrix is

$$H=2uu^T-I.$$

Exact Identities

$$H^T H=I,\qquad H^2=I,\qquad \det H=-1.$$

These three checks say: preserve lengths, undo itself, reverse orientation.

Reflection decomposes a vector into tangent and normal components, then changes only the sign of the normal component.

Use this slide as the algebraic bridge into reflection geometry. The formula H equals two u u transpose minus I is short, but it carries three important facts: lengths are preserved, applying the reflection twice returns the starting vector, and orientation changes sign.

Reflection Law As Vector Algebra

$$v_{\mathrm{out}}=v_{\mathrm{in}}-2(v_{\mathrm{in}}\cdot n)n.$$

Metric On Compact Sets

Hausdorff Distance Uses The Worse Directed Witness

Each direction has its own worst point. The Hausdorff distance is the larger of those two directed distances.

Point To Set, Then Set To Set
$$d(x,B)=\inf_{b\in B} d(x,b)$$
$$h(A,B)=\sup_{a\in A} d(a,B)$$
Symmetric Metric
$$d_H(A,B)=\max\{h(A,B),h(B,A)\}$$

Slow down on the two directed distances. Hausdorff distance is not asking for one closest pair; it asks whether every point of each compact set lies near the other set. The worse directed witness supplies the symmetric distance and explains the maximum in the formula.
Hausdorff Neighborhood Test

The First Full-Coverage Threshold Is \(d_H\)

Neighborhood Form

\(d_H(A,B)\le \epsilon\) exactly when both containments hold:

$$A\subseteq N_\epsilon(B),\qquad B\subseteq N_\epsilon(A).$$

Threshold Sweep Reading

  • At \(\epsilon=0.6177\), all sampled \(B\) is covered, but \(A\) is not.
  • At \(\epsilon=0.8648\), both sampled coverages reach one.
  • The exact sampled Hausdorff witness is \(0.8236\), between those sweep steps.

Measure And Symmetry

Steiner Symmetrization Preserves Fiber Lengths

For each vertical line, the original fiber is replaced by a centered interval of the same one-dimensional length.

Fiber Operation

For vertical symmetrization, each slice \(K_x=K\cap(\{x\}\times\mathbb{R})\) is replaced by a centered interval \(K_x^*\) with the same length.

Measure Consequence
$$|K^*|=\int |K_x^*|\,dx=\int |K_x|\,dx=|K|.$$

Area stays fixed because fiber lengths stay fixed.

Synthesis

The Euclidean Affine Reading Habit

1. Name The Object

Is the construction acting on points, free vectors, paths, compact sets, or fibers of a set?

2. Name The Measurement

Distances and angles live on vectors; Hausdorff distance lives on compact sets; area is assembled from slice lengths.

3. Name The Invariant

Orthogonality, determinant, fixed set, equal-angle reflection, directed witness, or preserved fiber length.

A Euclidean affine proof is convincing when the picture says what moves, what is measured, and which invariant makes the claim stable.

Chapter Takeaway

The chapter is not merely a list of classical constructions. It is a disciplined way to keep affine bookkeeping and Euclidean measurement together: subtract points to get vectors, use orthogonal affine maps for rigidity, unfold reflections when paths bounce, compare compact sets by directed containment, and preserve area by preserving fiber lengths.
