Abstract Simplicial Complexes

The datum

A vertex set $V$ together with a family $S$ of finite nonempty subsets.

Closure axiom

Any nonempty subset of a face is again a face.

No geometry yet

Only incidence: which vertices span a simplex. No lengths, no angles.

Definition

$\sigma \in S,\ \emptyset \neq \tau \subseteq \sigma \ \Rightarrow\ \tau \in S$

Dimension

An $n$-simplex is a face with $n+1$ vertices; faces are its nonempty subsets.

Printed pp. 123-130Abstract Simplicial Complexes
We recall the purely combinatorial datum: a vertex set and a family of finite subsets closed under taking subsets. Nothing metric is present yet, only incidence. The emphasis is that this is bookkeeping about which vertices span a face, deliberately stripped of any geometry.

The Model Simplex

Realize each face

Each abstract $n$-simplex is replaced by a model $M_\kappa$-simplex carrying a genuine metric.

Standard choice

The regular Euclidean simplex with all edges of unit length.

Local metric

The model simplex supplies distances, geodesics, and angles locally.

Printed pp. 123-130The Model Simplex
Each abstract n-simplex is realized by one model simplex from constant curvature geometry. The standard choice is the regular Euclidean simplex with unit edge lengths, but the construction allows any prescribed edge lengths satisfying the simplex inequalities. This model carries the local metric.

Edge-Length Assignment

The metric input

Assign a positive length $\ell(e) > 0$ to each edge of the complex.

Realizability

Edge lengths must satisfy the simplex inequalities so a model $M_\kappa$-simplex exists.

Safe default

Unit lengths on every edge always give a regular realizable simplex.

Triangle inequality

$\ell(v_iv_k) \le \ell(v_iv_j) + \ell(v_jv_k)$

Failure mode

Lengths violating the inequalities admit no Euclidean triangle — reject the assignment.

Printed pp. 123-130Edge-Length Assignment
The metric data is an assignment of a positive length to each edge. For the simplex to be realizable in a constant curvature model space the edge lengths must satisfy the simplex inequalities; the regular unit-edge choice always works. This is where geometry first enters the combinatorics.

Gluing by Face Identifications

Disjoint union

Take one model simplex $\Delta_\sigma$ for each abstract simplex $\sigma$.

Quotient

Identify shared faces according to the incidence relation $\sim$.

Compatibility

Shared abstract faces glue by an isometry respecting the assigned edge lengths.

Printed pp. 123-130Gluing by Face Identifications
We assemble the realization as a disjoint union of model simplices, one per abstract simplex, quotiented by the face identifications dictated by incidence. Compatibility requires that whenever two simplices share an abstract face the corresponding model faces are glued by an isometry respecting edge lengths.

The Intrinsic Length Metric

Piecewise paths

A path crosses finitely many simplices; measure each segment in its own model.

Path length

Add up the segment lengths to get the total length of the path.

Quotient metric

Distance is the infimum of lengths over all admissible paths joining two points.

Induced length metric

$d(x,y) = \inf_{\gamma} \sum_{i} \ell_{\Delta_i}(\gamma \cap \Delta_i)$

Local isometry

Inside any single simplex, $d$ agrees with the model metric.

Printed pp. 123-130The Intrinsic Length Metric
Distance between two points is the infimum of lengths of piecewise paths crossing finitely many simplices. Each path segment is measured inside one model simplex; the total is summed. This induced or quotient length metric is the canonical metric on the realization, built from the local pieces.

The Geometric Realization

The space $|K|$

The quotient of the disjoint union of model simplices is the geometric realization.

Standard metric

It carries the piecewise-Euclidean (or piecewise $M_\kappa$) length metric.

An $M_\kappa$-complex

Each open simplex isometrically embeds its model interior.

Printed pp. 123-130The Geometric Realization
The resulting space is the geometric realization carrying its standard piecewise-Euclidean, or more generally piecewise constant curvature, metric. Each open simplex isometrically embeds its model interior; the global object is an M-kappa simplicial complex. We now ask when this length space is well behaved.

When Is It a Length Space?

The danger

The infimum may not be attained; some point pairs could lack a finite-length path.

Shapes condition

Finitely many isometry types of simplices bound the local geometry uniformly.

Consequence

A uniform lower bound on simplex sizes prevents distances from collapsing.

Finite shapes

$\#\{\text{isometry types of } \Delta_\sigma\} < \infty$

Why it matters

Without it, shrinking simplices can make Cauchy sequences leave the space.

Printed pp. 123-130When Is It a Length Space?
A subtlety: the infimum defining distance might fail to be achieved, or two points might be joined by no rectifiable path of finite length. The shapes condition controls this. With finitely many isometry types of simplices the local geometry is uniformly bounded, ruling out degeneracy.

Completeness and Geodesics

Theorem (Bridson–Haefliger)

If an $M_\kappa$-simplicial complex has only finitely many isometry types of simplices, then its induced length metric is complete and the space is a geodesic space.

Local compactness

Local finiteness makes closed metric balls compact.

Geodesic existence

Hopf–Rinow then yields a length-minimizing path between any two points.

Uniform control

The finite shapes bound supplies the curvature and size uniformity the proof needs.

Payoff

A clean stage on which to test the $\mathrm{CAT}(\kappa)$ link condition later.

Printed pp. 123-130Completeness and Geodesics
Bridson and Haefliger's theorem states that if the realization has only finitely many isometry types of simplices, then the induced length metric is complete and the space is a geodesic space. Local finiteness gives local compactness; the finite shapes bound supplies the uniform control needed.

Metric vs Weak Topology

Metric topology

Open balls of the induced length metric $d$ generate the topology.

Weak topology

A set is closed iff its trace on every closed simplex is closed.

Coincidence

The two agree exactly when the complex is locally finite.

Local finiteness

$\forall\, v:\ \#\{\sigma : v \in \sigma\} < \infty$

Otherwise

At an infinite-valence vertex the weak topology is strictly finer than the metric one.

Printed pp. 123-130Metric vs Weak Topology
Two natural topologies compete: the metric topology from the length metric and the weak topology, in which a set is closed exactly when its intersection with every closed simplex is closed. They coincide precisely when the complex is locally finite; otherwise the weak topology is strictly finer.

Recap and Takeaways

The pipeline

Combinatorial complex → model simplices → face gluings → intrinsic length metric.

Edge lengths

Prescribed and realizable; unit lengths are the canonical default.

Good behaviour

Finite shapes ⇒ complete geodesic $M_\kappa$-complex.

Topologies

Local finiteness reconciles the metric and weak topologies.

Takeaway

Incidence data plus edge lengths metrize uniquely, giving the standard arena for non-positive curvature.

Printed pp. 123-130Recap and Takeaways
We recap the pipeline: combinatorial complex, model simplices with prescribed edge lengths, gluing by face isometries, intrinsic length metric. The finite shapes condition delivers a complete geodesic M-kappa complex, and local finiteness reconciles the metric and weak topologies. This metrization underpins the whole non-positive curvature program.
