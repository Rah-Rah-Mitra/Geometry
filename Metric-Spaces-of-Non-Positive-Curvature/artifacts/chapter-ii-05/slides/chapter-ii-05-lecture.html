M_k-Polyhedral Complexes

Cells

Each cell is a convex polytope in $M_k^n$, the model space of constant curvature $k$.

Gluing

Cells meet along isometric faces; finitely many isometry types ($\text{Shapes}(K)$ finite).

Intrinsic metric

$d(x,y)=\inf_{\gamma}\;\ell(\gamma),\quad \gamma:x\rightsquigarrow y$

Consequence

The finiteness hypothesis makes $K$ a complete geodesic space with well-defined angles.

Printed pp. 205-227M_k-Polyhedral Complexes
A polyhedral complex is built from convex cells in the model space of constant curvature k, glued along isometric faces with finitely many isometry types of cell. Bridson shows the gluing carries an honest length metric, so geodesics and angles between adjacent cells are well defined.

The Link of a Vertex

Directions

$\mathrm{Lk}(v,K)$ collects the unit directions leaving $v$.

Pieces

Each cell at $v$ gives a spherical simplex; its edges are the face angles.

Metric

Glue the simplices to a piecewise-spherical complex.

Printed pp. 205-227The Link of a Vertex
The link records all directions emanating from a vertex. Each cell containing the vertex contributes a spherical simplex whose side lengths are the angles between faces, and these glue into a metric simplicial complex. The link is the infinitesimal sphere encoding how cells fan out around the point.

Curvature is Local

Definition

$K$ has curvature $\le k$ if every point has a CAT(k) neighbourhood.

Interior points

Inside an open cell the metric is that of $M_k$, so CAT(k) is automatic.

Where curvature can fail

$\text{trouble} \subseteq \{\text{vertices of } K\}$

Reduction

By induction on skeleta, the only real test sits at the vertices.

Printed pp. 205-227Curvature is Local
Curvature bounded above is intrinsically a local statement, so for a complex it is decided cell by cell, and the only places where trouble can hide are the vertices. Away from a vertex every point already sits inside a CAT(k) neighbourhood inherited from the model cells.

Gromov's Link Condition

Theorem (Link condition)

An $M_k$-complex $K$ with $\mathrm{Shapes}(K)$ finite is locally CAT(k) if and only if

$\mathrm{Lk}(v,K)\ \text{is CAT}(1)\quad\forall\, v.$

Translation

Metric curvature of $K$ becomes angular curvature of links.

Direction

One CAT(1) check per vertex; the bound on $K$ follows.

For $k\le 0$

Same statement reads ‘$K$ is non-positively curved iff links are CAT(1)’.

Printed pp. 205-227Gromov's Link Condition
This is the central theorem of the chapter. An M_k-complex with the finiteness hypothesis is locally CAT(k) exactly when every vertex link is a CAT(1) space. The angular geometry of directions controls metric curvature, converting an analytic bound into a single condition on each link.

Large Links: the $2\pi$ Threshold

CAT(1) test

A small enough space is CAT(1) iff it contains no closed geodesic shorter than $2\pi$.

Large links

Every $\mathrm{Lk}(v)$ must have systole $\ge 2\pi$.

Link condition, restated

$\mathrm{sys}\big(\mathrm{Lk}(v,K)\big)\ \ge\ 2\pi\quad\forall\, v$

Printed pp. 205-227Large Links and 2 pi
For a CAT(1) space the operative obstruction is short closed geodesics. The link of every vertex must contain no closed geodesic of length strictly less than two pi. We say the links are large; a loop shorter than two pi is exactly a missing turning corner that would let geodesics branch.

Why $2\pi$?

Digon

A closed geodesic of length $<2\pi$ pairs two directions joined by two short angular routes.

Failure

That digon unfolds to a comparison configuration where convexity of $d$ breaks.

Spherical signature

$\ell(\sigma) = 2\pi \;\Longleftrightarrow\; \text{great circle on } \mathbb{S}^2$

Frontier

$2\pi$ is precisely the geodesic length on the round sphere — below it, curvature $\le k$ can break.

Printed pp. 205-227Why 2 pi
A closed geodesic of length below two pi in the link reflects a direction pair joined by two short angular routes, which unfolds into a digon and ruins comparison-triangle convexity. The two pi threshold is the spherical signature of CAT(1), so it is the precise frontier where the curvature bound can break.

The Cubical Case

Cells

Euclidean unit cubes, $k=0$. All dihedral angles are right angles.

Links

An all-right-angled link is an ‘all-right’ spherical complex.

Reduction

Its metric data is exactly an abstract simplicial complex.

Printed pp. 205-227Cube Complexes
In the cubical case the model cells are Euclidean unit cubes with k equal to zero, and every angle between faces is a right angle. The link of a vertex is then an all-right-angled spherical complex, which is the same data as an abstract simplicial complex. The geometry becomes combinatorics.

Gromov: Flag Links

Theorem (Cubical link condition)

A cube complex is locally CAT(0) iff every vertex link is a flag simplicial complex.

Flag, formally

$\{v_0,\dots,v_n\}\ \text{pairwise adjacent}\ \Rightarrow\ \text{spans a simplex}$

Meaning

No ‘empty’ simplices: every clique in the link graph is already filled.

Why it works

An all-right-angled flag complex has systole $\ge 2\pi$, so it is CAT(1).

Payoff

Curvature becomes a finite graph check — no metric needed.

Printed pp. 205-227Flag Links
Gromov's combinatorial criterion: a cube complex is locally CAT(0) precisely when every vertex link is a flag simplicial complex. Flag means every set of pairwise adjacent vertices already spans a simplex, so there are no empty triangles. This is a purely finite check on the link graph.

The Empty Square Test

Empty square

Three cubes round an edge, fourth missing → a length-$\tfrac{3\pi}{2}$ loop in the link.

Filled corner

The fourth cube present → the square is filled, link is flag.

Slogan

$\text{CAT(0)} \;\Leftrightarrow\; \text{no empty squares}$

Printed pp. 205-227No Empty Squares
An empty square is three cubes around an edge with the fourth missing, producing a length three loop in the link, well under two pi. Filling it is exactly the flag condition. The cartoon to keep: an empty square is forbidden, while the filled corner cube certifies non-positive curvature.

Cartan-Hadamard and Examples

Globalisation

Complete + simply connected + locally CAT(0) $\Rightarrow$ globally CAT(0).

Recipe

Check flag links on $K$; pass to the universal cover $\tilde K$.

CAT(0) cube complexes

A finite flag check yields a genuine CAT(0) space $\tilde K$.

Groups

$\pi_1(K)$ acts properly and cocompactly on $\tilde K$: a CAT(0) group.

Examples

Right-angled Artin/Coxeter groups, special cube complexes.

Printed pp. 205-227Cartan-Hadamard and Examples
Combining the local link condition with Cartan-Hadamard, a complete, simply connected, locally CAT(0) complex is globally CAT(0). For finite complexes this means checking flagness of finitely many links produces genuine CAT(0) cube complexes, a rich and computable source of non-positively curved spaces and groups.

Recap: the Curvature Ladder

1. Model cells

Fix local geometry in $M_k$ with finitely many shapes.

2. Links

Turn curvature into the angular data of $\mathrm{Lk}(v)$.

3. Link condition

Locally CAT(k) $\Leftrightarrow$ every link CAT(1) (systole $\ge 2\pi$).

4. Cubical shortcut

CAT(0) $\Leftrightarrow$ flag links $\Leftrightarrow$ no empty squares.

5. Globalise

$\text{loc. CAT(0)} \xrightarrow{\;\text{Cartan-Hadamard}\;} \text{CAT(0)}$

Outcome

One finite combinatorial check per vertex certifies CAT(0) groups.

Printed pp. 205-227Recap and the Workflow
The workflow is a ladder: model cells fix local geometry, links translate curvature into angular data, the link condition becomes flagness in the cubical case, and Cartan-Hadamard globalises. Checking one finite combinatorial property at each vertex now certifies that an entire group acts on a CAT(0) space.
