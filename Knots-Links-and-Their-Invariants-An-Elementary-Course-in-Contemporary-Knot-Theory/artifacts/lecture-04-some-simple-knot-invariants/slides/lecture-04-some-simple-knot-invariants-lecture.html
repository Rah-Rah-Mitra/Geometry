Crossing Number

Definition

The fewest crossings in any diagram of the knot.

Hard to compute

One must rule out all simpler diagrams.

Values

$c(\text{unknot})=0,\quad c(\text{trefoil})=3$

Use

It orders the standard knot tables.

Printed pp. 29-38Crossing Number
Define the crossing number as the least number of crossings in any diagram of the knot. It is obviously an invariant and orders the knot tables, yet it is notoriously hard to compute because one must rule out all simpler diagrams. The unknot has crossing number zero and the trefoil three.

Tricolorability

The rule

Color arcs with three colors so each crossing is monochromatic or rainbow.

Nontrivial

At least two colors must actually be used.

Invariance

Preserved by all three Reidemeister moves.

Payoff

The trefoil is tricolorable; the unknot is not, so they differ.

Printed pp. 29-38Tricolorability
Introduce tricolorability: a knot is tricolorable if its arcs can be colored with three colors so that at every crossing the three meeting arcs are all equal or all different, using more than one color. This property is invariant under Reidemeister moves and instantly distinguishes the trefoil, which is tricolorable, from the unknot, which is not.

The Linking Number

Definition

Half the signed count of crossings between two components.

Meaning

How many times one circle wraps around the other.

Formula

$\mathrm{lk}(A,B)=\tfrac12\!\sum_{\text{cross}}\varepsilon$

Hopf link

Linking number one certifies the circles cannot separate.

Printed pp. 29-38The Linking Number
For a two-component link, define the linking number by counting signed crossings between the two components and halving. It measures how many times one component wraps around the other and is invariant under Reidemeister moves. The Hopf link has linking number one, certifying that its two circles cannot be pulled apart.

The Unknotting Number

Definition

Fewest crossing changes needed to reach the unknot.

Well defined

Enough switches always untie any knot.

Complexity

A genuine measure of how tangled a knot is.

Difficulty

Like crossing number, hard to pin down exactly.

Printed pp. 29-38The Unknotting Number
Define the unknotting number as the minimum number of crossing changes, switching over to under, needed to turn the knot into the unknot. Every knot can be undone by enough switches, so this is well defined. It is a genuine measure of complexity but, like crossing number, is difficult to compute exactly.
