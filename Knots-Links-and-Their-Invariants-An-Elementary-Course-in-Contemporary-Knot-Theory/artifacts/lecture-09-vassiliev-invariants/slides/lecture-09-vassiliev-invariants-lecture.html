The Filtration by Order

Nested spaces

Each order $n$ contains all lower orders.

Low orders

Order zero is constants; order one adds nothing for knots.

Filtration

$V_0\subset V_1\subset V_2\subset\cdots$

Graded pieces

$V_n/V_{n-1}$ holds the new information at order $n$.

Printed pp. 77-86The Filtration by Order
Arrange finite type invariants in a nested sequence indexed by order. Order zero invariants are constants, order one adds nothing new for knots, and each higher order strictly enlarges the space. The associated graded pieces measure exactly the new information appearing at each order, the central object of the theory.

Chord Diagrams

Definition

A circle with $n$ chords marking double-point pairs.

Only cyclic order

Just the pattern of endpoints matters.

Symbol

The top-order behavior is a function on these diagrams.

Abstraction

Lower-order detail is forgotten.

Printed pp. 77-86Chord Diagrams
Encode the top-order behavior of an order n invariant by a chord diagram: a circle with n chords marking where the double points sit along the knot. Only the cyclic pattern of chord endpoints matters. The leading symbol of the invariant is a function on these diagrams, abstracting away all lower-order detail.

The Four-Term Relation

Constraint

Not every diagram function comes from an invariant.

Identity

Four diagrams differing by one endpoint move cancel.

Relation

$D_1-D_2+D_3-D_4=0$

Framing

A one-term relation kills isolated chords.

Printed pp. 77-86The Four-Term Relation
Show that not every function on chord diagrams arises from an invariant. Consistency forces the four-term relation, a linear identity among four diagrams differing by moving one chord endpoint past a neighbor. Together with the one-term framing relation it cuts the space of symbols down to the actual weight systems.

Weight Systems

Definition

Diagram functions obeying the four-term and framing relations.

Fundamental theorem

Every weight system is some invariant's symbol.

Proof tool

The Kontsevich integral realizes each weight system.

Identification

Graded invariants equal combinatorial weight systems.

Printed pp. 77-86Weight Systems
Define a weight system as a function on chord diagrams satisfying the four-term and framing relations. The fundamental theorem, proved via the Kontsevich integral, says every weight system is the symbol of some Vassiliev invariant. Thus the graded space of invariants is identified with the combinatorial space of weight systems.
