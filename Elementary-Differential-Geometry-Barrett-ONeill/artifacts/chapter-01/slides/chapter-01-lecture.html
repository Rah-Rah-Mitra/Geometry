Coordinates

A point can feed many scalar readouts

03 / 16
Working definition

A coordinate function is a scalar-valued measurement on Euclidean space, such as xi(p)=pi.

  • The point is the input; the coordinate is one report about it.
  • A function on a region becomes inspectable by its level sets and rates of change.
The important distinction is between the point itself and the coordinate functions that report its entries. Coordinates are useful measuring devices, but they are not the geometric object. This slide lets students see a point feeding several scalar readouts at once.

Tangent vectors

Same components, different point of application

04 / 16
Bookkeeping rule

A tangent vector is best stored as (p, v): a base point plus a direction vector.

Why the base point matters

  • Functions have different slopes at different points.
  • Fields attach many such pairs to one region.
  • Maps must move both the point and the direction.
A tangent vector in this chapter carries a base point and a vector part. Draw attention to the two arrows with the same components but different anchors: they agree as free vectors, yet they act at different locations when applied to a function.

Directional derivative

A tangent vector probes a function

05 / 16
Limit experiment

v[f] at p = limt→0 ( f(p + t v) - f(p) ) / t

The symbol is an operator: give it a smooth scalar function, and it returns the first-order change seen from the tangent vector.

Directional derivative notation can hide the simple experiment underneath it. We probe a function by walking from p in the direction v and watching the first-order change. The visual finite-difference secant is there so the limiting operator feels like a measurement, not a symbol.

Operator viewpoint

Components become a mixture of coordinate derivatives

06 / 16

At a point p

v = v1 e1 + ··· + vn en

v[f] = Σ vi (∂f/∂xi)(p)

The arrow becomes a recipe for differentiating any smooth scalar function.

This is the algebraic bridge from the geometric arrow to a differential operator. Coordinate derivatives are the basis measurements, and the vector components tell us how much of each measurement to mix. Stress that the operator depends on both p and v.

Curves

A moving point carries a moving tangent vector

07 / 16
Curve data

α(t) = (x¹(t), x²(t), x³(t))

α′(t) = x¹′(t)e₁ + x²′(t)e₂ + x³′(t)e₃ at α(t)

The derivative of the component functions supplies the vector part; the curve supplies the base point.

A curve is a moving point, and its velocity is the tangent vector attached to the current point of the curve. Students often remember only the derivative of component functions; this slide keeps the derivative attached to its location on the traced path.

Vector fields

A rule that assigns tangent data pointwise

08 / 16
Field rule

V(p) = (p, V¹(p)e₁ + V²(p)e₂ + ··· + Vⁿ(p)eₙ)

  • The drawing samples the rule at finitely many points.
  • Smoothness means the rule changes without abrupt jumps.
  • Frames are vector fields arranged into a moving basis.
Vector fields assign tangent vectors everywhere in a region. The slide separates the sample arrows from the rule that produced them, because the rule is the mathematical object. Mention that later frames and surface fields use the same bookkeeping.

Differential forms

A one-form measures a tangent vector

09 / 16
Measurement rule

A one-form at p is a linear rule that consumes tangent vectors at p and returns scalars.

ω = a dx + b dy

ω(v¹e₁ + v²e₂) = a v¹ + b v²

Differential forms reverse the viewpoint: a vector enters, and a scalar measurement comes out. The three gauges show that a form may measure horizontal motion, vertical motion, or a chosen linear combination. This is the language for line integrals and orientation-sensitive measurements.

Rules of calculation

Product and chain rules are information-flow laws

10 / 16

v[fg] = f(p) v[g] + g(p) v[f]

v[f ∘ F] = (F*v)[f]

The notation says which object is measured first and where the tangent data lives after a map.

The product and chain rules are structural promises about how local measurements behave. The formula strip is intentionally paired with a dependency diagram so students see that each rule describes how information flows through functions and maps.

Tangent maps

A map pushes base points and directions

11 / 16
Derivative as geometry

F*p(v) = JF(p) v

The output tangent vector is based at F(p), not at p.

source tangent spacetarget tangent space
The tangent map is the derivative of a mapping interpreted geometrically. It sends a tangent vector at p to a tangent vector at F(p), using the Jacobian as the local linear model. The visual emphasizes that base points move along with vector parts.

Local linearization

A nonlinear map bends grids, but its derivative is first-order linear

12 / 16

Finite grid squares may curve under F; the tangent map records only the best first-order linear behavior at one base point.

This slide gives a concrete deformation: a small coordinate grid is bent by a nonlinear map, while one tangent arrow is pushed forward. The parallelogram near the source becomes a first-order parallelogram near the target. The warning is that finite drawings curve, while the derivative is only the local linear approximation.

Regularity

Smoothness says the machines can be reused

13 / 16

Smooth function

All needed derivatives exist and vary continuously on the region being studied.

Regular curve

Velocity does not vanish, so the curve has a dependable tangent direction.

Nonsingular map

The derivative preserves the first-order dimension required by the argument.

Regularity language is how we say which local machines are allowed to run. Smoothness supports repeated differentiation, and a nonsingular derivative preserves the dimension of first-order data. Keep the emphasis practical: singular points are where the usual geometric inference can break.

Worked example

Curve through a map, then measured by a form

14 / 16

α(t) = (cos t, sin t)

F(x,y) = (x² - y², 2xy)

ω = u dv - v du

(F ∘ α)′(t) = F*α(t)(α′(t))

The same velocity can be computed by differentiating the composed curve or by pushing the original velocity through the tangent map.

The worked example gathers the chapter ingredients into one calculation. A curve enters a map, the chain rule predicts the pushed velocity, and a one-form measures the resulting tangent vector. This is the first small rehearsal for computations on parameterized surfaces.

Takeaways

The chapter is a grammar for local geometry

Object grammar

  • Points are inputs for coordinate and scalar functions.
  • Tangent vectors are first-order probes at a point.
  • One-forms are linear measurements of tangent vectors.
  • Tangent maps transport first-order information.
