Lecture Contract

What Counts As A Formula In Code?

  • A point is a small array with a declared coordinate chart.
  • A curve is a callable plus its parameter interval.
  • A tangent vector is a base point and a direction.
  • A surface patch is a two-parameter callable with partial velocities.
  • A differential form is a rule that eats tangent data and returns a number.
This slide sets the vocabulary for the rest of the deck. Ask students to notice that the code representation always adds bookkeeping that pure notation often suppresses: chart, parameter interval, base point, and tolerance. That bookkeeping is not clutter; it is what keeps a computation honest.

Python Fundamentals

Coordinate Arrays Need Geometric Names

Representation Pattern
P = array([x, y, z])
V = array([vx, vy, vz])
Q = P + h * V
The same array shape can represent a point, a free vector, or a tangent direction. The variable name and context carry the geometry.
The central warning here is that arrays are syntactically neutral. A student can add two arrays correctly in Python while still misunderstanding whether the result is a point or a vector. Encourage them to choose variable names that record the geometric role before any computation begins.

Curves

A Curve Is A Callable With Tests Attached

Curve Formula
alpha(t) = (x(t), y(t), z(t))
Computational Checks
  • Speed stays positive on the sampled interval.
  • Unit tangent has norm near one.
  • Frame vectors remain nearly orthogonal.
Move from arrays to functions by treating a curve as a machine that returns points. The derivative data is not merely symbolic decoration; it becomes tangent, normal, speed, and curvature tests. The helix is a good model because students can see the frame rotate while the computed invariants remain controlled.

Symbolic And Numeric Differentiation

Two Engines, One Residual

Symbolic Mode
Use exact formulas when expressions stay small enough to read. The output should still be checked on points, not admired as a long expression.
Numeric Mode
Use finite differences, sampling, or automatic routines when exact formulas become opaque. The output needs tolerances and scale-aware diagnostics.
This slide helps prevent a common split in student thinking: symbolic answers feel exact, while numerical answers feel approximate and therefore less mathematical. In practice both need interpretation. A symbolic formula can be too complex to teach, and a numerical formula can be reliable when its residual is measured against the right scale.

Curve Diagnostics

Frames Turn Motion Into Measured Geometry

Frame Data
T, N, B; speed; curvature; torsion
Notebook Evidence
The recorded appendix checks keep helix curvature and torsion residuals below one ten-thousandth, and the frame orthonormality error is essentially zero at floating-point scale.
The frame is a moving measuring instrument, not just three arrows drawn on a curve. Students should connect each arrow to a numerical check: unit length, mutual orthogonality, and stable curvature or torsion values. This is where the appendix starts to make differential geometry feel testable without making it trivial.

Surfaces

A Patch Converts Parameters Into Tangent Data

Patch Formula
X(u,v) = (x(u,v), y(u,v), z(u,v))
Immediate Tests
  • Partial velocities are not parallel.
  • The normal has stable orientation on the grid.
  • The surface Jacobian stays away from zero.
A surface patch is where bookkeeping becomes especially valuable. The pair of partial derivatives carries the tangent plane, normal direction, area scale, and metric coefficients. Ask students to think of a surface plot as incomplete until the patch has passed a regularity check.

First Fundamental Form

The Metric Is A Local Measurement Table

Computed From Partials
E = X_u dot X_u
F = X_u dot X_v
G = X_v dot X_v
Meaning
The table does not describe the surface visually; it describes how the surface measures directions drawn in the parameter domain.
The metric coefficients are a compact way of carrying surface geometry into the parameter plane. The ellipse in the diagram is deliberately not a picture of the surface; it is a picture of local measurement. This distinction helps students separate a surface's appearance from the quantities used in curvature and length calculations.

Differential Forms

Forms Are Measurement Rules On Tangent Inputs

In Code
A one-form can be represented as a function that receives a base point and a tangent vector. A two-form receives two tangent vectors and changes sign when their order is swapped.
Sanity Check
omega(U, V) = - omega(V, U)
Forms are easy to over-symbolize, so this slide anchors them as input-output rules. The key property to inspect computationally is antisymmetry, because swapping tangent inputs must flip the sign of an oriented measurement. This is a small test with a large conceptual payoff.

Exterior Calculus

A Zero Residual Can Certify A Structural Law

Structural Identity
d after d gives zero
Computational Use
This is not a numerical coincidence. It is a symbolic identity that can also serve as a regression test for any helper that manipulates forms.
Here the computation checks a law of the calculus rather than a plotted object. The identity that applying the exterior derivative twice gives zero is ideal for a symbolic residual check. Tell students that such tests are valuable because they catch sign conventions and index-ordering mistakes early.

Plots

A Good Plot Shows The Object And The Diagnostic

Plotting Standard
The viewer should know what to inspect: an invariant, an error curve, a domain boundary, or a singularity warning.
Common Failure
A beautiful surface without a diagnostic can hide a bad parameter domain, a flipped normal, or a discretization artifact.
The appendix treats plots as evidence, not decoration. A strong diagnostic figure contains both the geometric object and a measurement that can fail. This is especially important in differential geometry, where a visually smooth plot can still come from a singular patch or an unstable derivative.

Differential Equations

ODE Solvers Reconstruct Geometry From Local Rules

Workflow
Choose initial data, integrate the local rule, compare the numerical path with a known model or conserved quantity.
Notebook Evidence
The appendix laboratory records an ODE reconstruction error below one billionth for its model case, which is small enough to make the visual comparison meaningful.
The ODE section asks students to reverse their usual thinking about formulas. Instead of starting with a closed-form curve, we specify local motion and let the solver build the path. The comparison with a known model is what turns this from a black-box integration into a geometric experiment.

Reusable Helpers

Small Helpers Reduce Formula Transcription Errors

Design Principle
A helper should expose the geometric roles in its signature, return named quantities, and include at least one model-case check.
frame = frenet_data(curve, t_grid)
metric = patch_metric(surface, u_grid, v_grid)
residual = check_identity(model)
This slide is partly about software engineering and partly about mathematical hygiene. Reusable helpers are worthwhile only when they make the geometry more legible, not when they hide it. The best helpers return named geometric quantities and come with small tests that students can understand.

Audit Mindset

Every Computation Should Leave Evidence

Existence
Artifacts exist, are nonempty, and can be opened without depending on a hidden session.
Accuracy
Residuals are small, scale-aware, and tied to a geometric identity or model example.
Interpretation
The learner knows which invariant, failure mode, or diagnostic curve to inspect.
The appendix's final sanity checks are not administrative afterthoughts. They model a professional habit: every generated file and every computed number should support a claim in the lesson. This is a useful place to ask students what evidence would convince them that a new example still satisfies the same geometric idea.

Takeaways

From Formula Sheet To Experimental Geometry

Translate
Represent points, curves, surfaces, forms, and frames with explicit computational roles.
Inspect
Pair each plot with a quantity that should remain stable or reveal failure.
Extend
Change the model, rerun the checks, and explain whether the geometry survived.
Closing Principle
A computer formula is successful when it makes the mathematical object more inspectable while preserving the assumptions that made the formula true.
Close by returning to the big theme: computation is strongest when it clarifies a definition and leaves evidence behind. Students should now be able to read the appendix notebook as a laboratory rather than a list of recipes. The next productive exercise is to replace one model curve or surface and decide which checks must still pass.
