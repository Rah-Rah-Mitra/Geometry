Present the three-part rhythm as the course grammar. Translation names the data, visualization chooses a representation that exposes geometry, and checking records an invariant or residual. Representation Versus Geometry

Four Roles To Keep Separate

Data

Coordinates, arrays, sampled points, frames, and parameter values.

Transformation

Change coordinates, move a frame, reparametrize, or rotate a scene.

Invariant

The measurement meant to survive the allowed change.

Check

A residual or diagnostic that catches a broken claim.

A coordinate picture is a representationthe invariant is the geometry
Use the diagram to separate four roles that often blur together. Data is how an object is represented, transformations are allowed changes of description, invariants are what should survive, and checks are small tests that keep the visual honest. This distinction will matter immediately for coordinates, frames, forms, and curvature.
Checkpoint 1 · Functions And Notation

A Function Carries More Than A Formula

Reusable Rule

A function has a domain, a target, an expression or procedure, and assumptions under which the rule is meaningful.

input space -> rule -> target space
Functions are typed mathematical instructionslater: curves, patches, fields, forms
Explain functions as reusable rules with declared input and output spaces. In differential geometry, a map is rarely only a formula; it carries domain, target, parameters, and differentiability assumptions. The slide prepares students to ask what the code is allowed to feed into a rule.
Checkpoint 2 · Sets And Maps

Objects Live In Different Spaces

type

Most confusion in computational differential geometry starts when data from one space is silently used as if it belonged to another.

Point

Coordinates in a chart or ambient space.

Tangent Vector

A base point plus an allowed direction.

Form

A rule that eats tangent data and returns a measurement.

Frame

A moving instrument for decomposing vectors.

Track the set before trusting the operationsets and maps become error checks
Frame sets and maps as bookkeeping for geometry rather than elementary review. A curve, a surface patch, a tangent vector, and a form all belong to different kinds of spaces. When students track those spaces explicitly, many later type errors become mathematical errors they can diagnose.
Common Pitfall

The Drawing Is Not The Invariant

Inspection Question

If the picture changes, which measurement was supposed to remain stable?

Course Habit

Pair every visual with a nearby sentence naming the invariant, behavior, or failure mode to inspect.

changed representation != changed geometry
Visuals teach when they expose what survivesmismatch is useful evidence
Slow down on the warning because it is the main habit of the course. A plotted picture can change when coordinates or parameters change, while the geometric quantity of interest may stay fixed. The right question is not whether the drawing is attractive, but what it proves possible to inspect.

Debugging Geometry

Useful Failures Have Names

Wrong Base Point

A tangent vector is drawn at one point but evaluated at another.

Singular Patch

Partial velocities stop spanning the expected tangent plane.

Sign Convention

A frame, normal, or orientation flips a measured quantity.

Residual Alarm

An identity expected to vanish leaves a nonzero symbolic or numeric trace.

Sampling Alarm

A diagram hides behavior because the grid is too coarse or misses a boundary.

Type Alarm

Data from one space is fed into a rule defined on another.

failure -> assumption -> revised check
Debugging is mathematical inspectionnamed failure modes
Use the failure modes as a practical reading checklist. A tangent vector at the wrong base point, a singular patch, or a sign error in a convention should produce visible or numerical symptoms. Students should learn to welcome these failures because they expose the assumptions behind the definition.
Reading Code Cells

The Code Is Part Of The Explanation

Read For Roles

Variable names should tell you whether a value is a point, direction, patch, metric, form, or check.

Read For Assumptions

Look for domains, parameter ranges, tolerances, and model choices before interpreting an output.

Read For Evidence

Ask which line computes the object and which line tests the claim.

Executable prose is still proseread code cells with definitions open
Encourage students to read code cells as part of the mathematical exposition. Variable names are chosen to mirror roles such as tangent vector, patch, form, metric, and residual. The goal is not programming for its own sake; it is to keep every definition close to an executable witness.
Applied Lab

Change One Parameter, Predict One Invariant

Lab Protocol

  1. Choose one model parameter.
  2. Predict the visual change.
  3. Predict the check value that should remain stable.
  4. Rerun and compare.

Good Outcome

A mismatch gives a new question rather than merely a wrong answer.

asset: how-to-use-this-visualization-course-applied-experiment.pngpredict before rerunning
Present the applied lab as a controlled perturbation exercise. Students change one parameter, rerun the artifact, and decide which visual features and check values should change. This builds the habit of predicting invariants before trusting a regenerated figure.
