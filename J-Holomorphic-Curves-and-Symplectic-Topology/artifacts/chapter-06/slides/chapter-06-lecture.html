Why Compactify: Bubbling

The problem

Smooth curves of fixed energy need not converge to a smooth curve.

Gromov compactness

Energy concentration produces a bubble; the limit is a nodal configuration.

Energy is conserved

$E(u_\nu)=\langle A,[\omega]\rangle \to E(u_\infty)+\sum_k E(\text{bubble}_k)$

McDuff & Salamon · printed pp. 153-200Why Compactify
A sequence of embedded spheres can degenerate as energy concentrates, bubbling off lower curves. The limit leaves the smooth stratum, so naive moduli are non-compact. Gromov compactness tells us the limit is a nodal configuration, which we must legitimize as an object of the moduli problem.

Stable Maps

Definition

A nodal genus-$g$ curve $\Sigma$ with marks $z_1,\dots,z_n$ and a $J$-holomorphic map $u:\Sigma\to M$.

Stability condition

$\operatorname{Aut}(\Sigma,u)<\infty$

Every ghost (constant) component carries $\ge 3$ special points if genus $0$, $\ge 1$ if genus $1$.

Special points

Marked points and nodes together rigidify each component.

McDuff & Salamon · printed pp. 153-200Stable Maps
A stable map is a nodal genus-g curve with marked points together with a J-holomorphic map, subject to a stability condition: every ghost component must carry enough special points to rigidify it. Stability forces the automorphism group to be finite, which is exactly what compactness and Hausdorffness require.

The Moduli Space

Definition

$\overline{\mathcal M}_{g,n}(M,A;J) = \{(\Sigma,\mathbf z,u)\}/\sim$

Topology

Convergence is Gromov convergence of maps and domains.

Compact

By Gromov compactness no sequence escapes the space.

Metrizable

A natural distance makes it a separable metric space.

Hausdorff

Finite automorphisms separate limit points cleanly.

McDuff & Salamon · printed pp. 153-200The Moduli Space
We assemble all stable maps of class A, genus g, with n marked points into one set and topologize it by Gromov convergence. The resulting space is compact and metrizable. This single object replaces the open manifold of smooth curves and supports evaluation and forgetful structure maps.

Evaluation Maps

Evaluation at mark $i$

$\mathrm{ev}_i:\overline{\mathcal M}_{g,n}(M,A;J)\to M,\quad (\Sigma,\mathbf z,u)\mapsto u(z_i)$

Total evaluation

$\mathrm{ev}=(\mathrm{ev}_1,\dots,\mathrm{ev}_n):\overline{\mathcal M}\to M^n$

Use

Pull back constraints $\alpha_i\in H^*(M)$ to integrate over moduli.

McDuff & Salamon · printed pp. 153-200Evaluation Maps
Each marked point yields an evaluation map sending a stable map to the image of that point in M. Together the n evaluations form a map to the n-fold product. Pulling back cohomology classes through evaluation is how incidence constraints on curves become integrals over moduli.

Forgetful Maps

Forget the last mark

$\pi:\overline{\mathcal M}_{g,n+1}(M,A;J)\to\overline{\mathcal M}_{g,n}(M,A;J)$

Stabilize

Drop the point, then contract any component that became unstable.

Tower

These projections organize moduli into a recursive tower.

McDuff & Salamon · printed pp. 153-200Forgetful Maps
Forgetting a marked point or the map data defines projections between moduli spaces. After forgetting we must stabilize the domain, contracting any component that has become unstable. These forgetful morphisms organize the spaces into a tower and underlie recursive structures like the string and dilaton equations.

Stratification by Domain Type

Index set

Strata are labelled by the combinatorial type: the dual graph of the domain.

Dual graph

$\Gamma = (\text{vertices}=\text{components},\ \text{edges}=\text{nodes})$

vertices carry genus and class; legs carry marks.

Top stratum

Smooth irreducible domain, the open dense piece.

McDuff & Salamon · printed pp. 153-200Stratification by Domain Type
The moduli space decomposes into strata indexed by the combinatorial type of the domain: the dual graph recording components, nodes, genera, and marked points. The top open stratum has a smooth irreducible domain; deeper strata correspond to more degenerate trees of bubbles glued at nodes.

The Boundary and Codimension

Boundary strata

Domains with nodes form the boundary of the smooth stratum.

Node = diagonal condition

$\mathrm{ev}_+ = \mathrm{ev}_- \ \text{in}\ M\times M \Rightarrow \operatorname{codim} \ge 2$

Why it matters

Counts are stable only if boundary has real codimension $\ge 2$.

Edge evaluation

At each node, two component evaluations must agree, meeting the diagonal $\Delta\subset M\times M$.

Codimension counts nodes

Each transverse node raises codimension by $\dim_{\mathbb R}M$.

McDuff & Salamon · printed pp. 153-200The Boundary
Boundary strata are where domains acquire nodes. The codimension of a stratum grows with the number of nodes, since each node imposes a diagonal matching condition in the target. For meaningful counts these boundary strata must sit in real codimension at least two.

Virtual (Expected) Dimension

Genus-zero formula

$\dim_{\mathbb R}\overline{\mathcal M}_{0,n}(M,A) = 2\big(n + c_1(A) + \dim_{\mathbb C}M - 3\big)$

Source

Index of the linearized $\bar\partial_J$ plus domain deformations.

Index term

$2c_1(A)+2\dim_{\mathbb C}M$ from the Cauchy-Riemann operator.

Domain term

$2n-6$ from moving $n$ marks on a sphere, $\dim\mathcal M_{0,n}$.

McDuff & Salamon · printed pp. 153-200Virtual Dimension
The expected dimension comes from the index of the linearized Cauchy-Riemann operator plus the dimension of domain deformations. For genus zero it reads two times the quantity n plus the first Chern number plus the complex dimension minus three. This number is what transverse moduli should realize.

Obstructions to Smoothness

Multiple covers

A $k$-fold cover of a curve can have a large cokernel, inflating its stratum dimension.

Non-transversality

$\bar\partial_J$ may fail to be surjective; the moduli space is not cut out cleanly.

Actual vs expected

$\dim \mathcal M_{\text{actual}} \ge \mathrm{vdim} + \dim\operatorname{coker}\bar\partial_J$

McDuff & Salamon · printed pp. 153-200Obstructions to Smoothness
Multiple covers and non-transversality prevent the moduli space from being a smooth manifold of the expected dimension. A multiply covered curve can have a cokernel that inflates dimension, so the actual stratum exceeds the virtual count. These obstructions motivate the virtual fundamental class.

The Virtual Fundamental Class

Virtual class

$[\overline{\mathcal M}_{g,n}(M,A;J)]^{\mathrm{vir}}\in H_{\mathrm{vdim}}(\overline{\mathcal M})$

Construction

Cut down by the obstruction bundle, or by an abstract perturbation.

GW invariant

$\mathrm{GW}_{A}(\alpha_1,\dots,\alpha_n)=\int_{[\overline{\mathcal M}]^{\mathrm{vir}}}\mathrm{ev}_1^*\alpha_1\smile\cdots\smile\mathrm{ev}_n^*\alpha_n$

McDuff & Salamon · printed pp. 153-200Virtual Fundamental Class
When transversality fails one builds a virtual fundamental class of the expected dimension, against which Gromov-Witten invariants are defined. The obstruction bundle and an abstract perturbation cut the moduli space down to virtual dimension, restoring well-defined intersection numbers despite singular strata.

Genus Zero, Semipositive: Pseudocycles Suffice

Semipositivity

$c_1(A)\ge 0 \ \text{whenever}\ \langle\omega,A\rangle>0$ on spheres

no negative low-energy bubbles survive

Consequence

Bad bubble strata already have real codimension $\ge 2$.

Result

$\mathrm{ev}$ on simple maps is a pseudocycle; invariants are honest intersection numbers.

Payoff

No virtual class needed: pseudocycle intersection theory gives Gromov-Witten numbers.

McDuff & Salamon · printed pp. 153-200Genus Zero Semipositive Case
When the manifold is semipositive and the genus is zero, bad bubble strata already have codimension at least two. Transversality for simple maps then makes the evaluation map a pseudocycle, so invariants are honest intersection numbers and the heavy virtual machinery becomes unnecessary.
