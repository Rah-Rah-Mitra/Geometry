Fredholm Operators

Finite kernel

$\dim\ker D < \infty$.

Closed range

$\operatorname{im}D$ is a closed subspace of $Y$.

Finite cokernel

$\dim\operatorname{coker}D < \infty$.

Definition

$D \in \mathcal{F}(X,Y) \iff \dim\ker D,\ \dim\operatorname{coker}D < \infty,\ \operatorname{im}D = \overline{\operatorname{im}D}$

Why these three

They isolate exactly the data we can count; the rest of $D$ is an isomorphism on complements.

Printed pp. 531-548Fredholm Operators
A bounded operator between Banach spaces is Fredholm when its kernel is finite-dimensional, its range is closed, and its cokernel is finite-dimensional. These three conditions isolate exactly the finite data we can count, while the bulk of the infinite-dimensional map remains an isomorphism between complementary subspaces.

The Fredholm Index

Dimension budget

A single integer subtracting obstructions from free directions.

Defects may move

$\dim\ker D$ and $\dim\operatorname{coker}D$ can each jump; their difference does not.

Index

$\operatorname{ind}D = \dim\ker D - \dim\operatorname{coker}D$

Printed pp. 531-548The Fredholm Index
The index subtracts cokernel dimension from kernel dimension, producing the dimension budget every later moduli computation spends. Although kernel and cokernel can each jump under deformation, their difference is a discrete invariant. This integer, not the individual defect spaces, is what the appendix protects and propagates.

Stability of the Index

Open condition

$\mathcal{F}(X,Y)$ is open in the operator norm.

Locally constant

The index is continuous, hence constant on connected components.

Continuity

$\|D' - D\| < \varepsilon \implies \operatorname{ind}D' = \operatorname{ind}D$

Printed pp. 531-548Stability of the Index
The index is locally constant in the operator norm, so it cannot change under a small continuous deformation. Equivalently, Fredholm operators form an open set on which the index is a continuous, hence constant, integer along any path connecting two operators within the same component.

Compact Perturbations

Compact $K$

Adding any compact operator preserves the index.

Defects shift

Kernel and cokernel may both change; the difference is pinned.

Invariance

$K \text{ compact} \implies \operatorname{ind}(D + K) = \operatorname{ind}D$

Why it matters

The linearized $\bar\partial_J$ differs from a model operator by compact lower-order terms, so it inherits the model's index.

Printed pp. 531-548Compact Perturbations
Adding any compact operator leaves the index unchanged: kernel and cokernel may both move, but their difference is pinned. This is why the linearized Cauchy-Riemann operator, which differs from a model operator by compact lower-order terms, inherits a computable index from the model.

Determinant Lines and Crossings

Orientation object

One real line built from kernel and cokernel tops.

Parity rule

One regular crossing reverses sign; two crossings preserve it.

Determinant line

$\det(D) = \Lambda^{\max}(\ker D) \otimes \Lambda^{\max}(\ker D^{*})$

Printed pp. 531-548Determinant Lines
The determinant line tensors the top exterior power of the kernel with that of the cokernel, packaging both orientations into a single real line. Along an index-zero path with invertible endpoints the line can still twist; the parity of regular kernel crossings records whether orientation is preserved or reversed.

Implicit Function Theorem

Right inverse

If $D = df(x_0)$ is onto with bounded right inverse $Q$.

Graph over kernel

Correct along $\operatorname{im}Q$; free variables live in $\ker D$.

Model

$f(\xi,\eta) = \eta + \tfrac12\xi^2 + 0.2\,\eta^2,\quad D(\xi,\eta) = \eta$

Printed pp. 531-548Implicit Function Theorem
When the linearization is onto with a bounded right inverse, the implicit function theorem in Banach spaces graphs the zero set over the kernel. The nonlinear equation is corrected along the image of the right inverse while the free directions live in the kernel, exactly as in the planar model shown.

Regular Values and Submersions

Regular value

$df(x)$ surjective with complemented kernel at every preimage.

Smooth fiber

The preimage is a Banach submanifold.

Tangent space

$T_x f^{-1}(y) = \ker df(x),\quad \dim = \operatorname{ind}\,df(x)$

Consequence

The dimension of the zero set is read off directly as the Fredholm index of the linearization.

Printed pp. 531-548Regular Values and Submersions
A value is regular when the derivative is surjective with complemented kernel at every preimage. The Banach implicit function theorem then makes the preimage a smooth submanifold whose tangent space is the kernel of the linearization, giving its dimension as the Fredholm index of that operator.

Finite-Dimensional Reduction

Pseudoinverse

$T$ with $TDT=T,\ DTD=D$ projects onto image and cokernel.

Obstruction map

Image equations solved; a finite map remains over $\ker D$.

Kuranishi model

$D(u,v) = (0,v),\quad \kappa_a(u) = u^2 - a$

Printed pp. 531-548Kuranishi Reduction
At a singular point the derivative may fail to be onto, so a pseudoinverse splits the equation into image equations, solved by the implicit function theorem, and a finite obstruction map valued in the cokernel. The local zero set becomes the zero set of this finite obstruction over the kernel.

Sard-Smale as Finite Sard

Residual regular values

For $C^k$ Fredholm maps between separable Banach spaces.

Local split

$X = X_0 \oplus X_1$, $Y = Y_0 \oplus Y_1$ with $X_0 = \ker D$.

Reduction

$y_0 = f_0(x_0, x_1),\quad y_1 = D_1 x_1$

Finite Sard

For fixed $y_1$, regularity reduces to ordinary Sard for $x_0 \mapsto f_0(x_0, D_1^{-1}y_1)$; separability patches the charts.

Printed pp. 531-548Sard-Smale
Sard-Smale upgrades finite-dimensional Sard to Fredholm maps between separable Banach spaces: regular values form a residual set. The proof splits domain and target along kernel and cokernel complements, reducing regularity at each fiber to ordinary Sard in finitely many variables, then patches using separability.
