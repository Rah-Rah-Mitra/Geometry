Computing Grobner Bases

Command

Generators plus a monomial order.

Decision

Which order to choose.

Trade-off

$\text{grevlex (speed)} \;/\; \text{lex (elim.)}$

Bridge

Order conversion when both are needed.

Printed pp. 611-626Computing Grobner Bases
Each system offers a command that, given generators and a monomial order, returns a Grobner basis. Choosing the order, graded reverse lexicographic for speed or lexicographic for elimination, is the key decision, and order conversion bridges the two when both are needed.
