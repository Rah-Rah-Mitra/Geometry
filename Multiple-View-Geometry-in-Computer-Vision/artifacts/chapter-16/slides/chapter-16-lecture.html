Correspondences Give Linear Equations

Point triplet

$x \leftrightarrow x' \leftrightarrow x''$ yields four independent trilinear equations in the 27 entries $T_i^{jk}$.

Line triplet

$l \leftrightarrow l' \leftrightarrow l''$ yields two equations. Points and lines mix in one matrix.

Stack them

All equations form a homogeneous system $A\,\mathbf{t}=\mathbf{0}$.

Point relation

$x^i \big(x'^j x''^k \epsilon_{jpr}\epsilon_{kqs}\, T_i^{pq}\big) = 0_{rs}$

Line relation

$l'_j\, l''_k\, T_i^{jk} = \mu\, l_i$

Four point equations have only two independent; lines give a single vector constraint.

Printed pp. 391-408Trilinear Equations
Each point-point-point correspondence over three views contributes four linearly independent trilinear equations in the twenty-seven entries of the tensor. Stacking these gives a homogeneous system A t equals zero. Line correspondences supply two equations each, so points and lines mix freely to build the design matrix.

Counting

The tensor has twenty-six degrees of freedom up to scale but only eighteen are geometrically independent. Seven point correspondences give twenty-eight equations, enough to solve linearly. Mixtures count too: a point is worth four equations, a line two, so six points and four lines also suffice for the linear estimate.

Solving $A\,\mathbf{t}=\mathbf{0}$ by SVD

Overdetermined

With $n>7$ points, $A$ has more rows than 27. No exact null vector exists under noise.

Least squares

Minimize $\lVert A\mathbf{t}\rVert$ subject to $\lVert\mathbf{t}\rVert=1$.

Solution

Last right singular vector of $A$ — reshape to a $3\times3\times3$ array.

Algebraic minimizer

$\mathbf{t}^{*}=\arg\min_{\lVert\mathbf{t}\rVert=1}\lVert A\mathbf{t}\rVert = \mathbf{v}_{27}$

Printed pp. 391-408The Linear Algorithm
With more than the minimum data the system is overdetermined, so we seek the unit vector minimizing the algebraic residual. The singular value decomposition of the design matrix delivers it: the right singular vector for the smallest singular value is the least-squares nullspace estimate, reshaped into a three by three by three array.

Normalization Is Not Cosmetic

The hazard

Pixel coordinates like $(700,500)$ make some rows of $A$ dwarf others, so the algebraic min drifts from the geometric one.

Hartley fix

Translate each image so points centre at the origin; scale so mean distance is $\sqrt 2$.

Similarity transform

$H=\begin{bmatrix} s&0&-s\bar x\\ 0&s&-s\bar y\\ 0&0&1\end{bmatrix},\ s=\dfrac{\sqrt2}{\mathrm{rms}}$

Result

Equalized rows, far smaller condition number — same geometry, better numerics.

Printed pp. 391-408Why Normalize
Raw pixel coordinates make some rows of the design matrix vastly larger than others, so the algebraic minimum no longer tracks the geometric one. Hartley normalization translates each image so points are centred and scales them to mean distance root two from the origin, equalizing the rows before the null vector is chosen.

Internal Constraints: the Valid Manifold

The gap

A generic 27-entry array is not a trifocal tensor. The linear solution has 26 dof; valid tensors have only 18.

Slice structure

Each correlation slice $T_i$ has rank 2; the slices share epipolar null directions.

Printed pp. 391-408Internal Constraints
A generic twenty-seven entry array is not a trifocal tensor. The valid tensors form an eighteen degree of freedom manifold, so the linear solution must be projected onto it. Each correlation slice has rank two, and the three left and right null vectors are constrained, encoding consistency with three genuine cameras.

Enforcing Validity via the Epipoles

The handle

Parametrize $T$ by epipoles $e'$, $e''$ (second, third views) plus a linear part $a_i$.

Linear given epipoles

Fix $e',e''$ and the rest of $T$ is linear in the data.

Alternate

Solve linear step, update epipoles, repeat — output is always valid.

Camera-consistent form

$T_i^{jk}=a_i^{j}\,e''^{k}-e'^{j}\,b_i^{k}$

The epipoles are the null vectors of the slice transposes; recovering them is the first step in building consistent cameras $P',P''$.

Printed pp. 391-408Parametrization via Epipoles
The clean way to enforce validity is to parametrize the tensor by the two epipoles in the second and third views plus a linear part. Given the epipoles the remaining entries are linear, so an iterative scheme alternates between solving that linear problem and updating the epipoles, guaranteeing a geometrically valid result.

Algebraic vs Geometric Error

Algebraic

$\lVert A\mathbf t\rVert$: cheap, linear, but not the quantity we care about.

Geometric

Reprojection error in pixels — the distance between measured and predicted image points.

Roles

$\text{algebraic} \;\to\; \text{initializer}\;\to\; \text{geometric refinement}$

Printed pp. 391-408Algebraic vs Geometric Error
Algebraic error is the residual of the linear equations: cheap, but not what we ultimately care about. Geometric error is reprojection error, the distance in pixels between measured and predicted image points. The linear estimate minimizes algebraic error and serves as the initializer for the geometric refinement.

The Gold-Standard Iterative Estimate

Noise model

Assume Gaussian measurement noise; the maximum-likelihood fit minimizes total reprojection error.

Optimizer

Levenberg–Marquardt over cameras $P',P''$ consistent with $T$, started from the linear estimate.

Sampson

First-order approximation of geometric error — a fast stand-in for the full basin.

Printed pp. 391-408Gold Standard Estimate
The gold-standard method assumes Gaussian measurement noise and minimizes total reprojection error over the cameras consistent with the tensor, using Levenberg-Marquardt. The transfer residual landscape sampled in the notebook shows a clean basin whose minimum sits exactly at the correct correspondence, the picture motivating Sampson and full geometric refinement.
