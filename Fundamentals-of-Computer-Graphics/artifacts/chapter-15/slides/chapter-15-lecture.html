Representations

A Curve Is A Point Set; A Representation Is A Query Interface

Membership

Implicit form is natural when the main question is whether a point lies on, inside, or outside a shape.

Evaluation

Parametric form is natural when the renderer needs positions, tangents, samples, and animation states.

Construction

Procedural curves are recipes. The data is a rule, an iteration count, and a starting configuration.

Stress that representation choice changes the natural question. An implicit curve gives a membership test, a parametric curve gives an evaluator, and a procedural rule gives a construction recipe. Rendering and modeling lean on parametric pieces because sampling and interpolation are direct.
Parametric Curves

Reparameterization Changes Timing, Not The Traced Set

\( \tilde{\mathbf{p}}(v)=\mathbf{p}(\phi(v)) \)

Same Geometry

If \( \phi \) is monotone and covers the same interval, the visible point set is unchanged.

Different Speeds

Equal parameter steps can cluster on slow portions and spread out on fast portions.

Rendering Consequence

Stroking, texture coordinates, and camera paths often need distance-aware samples.

Frame reparameterization as a timing change, not a geometric change. Two maps can trace the same point set while placing parameter values at very different visible locations. This is the source of many uneven animation, stroking, and texture placement artifacts.
Arc Length

Distance Along A Curve Is An Integral, Then Usually A Table

\( s(u)=\int_a^u \lVert \mathbf{p}'(t)\rVert\,dt \)

Build

Sample the curve densely, accumulate chord lengths, normalize to distance fraction.

Invert

Given a desired distance fraction, interpolate in the table to recover the parameter.

Check

The cumulative table must be monotone, and equal-distance chords should be less variable.

Arc length is the practical antidote to misleading parameter spacing. Most useful free-form curves do not give a closed-form inverse from distance back to parameter, so graphics systems build a monotone table and interpolate through it. The diagnostic is uniform chord spacing.
Piecewise Curves

Continuity Contracts Say What A Join Must Preserve

\(C^0:\ \mathbf{p}_i(1)=\mathbf{p}_{i+1}(0)\)
\(C^1:\ \mathbf{p}'_i(1)=\mathbf{p}'_{i+1}(0)\)
\(G^1:\ \mathbf{p}'_i(1)=\lambda\,\mathbf{p}'_{i+1}(0),\ \lambda > 0\)

Distinguish Artifacts

A position gap, a corner, and a speed jump are different bugs even when the curves look close.

Treat continuity as a contract between neighboring curve pieces. C0 says the endpoints meet, C1 says the velocity vectors match, and G1 says only tangent direction matches. These are distinct visible and numerical conditions, especially when curves drive motion or shading.
Polynomial Pieces

Local Pieces Make Curves Editable And Testable

\( \mathbf{p}_j(u)=\sum_{r=0}^{d}\mathbf{a}_{jr}u^r,\quad 0\le u\le 1 \)

Why Pieces?

One high-degree polynomial is hard to control. Many low-degree pieces keep edits local.

What Stores?

Each piece stores a basis, input data, and a parameter interval.

What Tests?

Neighboring pieces must satisfy their stated endpoint and derivative constraints.

This slide turns many named curve families into one schema. A piece stores coefficients, a basis turns input data into weights, and constraints decide which coefficients are allowed. The implementation habit is to evaluate locally and check joins globally.
Cubics

Four Degrees Of Freedom Encode Useful Editing Constraints

Hermite

Inputs are endpoints and tangent vectors. The curve is designed around join control.

Lagrange

Inputs are interpolation samples. The curve is designed around passing through data.

Bezier

Inputs are control points. The curve is designed around an editable control polygon.

\( \mathbf{p}(u)=\mathbf{b}(u)^T M\,\mathbf{g} \)
Emphasize why cubics dominate practice. Four scalar degrees of freedom per coordinate are enough for endpoints and tangents, or four control points, while still staying cheap to evaluate. Different cubic bases change the editing interface more than the polynomial space.
Bezier Curves

Bernstein Weights Make A Controlled Average

\( \mathbf{p}(u)=\sum_{i=0}^{n} B_i^n(u)\mathbf{P}_i \)
\( B_i^n(u)=\binom{n}{i}(1-u)^{n-i}u^i \)

Convex Hull

On \(0\le u\le1\), Bernstein weights are nonnegative and sum to one.

Global Segment Control

Moving any control point influences the whole Bezier segment.

Introduce a Bezier segment as a controlled average. Bernstein weights are nonnegative on the unit interval and sum to one, so the curve stays inside the control polygon hull. Moving a control point affects the whole segment, which is powerful but global.
Bezier Evaluation

De Casteljau Turns Evaluation Into Repeated Linear Interpolation

\( \mathbf{P}_i^{(r)}=(1-u)\mathbf{P}_i^{(r-1)}+u\mathbf{P}_{i+1}^{(r-1)} \)

Stable Evaluation

Each new point lies on a segment between two previous-level points.

Subdivision

The left and right staircases become two Bezier curves that exactly reproduce the original trace.

Debug View

The construction exposes every intermediate point, so a bad parameter or control point is visible.

De Casteljau evaluation should feel like geometry, not just arithmetic. Repeated linear interpolation gives the same point as the Bernstein formula, but every intermediate point is inspectable. Subdivision at the chosen parameter produces two smaller Bezier segments with the same trace.
Bezier Piece Joins

Endpoint Handles Translate Continuity Into Authoring Rules

Position

For Bezier pieces, set the last control point of the left segment equal to the first control point of the right segment.

Direction

For \(G^1\), the adjacent handles must lie on the same line through the join.

Derivative Scale

For \(C^1\), the handle lengths must match the derivative scale required by the parameter intervals.

Use the handle diagram to connect continuity definitions to authoring practice. Bezier pieces meet in position when endpoints coincide, become G1 when the handles are collinear, and become C1 when the handle lengths match the derivative scale across the join.
B-Splines

Local Basis Functions Give Local Control

\( \mathbf{C}(t)=\sum_i N_{i,p}(t)\mathbf{P}_i \)

Local Support

For degree \(p\), at most \(p+1\) basis functions are active at a generic parameter.

Partition Of Unity

The active basis weights sum to one, keeping affine behavior predictable.

Editing Consequence

Moving one control point changes only the parameter range where its basis is nonzero.

B-splines are the locality answer to Bezier global control. The curve is still a weighted sum of control points, but only a few basis functions are nonzero at any parameter. The partition of unity keeps affine transformations and translation behavior predictable.
Knot Vectors

Knots Schedule Support And Spend Smoothness

degree \(p\), knot multiplicity \(m\): smoothness \(C^{p-m}\)

Uniform

Even spacing gives a regular parameter schedule and predictable basis shapes.

Nonuniform

Uneven spacing concentrates parameter influence where the model needs detail.

Repeated

Endpoint repetition can force interpolation; interior repetition can create a deliberate crease.

Explain knots as the parameter schedule that decides where basis functions turn on and off. Nonuniform knots concentrate detail, endpoint repetition forces interpolation, and interior repetition reduces smoothness. The useful mental model is trading smooth flow for intentional control.
NURBS

Rational Weights Pull Curves And Represent Conics Exactly

\( \mathbf{C}(t)=\dfrac{\sum_i w_iN_{i,p}(t)\mathbf{P}_i}{\sum_i w_iN_{i,p}(t)} \)

Weight As Attraction

Increasing \(w_i\) pulls the curve toward control point \(\mathbf{P}_i\) without moving the point itself.

Projective View

Evaluate a polynomial curve in homogeneous coordinates, then divide by the weighted coordinate.

Exact Conics

A rational quadratic with middle weight \(\sqrt{2}/2\) represents a quarter circle.

NURBS add one more lever: weights. The weighted numerator and denominator form a rational curve, so changing a weight pulls the curve toward or away from a control point. That rational form is why conic sections can be represented exactly.

Make the checks feel like engineering rather than ceremony. A robust curve evaluator verifies membership residuals, monotone arc tables, continuity residuals, partition of unity, locality, and rational conic accuracy. Each check corresponds to a visible failure mode in modeling or rendering.
Editing Behavior

Bezier Is Compact; B-Spline Is Local

Bezier Use Case

Icons, glyph outlines, and short authored segments where a compact handle set is natural.

B-Spline Use Case

Long smooth paths, CAD curves, and editable trajectories where local modification is valuable.

Design Question

Should one edit reshape the whole segment or only a neighborhood?

editing behavior is part of the representation
The comparison slide is about editing psychology. Bezier control is compact and expressive for one segment, but a single handle can affect the whole segment. B-spline control spreads a longer curve across local supports, so edits stay contained.
