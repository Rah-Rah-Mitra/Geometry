Fundamentals of Computer Graphics - Chapter 07

Transformation Matrices

Matrices become the common language for moving models, composing edits, carrying points between coordinate frames, and keeping normals meaningful after deformation.

Source span: printed pages 127-156; PDF pages 144-173.

Notebook: chapter-07-transformation-matrices/07-transformation-matrices.ipynb

Lecture promise: every matrix is read as a geometric claim, then tested by basis vectors, determinants, inverses, and frame labels.

Open by framing transformation matrices as a compact contract between geometry and code. The chapter is not just about memorizing scale or rotation patterns; it is about learning to read what a matrix promises to do, test that promise on basis vectors, and keep coordinate spaces explicit.

1. Linear maps move the basis first

Read a 2 x 2 Matrix by Its Columns

A = [ a1 a2 ],   A e1 = a1,   A e2 = a2

Once the two basis arrows are known, every point follows by the same linear combination.

  • Grid squares become parallelograms.
  • A determinant gives signed area scale.
  • A negative determinant flags an orientation flip.
Use this slide to make the column convention physical. Ask students where the canonical x and y arrows land, then reconstruct a generic point as a weighted sum of those two images. The determinant is introduced as a measurement tool, not an abstract number floating above the diagram.

2. Elementary transformations

Scale, Shear, Rotation, Reflection

Axis scale

[ sx 0 ; 0 sy ]

Diagonal entries change unit lengths along coordinate axes.

Horizontal shear

[ 1 h ; 0 1 ]

One basis arrow stays fixed while the other tilts.

Rotation

[ c -s ; s c ]

Columns stay orthonormal and determinant remains +1.

Reflection

[ -1 0 ; 0 1 ]

One axis reverses, so handedness changes sign.

Uniform scale

k I

Angles survive; area changes by k squared.

Rigid 2D motion

R plus t

Rotation and translation preserve distances.

The asymmetric marker prevents a false sense that all transformations are interchangeable. A circle becoming an ellipse diagnoses stretching or shearing, while the little protrusion exposes rotations and reflections. Emphasize that matrix patterns are memorable because they describe where basis arrows and simple test shapes land.

3. Composition order is geometry

Column Vectors Read Products from Right to Left

p' = R S p

The scale acts first, then the rotation. Multiplication is associative, so the product can be cached as one matrix.

R S != S R

Changing the order usually changes which axes are stretched, even when the determinant is the same.

Slow down on the convention, because many graphics bugs begin here. With column vectors, the rightmost matrix touches the point first. The same pair of matrices can preserve the same area scale while giving a visibly different result, so visual debugging should always include the intended order.

4. Products build new operations

Rotate Around a Point by Moving the Pivot

The simple rotation matrix knows only how to rotate about the origin.

To rotate about a chosen pivot, translate the pivot to the origin, rotate, and translate back.

The product order records the story in reverse reading order: T(q) R T(-q).

This pivot slide turns composition into a design pattern. Students already know translation and rotation separately; the useful graphics move is to surround a simple operation with coordinate changes. The pivot formula also prepares them for camera and object transforms, where moving the frame is often clearer than moving every point.

5. Decomposition makes a matrix inspectable

Symmetric Maps Are Scales Along Rotated Axes

A = R S RT

Rotate principal directions to the coordinate axes, scale there, then rotate back.

  • The unit circle becomes an ellipse.
  • Eigenvectors give the ellipse axes.
  • Eigenvalues give signed scale factors.
Present the symmetric case as a readable special case rather than as a prerequisite for numerical linear algebra. The picture says that a symmetric matrix has no hidden twist between input and output frames. It only chooses perpendicular axes, stretches by factors, and returns those axes to the plane.

6. General linear maps

SVD Uses One Input Frame and One Output Frame

The right singular vectors name the directions that arrive at clean axis scales.

The left singular vectors name the final directions after the scale has acted.

Tiny singular values warn that inverses and normal matrices may amplify noise.

The SVD slide extends the eigen-decomposition picture without making the algebra feel mysterious. For a general matrix, the useful diagnostic is that the best input axes and output axes need not coincide. That distinction explains shear-like behavior and previews why numerical conditioning matters for inverse transforms.

7. Translation joins matrix multiplication

Homogeneous Coordinates Separate Points from Directions

point: [ x y 1 ]T

The translation column contributes because the final coordinate is one.

direction: [ x y 0 ]T

The same numeric pair behaves as an offset and ignores translation.

[ A t ; 0 1 ] [ p ; 1 ] = [ A p + t ; 1 ]

xw, y + tyw, w)
This is the conceptual payoff for homogeneous coordinates. The final coordinate is not a technical nuisance; it is a type tag. Points have locations and should move under translation, while directions describe offsets and should keep the same arrow when the origin changes.

8. Affine matrices in graphics

The 4 x 4 Block Form Keeps Linear and Translation Parts Visible

M = [ A t ; 0 1 ]

A stores the linear part. The final column stores translation.

Rigid body transform: A is orthogonal and det(A) = +1.

General affine transform: A may scale, shear, or reflect, so distances and normals need extra care.

Connect the matrix layout to what students will see in APIs and shaders. The block form makes debugging practical: the upper-left block answers what happened to directions, the right column answers what happened to points, and the bottom row tells whether this is still an affine transform.

9. Windowing as a constructive product

Map One Rectangle to Another with Translate, Scale, Translate

Move the source lower-left corner to the origin.

Scale width and height to match the target rectangle.

Move the origin to the target lower-left corner.

M = T(target low) S(target size/source size) T(-source low)

Windowing is a concrete example where the product is more transparent than the final matrix entries. The point is not to memorize a large formula. The point is to build the mapping from operations whose intent is inspectable, then multiply them only when the renderer needs a single matrix.

10. Inverses undo the geometric story

Reverse the Order and Invert Each Step

(M1 M2 ... Mn)-1 = Mn-1 ... M2-1 M1-1

  • Scale inverse: reciprocal scale factors.
  • Rotation inverse: transpose when orthogonal.
  • Translation inverse: move by the opposite vector.
  • Near-zero determinant: inverse may be unstable or impossible.
The inverse rule should be taught as undoing a recipe, not as a formal trick. If shoes go on before laces, laces come off before shoes. In graphics terms, this is why object-to-world and world-to-object matrices are paired, and why cached inverses must be updated after composition changes.

11. 3D rotations are frame operations

An Axis Rotation Keeps One Direction Fixed

Choose an orthonormal frame whose third basis vector is the desired axis.

Rotate in the simple local z-axis frame, then convert back.

RT R = I,   det(R) = +1

Those two checks separate pure rotations from scaled or reflected impostors.

In three dimensions, a rotation angle alone is incomplete; the axis and frame matter. Guide students to think constructively: build a basis around the axis, perform the familiar z-axis rotation locally, then convert back. Orthogonality and determinant checks are the quick sanity tests.

12. Normals are covectors in disguise

Normals Need the Inverse Transpose

Tangents follow the surface: t' = M t.

Normals must remain perpendicular to every transformed tangent.

n' = (M-1)T n

Then (n')T(M t) = nTt = 0.

The normal matrix is often presented as a rule to memorize, so ground it in the dot product invariant. A normal is defined by what it annihilates: all tangent directions. After a nonuniform transform, applying M to the normal usually breaks that zero dot product condition.

13. Coordinate transformations

A Frame Matrix Stores Basis Vectors and Origin as Columns

F = [ u v e ; 0 0 1 ]

Frame-to-canonical: local coordinates become world coordinates.

The inverse converts world coordinates back into the local frame.

The same matrix can be read as moving geometry or changing the coordinate language.

This frame slide is the bridge from algebra to scene organization. A frame is not just a drawing of axes; it is a coordinate converter. Encourage students to say the source space and destination space aloud before multiplying, because the same numbers can represent movement or re-expression.

14. Graphics code labels every space

Model, World, and Camera Matrices Are Coordinate Converters

model_to_world places object-local vertices into the shared scene frame.

world_to_camera expresses the same world points in the viewer's frame.

The inverse names the opposite conversion and should be treated as a different object in code.

Relate the formal frame discussion to naming habits in a renderer. Matrix variables are safer when their names include both source and destination spaces. A matrix that looks mathematically valid can still be semantically wrong if it converts camera coordinates when the shader expects world coordinates.

15. Debugging matrix payloads

A Practical Transform Checklist

Affine?

Bottom row should be 0 0 0 1 before treating a 4 x 4 as affine.

Rigid?

Check ATA = I and determinant +1 before using transpose as inverse.

Invertible?

A determinant near zero means flattened geometry and unstable inverse calculations.

Handedness?

Negative determinant means orientation flipped; normals and winding may need attention.

Normals?

Use inverse-transpose unless the linear block is a pure rotation.

Spaces?

Every vector should carry its coordinate frame in code, comments, or type names.

Make the checklist feel operational. In real graphics code, matrices arrive from loaders, animation systems, UI widgets, and shaders. The fastest way to find the bug is to ask small invariant questions: affine bottom row, determinant sign, orthogonality, conditioning, and whether normals are being transformed with the right matrix.

16. Worked classification

What Does This Matrix Claim?

M = [ 0 -2 4 ; 1 0 3 ; 0 0 1 ]

  • Column one sends the x basis to (0,1).
  • Column two sends the y basis to (-2,0).
  • Translation sends the origin to (4,3).
  • det(A) = 2, so signed area doubles without flipping.
Use this as a short board exercise before revealing the annotations. Students should identify the linear block, the translation column, the images of the basis vectors, and the determinant. The example reinforces that reading a transform is faster and less error-prone than sampling many unrelated points.

17. Takeaways

Transformation Matrices Are Compact Geometric Claims

Columns tell where basis vectors go; determinants tell signed area or volume scale.

Products encode operation order; inverses undo the story in reverse.

Points, directions, and normals are different geometric types and transform differently.

Frame labels prevent model, world, camera, and shader-space confusion.

Close by gathering the habits rather than listing formulas. The durable skill is to interrogate a matrix: what spaces does it connect, where do its columns send the basis, what happens to area or volume, how is it inverted, and which geometric type is being transformed.
