Lecture Map

Four Questions For A Color Pipeline

Every bug in the chapter can be phrased as doing the right operation in the wrong space.
1. Measurement How does a continuous spectrum become \(X,Y,Z\) tristimulus coordinates?
2. Representation Which primaries, white point, matrix, and transfer curve define the space?
3. Arithmetic Which values are linear light, and which are display or storage codes?
4. Appearance When do two numerical differences produce the same visual difference?
Working habit: attach a name to every color triple before transforming, averaging, filtering, quantizing, or comparing it.

Frame the chapter as four engineering questions. First, how does a spectrum become three numbers? Second, when do those numbers define a color space? Third, what must be linear before arithmetic is meaningful? Fourth, why do equal coordinate steps fail to imply equal perceptual steps? This outline will organize the later debugging checklist.
Colorimetry

Spectra Are Functions; XYZ Is Three Integrals

A renderer may sample wavelengths, but a standard observer reports three weighted sums.
Standard observer computation
\(X = k\int \Phi(\lambda)\bar{x}(\lambda)d\lambda\)
\(Y = k\int \Phi(\lambda)\bar{y}(\lambda)d\lambda\)
\(Z = k\int \Phi(\lambda)\bar{z}(\lambda)d\lambda\)
  • \(\Phi(\lambda)\) is spectral power, not a color triple.
  • \(\bar{y}(\lambda)\) is aligned with photopic luminance in the CIE 1931 observer.
  • The integral compresses many wavelength samples into three responses.
Use this slide to slow down the common misconception that RGB is where color begins. The physical input is a spectrum, while the colorimetric output is obtained by integrating that spectrum against observer functions. Emphasize that this compression is intentional and powerful, but it permanently discards spectral detail.
Color Matching

Metamers: Different Spectra, Same Response

The notebook constructs a smooth spectral null direction whose XYZ response is essentially zero.
Metamerism
Two spectral stimuli can produce matching tristimulus values for the same observer even when their wavelength distributions differ substantially.
Notebook checks
  • metamer residual: \(2.5\cdot10^{-15}\)
  • Grassmann linearity error: \(1.9\cdot10^{-13}\)
  • color reproduction works because matches are observer matches, not spectrum copies
Connect this directly to displays and printing. A monitor does not recreate the daylight spectrum, and it does not need to if the observer response matches. The same fact also explains why spectral reconstruction from RGB is underdetermined. Mention that Grassmann linearity lets mixtures behave predictably under the measurement integrals.
CIE 1931

XYZ Trades Physical Primaries For A Stable Reference

The \(X,Y,Z\) basis is device independent, but the primaries are mathematical rather than buildable lights.
Why introduce XYZ?
  • Real RGB matching functions can contain negative lobes.
  • Positive matching functions are easier to use as a common measurement language.
  • \(Y\) is chosen to carry luminance information.
  • XYZ becomes a hub for transforms among device spaces.
Practical interpretation: XYZ is not the display format; it is the shared measurement coordinate system used to move between formats with known definitions.
Stress the distinction between measurement convenience and physical emission. XYZ is deliberately designed as a stable reference for communicating color matches, not as a recipe for three lamps in a display. Students should see why the chapter repeatedly returns to XYZ before entering RGB, Lab, or cone-response spaces.
Chromaticity Geometry

Projecting XYZ Reveals Gamut, Not Perceptual Distance

The \(xy\) diagram divides out scale; \(u'v'\) redistributes the same measured colors.
Projection
\(x = X/(X+Y+Z)\)
\(y = Y/(X+Y+Z)\)
  • Luminance is removed; \(Y\) must be retained separately when brightness matters.
  • All additive mixtures of three primaries lie inside their triangle.
  • Diagram distances are geometric, not automatically perceptual.
  • The notebook finds 383 sampled spectral-locus points outside the sRGB triangle.
Use the triangle as the key geometric object. The spectral locus marks possible monochromatic measurements, while the display can only produce mixtures inside its primary triangle. Then warn that the picture tempts students to measure visual difference with a ruler. Chromaticity diagrams are excellent for gamut reasoning, but they are incomplete appearance models.

Construction recipe
Convert each primary chromaticity \((x_i,y_i)\) to an XYZ direction with \(Y=1\), then solve for scale factors so RGB white lands on the specified display white.

  • RGB values without a white point are incomplete.
  • RGB values without a transfer curve may not be linear light.

Make the contract idea explicit. The letters R, G, and B only become physically meaningful after the primaries, white point, matrix, and transfer curve are known. The displayed matrix is a compact way to say how this particular RGB space communicates with XYZ. Without the contract, the same numeric triple can mean different colors.
Encoding

sRGB Code Values Are Not Linear Light

Encoding allocates code precision to perceptually sensitive ranges; arithmetic should usually happen after decoding.
Common bug
Averaging encoded sRGB values mixes display codes, not radiance. In the notebook's test, the wrong encoded mix keeps only about 0.43 of the luminance of the correct linear-light mix.
  • Decode sRGB to linear RGB before interpolation, shading, blur, and compositing.
  • Encode again only when storing or presenting to an sRGB target.
  • Quantization error is largest when the pipeline compresses too early.
Treat the transfer function as an engineering design, not as a mysterious gamma decoration. It improves coding efficiency by bending the relationship between linear light and stored values. The cost is that ordinary arithmetic on encoded values becomes physically wrong. Ask students to name which side of the curve their data is on before any operation.
Transform Discipline

Move Through Spaces Deliberately

The same three numbers can be samples, measurements, display drives, code values, or appearance coordinates.
Rule of thumb: If a transform changes interpretation, label the result immediately. If an operation assumes radiance, decode and linearize first.
This is the slide where the lecture turns into a workflow. Have students read the diagram as a type system for color triples. A value leaving an image file is not automatically linear RGB. A value leaving XYZ is not automatically displayable. The safe move is to annotate the space at every boundary.
Chromatic Adaptation

White Balance As Cone-Space Gain Control

The von Kries model maps XYZ into LMS, scales channels independently, then maps back.
von Kries form
\(L' = \alpha L,\quad M' = \beta M,\quad S' = \gamma S\)
\(\alpha,\beta,\gamma\) come from adapting whites.
  • Adaptation models color constancy under changed illumination.
  • Scaling happens in a cone-response basis, not directly in sRGB code space.
  • Quantizing before adaptation can amplify visible errors.
Explain chromatic adaptation as a controlled simplification of the visual system. The eye largely discounts the color of the illuminant, so a white object can continue to look white under many lights. In the von Kries model, the computational proxy is diagonal scaling in LMS space. Keep warning that code-space white balance is a different and riskier operation.
Appearance

Color Is Measured, Then Interpreted In Context

A tristimulus match is not a complete description of visual experience.
Why appearance models exist
XYZ and chromatic adaptation predict matches under controlled conditions. Appearance also depends on surround, adaptation state, luminance level, display medium, and the viewer's visual context.
  • Color constancy is useful but not perfect.
  • Brightness, colorfulness, and hue perception can shift with context.
  • A color-management pipeline should track the intended viewing condition.
Position color appearance as the chapter's reminder that colorimetry is a model of matches, not a complete theory of seeing. The same stimulus can be judged differently as the surround and adaptation state change. This matters when images move from a calibrated monitor to projection, print, mobile screens, or dim presentation rooms.
Perceptual Distances

L*a*b* Separates Lightness From Opponent Axes

Lab is useful for approximate differences, but it is not a chromaticity diagram and still needs a white reference.
Delta E habit
Convert comparable colors into Lab under the same white reference, then compute an approximate perceptual distance in that space.

Use Lab to give students a practical alternative to raw RGB distance. Equal numerical RGB steps can produce different visual effects because the transform is nonlinear and tied to a reference white. Delta E is still an approximation, so the correct message is not that Lab is perfect, but that it is often a better diagnostic than channel distance.
Applied Lab

A Compact Color-Management Debugging Routine

The notebook sanity checks are a practical contract for color transforms.
Before an operation
  • Name the current space and white point.
  • Decode transfer curves before linear operations.
  • Transform through XYZ when moving between known RGB spaces.
  • Adapt whites in LMS, then transform back to the target space.
  • Quantize and clamp at the boundary, not in the middle.
Checks worth automating
  • Matrix inverse residual is near floating-point zero.
  • Display white maps to the expected chromaticity.
  • Transfer encode/decode round-trips on test ramps.
  • Adaptation maps source white to target white.
  • Delta E flags perceptually visible edits.
Pipeline invariant: do not throw away precision or meaning before the next operation has had the information it needs.
Turn the chapter into concrete habits that students can carry into rendering assignments. Many color errors are not exotic; they are space-label errors, premature quantization, or arithmetic on encoded values. The notebook checks show how to make those mistakes visible with small synthetic data before they become hard-to-debug image artifacts.
Recap

Color Is A Chain Of Models

No single coordinate system answers every question.
Keep: spectra explain metamerism; XYZ standardizes observer matches; RGB becomes meaningful only with its contract.
Watch: chromaticity loses luminance; sRGB codes are nonlinear; perceptual distance needs an appearance-aware space.
Close by returning to the chain. Each model removes, preserves, or reinterprets information for a purpose. The successful graphics programmer does not memorize one universal color space; they choose the model whose assumptions match the operation. That is the core lesson connecting colorimetry, spaces, adaptation, appearance, and perceptual distance.
