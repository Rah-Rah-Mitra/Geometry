Section 12.1

Indexed Meshes Optimize Transfer, Not Surgery

Fast Answer

Which vertex positions form this triangle for drawing or transfer to a graphics API?

Slow Answer

Which faces touch vertex v, or which triangle lies across this directed edge?

DiagnosticShared vertices reduce duplication, but adjacency still requires a scan unless extra connectivity is stored.
Separate draw storage from mesh topology early. The indexed mesh is excellent when the GPU needs positions and face indices, but it cannot answer neighborhood questions by itself. Ask students which operation each column supports quickly, then point out that compactness and editability are different design goals.
Topology checks

A Tiny Mesh Can Audit A Large One

Closed Edge Rule

Every undirected edge has exactly two incident triangles in a closed triangular surface.

Orientation Rule

Across a shared edge, the two faces should list opposite directed edge orders.

Euler Check

For a sphere-like closed mesh, V - E + F = 2 is a compact sanity test.

Treat the small pyramid as an audit object rather than a pretty model. Closed edges should have two incident faces, oriented edges should appear with opposite directions across a shared side, and Euler characteristic should match the expected sphere-like topology. These checks catch invisible connectivity errors.
Triangle strips and fans

Compress Coherent Runs, Then Remember The Parity

Win

Fewer vertex references when adjacent triangles form a predictable sequence.

Catch

Consecutive strip triangles flip orientation unless the interpretation alternates order.

n strip vertices → n - 2 triangles
Triangle strips and fans are best presented as bandwidth structures. They reduce repeated vertex references for a coherent run of triangles, while a parity rule keeps orientations consistent. They are not a general answer to mesh surgery, because local editing still needs explicit adjacency information.
Connectivity records

Choose The Pointer Graph For The Walk You Need

Triangle-Neighbor

Lean and effective when all faces are triangles.

Winged-Edge

Edge-centered, useful for general polygon meshes.

Half-Edge

Directional traversal makes one-ring walks explicit.

Compare the three connectivity choices by the walk they enable. Triangle-neighbor storage is lean for triangle-only meshes, winged-edge generalizes around edges, and half-edge makes directional local traversal explicit. The cost is pointer volume and update discipline whenever topology changes.
Section 12.2

Scene Graphs Store Local Motion On Paths

Fast Answer

What transform carries this object's local coordinates into world coordinates?

Local Edit

Move the car relative to the ferry without rewriting wheel, ferry, or world data.

world = I enter(node): world = world * node.local draw(node.geometry, world) visit(children) restore parent world
The scene graph slide should feel like a matrix stack made visible. Local transforms stay attached to nodes, and a traversal multiplies along the current path. Changing the car node moves its wheels, while rotating a wheel should not rewrite the ferry, mast, or world transform.
Instancing in ray tracing

Move The Ray Into The Object, Not The Object Into Memory

Instance Record

One local object plus a transform. Many world placements can share the same geometry.

Hit Test

Apply the inverse transform to the ray, intersect the simple local object, then map hit information back.

rayworld → T-1(ray) → local hit → world record
Connect instancing to the same ownership idea as scene graphs. A transformed object can keep one local shape, while each ray is mapped backward into that local coordinate system. This avoids duplicating geometry and explains why ray parameters must be treated carefully under nonuniform transforms.
Section 12.3

Spatial Structures Cull Before They Intersect

Box

Convert geometry to intervals along a ray.

Question: can this box be reached at any t?

BVH

Group objects in a hierarchy of enclosing boxes.

Boxes may overlap; objects live in one branch.

Grid

Partition space into cells and walk them in ray order.

Cells are disjoint; objects may occupy many cells.

BSP

Recursively split space with signed planes.

Crossing primitives require duplication or cutting.
This taxonomy prevents a common confusion. A BVH groups objects and allows overlapping boxes, a grid partitions space and lets objects occupy multiple cells, and a BSP recursively cuts space with planes. All reduce candidate tests, but they distribute responsibility differently.
Bounding boxes

The Slab Test Is Interval Overlap

Hit

The ray interval that satisfies the x slab overlaps the interval that satisfies the y slab.

Miss

If any axis interval is empty, or the running enter value exceeds the running exit value, reject.

Parallel Case

A parallel ray inside a slab imposes no new bound; outside the slab, it misses immediately.

Make the slab test concrete by reading intervals on the ray. Each axis gives an entering and leaving range, and the box is hit only when the ranges overlap. The two parallel-ray cases are the useful edge cases: inside the slab survives, outside the slab rejects immediately.
Hierarchical bounding boxes

BVHs Delay Primitive Tests Until A Box Survives

Object Hierarchy

Each primitive belongs to one subtree, even when sibling bounding boxes overlap in space.

Traversal Rule

Reject empty box intervals. Descend into surviving children. Test primitives only at leaves.

Brute forceTest every primitive against the ray.
BVHSpend cheap box tests to avoid expensive primitive tests.
A BVH traversal is a disciplined refusal to test primitives too early. The ray first asks whether a node box can be hit, descends only into surviving children, and tests leaves after interval pruning. The hierarchy is object-based, so sibling boxes may overlap without violating the structure.
Uniform spatial subdivision

A Grid Turns Ray Traversal Into Cell Events

Preprocess

Register each primitive in every cell touched by its bounding box.

Traversal

March cells in increasing ray order and test only the candidates found there.

Failure Mode

Large primitives or clustered scenes can overload many cells and erase the expected gain.

Explain the grid as a spatial calendar for the ray. The DDA walk enumerates cells in increasing ray order, and each cell exposes only the primitives registered there. It shines when occupancy is balanced, but large or uneven objects can inflate candidate lists across many cells.
Axis-aligned BSP and kd-style trees

Splitting Space Changes Candidate Ownership

Near/Far Decision

A ray knows which child it enters first by comparing its origin and direction to the split plane.

Duplication Cost

A primitive that spans a split can appear in both children unless the implementation cuts it.

Selection Heuristic

Good splits reduce overlap, balance work, and avoid fragmenting geometry too aggressively.

Axis-aligned BSP and kd-style splits are about recursive half-spaces. They give clean near and far ordering for rays, but primitives that straddle a plane must be duplicated or split. That tradeoff is why split selection matters more than the drawing of the tree suggests.
Section 12.4

Visibility BSP Traversal Depends On The Eye Sign

Build Once

Choose polygon planes, classify primitives, and store a binary tree of signed half-spaces.

Draw Many

For a viewer, draw far side, then the splitter polygon, then near side.

if f(eye) > 0: draw negative, root, positive
For visibility BSP trees, emphasize that the viewer position changes traversal order, not the tree itself. The signed plane function classifies the eye, then the far side is drawn before the root polygon and the near side. This is a painter-style ordering argument.
Cutting triangles

Robust Splits Preserve Area And Orientation

Epsilon Band

Vertices nearly on the plane should snap consistently instead of creating unstable sliver pieces.

Orientation

Child triangles inherit winding so normals and front-facing tests remain meaningful.

Invariant

Children should not cross the same splitter after the cut, and their areas should add up.

Triangle cutting is the robustness slide. A good split preserves orientation, avoids tiny numerical classifications near the plane, and conserves area when child pieces are added. The epsilon band is not decorative; it prevents a nearly-on-plane vertex from manufacturing unstable slivers.
Section 12.5

Tiling Makes Locality An Indexing Decision

Row-Major

Horizontal neighbors are adjacent. Vertical neighbors are separated by a full row stride.

Tiled

Small two-dimensional neighborhoods are stored inside short contiguous blocks.

address = tile base + local y * tile + local x
Use the address diagrams to move from geometry to memory. Row-major order keeps horizontal neighbors close but separates vertical neighbors by a row stride. Tiling makes short two-dimensional neighborhoods more local, while padding and tile size become measurable costs rather than implementation trivia.
