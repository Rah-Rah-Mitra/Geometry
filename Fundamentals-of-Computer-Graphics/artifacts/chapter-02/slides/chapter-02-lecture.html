Sets, Mappings, Inverses
A formula is not a function until its domain is fixed.

Domains Control Whether Inverses Exist

Definition Pattern

f : A -> B,   image f(S),   inverse f-1

The same expression can define different functions when the legal input set changes.

Failure Mode

Two distinct inputs mapping to one output make a single-valued inverse impossible. Graphics code often hides this mistake as a branch ambiguity, a wrong sign, or a missing intersection.

Notebook Check

After restricting the square map to nonnegative inputs, the round-trip error for sqrt(x^2) is checked numerically.

Mapping notation behaves like a typed function signature.Source section 2.1
Emphasize that domain information is not cosmetic notation. A ray routine, texture lookup, or logarithm call has the same issue as the square function: the output can only be interpreted correctly when the allowed inputs and endpoint conventions are explicit. The square example is useful because everyone can see the inverse problem immediately.
Intervals And Logs
Boundary conventions are algorithmic choices.

Intervals Are Small Data Structures

Contract

log(exp(x)) = x   and   exp(log(y)) = y only when y > 0

Boundary mistakes are especially visible in clipping, ray parameter intervals, and texture-coordinate wrapping.

Intervals encode both extent and membership rules.Source sections 2.1.2-2.1.3
Use this slide to slow down on endpoints. Many graphics algorithms carry an interval for a ray parameter, a clipping window, or a valid texture coordinate range. Whether an endpoint is included can decide if a hit is accepted twice, rejected entirely, or allowed to pass into an inverse such as a logarithm.
Quadratics
Ray intersections often reduce to a polynomial.

Algebraically Correct Is Not Always Numerically Stable

Cancellation Risk

x = (-b +/- sqrt(b2 - 4ac)) / (2a)

When b and sqrt(D) are nearly equal, the small root can lose significant digits.

Stable Pairing

q = -0.5(b + sign(b)sqrt(D)),   r0 = q/a,   r1 = c/q

  • Check the discriminant before taking the square root.
  • Sort roots according to the ray interval contract.
  • Verify residuals when debugging missed hits.
Numerical stability is a geometric correctness issue.Source section 2.2
Connect the stable quadratic formula directly to graphics practice. A missed small root can mean a ray starts just outside an object but fails to find the first hit, or a visibility query jumps to a farther surface. The residual plot in the notebook is not decoration; it is a practical test for root quality.

Vectors
Length, direction, projection, area, and handedness.

Dot And Cross Products Are Geometry Tests

Dot Product

a dot b = |a| |b| cos theta

Use it for projection, angle tests, and orthogonality.

Cross Product

|a x b| = |a| |b| sin theta

Use it for oriented area, normals, and right-handed frame construction.

Type Discipline

A point is not a vector. A displacement can be added to a point, and two points can define a displacement, but adding two locations is usually a modeling error.

The notebook checks dot, cross, angle, and area invariants.Source section 2.4
Stress that vector operations are not merely formulas to memorize. The dot product asks how much one direction agrees with another, while the cross product measures an oriented area and supplies a perpendicular direction. Those meanings are what let a renderer test normals, projections, handedness, and frame quality.
Coordinate Frames
A frame is trustworthy only when it passes its checks.

Build Frames, Then Audit Them

Orthonormal Basis Check

G = [u v w]T[u v w] = I,   det[u v w] > 0

  • Start with a known direction, often a surface normal.
  • Choose a helper vector that is not nearly collinear.
  • Use cross products to make perpendicular directions.
  • Use the Gram matrix and determinant as final tests.
Common Failure

Almost perpendicular is not enough. Tiny errors can accumulate when a camera, shading frame, or animation rig repeatedly updates a frame.

Frame repair is a debugging and rendering habit.Source sections 2.4.5-2.4.8
This slide should make the frame checks feel concrete. An orthonormal frame is not guaranteed because three vectors look roughly perpendicular on screen. The Gram matrix tests lengths and dot products, while the determinant detects a left-handed frame that would flip normals, texture orientation, or camera roll.
Integration And Density
Units explain what an integral is accumulating.

Read An Integral As Amount From Density

Reading Template

integral = density value x domain measure, accumulated over the domain

Density TypeDomain MeasureGraphics Example
per lengthdistancecurve samples
per areasurface areatexture or irradiance
per directionsolid angleincoming light
Why It Matters

A density cannot be compared to an amount until it is multiplied by the size of the domain it lives on.

Density language prepares the Monte Carlo estimator.Source sections 2.5-2.6
Treat integration as a unit-checking activity. Learners should ask what quantity is being accumulated, what domain it is accumulated over, and which measure belongs to that domain. This prevents common graphics mistakes such as treating a probability density, a surface density, or a solid-angle density as if it were already a plain amount.
Implicit Curves And Surfaces
Membership tests and normals come from scalar fields.

Implicit Geometry Answers: Is This Point On The Shape?

Definition

curve: f(x,y) = 0    surface: f(x,y,z) = 0

The sign of f often gives inside or outside information.

Normal Direction

normal proportional to grad f

The gradient points in the direction of fastest increase and is perpendicular to the level set.

Orientation Caveat

Multiplying f by a negative constant leaves the surface unchanged but reverses the gradient direction.

Implicit geometry is strong for tests, classification, and normals.Source sections 2.7.1-2.7.5
Point out that implicit geometry is excellent when an algorithm needs to ask whether a point satisfies a condition. The gradient gives a normal without explicitly walking over the shape, but the equation can be scaled or negated, so orientation must be chosen deliberately before using the normal in lighting.
Parametric Curves And Surfaces
Traversal and tangents come from a map.

Parametric Geometry Answers: How Do We Generate Points?

Map Form

curve p(t) in R2 or R3,   surface p(u,v) in R3

Differential Data

pu, pv are tangent; pu x pv is normal

  • Line segments, rays, circles, and surface patches are naturally parameterized.
  • Parameter domains define where traversal starts and stops.
  • Normals depend on parameter order through the right-hand rule.
The notebook uses a rotatable torus surface to inspect tangents and normals.Source sections 2.7.6-2.7.9
Contrast this with the implicit slide. Parametric geometry is valuable when the renderer needs to generate points, walk along a curve, draw a surface patch, or sample a domain. The two tangent derivatives give local directions, and their cross product supplies a normal whose orientation depends on the chosen parameter order.
Linear Interpolation
A weighted average becomes a geometric position.

Lerp Turns A Parameter Into A Point

Segment Formula

p(t) = (1 - t)a + tb

When 0 <= t <= 1, the point lies on the segment. Outside that interval, the same formula extrapolates.

Attribute Formula

c(t) = (1 - t)ca + tcb

Positions, colors, depths, normals, and texture coordinates all use the same affine bookkeeping.

Affine weights are the bridge from positions to attributes.Source section 2.8
Make interpolation feel like a data movement rule. The same pair of weights that locates a point on a segment can also move an attribute between endpoint values. That is why linear interpolation reappears in rasterization, depth buffering, texture lookup, animation curves, and shading calculations.
Triangles And Barycentric Coordinates
The segment idea extends to three weights.

Barycentric Coordinates Are Triangle Weights

Inside Test

alpha, beta, gamma >= 0 and alpha + beta + gamma = 1

Area Interpretation

Each coordinate can be computed as a signed subtriangle area divided by the whole triangle area.

QuantityInterpolated By
colorvertex color weights
depthscreen-space triangle weights
texture coordinateper-vertex UV weights
normalweighted then normalized
Negative barycentric weights are useful diagnostics.Source section 2.9
Explain barycentric coordinates as interpolation weights rather than as abstract triangle algebra. If all three weights are nonnegative and sum to one, the point is inside. If one weight is negative, the point lies outside across the opposite edge. This makes barycentrics a compact language for rasterization and attribute interpolation.
Probability
Normalization before expectation.

PMFs And PDFs Are Bookkeeping Systems

Crucial Distinction

For a continuous variable, a single exact value has probability zero; intervals receive probability by integrating density.

Probability controls randomized graphics algorithms.Source sections 2.10-2.11
Keep the distinction between discrete and continuous probability explicit. A PMF assigns mass to outcomes, while a PDF assigns density that must be integrated over an interval. This prepares students to understand why renderers divide by the sampling density rather than by a raw count alone.
Monte Carlo Integration
Random samples become unbiased estimates when weighted correctly.

The Estimator Must Match The Sampling Density

Estimator

Integral of f approx (1/N) sum f(x_i) / p(x_i),   x_i sampled from p

Importance Sampling

Draw more samples where the integrand is large, then compensate by dividing by the density used to generate those samples.

Variance Warning

Unbiased does not mean low noise. A poor sampling density can converge slowly even when the formula is correct.

The notebook compares uniform and importance estimates for exp(-3x).Source section 2.12
The estimator is the heart of the probability portion. Students should read each term aloud: choose samples using density p, evaluate the function, divide by p to remove the sampling preference, and average. Importance sampling is not cheating; it is a change of sampling strategy with a required correction.
Applied Lab
A miniature graphics task ties the chapter together.

Average An Attribute Over A Triangle

Barycentric Sample

P = alpha A + beta B + gamma C

value(P) = alpha v_A + beta v_B + gamma v_C

  1. Sample uniformly over triangle area.
  2. Convert each sample to barycentric weights.
  3. Interpolate the vertex attribute at that point.
  4. Average the sampled values and compare to the exact affine average.
Exact Check

For an affine attribute, the mean over the triangle equals the mean of the three vertex values.

This lab combines interpolation, triangles, probability, and Monte Carlo.Notebook artifact: triangle-monte-carlo-lab.png
Use the lab as a synthesis rather than as a separate application. The triangle provides a domain, barycentric coordinates provide weights, probability supplies random points, and Monte Carlo turns the sample values into an estimate. The exact affine average gives a clean correctness target for the experiment.

A Graphics Math Checklist

Inputs

  • Declare domains and endpoint rules.
  • Restrict before requesting inverses.
  • Check units for angles and densities.

Geometry

  • Prefer stable root formulas.
  • Audit frames using Gram and determinant tests.
  • Choose implicit or parametric form by task.

Estimates

  • Use weights that sum to one.
  • Normalize PMFs and PDFs.
  • Divide sampled values by sampling density.
