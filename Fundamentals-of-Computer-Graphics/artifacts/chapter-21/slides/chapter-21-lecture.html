Chapter 21Implicit Modeling
Open by naming the central change: an implicit model is a field first and a surface second. The designer edits functions, operators, and sampling rules, then asks a renderer or polygonizer to find the visible level set. That shift explains both the elegance and the computational cost of the chapter.
Chapter map

The Same Query Runs Through Every Technique

Field contract

Given a point \(p\), return a scalar value \(F(p)\) and, when rendering needs it, a gradient \(\nabla F(p)\).

Composition habit

Primitives, blends, booleans, transforms, warps, and caches are all ways to answer the same field query.

Final surface

The model appears only after solving \(F(p)=c\), usually by ray search or polygonization.

Field query: \(p \mapsto F(p)\)Solve \(F(p)=c\) to see geometry
Use the pipeline as the lecture contract. Every later technique fits one of these boxes: define local distance, filter it into a field, compose fields algebraically, transform sample coordinates, and finally search or extract the surface. Students should see implicit modeling as a programmable geometry stack.
Implicit fields

A Surface Is A Level Set, Not A Vertex List

Definition

The implicit surface for a field \(F\) is the set \(S_c=\{p \mid F(p)=c\}\).

$$F(x,y)=r-\sqrt{x^2+y^2},\qquad S_0=\{F=0\}$$

What The Field Gives For Free

  • Inside/outside classification by sign or threshold.
  • Normals from \(\nabla F / \|\nabla F\|\).
  • Targets for rays, grids, and cached samples.
Implicit fieldLevel set plus differential data
Emphasize that the field contains side information, not merely a curve. The same function classifies inside and outside, provides gradients for normals, and gives root-finding targets for rays. A mesh can approximate the contour later, but the field is the authoritative object during modeling.
Skeletal primitives

Distance To A Skeleton Becomes Field Strength

Primitive recipe

Choose a skeleton, compute distance \(d(p,S)\), then apply a compact falloff \(g(d)\).

$$F_i(p)=g_i\big(d_i(p,S_i)\big),\qquad g(d)=0\ \text{outside support}$$

Why Split The Work?

  • New skeletons reuse the same rendering code.
  • Support radius bounds the set of contributing primitives.
  • Smooth filters help avoid normal discontinuities near the source.
Skeleton: lower-dimensional geometryFilter: field contribution
Separate the skeleton from the filter. The point, segment, and ring are low-dimensional sources; the falloff turns distance into influence. Finite support is a modeling choice and an acceleration hint, because primitives outside the support can be ignored during field evaluation.
Blending

Add Fields First, Then Extract The Surface

$$F(p)=\sum_i F_i(p),\qquad \text{surface where }F(p)=c$$
Modeling effect

Nearby fields reinforce each other. The extracted iso set may merge pieces even when each primitive alone stays separate.

Design risk

Additive blends are compact and fast, but they can create unintended bulges as many primitives accumulate.

Summation blendBulge comes from algebra before extraction
The key timing issue is that fields add before the surface is extracted. Two separate primitives can produce a single contour once their overlapping potentials exceed the iso value. Ask students to predict where the neck appears, then connect the bulge to the additive algebra.
More on blending

Blend Operators Control Shape And Smoothness

$$F_R(p)=\left(F_0(p)^n+F_1(p)^n\right)^{1/n}$$
As \(n\) grows

The blend moves toward hard union, so the soft neck shrinks and the operator behaves more like \(\max(F_0,F_1)\).

Operator Questions

  • Does the operator preserve the intended inside convention?
  • Is it smooth enough for stable normals?
  • Does it create extra volume in crowded regions?
Ricci-style power blendOperator choice affects normals and topology
Frame Ricci-style blending as a controllable path between soft addition and hard selection. Low exponents preserve rounded transitions, while high exponents approach max-like union. Smoothness is not free; the operator controls both the shape and whether normals remain continuous across the join.
Rendering cues

Ray Search Finds Points; Gradients Shade Them

$$n(p)=\frac{\nabla F(p)}{\|\nabla F(p)\|}$$
Ray tracing

Search for a parameter \(t\) where the ray crosses the level set. A robust method brackets or steps carefully through field values.

Normal risk

If an operator switches branches abruptly, \(\nabla F\) can jump even when the surface location looks plausible.

Direct rendering pathRoot search plus gradient normal
Rendering begins after a surface point has been found, but implicit rendering still needs the field at every search step. Once the ray root is located, the normalized gradient supplies the normal. Hard operators can make that normal jump, which appears as a crease or shading discontinuity.
Space partitioning

Cells Become Interesting When Their Corners Disagree

Marching-cell test

Sample the field at grid vertices. A cell can contain the surface when its corner values straddle the iso value.

$$\text{active cell}\iff \min F_c \le c \le \max F_c$$

Extraction Workflow

  • Classify corners into inside/outside bits.
  • Interpolate the iso crossing on each crossed edge.
  • Use a case table to emit segments or triangles.
Marching squares as 2D analogMarching cubes emits triangles in 3D
Present the grid as a way to avoid searching everywhere. Corner signs identify cells that can contain the iso surface, and interpolation estimates the crossing along cell edges. This is the two-dimensional version of the marching-cubes idea used for polygon meshes.
Polygonization caveat

Corner Samples Do Not Always Decide Connectivity

Ambiguous case

Opposite corners are on the same side of the iso value. The lookup table needs a convention or more samples.

Common fixes
  • Sample the cell center.
  • Subdivide the cell until the pattern is resolved.
  • Use tetrahedral decomposition in 3D.

Teaching Point

A sampled field is a finite measurement of a continuous object, so topology is a reconstruction decision.

Ambiguity is a sampling issueResolution adds information before emitting topology
The ambiguous cell is a useful warning because the corner samples alone do not uniquely determine connectivity. Opposite corners can be inside while two plausible contours pass through the cell. Extra samples, subdivision, or tetrahedral decompositions add information before topology is committed.
Constructive solid geometry

Booleans Are Branching Rules On Fields

Positive-inside convention

\(\text{union}=\max(A,B)\), \(\text{intersection}=\min(A,B)\), and \(\text{difference}=\min(A,-B)\).

Crease mechanism

The surface can be continuous while the selected branch, and therefore the gradient, changes sharply.

evaluate_csg(p): a = circle_field(p) b = box_field(p) return min(a, -b) # A minus B
CSG from field algebraSharp operators trade simplicity for creases
CSG becomes compact because the branch decision is encoded in the field operator. With a positive-inside convention, max keeps either object, min keeps their overlap, and min with a negated cutter removes material. The crease line marks where the selected branch can change abruptly.
Warping

Warp The Query Point, Not The Finished Mesh

Inverse sampling

Evaluate the original field at the point that would have mapped to the query location.

Normal caution

The gradient should transform with the sampling map. Reusing the unwarped normal gives incorrect shading.

Barr-Style Deformations

  • Twist rotates coordinates by height.
  • Taper rescales one direction by another.
  • Bend maps straight coordinates into an arc.
Warping is functional compositionNormals follow inverse-map derivatives
A warp is best taught as moving the query point rather than dragging final vertices. The renderer asks for the field at p, the warp maps that query back into the base coordinate system, and the base primitive answers there. Normals require the same inverse-map discipline through the Jacobian.
BlobTrees

An Expression Tree Makes Field Design Editable

Tree semantics

Leaves are primitives. Interior nodes are transforms, blends, booleans, warps, caches, and material annotations.

Traversal

A renderer evaluates a point by asking leaves for local field values and combining the results bottom-up.

$$\text{value at root} = T_\text{union}(T_\text{diff}(T_\text{warp}(B)), S)$$
Tree equals authored operator stackBottom-up evaluation gives field value and gradient
The BlobTree gives a data structure to the algebra. Leaves answer primitive field queries, internal nodes blend, subtract, warp, cache, or transform, and traversal combines results bottom-up. This lets a modeling system expose editable operations instead of one flattened expression.
Interactive implicit modeling

Caches Make The Tree Fast Enough To Edit

Why cache?

Complex trees re-evaluate many nodes for every ray step or grid vertex. Local cached grids reduce repeated work.

Invalidation rule

Editing a leaf invalidates its ancestors, but unrelated subtrees can keep their cached fields and bounds.

Interactive Design Loop

  • Edit the operator tree.
  • Refresh only affected field samples.
  • Preview by ray tracing or polygonizing the updated field.
BlobTree as system architectureCaches preserve responsiveness
Connect interactive systems to the cost model. Editing one node should invalidate only the caches that depend on it, while unchanged subtrees keep their sampled grids or bounds. This is why the tree representation matters for responsiveness, not just for mathematical cleanliness.
Recap

Implicit Modeling Is Powerful When The Checks Travel With The Field

Sign

Fix the inside convention before writing CSG formulas.

Support

Bound contribution so evaluation can skip distant primitives.

Smoothness

Choose blend and boolean operators with normals in mind.

Sampling

Validate grid resolution and ambiguous polygonization cases.

Final habit: field expression plus validation checksChapter 21 takeaways
Close with implementation risks rather than vocabulary. A sign mistake flips booleans, a blend constant changes topology, a hard operator breaks normals, a warp mishandles gradients, and a coarse grid misses features. The safest habit is to pair every authored field with numerical checks.
