Buffers And Vertex Arrays

Bytes Need An Interpretation Contract

storage
versus meaning
Buffer Object

Owns bytes in GPU memory. It does not know which bytes are positions, normals, colors, or texture coordinates.

Vertex Array Object

Records the interpretation: attribute location, component count, type, stride, offset, and enabled attributes.

Invariant

address = base + vertex_index * stride + offset

Buffers store; vertex arrays explain.VBO and VAO layout
Separate storage from interpretation slowly. The buffer owns bytes on the device, but the vertex array records how those bytes become named shader attributes. The same byte stream can be useful or meaningless depending on stride, offset, scalar type, component count, and attribute location.
The Cost Of A Wrong Stride

The Shader Can Be Right And Still Receive Nonsense

debug the
byte contract
Symptom

Exploding triangles, black lighting, or random colors can all be attribute decode errors.

Debug Moves
  • Output position, normal, color, or UV directly.
  • Check each attribute's offset and stride.
  • Confirm the bound VAO at the draw call.
A byte layout bug masquerades as a shader bug.Stride and offset checks
Use the wrong-stride panel as a visual explanation of corrupted geometry. The shader may be perfectly correct while receiving positions read from colors or normals read from texture coordinates. The address formula is the invariant: base plus vertex index times stride plus attribute offset.
Shader Programs

Programmable Stages Inside A Fixed Pipeline

vertex
to fragment
Vertex Shader

Runs per incoming vertex. It reads attributes and uniforms, then writes clip-space position and varying outputs.

Rasterizer

Groups vertices into primitives and interpolates varyings for candidate fragments.

Fragment Shader

Runs per candidate fragment. It usually computes color, but depth, stencil, and blending still affect the final target.

Shaders compute; fixed-function stages assemble, interpolate, test, and blend.GLSL stage model
Frame shaders as programmable islands inside a larger fixed pipeline. The vertex shader is responsible for per-vertex outputs such as clip position and varyings; rasterization then interpolates varyings; the fragment shader chooses output color or other framebuffer values for each candidate fragment.

Uniforms Replace Hidden Stacks

The host sends matrices explicitly. The shader applies them explicitly.

Clip-Space Checks
  • Is \(w\) positive for visible geometry?
  • Are NDC coordinates in the expected range?
  • Does viewport mapping explain the pixel location?
Transform bugs become coordinate-space bugs once the chain is visible.MVP uniforms
Connect transformation uniforms to the end of the old hidden matrix-stack era. The application now assembles model, view, and projection matrices explicitly, sends them as uniforms, and the vertex shader applies them. Ask students to track where coordinates change spaces and where clipping becomes meaningful.

Attribute Contract

Vertex attributes are read at vertices, but varying outputs are interpolated for fragments.

Shader Debug Views

Normalreveals orientation

Interpolation is geometry applied to shader data.Varying attributes
The important idea is that attributes are not just attached to vertices; after rasterization they become interpolated fragment inputs. Barycentric weights give a compact mental model: colors, UVs, normals, and other varyings should stay inside the convex combination dictated by the triangle.
Rasterization Context

Depth And Stencil Are Part Of The Frame Equation

hidden
buffers
Rasterization

Converts primitives into candidate fragments with interpolated attributes and depth.

Tests

Depth and stencil state decide whether a fragment is discarded, recorded, or allowed to update the color target.

Inspection Habit

Render depth, stencil labels, overdraw, or a flat color before assuming the material shader is the problem.

A correct shader can still produce no visible pixel.Depth, stencil, blending
Make the hidden framebuffer attachments visible. Fragment shading proposes values, but depth, stencil, and blending state decide what is kept, rejected, labeled, or combined. This is why a color shader can look correct in isolation while the final frame is empty or unexpectedly overwritten.
Texture Objects And Samplers

The Image Is Only One Part Of Texture State

uv + sampler
+ texture unit
Texture Object

Device-resident image data with target, format, mip levels, and storage.

Sampler State

Defines wrap and filtering behavior, especially when UV coordinates leave the unit square.

Common Failure

The shader samples the wrong texture unit, or the UV attribute is misread by the vertex array.

Texture mapping is geometry plus state plus memory lookup.Texture coordinates and samplers
Textures are best taught as data plus sampling state. The image alone does not determine the result; coordinates, wrap modes, filter modes, mip level, texture unit, and sampler binding all participate. The same checker data can clamp, repeat, or blur depending on the active sampler.
Meshes For Hardware

Topology Becomes Indexed Draw Streams

vertices
indices
attributes
Offline Mesh

May know adjacency, materials, groups, smoothing, and authoring history.

Hardware Draw Mesh

Usually becomes compact vertex buffers plus index buffers for triangles.

Practical Split

Keep rich topology for editing and validation; stream compact indexed arrays for rendering.

The mesh sent to hardware is a compact contract, not the whole modeling story.Indexed mesh drawing
Relate meshes to the memory structures from earlier chapters. Hardware usually wants linear vertex and index buffers, while modeling tools often remember richer adjacency. The lecture distinction is practical: keep enough topology offline for editing, then stream compact indexed triangles for drawing.
Meshes And Instancing

One Geometry Upload, Many Model Matrices

reuse
without copies
Reuse Contract

Shared VBO and index buffers stay resident; instance records supply transforms or materials.

Normal Transform

Nonuniform scale needs a correct normal matrix, often derived from the inverse transpose of the model transform.

Why It Matters

Instancing reduces repeated uploads and draw setup for repeated objects such as trees, particles, or identical props.

Instancing separates shared geometry from per-object state.Mesh instancing
Instancing is the reuse slide. One resident mesh can be drawn many times by changing per-instance transforms, materials, or attributes. The saving is not only fewer bytes transferred; it also makes the scene conceptually cleaner because shared geometry and instance-specific state are separated.

Treat performance as a set of pressure points rather than a single speed number. Host uploads, state changes, vertex work, fragment overdraw, texture traffic, and synchronization stalls each have different symptoms. A good optimization begins by identifying which pressure point is active.
Applied Lab

Diagnose The Draw Before Rewriting The Renderer

minimal
state tree
Earliest-Failing Contract
  1. Context and framebuffer exist.
  2. Shader program links and is active.
  3. VAO decodes attributes correctly.
  4. Transforms put geometry inside clip range.
  5. Texture and tests are intentionally bound.
Good Lab Habit

Replace the material with one debug output at a time; every temporary color should answer a specific state question.

Small diagnostic shaders turn hidden contracts into visible evidence.Draw-state lab
The diagnostic tree is meant to be used before rewriting code. Start with the earliest contract that can make the frame fail: context, program, vertex array, transform, texture, then depth or stencil state. Visual debug shaders are useful because they turn invisible state into inspected color.
Recap

Five Invariants For Graphics Hardware Work

chapter 17
takeaways
1. Resource Residency

Large buffers and textures should live on the GPU across frames.

2. Interpretation State

The VAO must match the byte layout expected by the shader.

3. Coordinate Spaces

Track local, world, eye, clip, NDC, viewport, and depth values.

4. Hidden Framebuffers

Depth, stencil, and blending can change what survives after shading.

5. Reuse And Instancing

Separate shared geometry from per-instance transforms and material state.

Final mental model: draw calls are precise contracts with the current GPU state.End of chapter 17
