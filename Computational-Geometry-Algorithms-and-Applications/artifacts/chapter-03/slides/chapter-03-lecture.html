Polygon Triangulation:
Guarding an Art Gallery

A simple polygon becomes an algorithmic object: insert diagonals, count triangles, color a triangulation graph, and place at most floor(n/3) guards.

Open the lecture by naming the modeling bargain. We will not try to solve every visibility question directly. Instead, we turn the gallery boundary into a simple polygon, prove that diagonals can decompose it into triangles, and then use a coloring argument to choose a small guard set. The number to protect carefully is floor n over three.

Gallery To Polygon Model

Definition

A gallery floor plan is modeled by a simple polygon P: a closed, non-self-intersecting chain of edges.

Visibility

A camera point g sees a point x exactly when the whole segment gx stays inside P, including the boundary.

  • Guards may sit at vertices for the theorem proved here.
  • Occlusion is represented by segment intersection with the exterior.
  • Geometry enters through straight-line visibility, not through room labels.
Model: simple polygon and segment visibility2 / 16
Make the definitions operational. A simple polygon has no crossing boundary edges, so it gives a clean inside and outside. Visibility is a segment test: if every point of the segment from the guard to the target remains in the polygon, the target is visible. This framing is deliberately geometric and will let triangulation replace a difficult global search.

Diagonals And Triangulations

Diagonal

A segment between two non-adjacent polygon vertices that lies entirely in the polygon.

Triangulation

A maximal set of pairwise non-crossing diagonals partitions P into triangles.

Maximal Means

If some face is not triangular, it still contains a legal diagonal. Therefore a maximal non-crossing family has only triangular faces.

Diagonals are internal chords between non-adjacent vertices3 / 16
Separate the vocabulary carefully. A diagonal is not any chord of the polygon; its endpoints are vertices, they are not neighbors on the boundary, and the segment must remain in the polygon. A triangulation is then a saturated non-crossing set of such diagonals. Saturation matters because it turns a combinatorial object into a geometric certificate that every remaining cell is a triangle.

Theorem 3.1 Proof Move

Existence Move

Every simple polygon with at least four vertices has a diagonal.

Leftmost Vertex

Choose a leftmost vertex v and inspect its two neighbors. If their chord lies inside, it is a diagonal.

Farthest Witness

If the neighbor chord leaves the polygon, a vertex inside the ear triangle witnesses the obstruction; the farthest such witness from the chord creates a legal diagonal to v.

The local ear argument starts recursive triangulation4 / 16
Present this as the engine behind induction. At a leftmost vertex, the triangle formed with its neighbors points into the polygon. If the opposite side is clean, we are done. If it is not clean, the triangle contains polygon vertices that explain the obstruction. Choosing the farthest witness from the neighbor chord avoids crossings and gives a diagonal from the leftmost vertex.

Triangle Count Invariant

Invariant

Every triangulation of an n-vertex simple polygon has exactly n - 2 triangles.

T(n) = T(n_1) + T(n_2),   n_1+n_2 = n+2
Induction

A diagonal creates two smaller polygons. Each side counts the shared diagonal endpoint pair, so the vertex counts add to n+2; the triangle totals become (n_1-2)+(n_2-2)=n-2.

Counting survives every legal split5 / 16
Use the diagram to explain why the formula is independent of the triangulation chosen. A diagonal divides the polygon into two smaller polygons, and the diagonal endpoints belong to both subproblems. That double counting is exactly the plus two in n one plus n two equals n plus two. The induction then forces every triangulation to have n minus two triangles.

From Triangles To Guards

Triangulation Graph

Create a planar graph whose edges are polygon edges and inserted diagonals.

3-Coloring

The graph can be colored with three vertex colors so every triangle has all three colors.

Guard Choice

Pick the smallest color class. Since each triangle contains every color, guards on that class see all triangles and therefore the whole polygon.

Color classes translate geometry into a guard set6 / 16
Now connect triangulation to guarding. Once the polygon is triangulated, every point lies in at least one triangle. If the vertices can be colored so that each triangle has all three colors, then choosing any one color class places a guard at a vertex of every triangle. Choosing the smallest class gives the numerical bound by the pigeonhole principle.

Dual Graph Tree

Dual Nodes

Put one node in each triangle of the triangulation.

Dual Edges

Connect two nodes when their triangles share an inserted diagonal.

Tree Structure

The dual graph is connected and acyclic. Removing a leaf triangle supports induction for the 3-coloring.

Dual tree = induction scaffold7 / 16
The dual graph gives a clean proof view. It has a node for every triangle and an edge for every shared diagonal. It is connected because the polygon is one region, and a cycle would enclose a hole or force incompatible separation in a simple polygon triangulation. Leaves are ears, so induction can remove a leaf triangle, color the rest, and extend the third color to the removed vertex.

Art Gallery Theorem And Comb Lower Bound

Theorem

Every simple polygon with n vertices can be guarded by at most floor(n/3) vertex guards.

Sharpness

Comb polygons with many thin teeth force one guard for each tooth pocket. This realizes the same order and, for the standard family, the same floor(n/3) count.

min color class ≤ floor(n/3)
The upper bound is also a worst-case lower bound8 / 16
State the theorem with the floor, not a ceiling. The upper bound comes from triangulate, three-color, and choose the smallest color class. The lower bound is a family argument: make a comb with separated pockets so one guard cannot see into two distant teeth. The construction shows that the theorem is not merely convenient; its dependence on n is tight.

Why Faster Triangulation Is Needed

Naive Cost

Repeatedly finding any legal diagonal can scan many vertices per split. Bad split choices produce a quadratic pattern of work.

Better Plan

First partition the polygon into y-monotone pieces by a sweep. Then triangulate each monotone piece in linear total time.

O(n log n) + O(n) = O(n log n)
Existence proof is not yet an efficient algorithm9 / 16
Emphasize the distinction between a proof and an efficient procedure. The leftmost-vertex argument proves that a diagonal exists, but a direct recursive implementation may repeatedly search through long boundary portions and split off tiny pieces. The chapter therefore changes strategy: impose monotonicity with a sweep, then exploit monotone structure with a stack triangulation.

Monotone Polygon And Vertex Taxonomy

Y-Monotone

Every horizontal line intersects the polygon in a connected segment, a point, or not at all.

Start

both neighbors below; interior angle below pi

Split

both neighbors below; interior angle above pi

End

both neighbors above; interior angle below pi

Merge

both neighbors above; interior angle above pi

Tie Rule

When two vertices have equal height, the left-to-right order breaks the tie consistently in the sweep queue.

Classification drives the sweep handlers10 / 16
Define monotonicity using horizontal lines because the sweep runs from top to bottom. A vertex type is determined by the vertical relation to its two neighbors and whether the interior angle is convex or reflex. Split and merge vertices are the dangerous ones because they create disconnected horizontal intersections. Mention the tie rule so students see that equal-height vertices do not leave the event order ambiguous.

Lemma 3.4 Proof View

Lemma 3.4

A polygon is y-monotone exactly when it has no split vertices and no merge vertices.

Proof View

If a horizontal line cuts the polygon in two separated intervals, sweeping that line upward or downward until a topology change occurs reveals a split or merge vertex.

Converse

A split or merge vertex locally creates two branches on the same side of the event height, so nearby horizontal lines see disconnected intersections.

Horizontal slices turn geometry into a vertex condition11 / 16
Use this slide as a proof sketch rather than a formal case table. If monotonicity fails, some horizontal line sees two separated pieces of the polygon. Move the line until the number of intersection components changes; the responsible event must be a reflex vertex with both adjacent vertices on the same side, hence split or merge. Conversely, either such vertex visibly creates a disconnected slice just above or just below it.

MAKE_MONOTONE Sweep

Event Queue

Process vertices from high to low, with the tie rule fixing equal heights.

Status Tree

Maintain polygon edges crossed by the sweep line, ordered left to right.

Helper

For each status edge, store the lowest processed vertex above the sweep line that may need a diagonal to a later merge or split event.

The sweep inserts diagonals that remove non-monotone events12 / 16
The MAKE_MONOTONE algorithm is a plane sweep with memory. The queue tells us which vertex is next. The status tree tells us which boundary edge lies immediately to the left of an event. The helper field is the compact state: it remembers a processed vertex that might need a diagonal when the sweep later discovers the matching event below it.

Handler Cases And DCEL Diagonal Insertion

Start / End

Start vertices insert incident edges into status. End vertices remove edges and may close a pending merge helper.

Split

Connect the split vertex to the helper of the edge immediately left of it, then update that helper.

Merge

First connect to a pending merge helper if needed; then use the left edge helper and update it.

DCEL Update

Insertion creates twin half-edges and splits one face cycle into two face records while preserving adjacency queries.

Handler logic is local; DCEL makes the edit explicit13 / 16
Do not dwell on memorizing every branch. The main idea is that split and merge events are repaired by diagonals to stored helpers. Start and end events mostly maintain the active boundary edges, while regular vertices behave according to which chain they occupy. The DCEL matters because adding a diagonal is not just drawing a segment; it rewires half-edges and creates two face cycles for later triangulation.

Monotone Stack Invariant

Invariant

The stack stores a chain of already processed vertices that form the visible side of an upside-down funnel.

Sorted Order

Process vertices by decreasing height. Monotonicity guarantees the remaining boundary separates into a left chain and a right chain.

Pop Logic

When a new vertex sees stack vertices across the interior, those diagonals are safe and the popped vertices are resolved.

Monotone triangulation is a linear stack sweep14 / 16
After partitioning, each piece has a much simpler geometry. Sort the vertices from top to bottom. The stack records an unresolved chain in the current funnel. The reason this can be linear is that each vertex is pushed once and popped at most once. The visibility test is local because a monotone polygon prevents hidden pockets from appearing behind the sweep order.

Two Cases In Monotone Triangulation

Opposite Chain

If the current vertex is on the opposite chain from the stack top, connect it to every stack vertex except the last boundary neighbor, then reset the stack.

Same Chain

If it is on the same chain, pop while the new diagonal remains internal. Each successful pop creates a triangle.

Linear Accounting

Every diagonal is charged to a pop or a chain switch, so all monotone pieces triangulate in total linear time.

The two cases are the whole monotone triangulation algorithm15 / 16
Give students the mental branching rule. Opposite-chain vertices can see across the monotone polygon, so the algorithm fans diagonals to the stack and then starts a new stack. Same-chain vertices require a turn test: pop and add diagonals only while the popped vertex remains visible from the current vertex. Since each stack operation is charged once, the whole pass is linear.

Full Pipeline And Extensions

1. Partition

Run MAKE_MONOTONE with event queue, status tree, helpers, and DCEL diagonal insertions.

2. Triangulate

Sort each monotone piece and apply the stack invariant to add all remaining diagonals.

3. 3-Color

Use the triangulation dual tree to extend a proper three-coloring triangle by triangle.

4. Choose Guards

Select the smallest color class, giving at most floor(n/3) guards.

Subdivision theorem: the same machinery supports planar subdivisions16 / 16
Close by assembling the pipeline. The sweep adds diagonals that remove split and merge vertices, producing monotone pieces. The stack algorithm triangulates those pieces without returning to a global search. The dual tree supports a three-coloring, and the smallest color class gives the guard set. The same decomposition viewpoint is the bridge to triangulating more general planar subdivisions.
