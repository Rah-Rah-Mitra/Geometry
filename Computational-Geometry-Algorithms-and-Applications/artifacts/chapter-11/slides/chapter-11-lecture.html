Inside Certificate

New Facet On Horizon Edge

A new triangle \(f=(p_r,e)\) is created from a horizon edge \(e\).

Candidate Set

\(P(e)=P_{\mathrm{conflict}}(f_1)\cup P_{\mathrm{conflict}}(f_2)\)

Filter

Test only points in \(P(e)\) against the new plane; add arcs for the visible ones.

Explain the crucial update rule from printed pages 248-249. For a new facet built on a horizon edge, a future point can see it only if it could see at least one of the two old facets incident to that edge. Therefore the candidate set is the union of two old conflict lists, followed by fresh signed plane tests.

Failure Mode

Wrong State

Repair

Backwards Analysis

Reverse The Insertion

New facets created by inserting \(p_r\) equal facets incident to \(p_r\) that disappear when removing it from \(CH(P_r)\).

Degree Bound

\[ \sum_v \deg(v)=2E\le 6r-12. \]

Expectation

\(E[\deg(p_r,CH(P_r))]\le 6\)

Thus total expected created facets is at most \(6n-20\).

Euler turns random local degree into an O(n) structural-change bound13 / 16
This is the core expectation argument from printed page 250. Instead of asking how many facets insertion creates, look backward from CH of the first r points and remove the last random vertex. The number of disappearing facets equals the degree of that vertex, and the average degree is bounded by Euler's edge bound.
