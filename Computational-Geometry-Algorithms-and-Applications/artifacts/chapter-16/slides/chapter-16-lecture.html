From Region To Simplex

Definition

A planar simplex is a triangle. A triangular query asks for \(S \cap \Delta\), where \(\Delta = H_1 \cap H_2 \cap H_3\).

Computational Check

For the displayed sample, membership by three oriented half-plane tests agrees with a barycentric-coordinate brute-force test.

Misconception

Triangle queries do not require a new recursive idea. They reuse half-plane logic; three boundary lines only change the crossing count by a constant factor.

A triangle is three half-plane decisions with shared output accounting2 / 16
Translate the polygon problem into the smallest non-orthogonal query. A point is in the triangle exactly when it passes three side tests. This matters because the partition tree algorithm will be described for a half-plane first, and the triangle version is the same recursion with three possible boundary crossings.

Canonical Subsets Start In 1D

Warm-Up

A balanced search tree stores subtree sizes. A half-line query selects entire subtrees on one side and recurses only where the split point is ambiguous.

answer = disjoint union of selected subtree point sets

Invariant

Selected canonical subsets are disjoint because tree subtrees partition the input points.

The range-searching habit: precompute canonical subsets and express queries as unions3 / 16
Use the one-dimensional tree to introduce canonical subsets before the geometry gets heavy. Each subtree is a precomputed subset with a stored count. The query never enumerates all points if it can select a whole subtree, and the selected subtrees are disjoint by construction.

Simplicial Partitions

Definition

A simplicial partition is \(\Psi(S)=\{(S_i,t_i)\}_{i=1}^r\), where the \(S_i\) are disjoint, cover \(S\), and triangle \(t_i\) contains class \(S_i\).

Fine Balance

Fine means no class is too large: \(|S_i| \leq 2n/r\). Balance is what keeps recursive depth and storage under control.

Careful

The triangles need not be disjoint. Counting still works because the point classes, not their enclosing triangles, form the disjoint partition.

Geometry encloses the classes; accounting belongs to the disjoint point subsets4 / 16
Define the object that replaces binary splits in the plane. The triangles are covers for classes, not cells of a planar subdivision, so they may overlap. The key accounting property is that each point belongs to exactly one class, while the fine condition prevents one child from carrying too much of the input.

Crossing Number Is The Lever

Theorem 16.1

For any \(1 \leq r \leq n\), a fine simplicial partition of size \(r\) exists with crossing number \(O(\sqrt r)\).

Query Consequence

A half-plane boundary line only forces recursion into classes whose enclosing triangles it crosses.

Displayed Check

The query line crosses 3 of the 9 displayed triangles; all other classes are selected or rejected at this level.

Low crossing number is the geometric reason the recursion is sublinear5 / 16
Now isolate the parameter that drives query time. If the boundary line misses a triangle, that whole class is either inside or outside the half-plane. Only crossed triangles need recursion, so Matousek's low-crossing partition theorem is the hinge between geometry and the later recurrence.

Partition Tree Structure

Node Record

Each child \(\nu\) stores an enclosing triangle \(t(\nu)\), a canonical subset \(S(\nu)\), and the value needed for the query, such as \(|S(\nu)|\).

Recursive Shape

The root has \(r\) children for a fine simplicial partition. Each child roots the partition tree on its class.

Storage Idea

Because the classes are disjoint and fine, the total number of nodes satisfies a linear-size recurrence for fixed \(r\).

The tree stores a repertoire of canonical subsets, not all possible answers6 / 16
Connect the partition to a data structure. Every child is both a geometric triangle and an accounting record for a subset of points. Recursion is only on the class, so the tree stores many canonical subsets that can later be selected wholesale by a query.

Half-Plane Query Trace

Three Outcomes

For each child: \(t(\nu)\subset h\) means select; \(t(\nu)\cap h=\emptyset\) means reject; otherwise recurse.

Disjointness Check

The selected nodes shown here have disjoint canonical subsets, so summing their stored counts is valid.

Direct-Filter Check

The union of selected leaves plus recursive descendants equals the points found by brute-force half-plane tests on the same toy input.

The query returns selected nodes, then counting only sums their stored sizes7 / 16
Walk through the query at one node. The important point is that a selected child contributes its stored count immediately; it is not searched further. Rejected children contribute nothing, and only boundary-crossed children keep the recursion alive.

Triangles Need Three Boundary Lines

Same Query Logic

Replace the half-plane \(h\) by triangle \(\Delta\). A child is selected if \(t(\nu)\subset \Delta\), rejected if disjoint, and recursively visited otherwise.

Crossing Bound

The boundary of \(\Delta\) has three lines, so at most a constant multiple of \(O(\sqrt r)\) children can be ambiguous.

Boundary Accounting

For counting, use disjoint canonical subsets. Points on shared triangulation edges need a consistent inclusion convention.

Triangle ranges inherit the half-plane partition-tree analysis8 / 16
Make the triangle extension feel almost anticlimactic. The recursion has the same three cases as the half-plane query. The only analysis change is that the boundary has three lines, and a class can be ambiguous only when one of those lines crosses its enclosing triangle.

Partition Tree Analysis

Storage Recurrence

\(M(n) \leq 1+\sum_\nu M(n_\nu)\), with \(\sum n_\nu=n\) and \(n_\nu\leq 2n/r\). For constant \(r>2\), storage is \(O(n)\).

Query Recurrence

\(Q(n)\leq r+\sum_{\nu\in C(h)}Q(n_\nu)\), where \(|C(h)|=O(\sqrt r)\). Choosing a large enough constant \(r\) gives \(O(n^{1/2+\epsilon})\).

Reporting

Counting sums stored values. Reporting appends the points from selected canonical subsets and costs \(O(k)\) more.

Linear storage buys roughly square-root query time9 / 16
Summarize the proof dependencies rather than redoing every algebraic detail. Disjointness and fine balance are what make the storage linear. Low crossing number limits the branching of the query recursion, and a sufficiently large constant r absorbs constants into the epsilon.

Multi-Level Partition Trees

Segment-Line Query

A segment intersects a query line when its two endpoints lie on opposite sides. One level selects candidates by one endpoint.

Associated Structures

Each selected canonical subset is stored in another partition tree on the other endpoint, turning a two-sided condition into two single-sided searches.

Effect

For partition trees, extra levels preserve the \(n^{1/2+\epsilon}\) query exponent and add only logarithmic storage factors.

Associated structures let one canonical subset carry another search problem10 / 16
Use segment-line intersection to show why multi-level structures appear before duality and cuttings. The condition has two endpoint predicates, so a first-level search selects canonical subsets for one endpoint and associated trees filter them by the second endpoint. This is the same canonical-subset philosophy, nested.

Why Cuttings Enter

Partition Tree Bargain

Near-linear storage means a modest repertoire of canonical subsets. Some half-plane queries still need roughly square-root many pieces.

Full Arrangement Bargain

Precompute the combinatorial answer in every arrangement cell and queries become very fast, but storage is quadratic.

Cuttings

A cutting tree keeps the fast-query spirit of arrangements while organizing the quadratic-scale canonical subsets recursively.

The chapter now spends near-quadratic storage to buy logarithmic query time11 / 16
Pause to explain why a second structure is needed. Partition trees are good because storage is linear, but the query time is not logarithmic. Full arrangements suggest that logarithmic time is possible if enough information is precomputed. Cuttings are the structured way to make that idea recursive.

Dual Half-Plane Counting

Duality Convention

A primal point \(p=(a,b)\) maps to the dual line \(p^*: y=ax-b\). A primal line maps to a dual point.

Sign Relation

With this convention, a primal point above a query line corresponds to its dual line lying below the dual query point.

Check

The displayed sample verifies the sign relation for every point-line pair before using the dual counting problem.

Half-plane range counting becomes lines-below-a-point counting12 / 16
Introduce duality as a problem transformation, not as a decorative symmetry. Under the chosen convention, above in the primal becomes below in the dual. The data structure will now partition the dual plane, while the original points have become lines.

(1/r)-Cuttings

Definition

A \((1/r)\)-cutting for a set \(L\) of lines decomposes the plane into disjoint triangular cells so that each cell is crossed by at most \(n/r\) lines.

Size

There are cuttings of size \(O(r^2)\). This is arrangement-like storage at one controlled scale.

Displayed Check

Inside the bounded viewport, the triangular cells do not overlap in their interiors and each displayed line crosses at most 2 highlighted cell interiors.

Cuttings partition the dual plane, not the primal point set13 / 16
State the most common source of confusion directly. A cutting is a triangulation of the dual plane, and the objects being controlled are lines crossing cells. The cells are disjoint, but a line may be stored in several crossing subsets, which is why storage grows quickly.

Cutting Tree Query Path

One Path

The query point lies in exactly one cutting cell at each level, so the main recursion follows one child.

Canonical Additions

At each level, the lower canonical subset of the cell can be added for lines already known to lie below \(q\).

Lemma 16.8

A cutting tree counts lines below a point in \(O(\log n)\) time using \(O(n^{2+\epsilon})\) storage.

The path is logarithmic because each crossed-line subset shrinks by a factor r14 / 16
Contrast this with partition-tree queries. A partition tree may branch into many crossed children, while a cutting-tree point query descends through one containing cell. The cost is that each cell stores information about lower, upper, and crossing line subsets, and the total storage is near quadratic.

Three Levels For A Triangle

Dual Triangle Query

A primal triangle becomes three labeled dual query points. A dual line qualifies only if it is on the required side of all three points.

Associated Cutting Trees

Level 1 filters by side one, level 2 by side two inside associated structures, and level 3 by side three.

Theorem 16.10

Triangular range counting can be answered in \(O(\log^3 n)\) time with \(O(n^{2+\epsilon})\) storage; reporting adds \(O(k)\).

Three half-plane constraints become three levels of dual side filtering15 / 16
Assemble the final data structure. The triangle is not stored as a primal object in the cutting tree; after duality it is three side tests on lines. Each level handles one test, and associated cutting trees carry the selected canonical subsets forward without breaking the disjointness needed for counting.

Misconceptions To Retire

Cutting trees partition the dual plane, canonical subsets must be disjoint for counting, fine balance matters, and logarithmic query time is paid for with near-quadratic storage.

Simplex range searching is a calibrated storage/query-time tradeoff16 / 16
Close by giving students the durable mental model. Partition trees are the linear-space end of the spectrum, cutting trees are the logarithmic-query end, and hybrids interpolate by switching structures when storage budget becomes tight.
