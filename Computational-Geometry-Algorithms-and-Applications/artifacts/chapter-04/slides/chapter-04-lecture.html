Open with the manufacturing question rather than the algorithm. A one-piece mold is useful only if the solid can be pulled out without colliding with any face of the mold. The chapter turns that physical clearance question into a geometric feasibility problem. The key promise is that the same low-dimensional linear programming ideas will later solve both castability tests and abstract constraint optimization.
Facet Clearance

Removal Direction To Facet Normal Test

Local Test

For every blocking facet with outward normal \(\eta\), a feasible pull direction \(d\) must satisfy

\(d\cdot \eta \le 0\).

Geometric Reading

  • Positive dot product means motion has an outward-normal component into the facet obstruction.
  • Nonpositive dot product means translation is tangent to or away from that facet.
  • Castability requires the test for all relevant facets simultaneously.
Explain the sign convention carefully. Each facet has an outward normal eta. If the removal direction d points into the forbidden side of a facet, the casting sticks. The local test d dot eta less than or equal to zero says the motion does not push into that facet. Students should read the diagram as a single face test before we intersect all face tests.
Dimensional Reduction

The Plane \(z=1\) Turns Directions Into Points

Normalization

Write \(d=(x,y,1)\) after scaling a direction whose \(z\)-component is positive.

Each normal \(\eta=(a,b,c)\) yields the planar inequality

\(a x + b y + c \le 0\).

The entire 3D orientation test becomes a list of 2D half-plane constraints on \((x,y)\).

Move from directions in space to points in an affine plane. By scaling any non-horizontal removal direction to make z equal to one, each 3D facet normal induces a linear inequality in the x and y coordinates of that plane. This is the reduction that lets a casting problem become a planar half-plane feasibility problem.
Theorem 4.2 Orientation

Castability Is Half-Plane Feasibility

Orientation Test

For a fixed orientation of the object, a valid removal direction exists exactly when the induced half-planes on \(z=1\) have a common point.

Lecture Translation

  • Facet normals become inequalities.
  • A direction is one point in the direction plane.
  • One feasible point certifies a pull direction for all facets.
State the orientation version of Theorem 4.2 in lecture language: for a chosen orientation of the cast, a valid removal direction exists exactly when the induced planar half-planes have a common point. The theorem is not magic; it is just the all-facets version of the previous normal test after directions have been normalized onto the plane z equals one.

Feasibility and optimization branch on this taxonomy: a bounded polygon can be reported, an unbounded region may still have an optimum, and an empty intersection ends the castability test.

Use the taxonomy to build geometric vocabulary before algorithms. Intersecting half-planes can give a bounded polygon, an unbounded wedge or strip, a lower-dimensional segment or point, or nothing at all. The later algorithms must distinguish these cases because an optimization target behaves differently on each one.
Computing The Whole Region

Divide, Recurse, Merge Convex Regions

Algorithmic Shape

  • Sort half-planes by boundary orientation.
  • Split the ordered list into two subproblems.
  • Recursively compute convex intersections.
  • Merge two convex regions by tracing their boundary intersection.
\(T(n)=2T(n/2)+O(n)=O(n\log n)\)
Present half-plane intersection as a convex-region merge problem. Split the constraints, recursively build two convex intersections, and then intersect those two regions. The price of the method is sorting and merge work, which gives the familiar O n log n bound when the full intersection boundary is required.
Merge State

Boundary Pointers Carry The Sweep Invariant

Sweep Invariant

The output chain built so far equals the boundary of \(P\cap Q\) from the starting event to the current pointer event.

Pointer Decisions

  • Advance the boundary whose next edge becomes visible first.
  • Drop arcs outside the other convex region.
  • Record crossings as new vertices of the merged region.
The merge is easier to trust when its state is visible. Boundary pointers walk around two convex chains while maintaining the next candidate edge of the intersection. At each step the algorithm decides which boundary contributes the next edge and discards arcs that lie outside the other region. The invariant is that the already emitted chain is exactly the merged boundary seen so far.
Output Versus One Optimum

Why Finding All Solutions Costs More

Half-Plane Intersection

Returns the complete feasible region, including all boundary edges and vertices.

\(O(n\log n)\)

Good when the region itself is the requested object.

Fixed-Dimensional LP

Returns one optimum point or a certificate of emptiness or unboundedness.

expected \(O(n)\)

Good when only a single best feasible direction is needed.

This slide separates two tasks students often conflate. If we need the entire feasible region, the output can have many edges and half-plane intersection naturally costs O n log n. If we only need one optimal point for a fixed-dimensional linear program, randomized incremental methods can avoid constructing the whole region and reach expected linear time.

Classify the outcomes of a planar linear program before discussing the algorithm. The feasible set may be empty, the objective may be unbounded, or an optimum may occur along an edge or at a vertex. The vertex case is generic, but the edge case is important because it exposes degeneracy and support constraints.
Randomized Incremental Core

Maintain \(v_i\); Repair Only On Violation

Bounded LP Step

  • Keep the optimum \(v_i\) for the first \(i\) constraints.
  • If \(v_i\in h_{i+1}\), reuse it.
  • If \(v_i\notin h_{i+1}\), the new optimum lies on \(\partial h_{i+1}\).
  • Repair by solving a 1D LP on that boundary line.
violation reduces dimension
Describe the incremental algorithm as a maintained certificate. After i constraints, v_i is the current optimum. If the next half-plane contains v_i, nothing changes. If it excludes v_i, the new optimum must lie on the boundary line of the violated constraint, so the repair becomes a one-dimensional linear program over that line.
Order Sensitivity

A Bad Order Forces Repeated Repairs

Worst-Case Trace

A deterministic input order can make nearly every insertion violate the current optimum.

\(\sum_{i=1}^{n} i = \Theta(n^2)\)

Randomization changes the order, not the local repair rule.

Show why the same repair rule is not automatically fast. A carefully chosen deterministic order can make almost every new constraint invalidate the current optimum. Each invalidation scans earlier constraints along the new boundary, so the accumulated work forms a quadratic staircase.
Same Algorithm, Better Order

Random Permutation Makes Repairs Sparse

What Changes?

  • Before the loop, shuffle the half-planes uniformly.
  • Insert and test constraints exactly as before.
  • Analyze the expected number and cost of repairs.
Instructor Cue

The plot is not a proof; it is a visual trace of the event type that backwards analysis will count.

The randomized algorithm uses the same geometric repair, but it removes the adversary's power to arrange constraints in the worst possible order. The plotted trace should be read qualitatively: many inserted constraints are harmless, and the expensive repair steps are sparse rather than forced at every stage.
Expected Linear Time

Support Constraints Give A \(2/i\) Change Probability

Backwards View

With \(i\) constraints present in the plane, the current optimum is supported by at most two constraints.

\(\Pr[v_i \ne v_{i-1}] \le {2\over i}\)

Delete a random constraint from the \(i\)-set. The optimum changes only if the deleted constraint was one of the supports.

Give the backwards-analysis argument in one sentence first. After i constraints are present, the optimum is determined by at most two support constraints in the plane. If we imagine deleting one random constraint from that set, the optimum changes only when a support constraint is removed, so the probability is at most two over i.
Beyond Bounded Polygons

Unbounded LP: Improving Ray And Tight Set \(H^*\)

Unbounded Certificate

A feasible point \(p\) and direction \(r\) certify unboundedness when \(p+\lambda r\) remains feasible and improves the objective for all \(\lambda\ge0\).

Tight Set \(H^*\)

Track constraints that can become tight along the escaping direction; the algorithm reasons about the boundary structure of a ray rather than a missing optimum vertex.

Unboundedness is not a failure of the model; it is a geometric outcome. If there is a feasible ray that improves the objective forever, no finite optimum exists. The tight set H star records constraints whose boundary is relevant to the direction of escape, and this lets the algorithm reason about rays rather than searching for a missing vertex.
Recursive Dimension Drop

Higher Dimensions: Boundary LP Certificates

Fixed-Dimensional Caveat

When a violated constraint appears in \(\mathbb{R}^d\), the repair problem lives on its boundary hyperplane, which has dimension \(d-1\).

What To Remember

  • Recursive repair gives strong bounds for fixed \(d\).
  • The hidden constants depend on dimension.
  • Support constraints are the certificate, not the full feasible polytope.
Emphasize the caveat in fixed dimension. The same violated-constraint idea recurses onto a boundary hyperplane, reducing dimension by one. The constants grow with dimension, so the result is powerful for fixed low-dimensional geometry but should not be sold as a general high-dimensional linear programming method.
LP-Type Echo

Smallest Enclosing Disks Share The Support-Set Pattern

LP-Type Behavior

The disk is certified by a small support set: two antipodal boundary points or three boundary points.

Same Randomized Template

  • Insert points in random order.
  • If the new point is inside the current disk, keep the disk.
  • If outside, recompute with the new point forced onto the boundary support set.
Close with the LP-type echo. The smallest enclosing disk is not a linear program, but it has the same support-set behavior: the answer is certified by at most three boundary points, and random insertion only repairs the disk when the new point lies outside. This lets students recognize the chapter's deeper pattern beyond half-planes.
