What Is Being Triangulated?

Polygon triangulation. Add noncrossing diagonals until every bounded face is a triangle.
Point-set triangulation. Use all sample points as vertices and triangulate the convex hull without crossing edges.

The same word hides two inputs. Later formulas depend on whether the boundary is prescribed or discovered as the convex hull.

Pause on the distinction between polygon input and point-set input. A polygon gives the boundary first; a point set asks the hull to emerge from the data. Both become embedded planar graphs, but the bookkeeping variables have slightly different meanings.

Euler Ledger For A Point Set

T = 2n - 2 - h
E = 3n - 3 - h
Ledger. If a planar point-set triangulation has n vertices and h hull vertices, then it has T bounded triangular faces and E edges as shown.

The outside face is the quiet accounting partner. Including it turns the disk relation into the usual sphere-style Euler count.

Derive the formulas verbally from Euler rather than presenting them as magic. Each bounded triangular face contributes three incidences, hull edges appear once in the boundary correction, and the outside face is what keeps the accounting honest.

A Flip Is A Local Rewrite

Flip move. In a convex quadrilateral formed by two adjacent triangles, replace one diagonal by the other.
  • The vertex set does not change.
  • Only two triangles are replaced.
  • Repeated flips connect the triangulation space for a convex polygon.
Describe a flip as the smallest possible edit that still changes a triangulation. This is the move that lets algorithms improve a mesh locally and lets the theory discuss connectivity among all triangulations. Point out that all four vertices of the quadrilateral remain fixed, so the operation changes incidence data without changing the input set.

The Pentagon Already Contains The Associahedron

Convex pentagon. There are five triangulations, and a single flip moves from each one to two neighbors.
C_3 = 5

For larger convex polygons, the flip graph grows into the 1-skeleton of an associahedron.

Use the pentagon as the smallest nontrivial state space. Students can see every triangulation at once, every edge in the graph is a flip, and the cycle foreshadows the associahedron without requiring a high-dimensional picture.

Why Prefer One Triangulation?

Not all triangulations are equally useful. Some contain long, skinny triangles that behave poorly for interpolation, mesh quality, and numerical work.
  • Delaunay triangulations are selected by local circle tests.
  • The same structure is dual to Voronoi diagrams.
  • The criterion is metric, not just combinatorial.
This is the transition from counting all triangulations to choosing a useful one. The Delaunay criterion is introduced as a local geometric preference that tends to avoid poor angles and supports nearest-neighbor structure. Contrast the two drawings by asking which triangle would be more stable for interpolation, then connect that visual discomfort to a formal circle predicate.

The Empty-Circle Certificate

Delaunay condition. A triangle is locally certified when no other input point lies strictly inside its circumcircle.
p \notin \operatorname{int} C(abc)

Points on the circle create degeneracy; tiny perturbations may change which diagonal is selected.

Define the certificate in words before pointing at the formula. The circle is not decorative: it is the local predicate that a triangulation algorithm can check and repair with flips. Make the strict interior condition explicit, because points exactly on the circle indicate degeneracy and may allow more than one valid Delaunay triangulation.

Illegal Edges Are Fixed By Flips

Illegal diagonal. If the opposite point enters the circumcircle of a triangle, the shared diagonal fails the Delaunay test.
Repair. Flip the diagonal of the quadrilateral. The operation is local, so the algorithm can march through certificates.
Make the before-and-after interpretation explicit. A Delaunay algorithm does not need to rebuild the whole triangulation after every local failure; it can flip the offending diagonal and then recheck nearby certificates. The important teaching point is locality: only triangles adjacent to the changed edge need immediate attention after the repair.

Delaunay Has A Voronoi Shadow

Dual intuition. Nearby sites share a Delaunay edge when their Voronoi cells touch.
  • Voronoi asks: which site is nearest?
  • Delaunay asks: which sites should be connected?
  • The chapter prepares the next unit by making this duality visible.
Do not prove the duality here; use it as orientation for why Delaunay structures matter beyond mesh aesthetics. The next chapter will make the Voronoi side primary. For now, highlight the reciprocal questions: Voronoi cells record nearest-site regions, while Delaunay edges record which sites become neighbors through shared cell boundaries.

The MST Hides Inside Delaunay

Theorem orientation. Every Euclidean minimum spanning tree edge is a Delaunay edge.
Reason. If an edge has a closer separator point, the cut property can replace it with a shorter connection.

The Delaunay graph is sparse, but rich enough to contain a global optimum from the complete graph.

Stress the surprise: a global object computed from all pairwise distances is contained in a sparse geometric graph. This is a useful algorithmic theme, because Delaunay preprocessing can reduce the search space. Sketch the cut-property intuition: if an MST edge had an intervening closer point in the relevant lens, a shorter replacement would contradict minimality.

Pseudotriangulations Change The Cell Type

Pseudotriangle. A face may have curved-looking polygonal chains, but only three convex corners.
Pointedness. A vertex is pointed when some incident angle is larger than \pi.

The chapter’s point is not that every triangulation must be Delaunay; different tasks ask for different cells and ledgers.

Use this slide to broaden the word triangulation. Pseudotriangulations keep a triangle-like combinatorial role while allowing faces whose boundaries are chains, which is useful in motion and rigidity contexts. Name the three convex corners and the reflex chains separately so students see why the object is not an ordinary triangle drawn badly.

Compatibility Is A Shared Combinatorial Promise

Same diagonal pattern. Two different geometries can carry the same triangulation graph.
  • Compatibility supports morphing and interpolation.
  • The coordinates change; the incidence data is preserved.
  • The right invariant is combinatorial rather than metric.
Explain compatibility as a promise that corresponding vertices and diagonals match. This is a useful counterweight to Delaunay: sometimes the desired property is not an empty circle, but preservation of a shared combinatorial skeleton. The two shapes can have very different coordinates, yet the same diagonal pattern lets one compare, morph, or interpolate them consistently.

Takeaways

  • Triangulations convert geometry into finite graph data.
  • Euler counts certify size in planar point-set triangulations.
  • Flips turn triangulations into a connected state space.
  • Delaunay triangulations are certified by empty circumcircles.
  • Special triangulations remind us to choose the invariant for the task.
