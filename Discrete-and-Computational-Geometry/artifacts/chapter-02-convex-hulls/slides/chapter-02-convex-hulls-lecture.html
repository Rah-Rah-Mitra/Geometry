Convex Hull As All Weighted Averages

Definition
conv(S) = { sum lambda_i p_i : lambda_i >= 0, sum lambda_i = 1 }
  • Every sampled weighted average stays inside the filled triangle.
  • The hull of a larger set is obtained by letting the anchors range over all input points.
  • Extreme points are the anchors that cannot be written using the others.
Start with the two equivalent definitions. The intersection definition is useful for proving minimality, while the convex-combination definition is useful for computation and sampling. Ask students to identify which displayed points can have positive weight in a combination that lands near the middle of the blue region.

Support Lines Are Boundary Certificates

Certificate

A line supports a finite set when the whole set lies in one closed halfplane and at least one input point lies on the line.

LocalA single support line justifies one exposed edge or vertex.
GlobalA cyclic list of supported edges certifies the planar hull boundary.
The key teaching move here is to replace the vague phrase outside edge with a support-line certificate. A directed line supports the hull when all input points lie on one side and at least one hull point lies on the line. This is the local evidence used by gift wrapping and by tangent searches later in the lecture.

The Orientation Predicate

Signed Area Test
orient(a,b,c) = sign((b-a)_x(c-a)_y - (b-a)_y(c-a)_x)
  • Positive: the triple makes a left turn.
  • Negative: the triple makes a right turn.
  • Zero: the points are collinear, so tie rules matter.
Make the determinant feel like the primitive operation of the chapter. It is not just a formula; it is the orientation oracle that tells an algorithm whether a proposed boundary step is turning left, turning right, or becoming degenerate. Mention that robust implementations must decide how to handle nearly collinear triples.

Three Ways To Search For The Same Boundary

Incremental

Insert one point, find visible old edges, splice in a new boundary chain.

repair(hull, p)

Gift Wrapping

Rotate a support line around the set until the next extreme point is certified.

next = arg leftmost turn

Graham Scan

Sort by angle, then maintain a stack that contains no right turns.

while right_turn: pop()
This slide contrasts three search strategies without changing the mathematical invariant. Incremental construction repairs a hull after inserting a point, gift wrapping rotates a support line to find the next extreme point, and Graham scan sorts first so that a stack can delete concavities as soon as they appear.

Gift Wrapping: One Support Edge At A Time

Invariant

The current edge is supported: every input point lies to the same side of its directed line.

time: O(nh)

Each of the h hull vertices costs a scan over n candidate points.

For gift wrapping, stress output sensitivity. If the hull has h vertices, the method does roughly one full scan of all n points per hull vertex. That can be excellent for small h, but it becomes quadratic on inputs where most points lie on the boundary.

Graham Scan: Sort, Then Delete Concavities

Stack Invariant

After processing the angular prefix, the stack is the convex hull of the processed points in boundary order.

  • Choose a pivot with minimal vertical coordinate.
  • Sort remaining points by polar angle around the pivot.
  • Pop while the newest triple does not make the required turn.
For Graham scan, the sorting step buys a very simple invariant: after each iteration the stack is the convex hull of the processed prefix in angular order. The pop operation is not a heuristic; it removes a point that has just been certified as non-extreme by a wrong turn.

Incremental Hulls Repair A Visible Chain

Proof Roadmap

Old hull edges visible from the new point cannot remain boundary edges. The two transition vertices define tangents, and replacing the visible chain preserves convexity.

If the inserted point lies inside the old hull, no visible edge exists and the hull is unchanged.

Use this as a proof sketch rather than a code lecture. When the new point is outside, the visible chain is exactly the portion of the old boundary that cannot remain exposed. The two tangent vertices are the transition points between visible and hidden boundary edges.

Why Ordered Hull Output Has A Sorting Lower Bound

Model Statement

In a comparison model, cyclic hull output can encode sorted order. Therefore a general ordered hull algorithm needs Omega(n log n) comparisons in the worst case.

Lower bounds are about every algorithm in a model, not about a slow implementation.

The important distinction is model-based. A lower bound is not a complaint about a known algorithm; it says any comparison-based algorithm that outputs the hull in cyclic order can be forced to reveal enough information to sort. The reduction arrow means a fast hull solver would create a fast sorter.

Divide-And-Conquer: Merge Two Hulls By Tangents

Merge Principle

The outer boundary of the union is formed by two common tangents plus the two hull chains that face away from each other.

T(n) = 2T(n/2) + O(n)

With presorted input by x-coordinate, the recurrence gives O(n log n).

Divide-and-conquer is the constructive answer after the lower-bound discussion. Recursively solve left and right subsets, then replace the two facing chains by upper and lower common tangents. Point out that the difficult part of the merge is not drawing the bridge but proving when the bridge is supporting both hulls.

Tangent Finding Is A Local Walk

Endpoint Correction

If the candidate bridge is crossed by a neighboring hull edge, advance that endpoint around its hull until the line supports both sides.

  • Each correction is decided by an orientation sign.
  • Convexity prevents an endpoint from needing to cycle forever.
  • The same idea reappears in rotating calipers methods.
This slide turns tangent finding into a local walk. If the candidate bridge is not supporting one side, move the endpoint on that hull. The walk terminates because each correction advances around a convex polygon. The same orientation predicate remains the only geometric test.

In 3D, The Hull Boundary Is A Surface

Output Type Changes

Planar hull: cyclic vertex list. Spatial hull: vertices, edges, and oriented faces forming a closed polyhedral surface.

A facet is valid when its supporting plane has all input points on one side.

Use this slide to prevent a common misconception: the 3D hull is not a polygonal cycle with extra coordinates. Its boundary is a mesh of faces. The certificate changes from a cyclic vertex list to a set of oriented facets whose planes support all points.

Combinatorial Sanity Checks For Spatial Hulls

Euler Check
V - E + F = 2
Triangular Facets
3F = 2E

when every face is triangular and every edge is incident to two faces.

Euler's formula is a sanity check on the combinatorics of a convex polyhedron. It does not by itself prove the hull is correct, but it catches inconsistent face-edge-vertex bookkeeping. For triangular facets, the relation 3F = 2E is another useful check when every face is a triangle and every edge is shared by two faces.

What The Chapter Adds To The Toolkit

Geometric Evidence

  • Extreme points identify the boundary.
  • Support lines and planes justify exposure.
  • Orientation signs make the evidence computable.

Algorithmic Evidence

  • Upper bounds come from explicit strategies.
  • Lower bounds come from information forced in a model.
  • Spatial hulls require face-level bookkeeping.
Close the lecture by aligning all algorithms with the evidence they maintain. Extreme points answer what belongs on the boundary; support lines and planes answer why it is exposed; orientation predicates answer how we test it; complexity results answer how much information must be discovered.
